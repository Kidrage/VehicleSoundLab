# 1882基线上的算法优化 V3

输入是 VehicleSoundLab-main(1).zip，SHA256为8c244e839ece410ffd160e167c6800c5c444786d810a992f0c8443dcb2b8c2cd。不是上一次ZIP的简单重新打包。新代码保留了owner/event_runtime指针、单锚点缓存、L1 FIR段、快速幅值路径及模态振荡器精确旋转。

## 声线DNA

2048点立体声复数波表，默认每128个采样重建并交叉插值。原1882版使用32个采样更新；前一版方案为64。随机系数和主相位仍逐样本推进，波表的系数快照更新率降为375Hz，采用三次读表。`VSL_DNA_TABLE_HOP=64`可恢复更细更新率供听评对照。保留320阶上限、19.2–21.6kHz渐退。主声线仍有轻微调制平滑，不能声称与原版逐采样等价。波表重建工作区移入L2，避免在音频栈放约6.25KiB数组。

## 机械特征为何贵

原来每个采样调用da_motion_tick和机械模态链：推进机械转速/相位/供油包络；V10逐缸检查三类跨角度事件；按命中触发多模态分数采样敲击；计算模态与legacy金属载波。低输出音量不会省去这些计算。原始solo中该层相对整体混音的电能量：怠速约-44.3dB、高转约-53.1dB、事件工况约-51.9dB（对本次默认配方而言，不是所有配方的结论）。

默认统一DNA模式取消独立机械链，把1760/3100Hz附近的少量金属色彩固化为已有模态声线的系数权重。机械旋钮平滑控制该权重，不增添振荡器、事件扫描或滤波器。每64个采样按需更新现有系数。独立mechanical stem因此为零；合并后的色彩计入DNA声线及模态成本。它保留少量色彩，舍弃独立敲击、阀门瞬态与随机细节，属于有意音色取舍。`VSL_LEGACY_MECHANICAL=ON`可恢复原独立声源，届时性能与默认版不同。

## 相干低频

从原低频模型的各阶均值相位与协方差编译1024点立体声表，使用同一主DNA相位，保留转速支持区、尺度和18ms增益平滑。以`均值功率+方差`匹配detail=1时各阶长期平均功率，无需第二套低频随机协方差计算、每阶hypot和相位递推。当前模型7阶；表容量也覆盖允许的320阶而不发生频率折叠。该简化舍弃独立低频随机起伏，稳定低频不再跟随旧detail参数的随机深度；低频gain仍有效。这个特征变化应在events/穿越5625RPM时听评，不属于无损替换。

## 共振细节

原支持区为模型锚点的0.9–1.1倍，V10锚点46.875Hz，即5625RPM。范围外原输出虽为零，滤波/随机激励却持续运行。新版本暂停零权重的独立共振声源，重新进入时10ms淡入；保持同一输入相位，不另起转速时钟。随机流因此变化，但谱模型和全部滤波阶数保留。休眠路径逐样本处理，以保证不同块长重放一致，避免提前计算静音样本带来的分块依赖。快速过锚点和长时间离开后返回是板测/听评重点。原256点包络LUT保留，不把每实例大表挤进L1。

## 空气纹理

1882基线是从8192阶中选择能量最大的连续512阶窗口，并保留原延迟；本次离线设计明确以这个有效窗口的功率谱为目标。6路独立噪声不能直接相加FIR系数：改为按功率谱合成2路，低路6kHz并8倍插值、高路48kHz，每路512阶。加权谱误差约0.112dB；原L/R差异能量比约6.58e-14，可视为这组资产的单声道纹理。以上是滤波资产的谱误差，不是完整混音误差。滤波块64/FFT128，减少音频突发并采用ADI FFT入口；短FIR频谱和历史继续放L1 FIR段。完全关闭空气且80ms跟随衰减到很小时暂停空气滤波，打开时通过相同跟随器恢复。噪声激励改用32位xorshift和正态分位表，保留罕见尾部处理，随机序列会改变。

## 启动/怠速/加速

启动仍保留短时轮廓和稀疏移动模态核心，但其核心/残差分别使用统一DNA已经平滑、已经乘以工况系数的line/air参数。air=0会同步关闭启动残差；启动不再绕过该参数。启动期间始终保留少量持续运转的驾驶声线，并将前景向背景的等功率交接从最后1/3扩展为最后58%，减小晚交接的突兀感。持续声线不因启动而重启相位。启动不再计算当前零权重的第三组噪声阶段。

怠速指纹与主声线改为等功率混合，空气纹理使用自身的独立混合权重；保留80ms状态/旋钮跟随，改善线性混合的能量低谷。等功率不能自动校准所有谱形和相位相关性，所以仍要听评全流程。所有驾驶状态、RPM、换挡和事件时序由原200Hz驾驶控制器决定，验证中A/B轨迹一致。

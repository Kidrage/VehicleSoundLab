# 固定 V10 内存版：板端接入

本次是固定单音色、单实例、干声量产配置。PC 保守链接预算为 597,314 B，含全部只读非代码段、64 KiB 栈和 2 KiB 输出；不是 ADI 实测认证。详细结果见 [内存报告](validation/memory-20261120.md)。

1. 从本目录完整源码接入，不能只拷几个新 C 却保留旧多 MiB 池。所有受结构变化影响的编译单元必须全量重编译，禁止混用旧库或旧头文件。
2. 沿用原 ADI 48 kHz / 256 帧、FP32、`-double-size-32`、优化等级与 FFT/fast_math 设置。所有相关单元统一定义 `VSL_FIXED_V10`、`VSL_DSP_STATIC`、`VSL_DSP_APPROX`、`VSL_DSP_FIR_TAPS=512`、`VSL_DSP_FAST_TRIG`、`VSL_ADSP_21569`，DNA hop 仍为 128。强制包含 `modules/dsp_support/fast_math.h` 的方式沿用原工程。fixed 不兼容 `VSL_LEGACY_MECHANICAL`，也不支持外部多锚点/多状态资产。
3. 加入 `embedded/fixed_assets.c`，include 根增加工程根。它只依赖已生成 C 系数，不需要运行时读 `voices` 文件。移除旧板适配层的资产 RAM 副本、模型初始化池、交叉检查快照、MCPS 大记录数组；离线模型加载器、作者工具、测试 EXE 不属于量产入口。未引用的通用函数及数据需按目标工具链正确剔除，map 中确认旧池没有残留。
4. 可将 `experiments/vehicle_source_v1/bridge.c` 作为普通 C 包装层一起编译（无需 Windows 渲染工具）；`vsl_source_open(0)` 获取唯一音色实例，返回 NULL 时停止初始化，勿继续 process。`vsl_source_process(h, stereo, NULL, 256)` 输出量产立体声。不要再用原 `cd_models_load` 路径复制资产。若坚持 native API，使用 `vsl_fixed_assets_acquire` / `vsl_fixed_initial`，并保持桥接内相同的统一 DNA、启动 flare 和控制初始化次序。
5. 外部接口最大 1024 帧，内部 64 帧拆分；600,000 B 表内输出按 256 帧计算。量产 packed 参数传 NULL；额外导出 23 声道会再占 23,552 B（256 帧），需另行预算。空间/IR 和 legacy 通用渲染明确拒绝；catalog 仅 0，自定义 DNA / 多状态导入拒绝。多实例会显式失败，初始化/销毁由调用方串行执行且不放在音频 ISR。
6. 保留现有 `seg_vsl_l1_state` / `seg_vsl_l1_voice` / `seg_vsl_l1_fir` / `seg_vsl_l2_history` LDF 映射；fixed 引擎已放 L2。DNA 波表 112,904 B、热缓存 15,376 B、FIR 池等已包含在 PC 总数，不可再重复相加。只读系数即使放 RAM 也要统计，不能仅以 BSS 当总 RAM。代码、芯片缓存按用户口径另列；RTOS/DMA/驱动缓存注明整机额外占用。
7. 链接后导出 CCES map，按地址区间去重统计算法可写段、驻留 RAM 的只读段、初始化临时段与栈。确认旧加载池、多状态池、测试快照和性能记录均消失。当前 PC 对严格 600,000 B 仅余 2,686 B，目标链接对齐或 ABI 差异可能改变结论。
8. 用栈填充哨兵/目标调试器测启动、四声部事件、高转、重启的高水位。64 KiB 是保守预留，不是已测峰值；初始化明显局部数组约 5 KiB，完整调用链还需实测。不能把整个堆或栈预留段当作未统计的公共资源。
9. 最终以关闭 `VSL_PROFILE` / `VSL_CAPTURE_MODULES` 的实际出声版测 MCPS 和欠载。沿用原流程的启动、怠速、全转速、共振支持区、换挡、收油、制动、重启以及 air/line 改参场景。1174.11 MCPS 属于上一版，不能直接标为本次内存版的结果。

桌面 `02_PC验证` 的 DLL/EXE/map 仅为 PC 复验物，不能烧入 ADI。保留原 03 工程和 05 App；本包没有覆盖旧 App 或启动其他用户窗口。

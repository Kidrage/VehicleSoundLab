# 事件完整区间与四频段包络 V1

2026-11-17。事件工作台现在能从四个频段分别提取能量随时间的变化，导出当前 C 已支持的控制点。此前的自动提取主要覆盖高频，低中频容易只剩一段规则衰减。**工具、C 和整车触发链已核查；这不表示新候选的整段音色已改善或已确认为回火。**

## 使用

事件页导入单一动作片段，手动选择完整动作及邻近背景，勾选源响应校准和多段包络，选择“包含低中频：提取四频段时间变化”。工具分别判断60–300、300–1200、1200–4500、4500–14000 Hz是否比背景高3 dB；只有可靠频段提取最多8个控制点，其余保留局部包络。参数可继续编辑、历史恢复及导出C／CSV／JSON／ZIP。

提取采用固定与自适应两种控制点布局，各做两轮时间形状／频谱校准；保留原六频谱门槛和可靠频段的时间形状不退化要求。此项是离线音色设计，不增加 C 声源组件或新的运行时算法。旧V2／V3参数可精确复现。

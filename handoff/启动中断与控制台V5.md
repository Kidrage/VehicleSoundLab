# 启动中断与控制台 V5

2026-11-16。本轮完善启动／停机控制，不重新设计音色，不做算力优化或空间渲染。前一目标轮仅确认生成侧算力边界，没有实现进展；本轮包含实际 C 修复、负例复现、正常音色对照和独立窗口验证。完整目标仍未完成。

## 行为与修改

原 V4 在接火过程中关闭点火，接火事件仍会播放自然尾音。使用现有 A 候选、衰减 4×，0 秒启动、0.45 秒关闭点火，驾驶器在 1 秒进入 OFF，事件却延续到 3.48 秒。

`modules/event_control/policy.c` 增加停机处理：进入 STOPPING 时先取消所有非 STOP 类型的待执行自动启动，再给可用类型发送 20 ms 淡出。原拖转退出的 18 ms 释放仍保留。独立 STOP 事件可以自然衰减；在 OFF 中主动单次试听仍能完整播放。前述接火事件现在于 0.47 秒结束，OFF 后事件分轨为零。

取消和释放分为两个循环。第一版把它们按类型交错处理；队列被后序类型的自动事件填满时，前序类型的释放会溢出。`queue-regression1` 的测试失败留存，最终测试覆盖满队列自动事件的取消和全部释放，不为退出额外增加声部或队列容量。

| 位置 | 职责 |
|---|---|
| `modules/event_control/policy.c` | 生命周期边沿与自动事件取消／释放，不含合成或第二套驾驶器 |
| `modules/event_control/scheduler.c` | 原有固定 16 项帧调度；实现不变 |
| `modules/event_synth` | 原有 4 声部 OSC／程序激励／共振／包络；合成实现不变 |
| `experiments/event_synth_v1/control_checks.c` | 停机、待发拖转／换挡／回火、满自动队列、OFF 试听回归 |
| `tools/vehicle_controller/native.py` | 默认使用 V5；可显式选择保留的旧 DLL 做对照 |
| `tools/vehicle_controller/ui.py`、`tools/sound_designer/controller.py` | V5 独立窗口及工作台启动目标 |
| `tools/startup_response_evidence_v1.py` | 为核查保存确切源文件与采用的 DLL 路径／哈希 |

UI 在 STOPPING 期间记住“再次启动”意图，观察到 OFF 后发送新的启动沿。原生 C 不负责排队这个按钮意图；直接调用 C 的客户端必须在 OFF 后发出新的 `start_id`。没有新增生命周期或重新设定 RPM 曲线。

## 对照与复现

- `baseline1` 是原 V4 缺陷复现，`--expect tail` 通过只表示观察到缺陷。
- `fixed3`、`regression3`、`ui3`、`stop-fixture2`、`cycle2` 对应最终 V5。12 预设分别开启／关闭事件的 24 个正常案例，混音、23 原生通道、状态和事件通知与原 V4 完全一致。
- 中断覆盖 0.15 秒、0.45 秒及非块边界帧 21733；持续声分轨及中断前全部分轨保持。变块回放、OFF 单次试听、两次启动与停机检查通过。
- 独立窗口核查是限时、静音、实际 Tk／WinMM，两次接火取消和待发重启，保存实际通知并回放；无短测欠载、拒绝、队列溢出或日志丢失。窗口仅关闭自身。
- `stop-fixture2` 是测试专用停机音，不加入声源库；它证明停机末响可跨过 OFF 自然结束，不宣称已做好真实停机音色。
- 最终 32 秒全流程与上一交付 V4 的混音、全部原生分轨逐样本对照；仍包含启动、怠速、加速、收油、制动和停机。事件音色和实车标定没有因此新增认可。

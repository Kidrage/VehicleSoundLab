# 事件多次触发联合提参 V1

2026-11-17。新增可选离线校准：原方法只对一次程序激励校准，换随机种子后，短事件的有限时长频谱可能明显漂移。新方法共同拟合4次激励，再用另外4次独立检查。运行时仍使用现有 `event_synth` 正弦模态＋程序噪声共振核；C、ABI、正式音色与驾驶窗口V13保持。

## 使用

工作台“独立事件”→导入含事件与背景的单状态音频→填写选区→勾选“校准频谱响应”→选“多次触发：稳定声音频谱”→提参→生成C试听。继续支持编辑、历史、JSON／CSV／C参数／ZIP导出及不含原录音的参数工程导入。新选项已在独占临时工作台实际验证；未重启用户现有常驻服务，旧进程的后端需用户正常关闭重开才能加载新Python代码。

明确任务为 `vsl.event-authoring-job/11`，示例见 `examples/event_authoring/A_catch_ensemble.job.json`。支持8毫秒–5秒全频事件、普通起落包络；长拖转可门控，短于60毫秒禁止门控。当前不与长窗分频起音／多段包络自动拟合组合，也没有替换已有车外启动的多段包络方案。

提参失败保留当前参数、试听及拒绝结果；不会固定运行时随机种子。4次独立检查只说明这4次通过，不保证任意种子的最坏结果。

## 方法和模块

| 入口 | 职责 |
|---|---|
| `tools/event_authoring/response_ensemble.py` | 每种子有限波形Gram、非负幅度联合拟合、高切训练选择、独立种子检查 |
| `tools/author_event.py` | job11边界校验、成功／拒绝报告，不改变旧方法 |
| `tools/event_designer/workspace.py` | 项目、历史、失败保留、实际C与参数包 |
| `tools/sound_designer/web/events.*` | 方法选择、互斥状态、结果读数 |
| `modules/event_synth` | 原C运行时，接收同一参数结构，无原录音／房间／空间处理 |

频率、相位、包络不变，只校准已有最多12个模态＋4个噪声频带的幅度。固定比较0／4／6／8／10／14kHz噪声高切，仅按训练结果选择，再检查独立种子，不根据独立结果重试。沿用原六频带门槛：显著目标±3dB，弱目标使用原上限。全部8次通过才编译参数；否则只保留分析。

## 实际结果

同源选区、背景、8组种子与0.25监听增益，48条实际C逐一核查：

| 素材 | 原单次校准 | 新共同校准 |
|---|---:|---:|
| A旧座舱启动早期470ms | 8/8 | 8/8 |
| A旧座舱接火800ms | 8/8 | 8/8 |
| B排名6的16ms短声 | 4/8 | 8/8 |
| B排名3的16ms短声 | 仍不合格 | 拒绝并保留旧参数 |

A两段用于通用方法验证，并非当前车外启动替换。B短声尚未确认真实动作，未晋升正式回火库。另将原固定六处B候选统一扩大到峰前20至后180毫秒、固定前后背景，六处均未同时达到两侧3dB；本轮补存这次先于计划发生的探索证据，不称为预先声明实验，不再挑换其他B窗口。

试听：[9条原声／单次／共同校准对照](http://127.0.0.1:8789/references/analysis/event_ensemble_v1/review3/review/index.html)。频谱稳定不是机械自然度或完整动作还原；本轮无新增听感认可。

# 回火压力脉冲 V3

2026-11-18。用户听评V2“清脆、不够impulse、不够爆破”；V2没有通过音色验收。本轮只替换默认回火配方，继续使用同一个App V20、v17 C库和原收油音量修复。

旧版两个随机纹理频带盖过短OSC声体。8次同控制、同请求序列的独立回火中，3–10kHz占所测四频带总能量约40.6%，250–1200Hz约18.9%。这些是生成器输出指标；原视频的混合车声不能直接当作独立回火频谱真值。

## 改法

- 3个OSC共同形成短促声体：175／410／975Hz，起始相位均π/2，衰减时间常数7.5／3.2／2ms。低中频声体前移，随后快速反向和衰减；不再让长的低频音符承担爆破感。
- 两个宽纹理频带改为650／2200Hz，高频频带幅度从1.9降到0.7、衰减缩到2.8ms，保留短裂响而减少清脆砂响。没有增加低通、额外滤波器或非线性削波。
- 每声占槽时长115→100ms。原6–10声、不规则间隔、逐声强弱／音高／时长变化不变；不靠增加次数或总音量伪装爆破感。
- 8次独立事件的整组RMS与V2匹配，误差小于0.001dB；通过设置同一个配方level完成，交付音频没有额外归一化。不同实例的RMS和峰值仍可不同，整组匹配不等于逐声匹配。

最终配方：`presets/events/reference_afterfire_G_v3.json`与同参数`.h`。频率、相位和衰减仍是**工程设计选择**，没有声称从混合录音辨识出真实压力波、排气管模态或冲击波传播模型。

## 对照与边界

| 指标 | V2 | 压力V3 |
|---|---:|---:|
| 8次独奏的250–1200Hz能量占比 | 18.9% | 33.3% |
| 8次独奏的3–10kHz能量占比 | 40.6% | 19.2% |
| 相同单声样例：前5ms能量占比 | 66.2% | 78.1% |
| 同一样例：90%能量到达时间 | 13.56ms | 8.13ms |
| 同一样例：峰均比 | 21.52dB | 21.39dB |

起音能量更集中、声体更靠低中频；**峰均比没有提高**，不能把这次改动描述为实测峰值／crest更大。较厚的另一候选因低频占比约76%、尾声更长而没有选入默认，仍保留作研究。是否更像排气爆破等待用户听评。

复查G视频已审核的153、155、157及444–449.6秒上下文，保存声学突发候选供核查。多车、风噪、传播、录音环境仍混合；候选峰不是逐样本物理回火标注。视频声明的SVJ V12改装排气风格与V10 DNA继续分档。

## 算力与验证

生产DLL **完全未改**，仍SHA256 `7fdda41236a97e6ec6c0833b8d0d7e608e095786ef6e525a4110d9782d5535f6`。每活动声部仍3OSC＋2频带、同一条内核路径，4并发声部、16命令队列；没有增加轮询器、随机调制、轮廓、空间或常驻模块。事件时长缩短，未增加每声的活跃采样数。这里说明的是结构与计算路径，没有重新测出严格零周期或ADI峰值保证。

- 新C参数表实际编译并通过既有收油／参数有效性检查。当前8项C基线来自V20；本轮生产C核未变，只重跑受参数表影响的一项。
- 36秒流程的19个连续通道逐样本相同；前19秒总混音、驾驶轨迹、主gain相同，事件触发时间与声部槽相同。
- 手动7声、正常峰值2声部；最密12声峰值4声部、队列溢出0。完整流程峰值0.350FS。
- 217／480分块、313帧回放精确一致。旧V20行程仍保存并使用原V2参数；历史V20验证工具显式绑定V2，避免默认配方更新后改变其含义。
- 真实Tk／WinMM静音检查：手动、自动快速收油、行程回放各7声，峰值2声部、供声中断／队列溢出0，截图已检查。`ui1`的脚本在回放线程结束但Tk尚未刷新按钮的40ms窗口点击了仍禁用的启动按钮，未能启动下一场景；脚本改为等待界面退出回放后，`ui2`通过，未修改生产控制逻辑。

主App“独立事件”页点“回火连发试听”，配方名应显示“G风格回火V3·压力爆破”。事件纹理控制主要改变裂响／随机空气量，音高与时长作用于同组声体；先用默认值判断，避免把时长拉得过长重新变成音符。旧窗口可导入新的V3 JSON，不需更换声源DLL。界面标题增加“回火压力V3”便于识别。

# 启动多段包络与控制台 V12

2026-11-17。增加可选的中高频多段包络，已接入 C 事件核、自动提参、工作台编辑及独立控制台。新候选待听评；原89份正式声源和认可行驶音色保持。本轮未开展ADI优化或空间渲染。

## 算法与模块

上轮中频渐起已改善，但单次起音加指数衰减无法表达录音的高频首响、低谷和再次建立。本版用粗粒度幅度控制点描述这些变化，仍由原正弦模态和程序噪声共振持续计算，不读取录音波形。

`EsProfile.contours`最多4组，各2–8个线性插值控制点。按成分的**原始中心频率**分组，区间左闭右开；变调、扫频时不换组。组内包络替代成分各自的起音和衰减，总起音、自然结束淡出和提前释放继续生效。控制点时间除以触发的`decay`倍率，末点后保持。未配置包络时保留旧计算路径。

| 文件 | 职责 |
|---|---|
| `modules/event_synth/contour.c` | 分组选择、连续包络插值 |
| `modules/event_synth/{api.h,profile.c,voice.c}` | 有界参数、校验、逐成分应用；保留相位和随机时钟 |
| `tools/event_authoring/contour_fit.py` | 从固定事件／背景提取两组粗包络 |
| `tools/event_authoring/{contract,model,export}.py` | 新旧布局、独立合成模型、C参数导出 |
| `tools/sound_designer/web/event_contours.js` | 独立包络编辑组件；增删、范围与控制点 |
| `event_designer/workspace.py`、`vehicle_controller` | 历史、导出、同一C事件池与配方／行程 |

提参方法`band-contour-v1`先沿用分频起音和有限响应校准，再拟合1.2–4.5／4.5–14 kHz两组各8点幅度，最后重新校准所有成分电平并执行原六频带门槛。2048帧周期Hann／240帧步长，左右功率均值，扣附近固定背景功率后截正；至少16帧观察。它提取的是录音的声学时间结构，不是独立发动机部件或实测RPM。

作者桥接ABI4／1408字节Profile，独立声源ABI11／默认`build-vehicle-source-v12`。旧696／704／800字节布局和二进制保留，旧ABI拒绝新包络；配方7／行程8仍按二进制身份严格校验。

## 使用

[实际C对照页](http://127.0.0.1:8789/references/analysis/startup_contour_v1/review2/index.html)：原素材、上轮／本轮接火和8秒完整启动各自对照。一个播放器、统一额外−12dB，无逐条归一化、房间或限幅。

工作台“独立事件”导入带背景的单次动作，指定选区，依次勾选“校准频谱响应”“按频带提取起音”“提取高频多段包络”。展开“多段包络”可改频段、控制点时间和增益；首点固定0秒，频段不能重叠。调高首点强调首响，降低中间点强调低谷，末段增益控制后续建立。生成后可导出JSON／CSV／C头文件、恢复历史，再在停止监听的独立V12窗口载入。

试听页的V12整车配方与确定性行程可直接下载。完整示范仍由A车外持续DNA＋F2怠速＋A车内启动组成，0.58秒拖转及220→1150→850 RPM是工程控制，不是同视角实车复刻。常驻服务未重启；已另存本地可编辑工程，路径见总验证记录。

## 验证与未完成事项

固定A接火37.22–38.02秒、背景35–36.2秒。四种子实际C的归一化功率曲线RMSE：1.2–4.5 kHz由0.962–1.008降至0.172–0.210，4.5–14 kHz由1.049–1.068降至0.515–0.615。独立逐帧rFFT同时复核原六频带频谱门槛，四种子均通过。这些结果不代替听感验收。

33组旧作者输出精确一致；12组新包络的门控／变调／时长／高切模型与实际C一致。V11和V12不带新包络的23通道启动精确一致；新候选仅事件音频改变，19条持续通道、状态、通知和变块重放保持。作者3项、声源6项C检查通过。实际浏览器完成提取、编辑、非法时间拒绝、历史恢复、四组／八点上限及导出；C头文件实际编译，数值一致。自有静音独立窗口两次8秒回放0欠载，测试窗口已关闭。

跨素材试验保留了一个明确失败：B持续启动片段在新包络后1.2–4.5 kHz误差约−6.37dB，工具按原门槛拒绝编译，旧B门控候选保持。当前不能宣称该提参方法已对所有启动片段有效。原版分频起音提参参数回归精确一致。

一个种子的原电平浮点峰值约1.032FS，原样保留并报告；统一−12dB试听未削波。生产增益需后续整体设定，未暗加限幅或逐条补偿。高频细微机械质感、B门控包络与频谱联合拟合、怠速变化、确认的全频回火及其他事件／RPM负载覆盖仍未完成。

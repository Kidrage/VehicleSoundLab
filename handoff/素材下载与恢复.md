# 下载与恢复完整素材

完整素材和开发证据放在 [handoff-2026-11-11 Release](https://github.com/Kidrage/VehicleSoundLab/releases/tag/handoff-2026-11-11) 的附件中。

已发布 24 个附件，共 19,389,160,812 字节（约 19.39 GB）。全部附件的大小和 GitHub 服务器 SHA-256 均与本地清单一致，见[上传校验记录](release-upload-verification.json)。另已在不带登录凭据的情况下下载清单和恢复脚本并核对哈希，见[公开下载核验](public-download-verification.json)。

## 下载

使用 GitHub CLI 下载全部附件到独立目录：

    gh release download handoff-2026-11-11 --repo Kidrage/VehicleSoundLab --dir release-assets
    cd release-assets

也可在 Release 页面手动下载。总量约 19.39 GB。分包后缀是 .zip.part01、.zip.part02，合并时同时需要两部分。

## 校验与合并

安装 Python 3.11+，在附件目录运行：

    python Restore-Release.py .

程序逐件核对分包 SHA-256，验证合并后的完整 ZIP 哈希，再生成原始 ZIP。只验证而不生成合并文件：

    python Restore-Release.py . --verify-only

## 恢复工程

选择一个新的空工程目录。先恢复可运行系统、历史版本和素材：

    python Restore-Handoff.py E:\VSL-Work .\01-system.zip .\02-history.zip .\03-references.zip

需要全部渲染和历史分析依赖时：

    python Restore-Handoff.py E:\VSL-Work .\04-renders-01.zip .\04-renders-02.zip .\04-renders-03.zip .\04-renders-04.zip .\05-analysis-dependencies.zip

恢复器保留不同内容的现有文件并报出冲突，因此请将旧版证据恢复到单独目录。Git 源码和冻结交接包各自维护入口说明。

03-references.zip 含 A/B/D/E 的原始素材、清洗音轨与分析结果。02-history.zip 含 48 个冻结版本。04-renders-* 含试听、录制和分轨；05-analysis-dependencies.zip 含离线分析依赖。原始交付清单和每个附件的 SHA-256 都随 Release 提供。

# ADI 21569 算力估算 V7

2026-11-15，代码基点 `47cdce6`。**已运行 C 的优化后规划上沿仍约 800 MCPS；最新幅度条件相位研究候选按当前逐采样结构，单锚点另估约 2300–4200 MCPS。** 不能把两者理解成同一个版本，也不能相加。

条件：48 kHz、双声道、单车、一次一个配方，21569 核心按 1 GHz 工作。假设已采用 FP32、SIMD、块处理、预计算、融合数学查表与内存布局优化，保留当前分音数量、12 因子与时间规律。**全部周期系数都是未经目标实测的工程假设；没有 CCES 优化内核、反汇编核查或板上最长块测量，尚未证明最低成本或真实最大周期。**

本轮逐一核对六份冻结声源及 1728 份条件映射：每份声源 288 分音、双声道、12 因子；每个分音有 32 个幅度乘积节点、40–42 个相位区间。旧 V6 绑定的源文件和参数 SHA256 全部一致，因此原 C 估算没有上调。

最新候选保留原幅度／共同相位流，另用独立随机流生成相对相位的均匀变量。按待实现的目标内核，只投影主流的 864 个必要特征和独立流的 288 个必要特征；两个完整随机／AR 状态流仍计费。每秒操作量为：

- 投影：`48000 × 1152 × 12 = 663,552,000` 标量 MAC。
- 条件相位映射：`48000 × 288 = 13,824,000` 次。
- 双声道分音处理：同为每秒 13,824,000 次。

MAC/s 与 MCPS 不等价。周期成本包括有效吞吐、寻址、读写和调度假设，不能用芯片浮点运算峰值直接相除。

条件查询没有按 Python 的方式逐采样构造完整 CDF 行。估算采用两行按需取值：幅度节点二分最多 6 次，相位区间二分最多 6 次；只插值查询需要的 CDF 边界，节点宽度倒数预计算。71–124 周期分解为：幅度乘积／缩放 2–4、节点搜索 `6×(2–4)`、权重与边界 5–8、插值 CDF 搜索 `6×(6–10)`、最终边界及逆插值 16–28。它是目标内核的成本假设，不是已验证汇编或测量。

只选一个条件 CDF，连同保留的完整原声源数值参数与节点预计算，FP32 数据约 **1.84–1.92 MiB／锚点**；未计运行状态、代码、栈、DMA 和音频缓冲。存储层级及随机查表延迟可能突破假设区间。相位映射仍存在陡峭尾部，纯 FP32、CDF 融合或二维逆查表的误差尚待资格验证，不能把小表近似的节省直接记入预算。

离线的五组对照、三个条件映射和六个素材模型均为备选，不同时运行。LP 求解、证书、Hann 分析器和诊断统计只用于离线研究，未计入车端。

按 1 GHz，核心每秒只有 1000 MCPS 的周期预算；SIMD 提高每周期运算数，不会把核心周期预算翻倍。当前 C 沿用 800 MCPS 规划、900 MCPS 分配额；900 已占核心周期 90%，不能代替其他业务和中断余量验收。240 帧／48 kHz 为 5 ms，共 500 万周期：现有 C 规划约 400 万周期，最新条件候选估约 **1167–2083 万周期／块**。后者在本成本模型内明显超出单核预算，但该估算不是“任何进一步优化都不可能运行”的下界证明。

现有 C 的落地重点是 SIMD 分音／模长内核、低频统计更新及存储安排。最新研究方案需要先做独立的投影和条件映射目标原型；若成本仍高，再研究经数值与听感验证的表示重构。降低调制采样率、缩减分音／因子或量化尾部均属于算法变化，不能冒充同一算法的无损优化。

基础 12 通道路由沿用 V6 的额外 10–30 MCPS 假设，声源只生成一次。完整 7.1.4 IR／HRTF／BRIR、同时多车、PC UI、离线拟合和其他产品业务未包含。最终按 CCES 发布构建，测各状态、锚点边界、统计更新／FFT 同块和存储争用时的最长块周期；PC 耗时不换算为 SHARC 周期。

# 当前代码阅读入口

本次代码基点为 `6125782`，分支为 `research/coherent-low-v1`。当前系统已有统一 C 驾驶窗口、分层监听和自包含行程录放。先读下面的主链，再按需查看研究记录。

## 编译和体验

Windows 上安装 Visual Studio 2022 的 C++ 桌面开发工具与 CMake，然后在仓库根目录执行：

```powershell
.\Build-Voice-Catalog.ps1
.\Launch-Voice-Catalog.cmd
```

构建脚本编译并运行测试；窗口默认停止、未点火。转速台架可独立调整 RPM 与正负负载，驾驶模式使用油门和制动；两种模式共用同一驾驶器。音色菜单、分层单听和行程录放在同一窗口。

## 读代码时区分这几件事

- 当前目录是七个 V10 观察／配方情境加两个解析示例，不是九款实车。A车外、E车内和F2尾排分档维护。
- 新 Sound DNA 使用 `modules/sound_dna` 等模块；旧 `src/core/dna.c` 和 `.dna` 是历史声源契约。当前主链复用驾驶器，不叠加两套旧新 DNA。
- 已认可的固定行驶35%配方与相干低频保留。用户最新对整体模拟效果给出正面评价；减速版“左右改善、音色仍电子”和怠速“节奏太规整”仍是具体改进项。
- [怠速联合起伏候选](../research/怠速优化当前状态.md)仍是独立离线试验，未获得单独听评，未自动接入 C。负载轴可操作不等于已完成同 RPM 不同负载的实车声纹标定。
- 设备监听为 Stereo；12通道数值／文件链已布局，实际7.1.4听评仍待完成。严格行程身份不同的旧录制使用各自冻结播放器。

当前代码最近一次验证见[台架负载摘要](../research/bench_load_ui_v1_summary.json)：66项CTest、442项原生静音检查及既有音轨／录放一致性检查。此次交接仅整理说明和听评，没有重新修改 DSP，也没有重复运行这些测试。

原始素材、大型试听和冻结二进制保留既有本地／Release交付方式；仓库中的 `127.0.0.1` 试听链接依赖原本地数据目录及服务。代码、运行参数、构建脚本和作者编写的研究文档在本分支中。

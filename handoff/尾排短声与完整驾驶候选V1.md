# 尾排短声与完整驾驶候选 V1

2026-11-16。把已批准的 E 素材中一条尾排短声提成可编辑参数，并通过现有 C 驾驶器接入自动收油。它是 **1.2–14 kHz 的局部候选**，尚未听评，也没有确证物理回火身份；没有替换正式事件库或认可的行驶声线。

## 素材与提参边界

E 视频 8–20秒的逐0.5秒帧显示驻车车外尾部补油。原始事件区间13.285–13.385秒，采样峰13.309145833秒；此前的谐波声线正在下降，有短暂宽频激励及衰减尾部。画面与声音支持尾排声学候选，不能代替点火／燃油／真实RPM遥测。

| 同一事件，背景区间 | 全频事件／背景 | 1.2–14 kHz事件／背景 |
|---|---:|---:|
| 事件前背景12.96–13.16秒 | +1.241 dB | +11.079 dB |
| 事件后背景13.47–13.67秒 | +10.033 dB | +19.010 dB |

背景随发动机回落明显变化，不能只挑较安静的后背景来通过全频3 dB门槛。本候选固定前背景，只拟合声明频带内的统计增量。12个阻尼正弦模态＋2个程序噪声SOS；运行时没有录音播放或房间处理。它没有还原低频冲击，也没有从混合录音物理分离排气。

单次 C 按事件裁剪起点放置；原片的明显瞬态峰在裁剪起点约24ms后。当前比较没有声称波形／起音精确对齐。平均频带功率接近也不证明起音、尾音或自然度还原。

## 模块与可复现入口

| 模块 | 责任 |
|---|---|
| `tools/event_authoring/context.py`＋`tools/probe_event_context.py` | 同一事件的前后背景并列检查、原始上下文图、采样／源码来源记录；不自动选背景或生成事件 |
| `tools/author_event.py`＋`event_authoring/{measure,fit,scoped_fit}.py` | 声学测量、限定频带准入及参数拟合／实际有限波形功率校准 |
| `tools/event_designer` | 编辑工程、历史、参数导入导出和实际 C 单次试听 |
| `modules/event_control/{policy,scheduler}.c` | 观察唯一驾驶器，收油资格与帧级触发／取消 |
| `modules/event_synth/{oscillator,excitation,envelope,voice,pool}.c` | 纯合成与四声部生命周期，不负责驾驶或空间渲染 |
| `modules/vehicle_source/{events,source,stems}.c` | 同一48kHz时钟接入、事件覆盖和原生分轨／实例通知 |
| `tools/vehicle_controller/events.py` | 独立窗口导入、宏参数、单次试听及“频带局部／类型未确认”说明 |

从仓库根目录运行（Python需NumPy／SciPy／SoundFile／Matplotlib）：

```powershell
python tools/probe_event_context.py examples/event_authoring/E_exhaust_return_band.job.json --context 12.6 14 --after 13.47 13.67 --output E:/VehicleSoundLab/references/analysis/exhaust_return_v1/context-new
```

输出为原始上下文、两种背景测量及源码绑定；没有清洗、拟合、自动标注回火或修改音色库。拟合任务在 `examples/event_authoring/E_exhaust_return_band.job.json`；完整驾驶演示由 `tools/build_exhaust_return_cycle_v1.py` 构建，复用原 `vehicle_scenarios` 和实际 C 入口。

## 验证与剩余工作

四个固定种子实际 C 对独立Python误差≤3.73e−9 FS，所选显著频带功率误差最大约0.865 dB；不外推所有种子和听感。8秒启停／补油演示中两次收油触发四次短声；事件电平0／100%时非事件分轨完全一致，混音差值由事件轨重建，误差≤3.73e−9 FS。

32秒流程包含一次A启动纹理、一次A接火和一次E尾排短声，9次驾驶换挡、一次收油；28秒稳定850 RPM／停车怠速，最后OFF／0 RPM／尾部静音。不同分块的PCM、通知和最终状态完全一致，事件池峰值2，无拒绝／溢出／日志丢失。实际限时静音Tk／WinMM窗口8秒回放与行程导入导出通过、0欠载；仅证明该短测，不是长期硬实时或ADI算力资格。

新增HTTP浏览器核查真实发现原音频URL无法seek；新页面改为缓存Blob，HTTP／本地文件的跳转、播放中切轨、音量、快速切换及手机布局通过。原cycle-web1失败保留；cycle-web2验证器未等待新音轨真正采用，已补上来源与就绪检查，cycle-web3通过。背景检查初版验证器受Windows默认GBK读取影响失败，显式UTF-8后的context-check2通过；原值、反相双声道功率与已知增益均复核。

当前V4 C DLL、正式事件库与89个声源文件保持原字节。本轮没有改实时DSP、做算力优化、空间处理、新下载或推送。正式库仍只有未听评A启动／接火，E仅为本工程显式覆盖；完整回火低频、启动声纹验收和其他事件素材仍需继续。此前更新常驻进程的自动审批返回“blocked by policy”，本轮未重试或绕过，只运行并关闭自身限时测试窗口。

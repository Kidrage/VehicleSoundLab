## 改了什么

回查批准 A 车外 **47–56秒完整上下文**：旧选段47.60–48.18秒遗漏了此前两次短促动作，也没有覆盖接火后直到约49.4秒的完整弯曲、回落。新增47.28–47.60秒前置动作和48.18–49.65秒接火声学选段，保留原拖转选择与历次失败记录。声学选段不等于已物理分离的起动机／排气，也不能从某根谱峰直接推断真实 RPM。

启动前景改为三段纯程序声源：前置动作12组、拖转40组、接火48组有限时长移动 OSC，各自配三组**剩余部分**的细谱随机激励。每组 OSC 存起点、长度、初频、扫频率、左右幅度／初相；残余模型存激励滤波器谱色。没有录音 PCM、逐采样包络或逐帧相位表。接火48组在同一选段的归一化波形投影解释率约59.5%，只说明这一表示的同片段容量，不是自然度或物理声源占比。

新增连续公共音高控制以及独立 OSC／纹理比例，音高与动作时长独立；拖长动作不降低音高。拖转相对原提取谱的音高倍率从0.82逐步到1.20，接火从0.82上扬到1.22，再经1.09回到1.00；它们叠加于分音各自的频率运动。纹理谱色没有整体同幅变调，听觉上的移动声线和空气／摩擦感可以分开调。

本次启动前景接管接火动作，后0.70秒以等功率权重交接到**现有主 C DNA**，而非把两套完整发动机同时叠满。这样也避免通过提高旧 DNA 的 RPM 去触发其指纹淡出与2倍音高封顶。旧全局规则、认可的怠速算法和加速淡出问题在本轮均未修改。交接时两种素材声学身份是否一致，仍需听评。

## 参数与代码

`recipe.json`控制前置／拖转／接火时长，三段`level`、`core`、`texture`、`pitch_knots`和`pitch`，以及交接时间。`core`是移动分音，`texture`是余下谱色，不代表已分离的物理部件。更强的拖转可先调`crank.core`与音高上行幅度；更大的接火张力先调`catch.pitch`峰值和回落时长；`level`最后确定。高比例移动分音仍可能暴露合成感，需要耳朵判断。

| 文件 | 职责 |
|---|---|
| `modules/startup_character/ridge.{h,c}` | 有限支持移动分音，连续相位积分；新增可变公共音高，保留旧固定倍率入口 |
| `modules/startup_character/voice.{h,c}` | 移动分音＋三阶段残余谱色，独立比例与包络；运行路径无文件I/O／分配 |
| `experiments/startup_character_v1/bridge.c` | 新增逐采样表达控制接口，旧接口保留 |
| `tools/author_startup_expression_v1.py` | 新选段提参，沿用未变拖转模型，输出各段独立参数 |
| `tools/startup_character_v1/expression.py` | 参数桥、平滑粗控制点 |
| `tools/render_startup_expression_v1.py` | 同一时间线调度前景和驾驶器，导出分轨与试听；支持`--recipe` |
| `tools/verify_startup_expression_v1.py` | 已知信号的动态音高、时长与连续相位独立解析检查 |
| `tools/audit_startup_expression_v1.py` | 保存音频重组／交接／哈希复核与精确源码留存 |

独立构建目录`build-startup-character-v3`。主 App 的事件池、控制面板与生产路由尚未接入此候选；不能通过旧窗口直接听到本次声音。此次无空间／房间处理；谱形可能保留原录音场景染色。仍是来源约束的有限启动动作配方，不是已证明能生成多次真实启动差异的统计族。未做 ADI 优化或新增500MCPS认定。

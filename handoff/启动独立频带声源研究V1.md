# 启动独立频带声源研究 V1

2026-11-17。新增了分支独立着色、限带和包络的离线生成模块，验证了频带控制和数值计算。真实启动候选仍未达标，没有替换C、控制台或演示音色。

## 算法变化

旧结构用四个宽频共振支路和公共低通，相邻频段互相牵连。新实验保留当前机械模态声线，将噪声换成四条独立支路：

`独立随机激励 → 素材拟合AR16声色 → 分支带通 → 分支幅度包络 → 与机械模态相加`

频带为60–300、300–1200、1200–4500、4500–14000Hz。滤波器用SOS表示并检查稳定性；每支路八个包络点，合计32个幅度参数。参数来自原录音的正功率差和时间能量曲线，播放时重新生成随机激励，支持独立修改声色、幅度轮廓、种子及释放时刻。没有保存原录音波形、混响或空间处理。

这只是声学参数分解，不能把四条支路标为四个真实机械零件。

## 发现与后续

稳态近似下，四条噪声支路可覆盖主体频段，但低于60Hz仍短缺约10–17dB，高于14kHz短缺约10dB。接火的固定模态已占据60–300Hz目标平均能量的约108%、300–1200Hz的约96%。仅增加噪声包络不能自由调整机械主声线与随机细节之间的比例。

这些是诊断线索，不是完整失败原因的证明：瞬态包络和有限波形交叉项会改变功率，广义特征值必要条件没有排除可行解，SLSQP失败也不代表纯合成不可行。

下步先在已知源上验证完整频谱覆盖、机械模态与随机细节的独立能量预算和可行初始化，再决定真实素材的下一次提参。不能删除频谱两端的原门槛、继续用同一预留种子调参，或把未合格候选接入UI。

## 代码边界与限制

`tools/event_band_texture/profile.py` 管参数/声色；`voice.py` 管生成和释放；`fit.py` 管离线响应和求解。诊断、已知验证、真实单次实验、独立审计分别有独立脚本。其一秒程序预热只用于离线初始化，尚无实时触发初态方案。

459个既有运行时代码/音色文件保持原哈希；没有新增运行时算力、ADI优化、空间渲染、下载、推送或持久服务重启。被否决的E片段继续排除为回火参考。完整系统目标仍在进行。

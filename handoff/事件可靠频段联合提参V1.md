# 事件可靠频段联合提参 V1

2026-11-17。本轮改进离线提参和工作台，不改实时 C、DLL、正式音色或 ABI。当前仍为 V12 声源 ABI11、作者 ABI4、事件 Profile1408 字节、配方7／行程8。渲染由外仓负责，算力优化继续后置。

## 问题与方法

旧多段包络在 A 接火上可用，但 B 启动拖转候选的1.2–4.5kHz频谱校准失败，不能通用地照搬。复核发现：

- 校准把之前极小的成分幅度继续作为基底，再限制相对增益到0–64，使已有成分难以重新获得合理电平。
- B的1.2–4.5kHz事件／背景平均对比为−2.154dB。逐FFT频点取正的频谱增量，与先汇总频段再取正的时间能量增量不同；该频段前者约为后者5.235倍，不能用同一个绝对能量目标强行拟合两者。

新增可选 `band-contour-v2`：先保留原分频起音与频谱搜索；只为平均事件／背景对比≥3dB的上部频段建立8个幅度控制点。时间拟合使用除以自身均值后的能量曲线；弱频段保留原局部包络。之后把已有模态／共振带的校准基底幅度置1，重新求成分幅度，沿用原有限时长响应、互功率、参数范围和六频段门槛。形状与频谱交替两次，从合格且相对进入联合拟合前不退化的候选中选误差最低者。

没有新增成分或频率，不要求弱频段静音，不宣称从混合录音分离了物理发动机声。弱频段的包络没有重拟合，但频谱校准仍可能改变其成分电平。

## 模块与使用

| 文件 | 责任 |
|---|---|
| `tools/event_authoring/response_basis.py` | 已有成分的单位幅度基底校准，复用原频谱求解器 |
| `tools/event_authoring/contour_joint.py` | 对比度判定、归一化时间形状、两轮联合校准与候选选择 |
| `tools/author_event.py` | job6校验、证据和拒绝结果输出；旧job保持原执行 |
| `tools/event_designer/workspace.py` | 工作台保存方法、提参、失败保留、历史与参数导出 |
| `tools/sound_designer/web/events.{html,js}` | 高频包络策略选择、弱频段保留原因显示 |
| `modules/event_synth/contour.c` | 沿用V12的实时幅度插值，不做分析／拟合 |

事件页导入带相邻背景的单次动作，设置事件／背景选区，勾选“校准频谱响应”“按频带提取起音”“提取高频多段包络”，策略选择“保护弱频带：联合校准包络与频谱”。原方式仍是默认选项；新方法没有替换已认可音色。编辑控制点后生成的是真实C合成试听，JSON／CSV／C头文件及参数包均保留完整系数。

CLI使用 `tools/author_event.py <job.json> --output <新输出目录>`；job指定 `schema: vsl.event-authoring-job/6`、`response_fit: source-response-v1`、`envelope_fit: band-contour-v2`。输入仍须为已批准素材、全频单次动作与独立背景选区。

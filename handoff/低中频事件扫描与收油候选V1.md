# 低中频事件扫描与收油候选 V1

2026-11-17。本轮补上低中频短声查找，并将批准 E 素材中的一处候选接入已有纯合成事件池、音色工作台和独立驾驶窗口。**工具与触发链已核查，候选的物理回火身份和音色尚未验收。** 前一目标轮只复核生成／渲染与 MCPS 边界，没有音色进展；本阶段继续实际素材和系统工作。

## 使用入口

事件工作台的“查找短促声音”增加“低中频瞬态”选项，适合寻找原高频检测容易漏掉的闷响／机械冲击候选。默认仍是原高频检测。流程为：导入已裁剪音频 → 选择检测方式 → 扫描 → 听原声上下文 → 带入固定选区和背景 → 人工判断动作 → 提取／编辑参数 → 用实际 C 试听 → 导出参数或加入整车配方。

检测只找声学候选，不自动认定回火，不自动提参。检测方式、候选和原声上下文随工程、历史、JSON／ZIP 保留。已有常驻服务未重启；新代码由本阶段自有测试服务验证，旧后端若尚未加载新选项，需要按工作台原启动方式重新打开。

CLI 示例：

```powershell
python tools/scan_approved_event_region.py --source E --range 8 20 --detector low_mid --output E:/VehicleSoundLab/references/analysis/my_E_scan
```

输出目录必须是新目录；命令只读取已批准且哈希一致的本地原素材。

## 算法与文件

| 文件 | 职责 |
|---|---|
| `tools/event_authoring/scan.py` | 原高频检测及新增独立低中频检测；固定窗口、背景和资格门槛。 |
| `tools/event_designer/{candidates,workspace}.py` | 保存选择、运行扫描、采用候选及历史恢复；不做物理分类。 |
| `tools/sound_designer/web/{events.html,events.js,event_candidates.js}` | 检测选项、候选显示和操作状态。 |
| `tools/prepare_{F3,low_mid}_event_context_v1.py` | 从原 PCM 独立复算功率对比，准备原音频、视频帧及声谱上下文。 |
| `tools/build_low_mid_event_v1.py` | 固定 E 候选的实际 C、多种子、可编辑工作台工程及收油对照装配。 |
| `tools/audit_low_mid_event_candidate_v1.py` | 直接核对原 PCM、C/Python、逐次原生调用的23通道、事件身份和变块回放。 |
| `tools/verify_low_mid_event_{review,ui}_v1.*` | 有界静音浏览器和独立窗口的实际使用核查。 |

低中频检测使用 80–300、300–1200、1200–3000 Hz 三带，960帧窗／240帧跳步／101帧局部中位数；第二高频带须高于局部背景6 dB。最小峰间隔100 ms；事件窗为峰前25 ms至后75 ms，前背景−350至−150 ms，后背景+160至+360 ms。沿用前后全频功率各高3 dB资格，不搜索更安静背景。

该修改发生在离线查找／参数设计工具。当前 C、V12 DLL、声源 ABI11、作者 ABI4 及89份正式音色均保持；空间与 ADI 优化不在本阶段范围。

## 素材结论

F3 原高频检测覆盖0–278秒：585候选，31处通过双背景，其中80秒后16处。已检查这16处及103.465秒已知点的原视频上下文；均不能确认为独立尾排回火，未生成 F3 事件参数。103.465秒对前背景+3.547 dB，对后背景−3.008 dB，资格不通过。

低中频检测：D36–46秒无候选；E8–20秒12候选、2处双背景通过；A300–344秒21候选、2处通过。A两处实际上为车内行驶，E12.390秒属于升速谐波语境，均不据此生成独立回火。E14.340秒是驻车车外视角的短声学变化，保留为候选。原始图像、PCM、声谱、全部失败和人工说明均留档；没有新下载或清洗。

## E 候选及实际操作

固定事件14.315–14.415秒、前背景13.99–14.19秒、后背景14.50–14.70秒。独立功率对比为+4.851／+8.027 dB。使用12个模态 OSC、4个程序噪声带及已有包络／滤波，运行时不含原音频播放；四随机种子通过原六频带资格。参数不是物理声源分离结果，100 ms选区也不代表完整首尾。

试听页：`http://127.0.0.1:8789/references/analysis/low_mid_event_scan_v1/C1/review/index.html`。先听原声上下文第1秒，再听固定选区／四个C种子，最后比较8秒“短声关闭／开启／只听事件”。同一播放器、固定电平、无房间处理或逐条响度补偿。

独立窗口先停止监听，载入页面的 `controller-preset.json`，空挡补油后收油可触发；`event-profile.json` 可单独导入事件页编辑。`afterfire` 仅为本地试听槽位，界面明确显示“物理类型尚未确认”，未晋升正式事件库。可编辑工程ID：`593d8c843ae1462ca5d9799ccacdd437`。

8秒工程动作的两次收油共触发4次短声，实际声音从请求后的下一采样开始；19个持续声通道与事件关闭版逐样本相同。变块重放23通道、通知和最终状态精确一致，峰值占2/4声部，无拒绝／溢出／日志丢失。原录音 RPM／踏板轨迹未复刻。独立静音窗口的关闭／开启两轮各8秒，通过参数载入保存及真实行程录放，均无供声中断；测试窗口已关闭。

# 启动、怠速与驾驶全流程接线 V1

2026-11-17。本轮修正完整启动示例的怠速资产选择，提供同一C声源系统的36秒整车配方。实时C、V12二进制、ABI11、89份正式voice均未变化；F2三份历史参数另行绑定。不是新的怠速拟合或听感认可。

试听：[启动—怠速—驾驶对照](http://127.0.0.1:8789/references/analysis/start_idle_lifecycle_v1/C3/review/index.html)。先比较两条“启动后6秒”，再比较“停车后怠速”。下载`controller-preset.json`，停止独立窗口后“载入参数”；`full.take.json`用于36秒完整重放。

## 修正了什么

上一阶段`A_exterior_startup_v1/C1`选择`v10-moving35`目录项（id1），其C配置没有F2怠速资产，最终`idle_weight=0`。该页及交接说明中“A/F2/E组合”的F2部分不成立；冻结原记录保留，这里明确更正。它仍是有效的启动事件对照，不能作为F2怠速已接入的证据。

本轮两版都选`v10-moving-fine-idle`（id0），使用相同启动/接火参数、踏板、事件和驾驶器，只把`idle_mix`从0改为1。F2在RUNNING/IDLE自动替换行驶层，给油淡出，停车淡回；使用原80ms交接与18ms旋钮平滑。原生`added`双声道在此配方中仅包含F2模态及细谱合成，不代表物理分离的发动机对象。

| 时间 | 动作 |
|---|---|
| 0.35s | 空挡启动；新A车外早期/接火事件 |
| 6s / 7s | 挂挡起步 / 深踩加速 |
| 19s / 21s | 收油保挡 / 制动安全降挡 |
| 30–34s | 停车保挡制动，怠速保持 |
| 34–36s | 熄火，释放尾音 |

最初C2场景在30s额外切空挡，触发旧驾驶器SHIFT_CUT/RECOVER，造成约0.3s怠速层退出/重入。最终C3保挡停车，不改运行中的换挡语义；29–33.5s实际遥测保持IDLE且怠速权重>0.99。RPM/速度由同一C驾驶器产生，850RPM怠速及启动曲线仍是工程设定。

## 模块与调音

- `tools/vehicle_scenarios/start_idle.py`只安排车辆控制，不生成音频或指定RPM轨迹。
- `tools/build_start_idle_lifecycle_v1.py`装配目录资产、新A事件及E收油候选，导出配方、行程、干声和对照页；不修改正式默认。
- `modules/fine_idle_layer`沿用模态OSC、统计幅度变化、程序噪声细谱滤波。没有录音回放；行驶DNA、事件、怠速各自保持原模块边界。
- 独立窗口“音色与分层”：`怠速声线`控制替换量，`怠速起伏`控制主声线幅度变化，`怠速纹理`控制细谱细节。三项均有真实资产支持，可独奏“附加声源”检查F2层。
- 独立事件页控制启动早期、接火、收油电平。接火保持25%对照；E只是声学短声候选，物理回火身份仍未确认。

## 证据与限制

证据根`E:/VehicleSoundLab/references/analysis/start_idle_lifecycle_v1`。`C3`为最终两组36秒实际C及变块回放；`C-audit2`独立逐次原生调用比较23通道/监听/事件/最终状态；`review-web2`检查8条音频与实际下载；`ui1`为自有静音独立窗口参数往返及36秒回放。最终汇总以`research/start_idle_lifecycle_v1_verification.json`为准。

两版驾驶轨迹及四事件槽PCM精确相同。启动后3–5.5s、停车后31–33.5s，F2权重均为1；9–17s加速时为0。固定主增益0.25、事件增益0.5，无限幅/归一化/空间效果。C1误把18ms平滑尾数当作必须位级为0而断言失败，保留已完成捕获与原失败；C2通过但停车换挡造成不必要声层退出，未作为最终版本。

当前配方仍混合A车外行驶/启动、F2怠速、E短声，未完成同车全RPM/负载标定或真实全频回火。F2三份历史文件位于`experiments`，旧通用行程identity只自动覆盖`voices`；本轮归档额外绑定这些输入，但尚未修复通用身份范围。后续应统一资产身份，不能把本轮独立绑定冒充已有运行时拒绝机制。完整目标继续，不开展ADI优化或渲染集成。

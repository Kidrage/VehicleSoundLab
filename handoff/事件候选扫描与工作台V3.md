# 事件候选扫描与工作台 V3

2026-11-17。把原先命令行的短瞬态筛查接入 **VEHICLE SOUND 音色工作台 → 独立事件**，服务于启动、回火和机械短声的素材设计。没有改动实时 C、控制台 V8、认可音色或正式事件库，也没有新增空间处理；扫描仅在非实时作者工具中运行。

## 使用

1. 导入包含事件与附近背景的0.12–60秒片段。
2. 展开“查找短促声音”，点击“扫描导入片段”。默认列出同时高于前后背景3 dB的候选，也可显示全部弱对比候选。
3. 点击候选，自动带入事件、前背景和后背景，并准备单播放器的原声上下文。不会自动播放或自动拟合参数。
4. 核对动作、录音视角和干扰，选择声音类型；需要时调整选区，再执行原有提参与 C 试听。
5. 扫描和选择均进入历史；生成参数包时额外包含 `candidate-scan.json`，JSON及ZIP保留完整扫描与选择依据。

候选时间相对导入片段。裁剪整片时须另保留原片起点及来源；本轮 A 诊断工程已记录342秒偏移。扫描只找声学变化，不会识别真实回火、换挡、RPM或物理部件。

## 模块与接口

| 文件 | 职责 |
|---|---|
| `tools/event_authoring/scan.py` | 原固定检测器；新增 `scan_file`，按30秒块及500 ms上下文读取，保留原帧格点、阈值和前后窗口。 |
| `tools/scan_approved_event_region.py` | 已批准本地源的身份核对与CLI包装；复用同一扫描器。 |
| `tools/event_designer/candidates.py` | 不可变扫描记录、原录音/报告SHA校验、候选选择和导出依据；不依赖 C 声源。 |
| `tools/event_designer/workspace.py` | 扫描、选择、前后背景核查、历史及现有参数的协调。 |
| `tools/sound_designer/web/event_candidates.js` | 折叠列表、全量筛选和候选选择；不含音频算法。 |
| `tools/sound_designer/server.py` | 串行作者任务新增 `/api/events/scan`、`/api/events/candidate`。 |
| `tools/event_designer/package.py` | 可选扫描证据随参数JSON、校验清单与ZIP导出；驾驶器仍只采用事件参数。 |

检测保持20 ms窗、5 ms步长、101帧局部中值、三个高频带中两带高于6 dB、最短100 ms间距。候选窗口为中心前25 ms至后75 ms；前背景为前350–150 ms，后背景为后160–360 ms。没有搜索更安静背景或放宽阈值。双声道按通道功率平均，避免反相抵消。

旧扫描列表失效、越界/非整数索引、原录音或报告身份变化时拒绝选取，保留工程。选取不会改写已有模型或试听宏；当前参考与旧模型不相同时，原有来源绑定提示继续生效。扫描记录不是音色验收，也不是物理声源分离证据。

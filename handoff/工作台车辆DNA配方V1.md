# 工作台车辆 DNA 配方 V1

2026-11-17。把已保存的单状态声纹工程组合为 V9 使用的多状态参数包。以前需要逐个导出，再在独立窗口手工组装；现在工作台可以直接保存默认、怠速、给油、收油四组及其来源快照。底层合成、驾驶器和认可目录音色均未修改。

## 使用

1. 在原“声纹设计”页调好各状态并保存。车辆 DNA 页读取的是已保存参数；尚未保存的旋钮修改不会自动采用。
2. 点击工作台顶栏“车辆 DNA”。默认组至少选一个工程，其他组可为空；每组最多八个锚点，自动按声学基频排序。不同组允许不同锚点网格和统计维度，但分音数与录音视角必须一致，不会截掉高频来兼容。
3. 填写默认组最低基频锚点的参考 RPM、统一细节、种子及状态过渡时间。RPM 是人工工程映射，各组共享，不等于测得发动机转速。统一细节覆盖各原工程的细节值；预览变调不写入模型；EQ／增益／宽度／联动及局部统计变换只写入系数一次。
4. 编译保存，下载“车辆 DNA 参数包”。在独立 V9 窗口停止监听，进入“音色与分层 → 导入／编辑工作台 DNA”导入，再运行踏板或完整流程。

缺少某状态时回退默认组。启动／接火短声和回火等独立事件继续在事件工具与控制台配置；本包不自动继承兰博基尼专用低频、细节、怠速、启动或事件层。它是可组合的主声线，不宣称已经完成整车所有音色。

## 留痕与隔离

工作台数据目录下 `state_recipes/<配方ID>/<版本ID>/` 保存 `vehicle.dnabank.json`、`provenance.json`、`snapshot.json`；顶层 `recipe.json` 指向最新版本。保存新版本保留旧版本；历史选择恢复的是当时的参数快照，再次编译才读取当前来源工程。

参数包包含全部系数，不含录音或音频循环。来源记录保存原工程及基础模型 SHA、已编译系数 SHA、原调参、选区与素材标注。来源修改／缺失时页面提示，旧快照继续可下载使用；错误配置在写新版本前拒绝，不覆盖已有配方。参数包与来源文件的哈希不符时拒绝打开。

统一声源时钟和原生干声分轨沿用 V9；本工具不生成空间对象位置、不加入房间／IR／HRTF。观察双声道仍是录音视角的左右关系，不冒称真实缸列或两个独立尾排。

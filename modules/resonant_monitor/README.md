# 完整声源监听适配器

`render.h/.c`只负责参数平滑、10ms启停淡变及输出，不新增驾驶器、房间或音色拟合。

| 接口 | 职责 |
|---|---|
| `rsm_render_init` | 非实时校验、绑定调用者拥有的模型，沿用完整声源的细节预热 |
| `rsm_render_set` | 音频线程设置目标；非法值及未配层的非零增益不改状态 |
| `rsm_render_process` | 连续生成、一次主增益／宽度／路由、启停淡变；不分配、不读文件 |
| `RsmCapture` | DNA／低频／细节为主增益前stereo；dry为淡变前的布局输出 |

停止淡变不可撤销，重新播放需重新初始化；静音不停止内部时钟。2／12仅将观察录音L/R映射到FL/FR，其余为0。数值作用域局限于本次处理并恢复。

宿主在`experiments/resonant_monitor_v1`：`models`非实时事务加载，`audio`复用`win_output`并按成功提交块记录调试控制，`ui`提供五个配方及四个滑条。模型切换先停机；调试记录不是正式行程协议。

运行根目录的`Launch-Resonant-Source.cmd`。默认停止、低转补细节候选；低转实际RPM／热怠速未确认，行驶35%为既有保留配方。音高仅0.90–1.10，不能代替全转速／负载模型。

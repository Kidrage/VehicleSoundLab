# 驾驶音色目录

本模块管理非实时的音色身份、参数所有权与声层能力。当前十二项为十个V10观察／配方情境和两个解析合成示例；目录数量不代表真实发动机数量。F3双声道细节和F2联合起伏的独立听评仍待答。E减速双声道已有“左右关系有改善，音色仍明显电子”的反馈。

`dc_preset_create`借助已有`AtAssets`复制完整只读参数及配置；原装载缓冲可立即释放。`dc_preset_config`返回对象内的稳定指针，`dc_preset_initial`返回初始控制副本。对象必须活到渲染停止，之后才能destroy。所有参数读取、验证、复制、分配和销毁均在音频线程之外；运行仍使用已有`atlas_drive`和唯一驾驶器。

`dc_aux_enabled`依据实际配置判断启动、接火、怠速、起伏、细谱控件是否有对应声源，回放时传行程内嵌配置。`dc_aux_amount`只定位已有控制字段，没有新增DSP、状态控制或录放字段。目录不纳入DSP身份；行程内嵌的实际模型／配置仍由现有严格身份与参数校验保护。

`dc_body_enabled`识别配方是否有独立低频参数。驻车及E减速配方只有DNA和共振细节，低频层控件禁用并标为“未配置”；主DNA本身仍包含低频。这个查询同样使用实际实时／内嵌回放配置。`DC_STATIONARY5`、`DC_DECEL`分别追加在旧七项之后，原身份和默认选择保持。

`decel_models.*`只在非实时装载冻结E原始DNA与Rvs参数，交给原配方核执行35%频带功率撤出和连续细节；不播放录音，不新建驾驶器，不自动在收油时切换。该通用配方校验扩展支持Rvs，因底层源文件变化更新严格渲染器身份；schema10／32字段保持。旧行程用其冻结旧播放器，见[接入记录](../../research/减速双声道配方接入V1.md)。

`F3_models.*`以同一非实时接口装载冻结F3单锚点DNA和十带Rvs，使用零功率撤出、无独立LF的叠加配方。`DC_F3`追加在旧九项之后，不改其索引和默认。主声线使用目录种子48271，细节依原规则得到8121907；离线混音的主声线种子为1，因此不声称与它逐样本相同。细节沿用局部根音支持，主DNA继续变调；界面禁用未配置的独立低频。详见[F3接入](../../research/F3叠加细节接入统一窗口V1.md)。

`F3_local_models.*`只装配两次五挡升速各自的前／中／后三点，索引10／11追加为两个独立选项。所有三点都持续推进统计状态，原`SaVoice`在相邻两点间插值；一个原驾驶器控制其根频率／音量／声层和录放。32阶对齐保留原局部库的周期原点关系，非物理曲轴标定。声纹支持范围分别61.36–67.96／60.82–67.36Hz，范围外仍可变调并由原界面提示超出素材范围。此处未添加独立低频或细节，低频控件沿用DNA内部的互补频带分层；高频细节控件因未配置而禁用。新旧行程内嵌完整参数，共享原schema10／32控制字段和同一渲染器身份。见[局部库接入](../../research/F3局部声纹接入统一驾驶V1.md)。

文件装载／组装在`experiments/catalog_drive_v1/models.*`；原生切换生命周期在`session.*`；窗口继续使用`experiments/atlas_monitor_v1/ui.c`。`--catalog`是同一程序的目录入口，旧入口继续可用。切换前UI保留未保存行程；构建成功的候选才提交，先停止音频，再改指针，旧预设最后销毁。新预设保持未点火，不自动开始声音。回放与返回实时配方分别保存控制，避免跨音色残留不支持的声层量。

本轮没有拟合新参数，也没有移植待听的`idle_complex75_v1`。目录里已有F2细谱怠速仍是候选；两款解析合成器不是用户Serum音色。RPM映射及声层模板仍有工程假设，不能据可运行声称工况音色、真实车型或7.1.4已验收。

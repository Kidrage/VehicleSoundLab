# 驾驶音色目录

本模块管理非实时的音色身份、参数所有权与声层能力。七项为五个已有V10观察／配方情境和两个解析合成示例，不是七款已拟合的真实发动机。

`dc_preset_create`借助已有`AtAssets`复制完整只读参数及配置；原装载缓冲可立即释放。`dc_preset_config`返回对象内的稳定指针，`dc_preset_initial`返回初始控制副本。对象必须活到渲染停止，之后才能destroy。所有参数读取、验证、复制、分配和销毁均在音频线程之外；运行仍使用已有`atlas_drive`和唯一驾驶器。

`dc_aux_enabled`依据实际配置判断启动、接火、怠速、起伏、细谱控件是否有对应声源，回放时传行程内嵌配置。`dc_aux_amount`只定位已有控制字段，没有新增DSP、状态控制或录放字段。目录不纳入DSP身份；行程内嵌的实际模型／配置仍由现有严格身份与参数校验保护。

文件装载／组装在`experiments/catalog_drive_v1/models.*`；原生切换生命周期在`session.*`；窗口继续使用`experiments/atlas_monitor_v1/ui.c`。`--catalog`是同一程序的目录入口，旧入口继续可用。切换前UI保留未保存行程；构建成功的候选才提交，先停止音频，再改指针，旧预设最后销毁。新预设保持未点火，不自动开始声音。回放与返回实时配方分别保存控制，避免跨音色残留不支持的声层量。

本轮没有拟合新参数，也没有移植待听的`idle_complex75_v1`。目录里已有F2细谱怠速仍是候选；两款解析合成器不是用户Serum音色。RPM映射及声层模板仍有工程假设，不能据可运行声称工况音色、真实车型或7.1.4已验收。

# 行程文件 I/O

非实时模块。`at_take_encode/decode`处理内存，`at_take_save/load`处理UTF8路径。当前独立`.vslrun`为schema10／32控制，继续保存原声源及可选旧固定怠速；新增可选细谱怠速的OSC、幅度统计因子、全部FIR系数、预热量、电平和过渡参数。后两项控制追加在原30字段之后。旧`.vsltake`是另一协议；schema9及更早使用各自冻结播放器，本版拒绝旧格式／旧渲染身份。

文件顺序：8字节`VSLRUN\r\n` → u32版本 → 64字节渲染身份 → u32字段数 → 配置／原声源资产 → 旧固定怠速presence及参数 → 细谱怠速presence及Ms／Mt／Sf／Fi参数 → 初始化控制 → 帧数、停止帧、双哈希 → 控制事件 → u64 FNV校验。整数和IEEE754双精度显式小端，不dump C结构体。每个可变count在读数组前限制，最终再校验整个拥有对象。

最大32MiB；锚点、谐波、统计组件、残差频带、事件数量及所有控制均有上限和范围验证。截断、尾随、错误版本／身份／校验及非法模型事务拒绝，原行程不变。成功载入拥有全部模型，不依赖外部路径。保存通过同目录独占临时文件、flush和原子替换；普通I/O失败保留既有文件。

# 驾驶分层监听

`split`只观察已有声源，输出六条干声stereo总线：DNA、低频、细节、辅助、启停／事件、其他声源。每条均包含原驾驶包络／层电平和一次master；外层`atlas_monitor`再施加同一启停淡化。细谱怠速按实际gate／包络／电平拆出主声线和细节；旧混合怠速、opaque附加声源归入其他，不声称物理源分离。六层之和在浮点舍入误差内等于完整干声，不要求等于含空间的完整输出。

`listen`只做输出监听：完整混音精确旁路，或六条干声单听；18ms线性交叉淡化。切换不改变控制器、声源相位、随机数或任何音色参数。没有归一化、房间、假立体声或12声道上混。总线保留L/R，未来空间渲染仍由既有对象／声床接口负责。

UI选择不进入`.vslrun`驾驶控制。录制和回放一致性使用单听之前的完整混音哈希；设备统计哈希对应实际监听信号。切换单听期间仍录制完整行程，回放时可重新选择监听层。声源代码身份依旧严格区分，旧文件用保留的旧播放器。

实时调用只用调用者预分配的缓冲和固定状态，没有文件I/O、分配或声源重新初始化。此模块不校准怠速／加速音色，也不把待听候选晋级。

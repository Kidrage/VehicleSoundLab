# 连续共振细节 C 核

从已冻结的离线细节生成器移植，不重新拟合或调音。供不同声纹参数共用；当前有行驶35%及两个低转候选。它是 Sound DNA 的非周期纹理部件，不是已分离的机械／NVH／房间声源，也不是严格纯 OSC。

| 文件 | 责任 |
|---|---|
| `profile.*` | 非实时校验数量、范围、AR／SOS稳定性及包络正值；模型由调用者持有 |
| `excitation.*` | 每带独立的xorshift64*／Box–Muller连续随机激励 |
| `filter.*` | 有状态AR24及后置SOS带通 |
| `envelope.*` | 在外部主声相位计算弱周期功率形状；未通过素材验证的带保持平坦 |
| `voice.*` | 串接各带，按固定增益及观察R/L比例输出细节；可选输出逐带信号 |

## 接口与生命周期

1. 非音频线程调用 `rdt_profile_load`（独立`resonant_detail_io`库），然后 `rdt_voice_init`。初始化先验证，失败不改变原声部。
2. 模型整个运行期保持有效、只读；更换模型须在音频线程外准备新声部，再由宿主设计切换。
3. 宿主预热`profile.warmup_frames`帧；现有三个参数均为96000帧。预热也须传入连续的外部相位。
4. 音频线程逐帧调用 `rdt_voice_tick(voice, phase_cycles, stereo, bands_or_NULL)`。相位必须有限且在`[0,1)`；非法相位不改变状态或输出。正常处理不分配内存、不读写文件。
5. 调用者将细节与主DNA／独立低频混合，并管理层增益、交通状态、输出淡变、空间及设备。`frame`仅计处理帧；本模块不产生第二个发动机时钟。

48kHz；最多12带、AR24、4个SOS、12阶能量包络。非实时Schur递推限制极点半径小于.9998；4096点网格及导数上界验证整个周期功率至少.05，再开平方得到幅度。

公开名字统一为`Rdt*`类型、`rdt_*`函数、`RDT_*`常量，与已有`residual_dense`的`RdVoice/rd_voice_init`分开；契约同时包含两套头文件并链接两套实现，避免单独构建掩盖合并冲突。

## 当前接入范围

`base_hz`是素材声学根音元数据，不能直接叫曲轴RPM；探针用它构造固定相位测试。共振器保持拟合的绝对Hz，目前没有宽转速／负载插值策略。改变外部相位只改变能量包络，不会自动重调共振器。观察R/L比例不代表发动机左右缸列或扬声器位置。

本核仅输出新增细节；`moving_35.rdetail`并不会自行削减原DNA的35%谐波功率。完整配方还须由适配器按`index.json`的谐波过渡和功率削减规则处理主声，再混细节与原相干低频。

已完成三个参数×三个seed的C／Python细节核对及48项CTest。尚未做完整混音重合成、原生监听、驾驶／行程接入、设备预算或长期运行验收。离线35%听评不能自动转为原生C听评；两个低转候选仍待原问题反馈。

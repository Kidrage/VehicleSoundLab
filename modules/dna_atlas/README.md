# 多锚点 Sound DNA · C 接口

同一组谐波 OSC 随根频率选择相邻模型，插值各谐波的幅度和确定性平均相位。每个锚点的统计细节沿用 `sound_dna/texture`，只调幅；没有随机相位、录音循环或两套完整声源的交叉淡化。

| 文件 | 职责 |
|---|---|
| `bank.h/c` | 初始化时检查并借用1–8档模型、拟合共同周期起点、建立相位分支与正弦查表 |
| `voice.h/c` | 唯一OSC时钟、相邻锚点插值、各锚点持续推进的随机状态、谐波抗混叠 |

`sa_bank_init` 在非实时线程运行；模型必须按 `base_hz` 严格递增，同为48kHz／1024窗／256步长、相同谐波数。沿用现有 `.model` 文件，不修改其均值、统计基或来源。锚点不同时混合不同车型或录音视角；这一语义由宿主／清单保证，C不能根据数字自动辨认素材身份。

`align_orders=0` 保留各自原点；1–32使用相邻模型低阶复均值的交叉相关，拟合一个共同L/R周期偏移。第一个锚点偏移为0。只能校正周期坐标的任意起点，不等于识别曲轴正时、排气传播或物理声源。当前 E 两档使用32阶。

`sa_voice_init/set` 输入绝对根频率0–1000Hz、细节0–1、增益0–1。参数18ms跟随。根频率为0时相位／统计时钟暂停，输出仍按当前相位计算，宿主须用生命周期包络静音。`tick/process` 不分配内存、不读文件、不调用驾驶或设备API；bank、原始profile和voice存储均由宿主管理且须保持有效。单个实例由音频线程独占。

幅度在相邻模型间线性插值。相位先取左观察通道的最短分支，再以左右相位差的最短变化确定右通道分支，防止两声道独立绕行导致中点翻转。均值趋零时相位本身不可靠，不能据此推断物理事件。模型间确定性相位变化仍可能形成音色运动，需要听评；此处没有把每个谐波强制对齐。

每档有独立 `SdTexture` 存储，并以显式种子初始化。所有锚点的时钟和RNG一直推进，增益／细节为0或当前权重为0均不暂停。纹理更新随共同周期推进，不按文件播放时长推进。相同统计模型与相同种子具有相同序列，不宣称不同录音模型的潜变量已配准。

超出首尾根频率时继续跟随输入音高，采用边界模型的声纹。`coverage=-1/0/+1` 和 `lower/upper/blend` 是即时诊断，不能把这种边界变调当成录音覆盖；覆盖标记有1e−8Hz数值容差，避免平滑器在边界的渐近误差被永久标成越界。各谐波19.2kHz开始平滑衰减，21.6kHz归零；这限制静态谐波载频，不保证任意快速控制／调制完全带限。

单锚点下，在无抗混叠衰减的频域内重现原固定相位声源；`experiments/atlas_drive_v1/atlas_checks.c` 还检查已知相位过渡、共同L/R对齐、同谱不衰减、块大小、RNG、超范围时钟和高阶抑制。它们不能替代实际音色听评。

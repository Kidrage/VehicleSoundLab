# Procedural startup character

Experimental crank texture source, pending human listening. Three measured
spectral shapes excite fresh random sources through the existing partitioned
FIR engine. Nine coarse amplitude controls and bounded stochastic variation
describe a gesture. The V1 noise-only starter was rejected as wind-like.

The optional `ridge` module adds a sparse short-time moving OSC score. Each
atom stores frequency/slew, support, and scalar L/R amplitude/initial phase;
it does not store a waveform or per-frame phase history. Its remaining colour
uses fresh random excitation. This is a source-conditioned controllable gesture,
not physical component separation or a fully qualified multi-start model.

`sc_create` is non-RT and owns compiled filters. `sc_tick` accepts normalized
progress/gate/strength from the single vehicle lifecycle. It owns no RPM or
vehicle state. Catch combustion belongs to the main DNA, not this crank voice.
Source colour filters are not spatial/room renderers.

The isolated bridge and paired audio live in `experiments/startup_character_v1`
and `tools/render_startup_character_v1.py`. Not yet integrated in the main App,
not an approved sound and not qualified for ADI timing. See
`handoff/启动声重建候选V1.md` and `handoff/启动拖转移动声线V2.md`
for evidence and limits.

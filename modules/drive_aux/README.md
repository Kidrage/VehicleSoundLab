# 驾驶辅助声层

`atlas_drive` 的独立进气、机械、排气空气、道路和风声适配器。五个量均默认0。复用已有工程模型与工况包络，不声称从录音中分离出五个物理声源。

| 文件 | 职责 |
|---|---|
| `motion.*` | 每样本读取同一驾驶状态，18ms跟随RPM／负载，推进720°曲轴时钟与喷油幅度门。没有第二个车辆积分器。 |
| `voice.*` | 持续推进原有机械模态／NVH，五路独立18ms混音控制，提供原始／增益后对象和直送监听。 |

机械旋转冲击可在启动拖转时出现；燃烧冲击还须满足 `vsl_fueling_allows_firing`。断油停止新燃烧冲击，允许旋转冲击与已有共振衰减。排气空气跟随喷油门，进气仍走工况包络；道路按车速、风按车速平方变化。具体频率、声级和这些映射来自工程模板，未标定实车。

源初始化后始终运行，关闭／再打开某层不重置时钟或随机流。机械的旋转／燃烧随机流、NVH随机流与DNA／残差／事件相互分离；NVH内部进气／空气／道路／风仍共享原有滤波噪声，不宣称完全统计独立。

所有实时函数仅操作预分配存储，无文件读取／分配／UI。不会调用旧DNA、PAD、排气激励器或旧总渲染；不会重塑已认可DNA。`da_stereo`是直送电平监测，mono等功率居中，空气左右直送；对象进入外层唯一空间渲染，可导出2／12通道。

`AdMix.intake_gain/mechanical_gain/air_gain/road_gain/wind_gain` 是0–1独立量。`AdCapture.aux_raw/aux_objects`为每帧10个源位置，`aux`为主音量前的立体声监听。`.vslrun` schema2保存全部25字段并把增益后辅助对象纳入声源哈希。

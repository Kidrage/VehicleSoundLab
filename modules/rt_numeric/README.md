# 实时数值作用域

`scope.h/.c` 仅管理当前调用线程的浮点环境，不拥有音色、驾驶或设备状态。

- x64：`rn_scope_enter()` 保存完整 MXCSR，只开启 FTZ（极小结果归零）和 DAZ（极小输入视作零）。舍入模式与异常屏蔽保持调用者设置。
- `rn_scope_leave()` 恢复进入时的完整值，包括原有状态位。按后进先出顺序支持嵌套；成功、参数拒绝和中途失败都必须退出。
- 其他架构：`rn_scope_available()==0`，进入／退出为空操作；未声称有性能收益。
- 没有分配、文件 I/O、全局可变状态或逐样本调用。

`atlas_drive::ad_render_process` 用一个薄包装覆盖完整块处理；`atlas_monitor::am_render_process` 再覆盖宿主传输淡化，两层可安全嵌套。独立 Sound DNA 监听与旧驾驶渲染不调用本模块。

本次 x64 实录对照允许最多 `1e-12` 满幅误差，实际最大约 `1.18e-38`；不能把驾驶输出写成逐字节相同。固定已认可 DNA 的独立输出仍逐字节相同。契约、156 音轨比较、实际设备与性能结果见 `research/数值作用域V1.md`。

源文件已纳入 `.vslrun` 严格渲染身份。旧行程用对应冻结播放器；不修改旧行程或降低校验。

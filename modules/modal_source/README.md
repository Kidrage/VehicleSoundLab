# 独立频率 OSC 声源

`profile.*` 校验最多64条独立频率的双声道幅度／初相；`voice.*`持续生成，`io.*`通过独立链接库负责非实时文本加载。没有车型、阶次、RPM、PCM或时间轴。

调用顺序：非音频线程加载不可变`MsProfile`并初始化`MsVoice`；音频线程通过`ms_voice_set`设置频率比例／增益，`ms_voice_tick/process`输出。模型由调用方持有，全生命周期不变。渲染不分配、不读写文件。

控制在864样本（18ms）内单调到达目标，重复同目标不重启。每条声线保留左右初相差，独立推进；零增益和超过可听范围均不重置。19.2–21.6kHz平滑淡出，每4096样本仅校正振子模长。

频率比例仅影响这些OSC，不自动变调外部共振器，也不代表实际RPM。核的允许范围0.25–4不意味着某个声纹在该范围都有效。固定怠速F2原型仍建议先在0.9–1.1内研究。

此核不维持不同频率间的发动机同步关系；可能拍频。将模型接到状态机时仍需独立的适用范围、包络、过渡与声源证据。当前仅由`experiments/modal_idle_v1`使用，没有替换既有DNA或驾驶器。

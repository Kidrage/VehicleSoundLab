# DNA／相干低频／连续共振细节的完整 C 配方

共用既有`dna_scene`与`resonant_detail`，将行驶35%及两个低转离线配方做成同一C接口。没有重新拟合、房间、素材循环或第二个发动机时钟。低转候选仍待原听评，热怠速及RPM未确认；这不是完整驾驶／负载音色库。

| 文件 | 职责 |
|---|---|
| `recipe.*` | 非实时验证原DNA，向独立存储编译正增益谐波功率替换；不改原模型 |
| `voice.*` | 原DNA／相干LF持续生成、细节预热与主相位同步、独立层控制和一次相加 |
| `output.*` | 独立主增益／宽度和2／12通道前置声床；无空间推断 |

## 生命周期

1. 非实时用既有加载器读取原DNA、可选同情境相干LF、`.rdetail`。
2. `rss_profile_prepare`将主DNA编译到调用者持有的另一份`SdProfile`。采用实际根音对应的1.2–1.9kHz平滑功率mask；mean／basis／root同时乘`sqrt(1−amount×mask)`，保留低阶、平均相位及AR相关。amount0逐字节复制，非法输入不改输出。
3. `rss_voice_init`接收编译DNA、可选LF及细节。模型只读、必须比声部长寿。初始化验证及预热不在音频线程；失败不改原声部。
4. 初始化只预热细节滤波器，不推进主DNA／LF。预热相位为相对未来源零点的负时间；进入播放后，细节每帧使用主DNA实际采样相位，不自行累计另一个时钟。
5. 音频线程通过`rss_voice_set`更新已验证的控制，再逐帧`rss_voice_tick`。`RssFrame`保留主DNA／LF原始分轨、校准LF、细节raw／包络后及完整mix，供后续驾驶／录放适配。
6. `rss_output_frame`独立应用一次主增益／宽度。2／12均保留FL/FR；另外10通道为0，不从录音L/R推断缸列、LFE或高度声源。未来空间处理应在此源边界之后接入。

`detail_gain`独立平滑，细节还乘主DNA工况增益，使未来断油／停止包络可同时作用于主声与其纹理。静音不会停RNG、滤波器或相位。可选LF保留独立包络和原固定校准量。

## 控制与限制

沿用现有`DsSourceControl`的0.90–1.10相对音高、DNA／LF幅度细节及层增益。`source.phase_texture`必须为0；本配方没有恢复先前未通过的共同微扰C音色。细节量0只关细节，不会撤销已编译的谐波功率替换；要完整原版，应在停止后使用amount0／无细节配方重启。没有把两者误做成一个干湿旋钮。

共振器保持拟合的绝对Hz；相位控制只改变弱周期能量形状，不能自动获得宽RPM／负载声纹。换配方／声源只允许非实时准备和停止后重启；没有承诺跨情境无缝混合。原低转、移动尾排和车内视角继续分开。

此库没有文件／设备I/O、内存分配、UI、驾驶器或行程协议。便携核支持声部控制；实时设备回调预算、原生监听、驾驶／行程接入及听评分别验证，不能从离线测试推定。

# 残差幅度细节

独立 C11 实验模块。复用 `sound_residual` 的密集正弦 OSC，以每带共同 L/R 正幅度增加统计变化。载频、相位与音高控制不受细节量影响。当前仅拟合已认可 A 移动尾排情境，尚未接入驾驶／设备，也没有音色认可。

| 文件 | 职责 |
|---|---|
| `profile.*` | 非实时事务读取、带宽配对与正幅度界限 |
| `envelope.*` | 独立随机流、100Hz AR(1)因子、逐样本插值与功率补偿 |
| `carrier.*` | 推进同一 OSC 状态，同时输出原声与幅度变化声 |
| `voice.*` | 拥有模型／状态，控制音高、增益与细节量 |

`rm_voice_init` 在非实时线程初始化；`rm_voice_set`、`rm_voice_process` 在同一音频线程调用。宿主自行交接控制快照。处理期不分配内存、不读文件、不调用UI。输出为交错stereo double；`raw`可为NULL，两个缓冲区不得重叠。0帧允许NULL输出。

48kHz，音高0.9–1.1×，增益／细节0–1。细节量约18ms跟随；0量与旧 `SrVoice` 的样本和整个载波状态精确一致。静音／0量仍推进独立随机流，切换时不重置其他层。

模型格式为 `VSL_RESIDUAL_MOTION 1 48000 480 <bands> <factors>`，随后为因子相关系数和逐带 `low high basis...`。最多16带、8因子，`rho<=0.95`。谱模型与幅度模型必须有相同频带。每带最坏偏差不超过0.75，保证所有种子下幅度为正；补偿的是统计预期功率，不是每个片段的实际响度。

AR因子使用独立随机正负激励，逐样本插值；每带`gain=(1+amount*Σbasis*x)/sqrt(1+amount²*Σbasis²*插值方差)`。L/R使用同一正增益，保留已有载波关系；有限片段的谱／相关性仍需实测。

本次拟合保守缩放至约15.35%，实际混音统计改善很小。技术契约通过不能证明自然度提高；详见[分析与限制](../../research/残差幅度细节V1.md)。

# 独立声线与连续共振的受控声源

`MlProfile` 借用不可变 `MsProfile`／`RdtProfile`，分别保存声线频率比例、两层增益、整体电平和进出时间。通用核不包含车型、RPM、状态名、PCM、房间或独立发动机时钟。

- `ml_profile_valid`：非实时校验参数，拒绝非零阶的周期细节包络。Rdt 文件的 `base_hz` 在此处不参与生成。
- `ml_voice_init`：非实时初始化并预热共振器，声线从其初始相位持续运行。
- `ml_voice_tick`：音频线程接收外部 gate 和驾驶包络。声线／随机激励／滤波器始终推进；gate 改变时从当前位置开始有限时长的淡入或淡出，同 gate 不重启包络。

位置线性插值后用三次 smoothstep 得到 `weight`；宿主用 `1-weight` 保留旧声源，用 `weight` 加入新声源。没有等功率补偿。中途反向保留当前位置，保证数值连续，但不保证反向时的连续一阶导数或听感无缝。

`MlFrame.modal/detail/raw` 均为未加整体电平的原始连续声源；`output=raw × 驾驶包络 × weight × level_gain`。固定的 `level_gain` 是独立电平控制，不改变音色系数，也不是自动响度跟随。

实时调用不分配、不读写文件。模型及 profile 由宿主持有且不得在播放中移动／修改。固定 F2 原型仍可能拍频，没有长期发动机同步、实际 RPM／负载或完整音色覆盖。

`state.*`在该核外增加独立0–1量控制。调用者提供gate和目标量，目标量以18ms一阶跟随乘到原有限gate权重；原源保留量仍为`1-weight`。零量不冻结声线／共振／随机数，恢复时不重新开始片段。`ml_state_init`负责非实时预热，`ml_state_tick`不拥有驾驶器、RPM映射或空间器。该类型允许宿主明确拥有参数，区别于无法通用序列化的opaque回调。

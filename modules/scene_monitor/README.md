# 直送／空间实时监听适配器

`render.h/.c` 是可移植C11监听混音层，复用 `modules/dna_scene`。它不拥有模型文件、UI或设备；配置与模型生命周期遵循下层接口，设备宿主独占并提供 `VslEngine` 存储。

`smo_render_init` → `smo_render_set` → `smo_render_process`。当前设备适配仅输出48kHz立体声；12通道仍由 `ds_scene_process` 离线导出。默认直送组合保留DNA＋相干低频的原始观察声道；空间模式使用下层明确的单声道投影与出口路由。

直送与空间始终由同一组持续声源生成。切换权重以18ms时间常数平滑，按线性幅度混合两条路径，不重设相位或RNG；空间参数可以提前设置。初始化时采用当前监听选择，不从错误模式淡入。独立5ms起音、锁存10ms停止包络由监听层处理；停止到零以后源仍可继续推进，直到宿主完成该块并回收设备队列。

`SmoCapture` 可选返回两层原始观察、未加起止包络的直送与空间输出。接口内部只使用固定大小栈缓冲；任意块长按512帧以内子块处理，零帧不锁存停止。参数无效时不改变目标或时钟。输出无压缩、剪裁或响度归一化；宿主负责余量。

所有输出与捕获缓冲区应互不重叠，并按所请求帧数配置。对称出口在没有房间时仍可接近单声道，宽度旋钮不会制造源差异；比较房间反射时启用空间监听并增加房间量。

Windows宿主在 `experiments/scene_monitor_v1`：

| 文件 | 责任 |
|---|---|
| `recipe.*` | 显式模型配置、种子48271／48271、低频倍率1.6658265329883064、共同输出0.5。 |
| `audio.*` | waveOut事件队列、512帧块、控制快照、线程回收、性能统计和有界调试控制记录。 |
| `models.*` | 非实时事务载入与兼容性检查；失败不修改原模型，成功后先停设备再替换。 |
| `ui.c` | 五个滑条、直送／空间与几何传播选项、模型选择、播放停止。 |
| `checks.c` | 干声／空间保持、源隔离、交叉淡化、无效调用和停止重启验证。 |
| `verify.c` | 实际设备静音提交、采用帧记录、逐样本离线重合成和捕获文件。 |
| `ui_checks.*` | 本程序内部的控件、音色切换、停止重启关闭与窗口截图自测。 |

设备宿主在块边界一次复制完整控制快照，短临界区内只复制数据，不做文件／UI／设备等待。DSP仍由音频线程独占。设备调用与文件导出不进入逐样本核。四块队列耗尽次数、渲染时间和设备播放时长可观测；设备连续2秒无进展会退出并回收。

调试trace记录实际采用的控制帧；容量256，溢出明确计数，不能当作无限录制或代替旧驾驶take。自动验证设备提交始终静音，在静音前捕获并检查输出。这证明宿主和算法一致性，不等于人耳听评或DAC／扬声器实际声音验收。

# Windows 立体声输出

`wo_init/start/stop/destroy` 提供48kHz float stereo、512帧×4队列、完成事件和MMCSS调度。`WoProcess` 回调负责合成、快照采用和停止淡化；本模块负责缓冲、提交、错误与统计，不知道驾驶、模型或UI。

回调每个提交块调用一次，返回−1失败、0继续、1完成。设备静音在回调后施加，统计与宿主捕获仍取静音前结果；静音验证不等于扬声器或声卡回环测量。统计包含队列耗尽、超预算、耗时、峰值、设备时间与首块提交后的播放墙钟；设备线程启动到首块提交的时间另列。

开始前设置稳定回调与context，运行期间不得覆盖或销毁。控制线程负责停止／重启，回调不能等待UI或读文件。旧监听后端保留，此模块目前用于新DNA驾驶监听。

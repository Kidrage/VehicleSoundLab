# 分块 FIR

通用单通道因果卷积，不含发动机、声源、房间或随机数。固定256输入帧／512点复FFT，滤波器按256点分区，频域历史环与重叠相加保持跨块连续。

`fft.*`负责只读变换表和原地变换；`filter.*`负责不可变滤波器编译、独立历史状态与整块处理。核和状态在非实时路径create/destroy，音频处理仅用已分配数组。状态借用核，须先销毁状态再销毁核。独立状态可以共享同一只读核。

`pf_filter_block`接受完整256帧，返回对应的256帧因果滤波结果；允许输入／输出同址。对外部实时输入而言，等待输入块有256帧的缓冲要求，接口不保证零延迟。内部生成声源可提前产生自己的激励，见`../spectral_texture/`；不得把这种前取解释成任意外部输入无延迟。

最多8192系数、每个有限且绝对值不超过64，输入幅值不超过1e100。长度／幅值共同保证FFT及乘加远离双精度溢出；这些是数值域，不能当作声学模型合格条件。无效输入在修改历史之前返回失败，输出数组不可指向内部状态。

# 启动细节原生接入

此目录只放接入检查；声源仍由 `sound_dna`、`dna_atlas`、`residual_atlas`、`start_texture`、`catch_bloom` 生成，驾驶时间由唯一 `VslDrive` 推进。

- `checks.c`：普通／可选模型相容、载入失败不改原资产、12带残差由行程独立持有。
- `ui_checks.c/.h`：向本程序自己的窗口发送控件消息，检查细节量、音色／模式切换、无模型时禁用控件；不启动音频，不代替鼠标操作或目视检查。

入口 `Launch-Startup-Detail-Study.cmd` 使用独立构建。默认停止、点火关闭、启动50%、接火50%、细节0%；只对A启动车内趋稳模型启用这组细节。模型在非实时侧载入，沿用 `.vslrun` schema5／27字段，实时DSP及已认可的车外模型不改。

构建和设备证据见 [接入记录](../../research/启动细节原生接入V1.md)。这些是功能验证，音色仍待听评。

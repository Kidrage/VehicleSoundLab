# 完整频谱与弱细节诊断 V1

本轮补齐有限片段起止点和谐波之间频率的约束，完成同一台 V10、F3 两次升速各早／中／晚六份输入的统一拟合。**整体波形接近不等于高频细节和左右关系已经保留。** 现有认可音色、670 份 C／H、82 份音色参数、唯一驾驶器和录放格式均未改变。

## 实现与模块

`tools/observer_complete_v1/frame.py` 负责完整有限长 Hann 变换：4096 点窗、256 点 hop、全部频率格，包括 DC／Nyquist；窗口向两端延伸，以每个录音内采样的窗口平方覆盖归一化。录音外补零只定义有限向量运算，不是假设真实车辆在片段外静音。

`synthesis.py` 保持原 288 阶次、双声道复包络节点与插值，提供实 OSC 合成和波形伴随；`fit.py` 负责新的数据目标、原曲率／岭项、可逆右预条件和求解状态；`metrics.py` 负责与原观察器比较。运行、独立数值审计、发布、发布审计和归档分别由独立脚本承担。它们都是离线分析模块，未进入音频回调。

新目标为 `||S(s*q)-audio||² / sigma² + 0.001||D2*q||² + 0.000001||q||²`，`sigma` 是整段双声道联合 RMS。完整归一化 Hann 变换满足 Parseval，因此其全频谱平方误差与这里的波形数据项严格等价。这是**新目标**，不等于上轮按阶次归一化的谐波目标；旧结果与门槛完整保留。

七组已知完整窗控制覆盖首／尾脉冲、相邻载频、谐波之间高频、右声道静音、任意信号和零信号；另有四组合成／伴随及三组显式稠密求解对照。独立 SciPy STFT、闭式脉冲、标量 OSC、显式矩阵与预条件列范数校验通过，随后才进入六份素材。

## 结果

所有结果都用原 Hann4096／hop256／全局解调重新观察，保留全部 288 阶次、六频带、六组载频的 12×12 复数 Gram、Parseval、有符号交叉项和三个连续时间分区。24 组重建、11520 个频带 Gram 及全部发布行／改善退步计数经过独立实现核查，两张图逐张查看。

| 描述性指标，六份输入均值 | 旧观察行插值 | 旧谐波目标 4000 步 | 新完整目标 4000 步 |
|---|---:|---:|---:|
| 整段波形 NRMSE | 0.43140 | 0.28030 | **0.00211** |
| 内部波形 NRMSE，去首尾各 2048 点 | 0.37718 | 0.18849 | **0.00228** |
| 完整频带功率绝对误差，dB | 3.5328 | 0.7532 | **6.6169** |
| 复数左右关系误差 | 0.04545 | 0.02236 | **0.13915** |
| 频带功率 CV 误差 | 0.05927 | 0.05323 | **0.09750** |

新结果对旧谐波 4000 步：6／6 整段与 18／18 区域波形误差改善，但 59／72 频带功率、29／36 左右关系、48／72 时间 CV 变差；分成三段后仍有 175／216 功率、77／108 左右关系、131／216 CV 退步。全部比较和第三个旧校正基线均保存在 JSON，不按频段挑选胜者。

新结果各频带的平均有符号功率偏差为约 `−0.00007 / −0.676 / −4.240 / −10.831 / −17.437 / +6.446 dB`，频带依次为 `0–3 / 3–6 / 6–8 / 8–10 / 10–14 / 14–21.6 kHz`。原始频带绝对能量也随每行输出：这些局部录音的低频远强于高频，微小全局残差仍能伴随很大的弱频带相对损失。最后一带尤其弱，不能把其相对误差直接解释成可听响度变化。

**六份求解全部达到 4000 步、stop7，原空间相对梯度约 2.61e-6 至 4.15e-6，未达到 2e-7 门槛且停止码不合格。** 尚不能把观察到的高频衰减全部归因于目标权重，也不能称其为精确最优解的性质。波形小误差、数值验证、求解收敛、持续生成和听感是各自独立的要求。

发布第一次因原素材存档没有预存三分段统计而失败，执行源码与失败记录保留在 `review1`；`review2` 仅从原始功率／复交叉数组重新计算同样的三个时间分区，未改音频、节点、求解或门槛。

## 决策与下一步

本候选不推广到实时 C，也不将这六段拟合节点循环充当持续声源。下一步先在已知“强低频＋弱高频、不同时间曲率”信号上用显式稠密解区分非收敛与目标尺度效应；再验证保留全部频率／端点、左右共享频率权重的约束方案及其伴随／尺度／零信号／条件数。权重只用于离线拟合误差，不能被当成给产品加亮的 EQ；新目标必须明示，并继续用原观察器核对所有六份输入。

在获得合格潜在时间表示后，才拟合统计持续声源、检验原生 48 kHz 带限、声纹稳定性和算力，再决定 C 移植及听评。不得直接降低调制速率、缩减分音／因子或只强化独立高频 OSC 来掩盖问题。

产品结构仍是 V6 的 DNA／BODY／DETAIL／EVENT／AUX 五层、一个驾驶控制器和未来独立的空间渲染器；这次既未增加房间模型，也未证明多发动机、完整状态或物理 7.1.4 已完成。完整目标继续。

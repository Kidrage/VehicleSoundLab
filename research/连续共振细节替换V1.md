# 连续共振细节替换 V1

2026-11-12。承接[高频质感诊断](DNA高频质感诊断与优化V2.md)，已实际生成两个素材驱动的离线候选。它们减少高频周期重复结构，**机械自然度尚待听评**；原C／驾驶／原生窗口和默认模型不改。

[单播放器试听](http://127.0.0.1:8789/references/analysis/resonant_detail_v1/review1/index.html)可切换原版／替换35%／70%、完整／四个频段、短对照／7.5秒持续生成片段。录音参考仅在短片模式可选，不循环。所有输出统一0.5源增益；分频不单独放大，无逐条响度补偿。35条音频只是播放器切换所需文件，并非35个候选或35份录音。

## 这次实际改变什么

- 主声线仍用已有固定相位Sound DNA C核。将1.2–1.9kHz平滑过渡以上的谐波功率削减35%／70%，共同正增益同时作用于均值、basis和残差root；低阶原模型行保持，幅度RNG／AR相关系数不改。
- 根据同一A移动尾排归一化参考的局部谱形，为八带拟合稳定24阶全极点滤波器和后置带通。新的逐采样随机激励持续进入滤波器，输出有带宽、有衰减的细节；没有稀疏固定正弦云的永久载波，也没有新锯齿／摩擦模板。
- 1.9–3／3–6／6–8kHz用此前通过双向留出的弱周期功率形状；前两个1.2–1.9kHz子带未通过，保持平坦。用16个傅里叶系数计算能量包络，不存录音时间轴或周期PCM波形。没有加深共同PM或回到每根谐波独立摆相位。
- 按实际剩余C DNA＋原LF的频带功率计算固定补入量。理论预算包含AR频响、包络侧带、后置带通和2048帧Hann测量窗口；非负最小二乘给出每带固定增益，随后三个随机种子全部沿用。没有听一条后再单独归一化。
- 已认可独立相干LF分轨及scale保持。这里只保证该分轨／低阶模型行未改；随机细节滤波有边缘泄漏，不能称整个混音低通波形精确相同。房间处理全程关闭。

这是**OSC主声线＋连续随机激励／共振细节**，不是严格纯OSC，也不是事件触发器或素材循环。用户先前已允许事件激励／共振算法边界。本轮细节拟合音色纹理，不构成已分离的物理摩擦、进气或排气声源。

## 数值与听感边界

| 配置 | 三种子6–8k周期重复相关范围 | 八带平均功率最大误差 | 共同增益后最高峰 |
|---|---:|---:|---:|
| 原版 | 约0.790 | 部分带本已有偏差 | — |
| 替换35% | 0.537–0.543 | 0.118dB | 0.547FS |
| 替换70% | 0.230–0.247 | 0.200dB | 0.551FS |

重复度取固定0.5秒后约1.217秒块、一个声学周期间隔、左观察声道；并非8秒整体相关。参考6–8k约0.057，因此70%仍未到参考结构。左右及1／2／4周期的完整测量在原始报告，不能解释为物理噪声比例或真实度。

**统一替换量也有局限**：1.2–3k以及3–6k在强档可能比参考分散得更多。例如参考3–6k约0.602，35%约0.530–0.543，70%约0.272–0.278。下一步要根据分频听评确定哪些带保留原声线，不能因最高频指标改善就将70%设默认，也不直接由相关比值计算“真实分离比例”。

最大左右复相关误差约2.58e−7。A原段近双mono，新细节只用共同激励和每带R/L比例，未拟合非零延时／真实宽度。保留原DNA／LF的L/R，不能据此宣称新增stereo空间，更不代表物理7.1.4。

最慢AR极点半径0.9994544，低于预定0.9998门槛；2秒暖机后才输出。已知阻尼振荡对的独立递推误差0、直接复频响误差<9.15e−15；带周期AM的理论Welch预算与20秒实际输出最大相差0.0412dB，低于预定0.25dB。两个替换量共六条实际float混音通过原定0.5dB功率／峰值检查；原C削减与独立谐波和之差<2e−7FS，零削减C样本精确回到冻结DNA。

这些只验证生成和预算。前后半留出属于同一1.217秒归一化录音，不是其他片段／发动机验证；全部RPM、负载、启动、换挡、断油、回火和原始录音的非周期时间结构仍未由本模型覆盖。均值合格不能消除风声／嘶声／沙感风险，以试听为准。

## 模块及工程接入

```text
原DNA模型 → 派生谐波增益 → 原Sound DNA C核 ─┐
模型参数 → 连续新激励 → 稳定共振 → 弱包络 → 带通 ─┼→ 干声混音 → 可选下游空间
原独立LF分轨 ────────────────────────────┘
```

| 文件 | 责任 |
|---|---|
| `tools/resonant_detail_v1/envelope.py` | 只读已验证的周期功率形状，逐样本计算正幅度 |
| `filters.py` | 离线拟合稳定AR／带通、理论侧带及Welch功率预算 |
| `voice.py` | 只消费参数与种子，持续激励／滤波；不读取录音 |
| `controls.py` | 独立递推、频响与理论功率已知控制 |
| `fit_resonant_detail_v1.py` | 哈希绑定素材、原C导出、预算与模型拟合 |
| `render_resonant_detail_v1.py` | 三种子重合成、实际float音频核查 |
| `review_resonant_detail_v1.py` | 同增益分频／长短片与单播放器 |
| `voices/resonant_detail_v1/detail.json` | 纯参数快照，无PCM／时序轨迹；尚无C加载器 |

当前新核是离线Python原型，没有新增C/H；原478份C/H及认可模型哈希保持，不重复47项既有CTest。35条PCM24通过HTTP字节核查与FFmpeg解码，播放器JS通过Node语法检查；没有声称真实浏览器交互／设备／长时或12扬声器验收。

若听评成立，再把**参数校验、连续激励、共振滤波、包络、独立混合量**分别移入C；使用现有C同规则xorshift／Box–Muller创新，避免再静默更换随机过程。先证明已听候选的信号一致性，再让同一个驾驶器传入相位／状态。不把房间、文件、UI或车辆状态机塞进声源内。

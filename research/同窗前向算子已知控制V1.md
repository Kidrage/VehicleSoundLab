# 同窗前向算子已知控制 V1

新增离线 `observer_forward_v1`：输入各阶次的复包络节点，线性插值为逐采样包络，合成为双声道实波形，再通过原素材分析使用的 Hann4096／hop256 与全局相位解调。前向算子和实内积下的伴随已实现，七项已知控制及独立数值核查通过；**尚未反演实际素材，也未建立新音色**。

这一步为后续“生成后经过同一观察器拟合”提供基础，避免把观察到的窗口统计直接当成不可见的逐采样发动机轨迹。算子是实线性的，复系数输入必须采用 `Re〈y, Fz〉 = Re〈F*y, z〉` 的合同，不能把实波形合成误当成复线性映射。

模块划分：`operator.py` 负责插值、OSC、FFT 观察及伴随；`fixtures.py` 定义已知控制；`audit_oracle.py` 使用独立标量插值／cos-sin、直接 DFT 和显式节点帽函数验证。运行和审计宿主分开，执行源与输入／输出快照保存到本地。

| 已知控制 | 验证内容 |
|---|---|
| 固定复包络 | 原观察器的幅度、相位和声道排列 |
| 幅度斜坡 | 时间插值与窗口平均 |
| 旋转复节点 | 节点间复平面插值；不冒称恒模纯相位插值 |
| 相邻载频／镜像泄漏 | 保留邻阶次及实信号负频率像的影响 |
| 非对称／右声道静音 | 左右独立与严格静音 |
| 伴随 | 原始实内积恒等式及独立逐节点梯度 |
| 欠定空方向 | 非零波形可以在所选有限谐波观察行上为零 |

最大独立波形误差 1.554e−14 FS，直接 DFT 误差 2.712e−15 FS，伴随误差 1.066e−15。37／1024 块合成逐位相同，双声道案例同时与原 `sound_dna.windowed.coefficients` 对照。

空方向控制有 76 个实输入、12 个实观察量，秩 12、空空间维数 64；其中一条波形 RMS 为 0.13657 FS，所选观察量最大约 1.923e−17 FS。该反例仅针对控制中选定的两个阶次／三个窗口，不代表其完整频谱或所有宽带特征相同，也不证明真实素材反演必然存在同等规模的歧义。它要求后续反演明确正则化与可识别范围，不能仅凭谐波观察误差接近零就宣称还原了原声音。

下一步读取全部六份原冻结素材及原 native／warp 坐标，构建带正则化的潜在时间轨迹推断；必须同时报告原观察器残差、条件性、未解释频带和短段退步，再把轨迹统计化为无素材时间线的可持续声源。原生 48 kHz、听感、目标成本与 C 移植另行验证。

本轮不改 C、参数、驾驶器或默认声音；继续保持 V6 五层与独立未来空间接口。完整多发动机／全驾驶状态／实际 7.1.4 目标仍进行中。

# 原始算子修正与存储 V1

本轮解决上一轮带状提取中延迟右声道的数值资格问题。同一原12组及独立左右8组均经独立原方程核查通过；延迟右声道的完整停止量从1.241115519952177e-11降至1.0292987912057811e-14，原门槛仍为1e-11。这是离线提取可靠性的进展，还没有生成或替换新的持续音色。

## 为什么需要修正

带状度量准确保留了原有限窗的所有非零条目，但分解舍入使根模型内部的小残差不足以证明原FFT目标通过。上一轮原12虽通过，独立左右8组仍只有7组通过；可逆对角缩放也只有4/5。失败及额外严格Gram诊断完整留在`baselines/waveform_banded_v1`，没有重新标成通过。

现在只把旧根／QR当作预条件，误差从完整原FFT及其伴随重新计算。每个案例固定执行两次修正；原音频、左右目标、尺度、窗口频点、阶次、节点及所有资格门槛均不变。

## 模块

| 文件 | 职责 |
|---|---|
| `tools/waveform_correction_v1/inverse.py` | 用右正交基与内层QR应用逆正规算子；保留全部方向，避免Woodbury相减 |
| `correct.py` | 两次原FFT完整法向修正，同时维护稳定波形残差及三步历史 |
| `problem.py` | 恢复小型已知原问题，并按完整方程评估；显式拒绝大于512未知量的问题 |
| `fixtures.py` | 大／小尺度、秩缺失、混合旋转等逆算子控制 |
| `native_triangular.py` | 实验性原生leading-dimension三角访问，不复制方阵T；尚未接入求解器 |
| `tools/audit_waveform_correction_known_v1.py` | 独立完整FFT／载波矩阵、标量Householder、两次轨迹、左右静默和全部原门槛 |
| `tools/audit_waveform_correction_resources_v1.py` | 因子别名／存活账目、原生访问与条件资源算术；不分配完整问题 |

加权源QR的上梯形部分为F，令`Fᵀ=Z[R;0]`，再将`[I;−Rᵀ]=UT`作QR，得到：

`(I+FᵀF)⁻¹g = Z diag(T⁻¹T⁻ᵀ, I) Zᵀg`。

生产实现以反射器应用正交变换，不显式保存完整Q、不截秩、不以正规方程分解代替QR。单位补空间的全部方向也保留。独立小型审计可以展开Q或高精度矩阵，仅作为核查。

令节点惩罚为`R_penalty=L Lᵀ`，系数`q=L⁻ᵀz`、稳定波形残差为e，每步计算：

`g=L⁻¹ Φᵀ W_original e + z`，`δz=−P g`；

随后更新`e←e+Φ L⁻ᵀδz`及`z←z+δz`。每一步都保留旧结果、更新量和原完整法向，核对系数／波形一致性。

## 资源与原生访问

原12及共享8生产进程累计工作集峰值分别为107,155,456B及98,865,152B。这次从旧档案选择性读取X和小状态，不重新建全部基因子，不能与上一轮完整建因子的413MB直接比较并声称整体提取更省内存。登记账目也只覆盖注册的数组；评估、调用方及库临时分配另由进程峰值反映。

新增右QR、内层QR及方阵T都会增加存储。完整12289／49／288的修正阶段主要数组小计为9,173,984,280B；旧带状构建阶段小计8,368,514,064B。两阶段释放／重载尚未接成完整路径，不能只取较大者就宣布可运行；若全保留，必须把新增因子同时计入。

实验性原生三角访问直接使用内层`2k×k`QR的上三角，传入实际leading dimension，避免单独复制`k×k`T。20个实际已知因子及3个补充非整齐形状的正／转置解均通过；原QR只读且逐位不变、右端原位更新，另有5种错误／奇异输入被拒绝。这只证明当前主机的已声明SciPy Cython LAPACK ABI，尚未替换`NormalInverse`，也不是21569代码。

若未来分阶段释放且保留当前方阵T，六段原素材主要数组约12.02–12.60GB、上下文约19.99–20.73GB；加同一1.5GiB临时／原生预留与3GiB余量，分别要求约16.85–17.43GB与24.82–25.56GB。当前六段两种情况都未通过资源门槛。去掉T的实验也仍需实际集成、完整资源证明，不能从23组原生访问通过直接推广。

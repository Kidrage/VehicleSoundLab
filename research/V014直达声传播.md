# V0.14 · 直达声传播

新增一个默认关闭的试听选项：**Sound detail → Source distance / stereo depth**。它根据独立声源与监听位置，计算距离衰减、stereo 左右耳的到达时间和简化的远耳高频遮挡。7.1.4 使用监听中心的传播路径，然后做扬声器声像分配，不向扬声器床写入耳机用的双耳滤波。

当前版本 0.14.0，构建目录 `build-v014`，入口 `Launch.cmd`。关闭选项会保留 V0.13 的声音。对照页 `V014试听.html` 提供六组使用共同固定增益的比较；主观真实度尚未获得确认。

## 为什么补这一层

你指出的左右差异需要在“声源”和“听到的通道”之间建模。已有录音分析显示，A 的车外声道非常接近，B 的车内双耳差异更大；这些是麦克风观察，不能等同发动机两侧，也不能直接把 B 的宽度套到车外。

核查冻结 V0.13 的 `spatial/scene.c`：已有十个独立物体、频率相关低频合并、几何声像、车内简化遮挡和两路早期反射；直达声主要使用增益声像，没有计算每个物体到左右耳的不同传播时间。本轮保留既有声源和声场路径，增加可单独验证的直达传播模块。没有根据 A／B 的通道统计拟合耳间距、头部滤波或排气空间宽度。

GitHub HEAD 重新核对仍为 `ac2b37d8639027d79934a2023cf8d1d37d3b2f96` 的 V6 基线，证据在 `upstream_head_v014.json`。继续沿用其驾驶控制 → 工况 → 分层声源 → 空间／输出的组织；这次几何传播是本地 C 扩展，不是声称 V6 已包含经过测量的双耳模型。

## 实际处理

坐标继续使用车辆前方为 +x、左方为 +y、上方为 +z；监听者面向车辆 +x。stereo 耳位置为监听中心沿 y 轴 ±0.09 m。每个物体到接收点的路径长度为 `r`：

```
物理传播时间 = r / 343 m/s
stereo 每耳增益 = (1/√2) × 1.4 m / max(r, 0.35 m)
speaker bed 中心增益 = 1.4 m / max(r, 0.35 m)
```

1.4 m 只是显式的幅度参考，0.35 m 防止点声源近距离发散；源振幅没有经过绝对声功率标定。车内遮挡保留原模型。远耳额外混入 1800 Hz 一阶低通，最大比例 0.65、按相对横向方向缩放。它提供一个有方向的高频差异，是工程近似，不是实测 HRTF、耳廓、头部衍射或人体模型。

左右分别读取同一个物体的延迟线，不为两个耳朵另造发动机转速或随机波形。7.1.4 仅读取监听中心路径，不套每耳增益／头部滤波。几何参数变化与开关用 18 ms 跟随；新模式的 WIDTH 在最终 M/S 输出控制宽度，零宽度也合并反射和滤波历史。旧模式保留原来的增益／WIDTH 行为，避免悄悄改旧音色。

早期反射和源 IR 仍按原通路处理；本轮没有完成真实房间、地面、车身遮挡或随距离变化的反射模型。新直达声与已有反射混合后的比例也只是预览。Pure OSC 可以选择该传播监听；源端随机声层与源 IR 仍被旁路。

## 高频与短距离边界

最初检查发现，低阶分数延迟插值会削弱高频；因此采用 **25 抽头 Blackman 窗 sinc、256 相位表并在相邻相位间插值**。相位表在初始化建立，音频过程中只读表、积和，不分配内存。每相位保留单位 DC 增益和正确一阶矩。延迟线即使旁路也继续更新，切换时已有连续输入历史。

测试还发现低采样率下，部分车内近距离路径短于滤波器所需的因果长度。修正为所有路径共同增加 **13 个采样的算法延迟**，并单独写入元数据；48 kHz 下约 0.271 ms。它不计入声学距离，也不改变左右几何时间差。当前支持 16–192 kHz；所有现有物体和 101 个车外至车内位置的路径均不触及延迟线限制。未来修改坐标超出缓冲范围时有明确钳位计数。

实际 C 模块导出的控制结果：

- 车外监听、左尾排物体：纯几何左右到达时间差约 **204.124 µs**。最终左右相位还受到头部滤波、其他声源混合与房间反射影响。
- 48 kHz、17 种分数延迟，28 Hz–20 kHz：相对理想延迟，最大幅度误差 **0.1893 dB**，最大相位误差 **0.6234°**。
- 16／48／192 kHz 实际几何脉冲：DC 增益和近耳／监听中心的有符号脉冲一阶矩与配置一致；远耳滤波具有额外的频率相关相位。

这些是有限测试条件下的数值误差，不是任意移动延迟的无混叠证明、接近 Nyquist 的透明度证明或声浪真实度评分。

## 兼容、实际导出和设备检查

默认开关为关闭，新预设显式保存 `propagation`。缺失此字段的 V0.13 及更早预设继续使用原有空间模型；不会因为加载而增加宽度或改变其他参数。主界面布局保留，一个选项放在现有细节窗口。

16 项 CTest 通过，新增检查包含脉冲到达／增益、镜像与居中对称、采样率与近距离边界、连续切换、不同宿主分块、启用传播后的 Pure OSC 种子独立，以及实际源样本／完整驾驶状态独立。

实际 WAV 验证：六组场景中，关闭传播的 V0.14 输出与冻结 V0.13 逐字节相同；五款模板另外逐一复现旧输出。开启后，30 秒驾驶的十个 pre-spatial float32 声源，与关闭传播、冻结 V0.13 及 7.1.4 导出逐字节相同；驾驶 CSV 也完全相同。变化发生在声源之后。高度声道继续只放早期反射，speaker bed WAV 不是 Atmos 对象封装。

静音 native UI／设备实测中，新增开关的实际点击、参数隔离、非默认预设往返和旧预设回退均通过；设备状态确认传播已启用。512 帧平均渲染 **1.6517 ms**、最大 **4.3085 ms**，设备时间 **10.6667 s**／墙钟 **10.7892 s**，空队列观察 **0**。这证明当前机器的测试过程正常运行，不代替实际监听。

## 如何试听与未完成事项

先用耳机在 `V014试听.html` 对照 1200／4000／8000 RPM；这三组关闭早反射，便于判断直达声。驾驶组保留原来空间参数，另有车内预览和导入 DNA。每组共用一个固定增益，不分别归一化，因此车内组距离衰减带来的约 3.1 dB 录音整体电平差仍保留。

需要判断的是：位置感是否自然、耳间时间差是否让某些频率变薄、电子感是否仍由声源本身主导。扬声器会叠加物理双耳串音，不能据耳机上的宽度直接验收车载或 7.1.4 回放。启用几何传播不意味着应该尽量调宽。

主排气 RPM×负载谱形、真实进排气传递、弱高阶分量、实际 NVH 参数和主观音色仍待验证。动力学的物理阶次／RPM、惯量与损失、生命周期耦合、完整 DCT 轴系／轮胎模型也未完成。上一轮补油落转观测的歧义仍然成立。本轮没有用额外随机高频噪声或修改发动机声纹掩盖这些缺项。

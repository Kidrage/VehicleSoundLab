# 多锚点 DNA 驾驶接入 V1

2026-11-11。新 Sound DNA 已通过独立 C 适配器接入原驾驶控制器，可按转速连续过渡模型、响应启动／负载／换挡／收油，并导出原始观察、分层、对象与stereo／12通道。**当前是E车内两档高转锚点的工程验证，音色听评待定；完整低转／负载／工况库、原生驾驶UI和设备稳定性尚未完成。** 已认可A车外DNA与相干低频保持独立，旧DSP0.20.0和take schema5不变。

## 代码边界

| 模块 | 核心C文件 | 作用 |
|---|---|---|
| 素材统计模型 | `modules/sound_dna/profile.c`、`texture.c` | 原`.model`解析和统计调幅，不重新训练已认可模型 |
| 多锚点声源 | `modules/dna_atlas/bank.c`、`voice.c` | 共同周期起点、相位分支、唯一OSC时钟、相邻模型插值、边界诊断和高阶抑制 |
| 驾驶适配 | `modules/atlas_drive/control.c`、`render.c` | 输入校验、唯一驾驶时钟、工况增益包络、事件、分轨与空间调度 |
| 既有驾驶／状态 | `src/drive/`、`src/core/orchestrator.c` | 原车辆、换挡、生命周期和分层包络；工程参数，非Lamborghini逐车标定 |
| 对象和空间 | `modules/dna_scene/routing.c`、`src/spatial/` | 显式观察投影、双出口各半幅度、stereo／12通道 |
| 文件宿主 | `experiments/atlas_drive_v1/probe.c` | 输入脚本、float WAV、200Hz CSV、配置及性能记录；不在DSP里做文件I/O |

初始化顺序：`sa_bank_init` → `ad_render_init`。音频运行：`ad_render_set` → `ad_render_process`。模型、bank、voice、驾驶和空间存储均由宿主管理。详细参数边界见[声源接口](../modules/dna_atlas/README.md)与[驾驶适配器](../modules/atlas_drive/README.md)，后者附模块图。

## 声纹过渡与相位

两档来自E89.3–90.3秒、90.6–91.6秒，沿用288谐波、12统计分量、四周期Hann分析的原模型，根频率60.634／64.847Hz。初始化时用低32阶复均值求相邻模型的共同L/R周期偏移，本次第二档为−0.123597rad。独立NumPy复均值相关核对通过；拟合分数由0.074779到0.093361。该分数只检验任意周期原点的配准，不证明音色自然度或物理时序识别。

运行时共用一组OSC，相邻谐波幅度与确定性平均相位分别插值，避免直接平均相反的复系数形成中点衰减。随机细节仅调幅，不引入原先被指出的随机相位震荡。左右相位差沿共同分支过渡；它们仍是录音观察，不能当物理左右缸列。全部模型的随机状态持续推进，静音和权重0不重置。

根频率不钳在训练区间。区间外按实际驾驶音高生成、采用边界声纹，并记录覆盖标记；1e−8Hz容差仅处理平滑器渐近到端点的数值误差。各谐波19.2–21.6kHz平滑归零，避免静态高阶越过奈奎斯特；快速控制／调制仍可能有边带，不能视为任意输入严格带限的保证。

## 驾驶状态如何接入

唯一的原控制器每240样本／5ms推进一次。新源根频率取RPM/120，此映射仅采用E高转仪表与多谱线的有限证据；没有转移给A。工况增益复用现有`voice.dna_gain`，再以18ms接到音频率；模型过渡只由该持续根频率决定。没有播放旧DNA，也没有运行两套驾驶积分器。

这版已接通的状态差异是增益、换挡切断／恢复、生命周期和音高路径。尚未训练怠速、收油、不同负载或换挡瞬态各自的DNA模型，也未套用原DNA的谱倾斜／截止。回火／换挡／起动机可选复用`events.c`，默认事件增益0；这仍是旧程序事件，不是新实录拟合或已认可的事件音色。车内独立低频／进气／机械／噪音源为空。

自动30秒脚本产生8次挡位事件、2次收油事件，仅约6.08%的整段样本落在两个锚点之间。此脚本是原控制器的踏板场景，不是复现E视频的实测驾驶轨迹。高转有锚点依据不等于对应负载／工况均有实录覆盖；下一步优先补A车外的低转与多工况模型，再形成有来源的状态库。

## 验证与局限

最终统一构建29项CTest全通过。新增解析控制验证：原单锚点声源等价、同谱锚点不产生幅度凹陷、已知相位过渡、共同L/R配准、正弦表边界、随机状态不中断、块大小一致、抗混叠和非法参数拒绝。驾驶适配器与原控制器逐步一致，源时钟不受静音／布局影响；未连接层静音。

八组真实模型导出覆盖自动、空挡、升降挡、事件开关、两端／中间稳态及12通道。自动两种布局的原始声源与200Hz遥测逐点一致；所有输出有限、最高峰0.39949。对象和干声混音在float32量化误差传播界内一致，保留原始L/R差异与非循环统计变化。房间0时高度通道按设计静音，不人为给每个扬声器填声。

离线5ms块的平均处理低于预算，最终场景中仍有超时块：自动stereo11块、12通道9块、升降挡10块；最坏约8.49ms。这里包含宿主调度影响，未做waveOut队列或实际扬声器验证，不能声明已满足实时稳定性。后续接原生驾驶UI时单独检查音频块、设备队列和控制采用时序。

首次导出发现事件层／事件对象同名路径，已分开并加路径去重；最初文件仅保留作无效导出留痕。初期验证器误用短对象名、过严的绝对舍入阈值、以及“每个空间通道都必须非零”的假设；已按实际对象名、float32半ULP传播和当前空间路由修正。随后补齐正弦表极小负输入边界、覆盖端点容差。此前输出全部保留，最终依据为`final_v3`，没有把这些导出／验证问题记为听感失败。

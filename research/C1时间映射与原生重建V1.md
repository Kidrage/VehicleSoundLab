# C1 时间映射与原生重建 V1

2026-11-16。研究目标是确认经过共同相位时间映射后，原录音的声音信息能否恢复到原生 48 kHz，尤其检查高频、左右关系和时间变化。它是离线提取前端的验证，不是持续声源或新的音色预设。

上一轮为 MCPS 复核，没有合成进展。本轮按已知信号先行、独立复核、同一真实片段诊断的顺序执行；结果见下方。

## 方法与模块

保留上一阶段的 89 个观测节点和单调 C1 三次曲线。反向查询在每个区间求三次方程的根，使用带括区间保护的 Newton 迭代，禁止越出观测支持范围。独立审核另写加权调和斜率与归一化 Hermite 系数，通过 48 步二分法逐点解方程；不把正向生产实现当作独立证明。

每个物理查询的时间为 `native_start + integer_tick / (48000 × up)`。C1 与原分段线性时钟分别反查原相位网格，使用原已核验的半径 128、Kaiser12 sinc 重建，再经 22 kHz 物理低通及有效区降采样。16／32 倍分别使用 4097／8193 taps，并保留前后各 128 个物理帧的真实上下文。没有补零或外推。

独立实现另按全部 256 个 sinc 偏移累加每个稠密样本，用显式 Kaiser-sinc taps 和 polyphase 检查全部原生输出，并对 33 个输出点直接做 FIR 点积。

`tools/clock_native_bridge_v1/` 按功能拆分：

| 模块 | 职责 |
|---|---|
| `inverse.py` | 支持范围内反时钟和正反闭合 |
| `render.py` | 共同物理时间网格、相位网格重建与原生滤波 |
| `controls.py` | 解析时钟、声道对照和原八个录音上下文控制 |
| `observation.py` | 原生全频点、六频带及四个高频分组观察 |
| `audit_inverse.py` | 独立系数、二分求逆与全部查询闭合 |
| `audit_render.py` | 独立逐样本重建、滤波与输出检查 |
| `audit_observation.py` | 独立 Welch／CSD／直接 MS 及冻结序列统计 |

运行、独立数学审核、补充绑定、发布、发布审核与归档分别有 CLI。所有执行源码和参数留存。实时 C、认可音色和驾驶器未修改。

## 已知控制

22 个案例：八种原时钟（含 160 秒绝对时间起点）、mono／zero／weak／0.35 ms 左右延迟四个路径、近奈奎斯特与纯阻带两个案例、原八个录音上下文案例。

沿用预先声明的门槛：普通解析波形 NRMSE 小于 0.003，原八个上下文波形小于 0.005；纯阻带按原输入峰值衰减不大于 1e-5 检查，零／mono 保留精确身份。所有案例仍单独记录六频带的 16／32 倍收敛旗标，不用波形合格替代频带合格。

已知生产结果：22 个波形／衰减检查通过；八上下文最大 NRMSE 为 `7.062246214987282e-6`，源网格正反时间最大误差 `1.423954343245886e-14` 秒。纯阻带输出峰值／源峰值为 `2.5727868156401956e-7`。

**两项频带收敛失败保留：** `near_Nyquist` 的若干空白／弱低频带，及 `pure_stopband` 的残余频带。纯阻带整波 16／32 NRMSE 为约 0.00588，其 6–8 kHz 极弱带相对误差约 317.59。没有能量抬底、换门槛或删掉这些案例。上述整体资格与频带收敛是预先分开的判据。

## 真实诊断与独立复核结果

全部 22 已知案例的独立数学审核、11 类非法输入拒绝和补充绑定完成后，才处理一条冻结的 `F3 Fifth First Mid`：原生起点 `160.39166666666668` 秒、10372 帧，原 288 阶／74 拟合节点／18434 源网格查询不动。C1 和原 PL 分别在 16／32 倍重建，共四条。

| 实际物理检查 | 结果 |
|---|---:|
| 独立 C1 求逆全部查询最大差 | 3.55271e-15 cycles |
| 独立正反闭合最大差 | 2.84217e-14 秒 |
| 独立稠密重建最大差／源峰值 | 2.93889e-15 |
| 独立全部原生 FIR 最大差／源峰值 | 8.92553e-15 |
| C1 32 倍结果对源 FIR 参考整波 NRMSE | 8.95971e-8 |
| 同参考 0–14 kHz 最大功率变化 | 5.22656e-7 dB |
| 同参考 0–14 kHz 最大复相干差 | 1.61390e-8 |
| 同参考 0–14 kHz 最大功率 CV 差 | 1.24159e-8 |
| C1 16／32 整波 NRMSE | 3.29701e-9 |
| C1 16／32 最差频带 NRMSE | 4.99827e-6，低于原 0.003 门槛 |

C1 16 倍／32 倍共有 170033／340065 个真实支持查询，独立核查覆盖每个查询和稠密样本、全部 10372 个原生输出。原 PL 同样核查。真实两条时钟的全部六频带收敛均通过。

**C1 往返能保留已经经过源 FIR 的声音；不能恢复 FIR 已去掉的声音。** 对未滤波原声，C1 32 倍在 10–14 kHz 的复数 NRMSE 仍为 0.0114524，14–24 kHz 为 0.991113；仅原 FIR 对原声已分别为 0.0114524 和 0.991113。14–24 kHz LR 合计功率约从 1.20338e-9 降至 4.20123e-12 FS²，约低 24.57 dB。该片段最高频段本身很弱，不能仅凭这项比例声称解释了此前所有可听电子感。

C1 对源 FIR 的最高带 NRMSE 为 9.62506e-6，原 PL 为 0.00206731，说明 C1 的物理往返误差更小；两者的整波误差都很小，不直接等同于可听自然度改善。原声与滤后声音最高带的 Side/Mid、复相干和 CV 差异也全部保留，不能用整体协方差的小变化掩盖高频缺失。

独立 Welch／CSD／直接 MS、原六带、四个最高分组、全部 2049 bins、冻结序列统计与所有有符号比较核查通过。没有宣称修复此前五个极弱谱线的跨 FFT 归一化失败或建立其认证误差界。

## 与完整系统的关系

该桥只检查离线提取前端的信息损失。原生录音、原有源 FIR 后的参考、C1 重建和旧时钟重建必须分别比较；源 FIR 已经去掉的物理高频不能靠反时钟恢复。所有观察沿用原始增益，不做时间对齐、响度匹配、左右折叠、扩宽或房间处理。

录音 LR 的互谱、直接 Mid／Side、功率 CV、完整协方差与 1–8 lag 变化用于检查素材的立体声与时间结构；不把它们直接解释成十二路物理声源。未来 7.1.4 仍通过独立空间渲染，声源与房间／IR 保持可拆分。

下一步是显式的新输入适配：保留旧 `metric_target` 标尺、weights／sigma／floor／amplitude／scale／完整 orders 和节点，另外标明新时钟、新源坐标和实际分析带宽。先做完整已知方程验证，不以本次重建替代声源拟合资格。高频带宽必须单独核算；尤其低转速的阶次网格不能无条件承载全物理高频，不能把缺失功率全部加给 DNA。原拟合系数不能直接挪到新时钟，拟合轨迹也不能循环成为发动机。

原目标最高带 `0.44248390217893097 > 0.02`、source fidelity false、持续统计准入 false 和所有旧失败保持。本轮不重拟合 FirstEarly／FirstMid、不启动其余四个拟合、不推广 C 或提出新听评。后续见 `clock_native_bridge_next_v1_plan.json`。

完整目标继续为多真实发动机、全部视频工况、V6 DNA／BODY／DETAIL／EVENT／AUX 五层、唯一驾驶器、自主持续联合 LR 声源、模块化 C、owned／takes 及独立物理 7.1.4；这些不能用一次时间往返验证宣布完成。

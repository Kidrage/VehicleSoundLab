# F3 原生频谱区域与包络 V1

**当前六段加速素材在 6 kHz 以上没有可分辨的干净线间 FFT 点。应先保留完整高频能量与左右变化，不能从这些区域单独提取“机械噪声”再叠加。** 这是指定观察条件下的不可分辨性，不表示录音没有噪声，也没有推翻原 Sound DNA。

上一轮已排除直接把谐波投影余项当独立细节源：余项含确定性 AM 边带，且某些高频带依靠很强的负交叉项相消。本轮改为互不重叠的频谱区域测量，不做波形相减。已有行驶 35%、当前驾驶器、空间和音色没有修改。

## 方法

完全沿用六个原生短片段及 54 个等长 C 子段，48 kHz，4096 点周期 Hann、1024 点步长、8192 点 FFT、八个频带（28–14000 Hz），交叉谱约定 `L*conj(R)`。声音样本不重采样，不重新估计时钟。

每窗取冻结逆映射所有相交区段的斜率范围。第 h 阶邻域为 `h×[根频率下界, 上界] ± 23.4375 Hz`，h=1..288。23.4375 Hz 是该 Hann 窗第一零点半宽，旁瓣仍在；根频率范围是估计坐标的条件范围，不能解释为真实发动机瞬时频率的严格误差界。

每个频点互斥归为四类：一个邻域覆盖、模型范围内无邻域覆盖、两个以上邻域重叠、模型范围之外。完整保存每窗计数、左右 2×2 复数功率矩阵及原始特征值。相同原声掩码用于九个 C 子段，方便比较相同频点；C 为局部稳态、原声在升速，差额不等于缺少某个独立物理声源。

代码分工见 `tools/native_regions_v1/README.md`。区域几何、频谱和已知控制分开，运行、独立审计、图表及归档分别编排。

## 结果

- 稳态谐波约 99.95% 能量落入谐波邻域；已知半阶线间音约 80.41% 落入线间区域，说明稳态控制能区分这两种输入。
- 升速半阶音几乎全部落入重叠区。即使已知声源存在，当前窗也可能无法把它分成独立线间部分。
- 六段实录 6–8、8–10、10–14 kHz 的干净线间计数全部为零；重叠区能量占各频带的约 **10.45%–100%**。部分 3–6 kHz 仍有线间区域，但不能据此推断更高频带的噪声构成。
- 已知 `1+0.4cos(2π4t)` AM 的完整 8–10 kHz 功率，与精确 Hann 平方加权包络最大相对差约 `7.07e-8`，说明完整频带包络测量可用。
- 原声／C 全频带比较继续显示约 2.15–5.29 dB 的 3–14 kHz 缺额，但只有约 206–228 ms 的原生片段，不足以拟合长期调制规律。九个 C 子段的范围是模型随机变化，不是独立录音的置信区间。

`review1/full_band_observations.json` 保留每个原生窗的左右功率、复数交叉项、时间与区域计数，明确标记为观察值，**不是可直接加载的运行预设**。

## 对下一步生成的约束

回到已批准、已听过的两次 F3 五挡升速上下文，测更长原始时间片段的完整高频带联合包络和左右关系。先保留频带间同步起伏、左右共同／差异变化，再判断何种统计调制可以在同一 DNA／DETAIL 系统中生成。不要只补平均亮度、盲目扩宽、添加一团独立高频 OSC 或把本次短包络循环播放。

后续仍复用同一驾驶器和 DNA／BODY／DETAIL／EVENT／AUX 干声总线，空间渲染单独维护。双声道观测没有分离出进气、排气等物理对象，不能直接映射为物理 7.1.4 声源。全转速／负载、完整驾驶状态与其他实车仍需继续。

## 核查与失败记录

先执行 13 组已知输入，再执行六个原声与 54 个 C 子段。独立核查覆盖 **73 组双声道输入、718 窗、34464 个显式复数 DFT 值**，另外逐点重算区间覆盖、用 Welch／反序 CSD 复算全部区域矩阵，并核对已知 AM 和噪声关系。最大矩阵差 `2.78e-16 FS²`、DFT 差 `5.65e-12`，根频率界差为零。

`audit1` 在已知 AM 的近零特征值核查失败：两个独立 FFT 矩阵仅约 `1.91e-17` 的差导致近零特征值变化，原矩阵比较通过。`audit2` 改为同一保存矩阵的长精度解析特征值核查，独立矩阵之间另外按 Weyl 扰动界核对，原矩阵门槛保持；随后在白噪声控制失败，因为实协方差只能核对单边复数交叉项的实部。`audit3` 增加独立 Hilbert 内积核对虚部，完整通过。三次执行源码和失败报告全部保留；没有修改测量数据、窗、时钟、模型或原数值门槛。

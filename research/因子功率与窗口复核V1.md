# 因子功率与窗口复核 V1

2026-11-12。上一轮AR8候选的16秒功率失败，**与有限片段的随机起伏相符，没有在本轮发现期望功率补偿有偏的证据**。另一项更直接影响音色建模的发现是：固定失谐也会产生“四步相关更强”，不能把这项结构直接复制成真实发动机AM。没有改动认可DNA／LF或实时C。

## 功率偏差来自哪里

归一化幅度为`A = RMS × exp(z−v)`，其中零均值高斯`z`的方差为`v`。因此`E[A²] = RMS²`；该式约束统计期望，不保证每段音频都达到同一均方值。

本轮独立核对了四个已知控制声部：

| 检查 | 结果 |
|---|---|
| 高斯矩的数值积分 | 期望平方幅度相对目标的最大绝对误差`2.23e-16` |
| 有限16秒包络均方值的理论标准差 | 约4.26–6.52% |
| 512次独立模拟的平均包络均方值 | 目标1.0，实际0.9968–1.0027 |
| 理论／模拟均值差 | 最大1.72个均值标准误差 |
| 理论／模拟方差差异 | 最大约13.4%，通过预设25%检查 |
| 旧三个种子的Welch功率快速重建 | 与冻结记录最大差异小于`1e-12dB` |

曾失败的种子62017，第二带包络功率为目标的0.8911，约偏离理论均值−1.67个标准差；对应原Welch误差−0.503918dB。512个独立16秒模拟中，该带约8.8%超出±0.5dB。这个计数是本次模型模拟结果，不是对任意音色的保证或通用失败率。

预测使用高斯矩关系`Cov(exp(2z−2v), exp(2w−2q)) = exp(4Cov(z,w))−1`，再计算有限区间平均的方差；8／16点积分一致。独立批量状态模拟与SciPy `lfilter`重建分别核对分布和原失败片段，未给WAV追加增益补偿。这里的精确期望针对**归一化平方幅度**，不能直接泛化为任意混音／滤波后的听感或响度。

原“每个16秒控制均须小于0.5dB”的记录仍为`not_passed`，阈值不变。本轮说明：不应把这次超限本身当作功率补偿公式错误，也不应为通过检查给每条输出归一化。

## 四步相关是否就是发动机变化

使用原冻结的幅度方向作观察，不重新拟合。比较1周期矩形、2／4周期Hann三种窗口和四个起点，共7个情境／84个配置；每种窗口使用同一段支持范围内的中心点。起点与重叠帧是敏感度检查，不是独立录音。

以下为第一因子、零起点的描述；“相关”是有限块的滞后比，不是物理事件或总体统计估计。

| 观察 | 窗口 | 一步相关 | 四步相关 |
|---|---|---:|---:|
| 已知固定幅度OSC，恒定0.1%失谐 | 1周期矩形 | −0.002 | 0.532 |
| 同一已知声源 | 2周期Hann | −0.007 | 1.000 |
| 同一已知声源 | 4周期Hann | −0.003 | 1.000 |
| 固定A参考 | 1周期矩形 | 0.379 | 0.632 |
| 同一参考 | 2周期Hann | 0.995 | 0.975 |
| 同一参考 | 4周期Hann | 0.996 | 0.979 |

固定失谐控制**没有施加源AM**，却出现四步相关强于一步的结构；4周期Hann使其第一因子方差从约0.005降到`1.37e-5`。这证明这种形状可以来自有限窗／失谐／串扰，不能据此认定真实参考里的全部变化都属于分析误差。

已知准确时钟的固定OSC近乎无幅度变化；三份平稳噪音控制则仅因窗口平滑，就让第一因子的一步相关由约0.47–0.50升至0.90左右。单独的真实1.5Hz AM控制仍可读出，幅度误差不超过0.0166dB。近零方差控制的滞后比、稀疏单音控制的整套PCA投影都不作解释；后者只用于核验第5谐波的已知AM。

实际DFT核验通过，最差相对误差`5.94e-10`。不同窗口同时改变噪声增益、泄漏和时间平滑，表内数值不能互换成相同物理能量预算；也不能直接用Hann结果替换原模型。真实短参考仍有简单控制未解释的变化，目前没有识别恒负载纹理或真实时钟误差。

# V0.12 · 纵向动力链

本轮把踏板驾驶中的速度经验公式换成带单位的轮上力模型，继续采用上游 V6 的「驾驶控制 → 工况 → 各层包络 → 声学／空间」结构。实时界面、离线渲染和自动驾驶都调用同一条 C 控制链。声源算法沿用 V0.11；相同 RPM／负载下的低转、高转、收油和导入 DNA 导出均逐字节相同。驾驶过程的转速、负载和声层比例会因动力链改变。

## 模块

| 文件 | 职责 |
|---|---|
| `src/profiles/vehicle.c/.h` | 车辆质量、等效惯量、扭矩曲线、传动效率、轮胎抓地上限、滚阻／风阻／制动配置 |
| `src/drive/powertrain.c/.h` | RPM/kph 到 rad/m 的单位换算、发动机净扭矩、前向／倒拖效率、实际传动挡位 |
| `src/drive/longitudinal.c/.h` | 轮上力、阻力、等效惯量和车速积分；车辆停止边界 |
| `src/drive/vehicle_types.h` | 有单位的力学采样状态 |
| `src/drive/drive.c` | 踏板、运动自动挡策略、驱动各模块、工况和声学控制量 |
| `src/drive/shift.c` | 断开、匹配、接合、补油和超转拒绝；继续保留原独立状态机 |
| `src/io/drive_trace.c` | 输出扭矩、牛顿、kg、m/s² 和计算时使用的挡位／车速／RPM |

断开离合期间仍使用**原挡位**计算残余传递力。目标挡位用于匹配转速；离合打开后才成为接合路径。内部补油继续只影响发动机声音，不作为轮上驱动输入。关闭点火后发动机传递力为零，路阻和制动仍能使车辆减速。

## 参数依据与边界

核对 [Lamborghini 官方 Performante 页面](https://www.lamborghini.com/en-en/history/huracan-performante)：600 Nm @ 6500 RPM、470 kW @ 8000 RPM。页面摘录和获取时间保存在 `vehicle_specs_v012.json`。这两个点进入曲线；其余节点为工程插值，并受峰值功率包络约束。不是整条测功机曲线。官方 1382 kg 是**干重**，没有当成驾驶时总质量。

当前五种声音模板仍共用一个车辆代理。1600 kg 行驶质量、70 kg 轮系等效质量、0.22 kg·m² 曲轴等效惯量、0.72 m² CdA、0.013 滚阻系数、0.90 传动效率、1.10 纵向附着系数和 1.05 g 制动配置均为工程假设。非 V10 模板只按自己的最大 RPM 缩放同一条归一化曲线，尚无各车型实测动力配置。

既有 `[114.2, 76.7, 55.5, 43.8, 34.3, 27.7, 22.6]` 是 **RPM/kph**，并非变速箱齿比。令 `k = RPM_per_kph × 3.6 × 2π/60`，单位为 rad/m。稳态无滑差时 `ω = kv`，正向轮上力为 `ηTk`，倒拖时为 `Tk/η`。正负传递中的能量损失方向分别测试。这里没有声称这些有效传动比来自目标车厂家资料。

轮上力减去 `Crr·mg`、`½ρCdA·v²` 和制动力，再除以等效质量，积分得到 m/s。曲轴反射的等效质量按 `Jk²` 及离合传递／低速耦合系数近似加入；发动机制动和制动踏板共享轮胎纵向力上限。车速到零后不会反向运动；没有旧版 300 kph 的全局硬限速。固定挡位靠扭矩衰减、转速保护和阻力稳定下来。

这是**约化纵向模型**。起步滑差、空挡转速跟随和换挡匹配仍采用工程控制器，未联立求解曲轴／车轮双惯量与离合摩擦；跨离合状态转换不具备完整能量守恒证明。没有坡度、倒车、轮胎滑移、ABS、独立车轮、温度和空气密度变化。低速损失／怠速支持也是简化规则。

## 对声音的影响

踏板驾驶的 `load` 改为由有效发动机油门对应的净轴端扭矩除以当前可用全油门扭矩得到的有符号控制量；怠速保留 0.04 声学底值。制动踏板不再直接减去一段虚构的发动机负载。内部补油能提高声音侧负载，车辆侧只接收驾驶员踏板与换挡扭矩削减。这个量用于驱动声层，不是实测 BMEP、ECU 负荷或扭矩传感器读数。

加／减速声学控制改为实际加速度除以 g 后限幅。台架模式继续接受直接 RPM 和 −1～1 负载，适合单独比较音色。松油保挡、制动安全降挡、超转拒绝、燃烧供给状态和各层独立包络继续有效。

## 已验证结果

- 14 项 CTest 通过。新增检查包括 SI 功率传递、峰值功率包络、同速同踏板的挡位差别、离合打开时零传递、制动被动性、轮胎合力上限、停车边界、步长减半收敛、点火关闭后的制动和固定挡位超转保护。
- 30 秒自动驾驶：最高 206.065 kph，8 次换挡、0 次中止，结束时停车。这个结果来自工程代理，不是 Performante 加速性能验证。旧版最高 210.908 kph。
- 连续降挡、手动换挡／停机、空挡补油均有新旧实际导出；每组使用一个共同固定增益。比较的是相同踏板编排下的响应，相同时间点的 RPM 未必相同。
- 低转、高转、固定 RPM 收油和用户 DNA 四组台架导出与冻结 V0.11 逐字节相同。
- 十个预主混声源在 stereo／7.1.4 导出中逐字节相同。未新增空间化标定或实机 7.1.4 听音。
- 实际静音 UI 测试确认新动力链参与实时运算、手动换挡、预设／控件隔离和启停有效。512 帧平均渲染 1.2098 ms、最大 4.2705 ms；设备播放 10.5920 秒／墙钟 10.7095 秒、空队列观察 0 次。

试听入口：`V012试听.html`。音色主观审阅仍待用户反馈；本轮验证不能证明声浪已经像实车。完整任务仍包括 RPM／负载／状态谱形、进排气传递、离合／惯量细化和真实回放空间听音。

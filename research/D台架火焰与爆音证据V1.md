# D 台架火焰与爆音证据 V1

已批准 D 的 36–44 秒提供多处可见蓝色排气火焰，但本次没有得到足以编译独立回火声源的声学候选。**这不是“录音绝无爆音”的结论。** [原声与画面对照页](http://127.0.0.1:8789/references/analysis/D_flame_audio_v1/review1/index.html)保留完整语境、前段、火焰附近和后段四段原声。

## 实际检查

依据先前已看过的40.040秒画面，在新读波形之前固定36–44秒语境与38–42秒主区间；没有事后搜索更强片段或调整检测门槛。35张原PTS画面、五张联系表均已查看，时间36.003–43.944秒，实际采样间隔约0.234秒。多张画面有蓝色排气火焰；字幕和画面不能识别踏板、供油、换挡切扭或精确点火时刻，屏幕数值未标为已校准RPM。

音频保持48kHz原始双声道float。20ms周期Hann窗、5ms步进，共1597窗；按七个固定频带统计左右功率、复互谱及原始RMS／峰均比。瞬态观察条件预先固定为1.5–3、3–6、6–10kHz中至少两带同时比101帧局部中值高6dB，候选间距至少100ms。它检查相对局部背景的宽带突出量，不是通用回火识别器；较弱、较长或被连续发动机声掩盖的事件可能漏检。

稳定正弦已知对照无候选；带单个已知短宽带脉冲的噪声对照在目标附近检出一个候选，先于原录音读取完成。这不等于对所有实车录音有完整召回率保证。

| 结果 | 本次证据与含义 |
|---|---|
| 固定条件下候选数 | 完整8秒及主区间均为0；最高两带突出量3.5144dB，未降门槛 |
| 原声电平 | L/R峰值0.8572／0.8411FS；不是经过逐段归一化的比较 |
| 左右关系 | 120–500Hz复相干幅度约0.985，6–10kHz约0.149；只是这段混合录音的频带统计，不能据此恢复声源位置或复制到高度声道 |
| 独立核对 | 从主文件重读全8秒、全部1597窗直接FFT／独立局部中值计算；最大功率差2.22e−16FS²、突出量差7.15e−14dB |
| 试听 | 四段同0.5增益、首尾5ms淡化；float样本与处理公式逐样本核对，无EQ／去噪／响度补偿 |

20ms窗的频率间隔50Hz；低频统计只适合宽带观察，不提供精细次声／阶次分离。相干度也不能区分直达排气、房间、滚筒、风机及录音链贡献，不能把D台架室传递特征当成车外尾排DNA。

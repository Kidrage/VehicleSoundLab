# 稳定残差声源提取控制 V1

本轮修正了离线声源提取的小型问题终止判定：同一组4个有限矩阵和8个Hann控制，资格由4/12变为12/12，拟合参数与上一轮逐位一致。变化来自残差计算及终止检查，没有改声纹目标、正则化或声音。完整288分音测试另行运行，未包含在本次小型控制资格内。

该模块服务于素材声纹提取。后续仍需把时间轨迹提炼成可持续、可调的生成规律，再接V6的DNA／BODY／DETAIL／EVENT／AUX、唯一驾驶器和独立空间层；不能把拟合片段循环当成持续声源。

## 算法改变

保留原目标 `min_z ||BTz-b||²+||z||²`，其中 `T=L_R^-T`，`R=.001 D2ᵀD2+.000001 I`。左右Krylov基继续完整重新正交化。投影矩阵H做完整QR，用正交补构造残差系数：

`c = -Q_perp (Q_perpᵀ beta0 e0)`，`r_model = Uc`。

这避免在小残差处直接相减 `Hy-beta0 e0`。随后对整个`r_model`应用完整原算子的伴随，显式记录V子空间外梯度；不能只用几乎必然很小的`Hᵀc`判断收敛。

候选终止必须同时通过原`atol=btol=1e-11`、模型残差与直接残差之差相对`||b||`不超过`1e-11`、原空间梯度小于`2e-7`，以及**原有两种**gap各不超过`1e-6 J+1e-10`。任一不通过继续迭代或保留失败，没有用新指标替换原门槛。

## 数值证据与边界

| 核查 | 结果 |
|---|---|
| 明确残差控制 | 7组，独立80／110位Decimal复核 |
| 同一有限矩阵／原Hann控制 | 12/12通过，全部stop2 |
| 原拟合参数 | 12/12与上一轮逐位相同 |
| 独立稠密节点相对误差 | 2.74e-14至1.42e-11 |
| 独立模型／直接残差差异最大值 | 9.59727e-12，门槛1e-11 |
| 实际磁盘映射后端 | 同12组通过，12×18数组与RAM逐位相同 |
| 原始映射基文件 | 24个裁剪后U／V文件独立核对 |

RAM与映射版是同12个问题的两个存储后端，不能计作24个独立案例。靠近门槛的残差差异完整保留。此前8个直接终止失败仍保留在冻结父档案，不追溯改为通过。

三个反例限定了“稳定残差”的含义：子空间外控制的`Hᵀc=0`，完整梯度范数却为3；病态控制的模型梯度约1e-16，而对原二进制输入以110位计算的实际梯度范数约3.0827，差异可由投影误差界覆盖；故意使投影偏1%时，直接／模型残差差异为0.00898547，被1e-11门槛拒绝。稳定量是投影问题的估计，**不是原完整梯度的严格区间界或物理声源证明**。

# 怠速细节提取 V2

本轮按用户“怠速还不够漂亮，多从素材提取”的要求，改进固定怠速的细节声源。新增两个离线候选，供听评；当前 C 驾驶版本、行驶35%配方与旧声音文件保持原样。

素材仍是已批准的 F2 LP-610 尾排，原生48kHz：6–9秒训练，9–12秒只用于最终观察和试听。没有新下载、降噪、变调、压缩或房间处理。不同机位与车型没有混合训练。

## 发现

- 旧提取保留13条独立OSC，最高486.82Hz。余下频段使用6组AR24共振器；原频谱统计约23.4Hz分辨率，再平滑50Hz，可能抹平细小峰谷。
- 新的分频带谱峰检查没有得到可新增的稳定高频声线：400–1200Hz只通过一条已有472.48Hz，其余频段没有达到80%窗口支持。此结论仅针对当前窗口、峰清单和规则，不证明源中不存在运动或短暂声线。
- F2训练段侧／中能量约−71.71dB，有效低中频左右几乎相同。全段最大左右差约0.0018FS，不能简单称全样本相等；不据此人为增加宽度。

## 两个候选

主声线13条的频率、幅度与初相保持完全相同，仅替换余下细节。

| 模块 | 处理 | 可维护边界 |
|---|---|---|
| 声线观察 | 每频带峰清单、固定中央锚点、跨窗支持 | `tools/idle_texture_v2/observation.py` |
| 细化共振 | 原生0.5秒Welch、8Hz平滑、带边渐变；实倒谱得到8192点最小相位FIR | `tools/idle_texture_v2/spectral.py` |
| 起伏统计 | 200ms频带能量／20ms步进；半对数幅度协方差与一阶相关 | `tools/idle_texture_v2/dynamics.py` |
| 生成／导出 | 冻结原OSC＋新激励共振／可选统计幅度 | `tools/run_idle_texture_v2.py` |
| 复核／试听 | 独立卷积和状态重建；单播放器同增益对照 | `tools/audit_idle_texture_v2.py`、`tools/review_idle_texture_v2.py` |

第一条“细化共振”只改变细节频谱。FIR存储的是由功率谱编译的滤波器参数，激励为新生成噪声，不含原波形或原时间序列。按原频带功率扣除旧OSC预算，用非负拟合分配剩余能量，避免单纯叠加高频。

第二条“共振＋幅度起伏”在第一条基础上加入新生成的相关幅度变化，固定强度0.5。训练所得半对数幅度标准差0.054–0.128，一阶相关0.883713；不是人为周期LFO或音高抖动。协方差决定跨频带关系，余弦插值避免台阶，指数偏置校正保持期望平方增益为1。

这些起伏来自录音的整体频带能量，是带有机位／风噪影响的统计代理，尚未识别为真实燃烧或机械运动，也没有与发动机循环同步。独立OSC本身仍可能有长期拍频。

## 本轮检查

已知小幅高频线／缺失线、最小相位滤波器、卷积／方差、解析频带功率、幅度递推与插值方差控制通过；三种子149921／277139／381611全部保留，未选择最好的一组。独立全段FFT卷积、分散采样点直接FIR求和、逐状态重建对导出混音最大误差1.491e−8FS，来自FLOAT文件量化。

8Hz平滑后的训练对数谱RMS误差（各种子范围，dB）如下，仅描述谱形接近程度：

| 频带 | 上一版 | 细化共振 |
|---|---:|---:|
| 120–400Hz | 3.07–3.37 | 1.06–1.12 |
| 400–1200Hz | 4.98–5.06 | 0.79–0.90 |
| 1.2–2.2kHz | 2.90–3.04 | 0.96–1.02 |
| 2.2–4kHz | 2.43–2.49 | 0.98–1.01 |
| 4–8kHz | 1.89–1.92 | 0.82–0.86 |
| 8–14kHz | 1.65–1.66 | 0.63–0.64 |

两种新候选三种子的最大频带功率误差：训练0.267dB、同录音保留段1.131dB。各版最大绝对峰低于0.396FS；试听保护增益恰为1，没有逐版响度补偿。数值改善不等于机械质感获认可。

30种页面组合的HTTP音频、时长、跳转、播放中切换及手机布局检查通过，截图已目视；自动播放验证始终静音，不能替代听评。无C改动，未重复59项CTest；569份C/H和67声音配置以哈希确认原样。

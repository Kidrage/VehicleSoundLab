# 波形空间声源提取 V1

本轮验证了同一声纹提取目标的波形空间表示。它不删频率、分音或时间节点，但当前仅通过原12个验证问题中的9个，尚不能用于完整素材提取或替换实时C音色。上一轮MCPS复核只确认资源预算，本轮继续推进离线提取器。

目的仍是从素材提取可持续、可控的声源规律，改善高频和左右关系，再接同一驾驶器及V6的DNA／BODY／DETAIL／EVENT／AUX。拟合一段波形不是完成了可操控音色；空间渲染继续独立，不能用混响掩盖声源误差。

## 方法与模块

原问题为 `min (S q-y)^T W(S q-y)+q^T R q`：S合成节点包络驱动的OSC，W保留全部原波形及完整支持Hann频谱项，R保留原二阶平滑与ridge惩罚。

令 `W=Lw Lw^T`、`R=Lr Lr^T`，定义 `X=Lw^T S Lr^-T`、`t=Lw^T y`。等价波形对偶为 `min ||X^T v||²+||v-t||²`，还原 `q=Lr^-T X^T v`。QR保留全部 `min(m,n)` 方向，包括秩亏方向；没有奇异值截断。减少观察行的代数冗余不自动改善条件数。

| 文件 | 职责 |
|---|---|
| `tools/waveform_representer_v1/metric.py` | 原有限Hann度量的完整波形Gram；含覆盖、窗、频率权重和单位 |
| `tools/waveform_representer_v1/algebra.py` | 平方根／Householder QR求解、完整模型残差及伴随；不求正规方程 |
| `tools/waveform_representer_v1/fixtures.py` | 显式矩阵与DC／Nyquist等已知控制 |
| `tools/run_waveform_representer_{controls,known}_v1.py` | 先运行显式控制，再运行冻结原12问题；记录时间和进程累计峰值内存 |
| `tools/audit_waveform_representer_{controls,known}_v1.py` | 独立高精度解、标量DFT及原方程／两种gap／完整伴随复核 |
| `tools/{publish,audit}_waveform_representer_publication_v1.py` | 绘图与逐项独立发布核查；保留失败和资源边界 |

第一版直接相减构造残差。第二版用Householder变换保留目标正交补，结合小型对偶QR的完整补空间构造稳定残差，再映射回原观察算子检验；没有把投影梯度直接设为零。

## 实际结果

两版各通过7个显式矩阵控制（80／110位Decimal交叉核查）和4个41×41有限DFT全Gram控制。包含宽／高矩阵、秩亏、零目标、尺度差异、双右端及静音右声道。

原12问题为4个33点代数问题和8个8705点Hann问题；后者17节点、2阶次，是已知输入验证，不是完整288分音，也没有读取真实录音。

| 项目 | 第一版 | 第二版 |
|---|---:|---:|
| 原参数误差、原梯度及两种gap全部通过 | 12/12 | 12/12 |
| 完整原算子停止规则资格 | 4/12 | 9/12 |
| 残差构造 | 直接相减 | Householder稳定模型 |

第一版自身变换空间的直接停止量曾显示9个通过；独立原算子检验只有4个，因此采用4/12。第二版独立确认9/12，参数相对原稠密解误差约 `3.88e-14～1.03e-11`。

保留的三个失败为：

| 原控制 | 原完整模型停止比，门槛1e-11 |
|---|---:|
| constant_0.01 | 1.77127898e-11 |
| constant_0.0001 | 1.59266230e-11 |
| constant_1e-05 | 1.37394759e-11 |

它们虽然通过参数、梯度和两种gap，仍不能宣布合格。所有原容差、尺度、目标与失败文件保留；没有以新门槛重新标记结果。

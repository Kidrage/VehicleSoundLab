# F3多音高局部声纹 V1

**同一套288分音／12统计分量的Sound DNA提取与C生成链，在五个预先固定的局部观察中均通过原声线门槛。** 它们提供更宽的局部音高证据，尚未形成全转速、全状态或多款发动机的音色库。

前一目标轮仅复核ADI算力，没有推进合成；本阶段完成此前已运行的五点提取、数值核查和同音高比较，并增加可直接使用的单播放器试听与完整冻结。

范围58.23–67.96 Hz，最高／最低约1.167倍；五个根频率**均未超过旧288阶加载边界68.1818 Hz**。本轮使用带限导出协议，但没有取得新的高于旧边界的实录验证。窗口在读取前固定，未移动窗口以获得更高数值。

五点都位于此前批准并核查的F3片段内，复用已有20张原PTS显示注释，没有新下载、重新读图或插值出精确RPM。它们来自同一视频，不证明独立录制，也不能标定油门、负载、燃油、机械源或音画延迟。

## 算法与模块边界

```mermaid
flowchart LR
    A[批准素材与固定局部窗口] --> B[既有声线跟踪与相位坐标]
    B --> C[既有Sound DNA统计提取]
    C --> D[分音均值与双声道统计参数]
    D --> E[显式导出协议]
    E --> F[原SaVoice持续生成]
    D --> G[同64 Hz比较与单播放器]
    F --> G
```

- `local_voice_batch_v1/batch.py`继续编排原80 ms Hann／240步长、18周期孔径、5阶相位参考与独立3／7阶检查，至少32观察、每声道相干大于0.8。声线提取和拟合门槛没有改变。
- 新`local_voice_batch_v1/render.py`区分旧raw导出的相对音高参数与带限导出的绝对Hz参数，拒绝未知协议。旧调用默认仍为相对1倍，新调用显式给出提取根频率。
- `sound_dna`保存均值、统计方向与每分音残差；`dna_atlas/SaVoice`继续负责同一相位时钟下的持续OSC、固定平均相位和幅度细节。没有新建第二套C声源、驾驶器或空间处理。
- `run／audit／compare／review_F3_pitch_anchors_v1`分别负责提取、独立核查、同音高描述统计、试听导出；原素材、参数、C持续声和监听副本分开留存。

每点三种子1／23117／61927，各8秒原生根频率持续声；再以同一参数各生成三条64 Hz持续声，共30条实录模型C音频。无PCM循环、额外高频OSC云、EQ或新增房间。全部288个保存阶次保留，SaVoice仍使用现有19.2–21.6 kHz载波渐隐；这不是所有随机调制边带的砖墙保证。

## 核查结果及其范围

1. 递增／递减、边界拒绝、静音和90 Hz已知带限随机双声道控制先于实录运行。独立PRNG／直接三角求和包含全部288阶的状态推进，含不可听高阶。
2. 独立核查全部725个原生观察窗的功率、`L*conj(R)`互谱、候选峰和路径。最大频带功率／互谱差分别约1.11e-16／5.56e-17 FS²；路径根频率差约1.42e-14 Hz。
3. 独立重建逆坐标与保存坐标一致；直接FIR／插值重建转FLOAT后，与五份提取波形逐样本一致。所有分音均值及每分音4×4边缘协方差独立核查，最大误差约1.21e-14 FS／6.94e-17 FS²。
4. 原提取器与因子分解重放后，五份参数文件均字节精确。**这属于可复现性，不是独立SVD证明或全部跨分音协方差审计。** 本轮没有重启此前微弱残差比值的救援，也没有把旧1e-9失败改称通过。
5. 30条C音频各检查覆盖0–8秒的14个固定采样位置，使用独立PRNG／直接三角求和／实际根频率载波渐隐参照。最大差约2.98e-8 FS，满足每值0.5001 FLOAT ULP＋2e-10 FS预定界限。这是稀疏核查，不是全样本oracle。
6. 新协议分派的旧路径复现了冻结五挡中点：参数、坐标容器和三条C WAV字节相同。`legacy1`对三个Python写出参考WAV要求整文件相同而失败；`legacy2`只复核已有输出，确认PCM逐样本相同，唯一差异为RIFF `PEAK`时间戳。两次执行源与结果都保留，没有重新拟合来消除差异。

656份C/H、76份声音参数及F2三个文件与上阶段精确相同；当前工作只改分析编排和增加研究／试听工具。未重复运行未改动的70项CTest；新浏览器检查覆盖45个片段的加载、时长、定位、静音播放、切换暂停与快速切换竞争，桌面／手机无横向溢出，三张界面图已目视。此前比较图也已目视。技术播放检查不等于听音验收。

## 对声音分层的结论

统一64 Hz后，三种子平均双声道频带相对短参考的差异范围为：

| 频带 | 五点C相对参考 |
|---|---:|
| 28–120 Hz | −7.39 至 −4.60 dB |
| 120–400 Hz | −0.29 至 −0.13 dB |
| 400–1200 Hz | −0.59 至 −0.26 dB |
| 1.2–3 kHz | −1.26 至 −0.50 dB |
| 3–6 kHz | −3.19 至 −2.13 dB |
| 6–8 kHz | −4.30 至 −3.39 dB |
| 8–10 kHz | −4.40 至 −3.87 dB |
| 10–14 kHz | −4.39 至 −3.86 dB |

120–1200 Hz主线较接近，高低频缺口及高频左右复相关差仍存在。统计比较使用短训练参考对8秒随机生成声，是描述证据，不是自然度门槛、泛化证明或应该全部补回的物理发动机能量。低频／道路／车内／风噪／相位处理都可能参与差额，不能整体增亮或用独立OSC云全填。

下一步把两次五挡升速各自的前／中／后三点作为**两个分组的局部库**，核查同一SaVoice连续音高和锚点过渡；中点使用此前冻结参数。六挡观察单独保留，不把不同语境直接按Hz堆在一起。继续保留唯一驾驶器，以及DNA／相干低频／联合双声道细节／事件／空间边界。未来7.1.4复用声源与对象总线，不把录音L/R当作已分离的物理声源。

本轮没有写入`voices/`、目录、实时默认或行程格式，也没有改变待听的F2怠速／F3细节候选。E反馈仍为“左右关系有改善，音色仍明显电子”；不得用新客观核查覆盖它。宽转速、完整启动怠速加减速换挡状态、其他真实发动机和物理7.1.4仍需继续。

# 压力层在完整混音中的采样差异 · V1

本轮结果支持降低这项采样优化的优先级。在当前 V017 配方、两个细节控制均为 65% 的五组输入中，只将短压力冲激替换为其理想带限近似，再经过相同的原生 IR、空间、主音量处理，完整 stereo 混音的 AC 差异约比原声低 **72～80 dB**。这项局部问题尚不足以解释用户反馈的整体电子感。没有因此改动原生音色，也没有获得新的听感认可。

这不是整个声浪系统的总混叠测量，也不是真实度百分比。比较对象是我们自己定义的压力冲激响应；理想硬带限版本是**非因果的离线诊断**，不能直接部署到实时驾驶系统。参数、窗长和录音视角改变后，结果未必相同。

## 保留的声音与控制

- 原生版本仍为 0.17.0；V011 连续排气系数、机械声音、驾驶状态机、点火事件、逐次随机序列、源 IR 和声场算法保持原样。
- 新建五份 V017/schema2 take，种子 48271，48 kHz。使用冻结版本原生 `vsl_character_probe.exe` 录制实际输入，未改写历史 take。
- 三个固定目标分别为 1200／4000／8000 RPM、负载 .65，时长 4 秒；空挡补油 8 秒；5000 RPM 收油／恢复负载 7.5 秒。所有片段都从新会话开始，包含原生启动过程，固定 RPM 是输入目标，不能把全片视作稳态。
- `pressure_texture=.65`、`structure_transfer=.65`，其余参数使用原生默认。当前产品默认两者关闭；这轮特意使用已有试听起点来观察新增层。
- 没有读取、清洗、下载或播放新的实车素材；没有把实车录音引入合成器。

## 测量结果

下表为整段 float32 stereo 输出的功率差比，`10 log10(差值 AC 功率 / 原生 AC 功率)`。去除 DC；没有响度匹配、归一化或放大差值。

| 工况 | 完整混音 AC：L／R | 混音 3–8 kHz：L／R | 仅新增压力层 AC：L／R |
|---|---:|---:|---:|
| 1200 RPM 目标 | −79.17／−79.83 dB | −65.77／−65.89 dB | −42.60／−45.88 dB |
| 4000 RPM 目标 | −71.61／−71.78 dB | −59.23／−59.35 dB | −41.23／−44.16 dB |
| 8000 RPM 目标 | −71.93／−72.23 dB | −60.29／−60.41 dB | −43.81／−47.34 dB |
| 空挡补油 | −72.68／−73.05 dB | −56.56／−56.68 dB | −42.66／−45.93 dB |
| 收油／恢复 | −71.58／−71.66 dB | −59.77／−59.90 dB | −42.15／−45.28 dB |

压力源 L／R 是工程模型的两路声源，混音 L／R 是监听声道；不能把它们等同，也不能直接用两者 RMS 比值当作经过路由后的声源占比。右侧压力源还经过原有 0.38 ms 的基准采样率线性分数延时，因此其差异与左侧不同。

较早的 [短压力模块核查](压力层采样核查V1.md)使用无逐次变化、无包络、无延时、无驾驶和空间的受控周期信号。本轮纳入实际事件和整条声音链，两组数字的参照和条件不同。

## 模块与计算

独立工程在 `experiments/pressure_mix_v1/`，只链接冻结的 `baselines/v0.17.0/bin/vsl_core.lib`。CMake 从冻结源码提取 character、逐样本调度和 take 调度函数，对每个观察钩子检查唯一匹配，再生成本次离线观察器；原生文件不变。

1. `observer.c` 记录实际压力 strike 的帧号、缸列、增益、形状与采样内经过时间。事件时间为 `frame / sample_rate - elapsed`；逐次能量和形状保持原生。
2. 每帧保留原生新增压力 L／R 和响应后的增益。原生短模态、右声源分数延时、原有随机状态继续执行。
3. `tools/pressure_mix_response.py` 用复指数递推重建这些事件。与原生 double 压力增量的最大样本误差约 `2.52e-17`。
4. 另将同一事件列用八点 Lagrange 插值沉积到较细时间网格，FFT 后只保留基准 Nyquist 内频点，乘以连续模态传递函数。频域逆变换乘以基准采样率，保留正确单位和增益。正负 Nyquist 端点采用有限积分的梯形半权重。
5. 保留相同右声源线性延时和逐帧增益。离线第二遍在 character 完成之后、源 IR 之前，只给两路排气增量加上“替换压力 − 原有压力”。因此 IR 的机体返回和完整声场自然响应于这项变化。

连续模态的传递为 `ω0 / ((1/τ + jω)^2 + ω0^2)`；三组频率、衰减、权重和形状系数都从 C 配方导出。它们仍是工程听评参数，不是测得的缸压或排气管传递函数。

频率截断之前的压力冲激才是本轮带限对象。其后的动态增益仍可能产生边带，延时和源 IR 也保留原有实现；本实验没有宣称整个输出严格带限。

## 验证与数值边界

- 原生重放和观察器旁路的 stereo WAV 逐位相同，均复现 take 内的完整音频指纹。
- 将记录的原生 double 压力增量重新注入，完整输出和全部十路声源仍逐位一致。这排除了替换接口本身制造差值。
- 替换前后，逐块完整驾驶日志、所有非声学反馈的引擎状态指纹、逐帧原生压力增量、事件列均一致。指纹包含原有 character 响应和 RNG。排除的状态只有声学／空间历史、输出对象和 peak 表；源 IR 配置来自同一份嵌入 take。
- 只有排气左、排气右和受排气驱动的机体 IR 返回允许变化，其余七个源文件逐位不变。
- 8000 RPM 组另外重放到 12 声道；原生、观察器和压力替换三条路径的十路源、驾驶日志和非声学反馈状态都分别与 stereo 相同。未据此声称已完成实体 7.1.4 阵列听评。
- 8×／16× 网格比较：压力输出 AC 差异低于约 −175 dB；周期加倍的比较低于约 −82 dB。高转组的周期边界误差最大，仍明显低于本次压力差值。这里是**实测收敛**，不是无限补零误差的严格上界；周期比较使用 8× 与 16×，包含极小的网格差异。
- 单个事件相位插值的解析余项上界和舍入余量另行核对；独立控制用三个分数时刻事件，对每个保留频点做精确非均匀 Fourier 求和，不使用事件沉积，最大压力样本差约 `7.9e-14`。
- 独立有限历史事件求和在各工况分散样本上再次核对原生压力；独立时域去均值功率计算核对 AC 结果。
- 验证文件还记录每组末尾一秒的差值，避免只保留全片含启动的平均结果。完整结果保存在 `renders/pressure_mix_v1/`。

构建与复现：先 `cmake -S experiments/pressure_mix_v1 -B build-experiment-pressure-mix -G "Visual Studio 17 2022" -A x64`，再 `cmake --build build-experiment-pressure-mix --config Release`。分析入口为 `tools/analyze_pressure_mix.py`，独立核验／冻结入口为 `tools/verify_pressure_mix.py`。已完成目录拒绝覆盖，复跑应使用新实验名。Python 依赖沿用 `runtime_review` 的本地依赖路径。

## 下一步音色方向

本次没有提出新的叠加配方。先前“压力／机械哪个组合更接近”的调参页问题仍待听评，不能从等待时间推断接受。现有可操作入口仍是 [燃烧与机械调参](燃烧与机械调参V1.html) 和原生 `Launch-current.cmd`。

在这项局部采样修正上投入更多复杂度，目前缺乏完整混音中的收益证据。接下来的音色迭代应围绕逐次压力响应的形状、衰减、负载变化以及机械结构的听感决定，继续保留 V011 的连续排气声线；这些方向仍需与用户选择和已批准录音的有效片段相互核对。

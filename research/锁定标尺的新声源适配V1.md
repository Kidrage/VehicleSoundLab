# 锁定标尺的新声源适配 V1

新带限源查询已经过独立验证，但旧首段系数对新参考的最高带误差反而更大，不能直接换输入沿用旧系数。本轮实现独立的新方法适配：**新音频用于拟合，原音频只用于固定误差标尺**。原首段不重拟合，原任务和全部失败保持。

## 模块与信号关系

```text
原音频 target ──→ metric_target ──→ 原 sigma／amplitude／频带权重／floor
                                              │
新 sinc128 音频 ──→ 完整288阶／原节点／真上下文拟合 ──→ 独立数学复核
                                                     │
                                        原生48k／高频／LR／时间诊断
```

`tools/locked_source_fit_v1/adapter.py`装配现有求解模块，明确要求两个不同输入。`fixtures.py`产生解析控制；`oracle.py`独立构建全部方程；`complete.py`独立核查完整误差、三次历史、两次更新、17个保真指标、双gap与四个因子文件。原生产求解器不改。

`prepare_locked_source_real_v1.py`只准备五段未拟合的原素材，`audit_locked_source_preparation_v1.py`独立核对；`run_locked_source_real_v1.py`每次只运行一个完整真实案例，结束后调用独立审计并停止，不自动继续后面素材。

## 已验证内容

四个解析案例均通过：不等左右声道、右声道0.35ms相位延迟、右声道静音、全零。另六个错误输入拒绝。三个非零案例与独立完整增广QR的系数相对差为 **1.70–1.84×10⁻¹⁴**。原2e-12一致性、1e-11稳定／反向误差、2e-7梯度、双gap和0.02保真门槛保持；频谱覆盖全部bin和DC／Nyquist端点。

控制的新音频幅度刻意不同：若误用新target重新标定，sigma会下降约19%，足以暴露错误路径。实际适配保持旧sigma与amplitude精确一致，独立频带权重差约浮点末位；右声道静音保持精确零，零参考的坏候选保留未定义误差而不转为好分数。

五段真实输入全部通过独立核查，保留原288阶、72–74节点、2048点真实前后文、共同LR时钟、原尺度和完整频谱。新旧target的整体相对差约6.48–6.89×10⁻⁶；这不证明可听改善，只确认输入变更很小、原评价尺度未漂移。

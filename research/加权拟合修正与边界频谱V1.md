# 加权拟合修正与边界频谱 V1

本阶段完成六份保存解的修正、额外最优性差距检查，以及首尾分析窗诊断。**修正结果不采用为新声源。** 原认可行驶版本、默认值、实时 C 和驾驶／空间结构保持。

## 固定原目标后的结果

`correction.py` 从上阶段每份 `weighted.npz` 出发，使用已通过单／双声道及稠密解控制的 `OrderBlockRight`，求解同一目标的残差修正。保留所有 288 阶次、原时间节点／尺度／共同频率权重、D2 0.001 和 ridge 0.000001；每份只做一次最多 4000 次修正，总计每份 8000 次，没有重启原进程。

| 同一目标下的版本 | 目标均值 | 波形 NRMSE | 宽频功率 MAE dB | 复数左右误差 | 宽频 CV 误差 |
|---|---:|---:|---:|---:|---:|
| 原保存 4000 次 | 2.78714 | 0.000412 | 0.37906 | 0.03635 | 0.04321 |
| 新块预条件修正 | 2.53752 | 0.000392 | **1.02345** | 0.02941 | **0.05018** |

六份波形误差都改善，但 14–21.6 kHz 平均功率偏差由 +2.015 变为 −6.072 dB。宽频功率虽然 51/72 项改善、21 项退化，平均绝对误差仍变差；原三段分区功率／左右／CV 分别退化 55/216、45/108、84/216 项。8–14 kHz 的功率偏差仍接近上一阶段，不能把这次很弱高频的退化推广成所有频段同时消失。

六份梯度残差 3.05e-8 至 6.28e-8，均小于原 2e-7 门槛，但全部 stop7／4000，原收敛字段保持 false。改善求解坐标不保证音色指标随迭代单调改善，也不证明当前目标的精确最优解正确。

## 额外最优性界限

`optimality.py` 对同一凸二次目标 `J(q)=||Bq-y||²+qᵀRq`，取实际残差构造可行对偶点 `u=t(Bq-y)`，计算稳定的非负和：

`J-D = ||r-u||² + ||R^(1/2)(q+R^(-1)Bᵀu)||²`。

它给出距离该正则化数学最优值的上界，不是实际声学误差、物理声源唯一性或听感评分。先声明额外门槛 `gap <= 1e-6*J + 1e-10`，再通过九个已知候选和独立稠密最优解核查；之后只读取全部六份原解／修正解，**没有新增求解**。

相对 gap 上界由原来的 0.346–0.933 降为 0.0462–0.3851，但十二份状态均未过额外门槛。这是尚未获得足够紧的最优性证明，不表示实际误差必然达到这些百分比，也不是已证明最优解不可达。

最初已知审计对两个几乎同样有效的对偶射线尺度作直接相等检查，受浮点差异影响失败；保留原执行版本，改为独立核查报告中实际可行对偶点及原 gap 门槛，不放宽门槛。首次实源审计在长角度直接三角函数／相减路径下也未通过原 2e-8 算术一致性门槛。新独立审计使用精确整数周期相位取模、约化角度三角表和直接矩阵伴随，先验证三份已知信号，再按相同门槛核查全部十二份状态通过，最大算术差异 8.68e-9。本机 NumPy `longdouble` 实际仍为 64 位，不能将它描述成额外精度收益；本检查也不是区间算术的严格舍入保证。

## 找到的观察度量问题

完整有限长 Hann 分析包含首尾补零的不完整窗。它保证记录每个采样被约束，但不能把这些窗的高频统计直接当成记录内部的机械高频细节。纯低频已知信号在完整窗内几乎没有 14–21.6 kHz 能量，却在首尾不完整窗出现高频能量；1e-5 倍真实高频控制也会被它掩盖。独立 SciPy 帧公式复核通过后，才分析六份实源。

| 素材局部窗口 | 14–21.6 kHz 参考能量位于首尾不完整窗的比例 |
|---|---:|
| 第一次升速／前 | 99.999798% |
| 第一次升速／中 | 99.999667% |
| 第一次升速／后 | 99.999522% |
| 第二次升速／前 | 99.999733% |
| 第二次升速／中 | 99.999676% |
| 第二次升速／后 | 99.999748% |

这描述所用完整帧度量的能量分配，不是原录音真实高频的物理来源占比。六份原权重的 1e-8 数学下限均未激活，所以不能将本次首尾占优归因于该下限。上述证据也没有独立证明它是全部电子听感或全部拟合退化的唯一原因。

下一步按 `research/observer_supported_metric_v1_plan.json`，将保留首尾的全波形约束与完整窗内的相对频谱约束分别建模。先用已知强低频／弱高频精确解核对单位、权重、下限激活、伴随、条件数和 gap，再决定是否做新的六素材拟合。停止继续追加同一目标的迭代次数或靠高频增益掩盖问题。

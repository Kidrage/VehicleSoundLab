# 怠速主声线幅度纹理 V1

本轮有新的[怠速试听](http://127.0.0.1:8789/references/analysis/modal_texture_v1/review1/index.html)：前轮细化共振候选、主声线起伏50%、起伏100%，可切换完整声音／主声线独奏。三个种子全部保留，同增益1，无逐条响度补偿。**它仍是离线候选，未替换C驾驶Demo，也未获得听感验收。**

## 修正上一轮对断线的解释

用原低频拟合／对应规则观察已知单声线：恒音、20%缓慢AM均得到11窗连续轨迹；±1.2Hz、1.6Hz的连续非线性FM，11窗都数值成功且局部受支持，轨迹却逐窗断开。再仅向对应器提供精确瞬时频率／变化率，仍逐窗断开。

这证明旧相切预测与变化率限制不适用于该非线性例，**不能把真实录音中的断线直接解释成声线不连续**。真值从未用于拟合初始化；精确坐标只检查对应器。旧单声道噪声反例也仍保留，局部能量支持不是声源检测器。

本轮不拼接这些局部相位。改用已冻结F2的13条独立OSC，让其原有频率／平均相位连续推进，只观察和生成缓慢幅度纹理；不声称恢复了新的共同发动机相位。

## 从素材到控制参数

素材只用原F2尾排6–9秒训练，文件与上一轮冻结相同。200ms原生Hann窗，每20ms联合投影13条已知频率的cos／sin／DC，设计条件数1.419。联合投影可避免把这些固定声线的普通拍频重复提取成AM，但不消除实际变频、噪声与机位影响。

取各条复系数的幅度，提取中心化对数幅度协方差，以及相距200ms、不共享样本的窗口相关。141个重叠窗口不是141次独立试验。约75／112Hz两条强线的对数幅度标准差0.095／0.100；弱线读数更不稳定，不能把全部读数当成燃烧变化。

| 参数 | 本轮做法／含义 |
|---|---|
| 频率、幅度标定与平均相位 | 原13条OSC参数逐位不改 |
| 幅度关联 | 保留跨声线协方差；各行／列共同缩放，限制对数标准差≤0.12，保持半正定与相关系数 |
| 相关时间 | 200ms滞后估计，原值0.0302024；不是物理燃烧周期 |
| 变化量 | 0／0.5／1是明确的工程试听量，不是实车状态标定 |
| 波形与时间序列 | 只在研究证据保存观察；合成profile仅含固定OSC及协方差／因子／AR系数，不含原片或包络轨迹 |

已知固定音调幅度误差约4.9e−15，普通拍频没有产生可见的新幅度统计。已知20%AM与独立有限DTFT／加权包络误差分别2.83e−16／4.84e−7。已知非线性FM仍产生0.0113的假对数幅度标准差，**不是零，也不是实录的通用误差上界**；本轮参数是录音混合幅度的统计代理，不证明物理AM，未据此扣减或标定实车抖动。

## 合成与模块边界

```text
训练录音 → 固定频率联合投影 → 幅度统计profile
                                       ↓
                       新生成的相关Gaussian AR状态
                                       ↓
            方差归一的平滑插值 → 正幅度增益 → 原13条OSC
                                       ↓
                    同一份冻结细谱共振 → 干声监听
```

新过程支持奇异协方差，零协方差精确产生单位增益；不会为Cholesky分解强加随机纹理。相邻状态作余弦插值，再除以其精确标准差，保持各时刻边缘协方差一致。增益为`exp(s·z−s²·V)`，使每条OSC的期望平方增益为1。有限12秒的响度仍可变化，不逐种子补偿。

同一OSC左右声道使用同一幅度增益。没有频率／相位调制、周期LFO、房间模型或人工加宽；不是新低频噪声层。旧细节层的幅度起伏在本对照中关闭，避免同时改变主声线与细节。新版本不会通过填入独立高频OSC改变声线。

| 模块 | 职责 |
|---|---|
| `tools/modal_texture_v1/analysis.py` | 原生联合幅度观察、统计编译；不推断频率／发动机相位 |
| `tools/modal_texture_v1/envelope.py` | 通用相关幅度状态与正增益；无车型／素材ID分支 |
| `tools/modal_texture_v1/voice.py` | 给独立OSC施加幅度，不改频率／平均相位；复用原0量渲染 |
| `diagnose_modal_texture_v1.py`／`run_modal_texture_v1.py` | 已知先行控制、素材宿主、全部种子／参数／音频 |
| `audit_modal_texture_v1.py` | 独立QR投影、标量状态／增益、复OSC与全长FFT卷积复核 |
| `review_modal_texture_v1.py`／`check_modal_texture_v1.cjs` | 单播放器、同增益导出和静音浏览器检查 |

表中未写目录的入口均在`tools/`。C的`modal_source`／`modal_layer`及当前驾驶链不改，本轮没有把Python模块画成已部署C模块。未来若音色成立，幅度状态／声源核／参数IO／驾驶适配仍分开接入现有唯一驾驶器；不会新增一个RPM状态机。

## 交付与验证边界

全部三种子、三档变化量均导出完整混音与主声线独奏，0量混音与冻结F2V2细化共振FLOAT逐样本相同。新参数编译和全部渲染保存后，试听页才复制原9–12秒参考；同一次录音保留段不是独立实车验证。

独立复核重建33个已知局部模型／全部对应，使用QR复核141窗幅度／协方差，另以标量AR、独立PRNG和复OSC／全长FFT卷积重建全部9组主声线与混音，最大FLOAT误差1.49e−8FS。三组最大峰0.391FS；相对0量有限频带功率变化−0.205至+0.106dB，未据此称听感改善。

19种播放组合、跳转、播放中切换、原录音控件限制与手机布局通过，桌面／手机截图已目视；自动播放全程静音，不能代替听评。569份C/H、67运行声音配置逐哈希保持，未重复59CTest。资料冻结`baselines/modal_texture_v1`。

下一步先判断主声线起伏是否有帮助，警惕泵动和弱线噪声被当作幅度；之后再决定是否与旧细节幅度协同，并验证通用实时实现。原F2V2问题不重复提问；原共同相位资格、实际RPM／负载、完整加速、多发动机与物理7.1.4仍未完成。

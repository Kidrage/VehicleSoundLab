# F3五挡局部声线 V1

后续[微弱残差数值核查V1](微弱残差数值核查V1.md)已逐字节复现模型，并用精确二进制矩核对全部保存时间系数；原替代路径的1e-9比值检查仍失败并保持原状，差异有条件扰动解释。下文是本阶段的历史状态，不据此追认听感或推广到实时。

**同一套局部Sound DNA方法在两次五挡升速观察中均提取出可持续生成的主声线；尚未取得完整参数审计通过，不接实时目录。** 两个模型的声学根频率约64.80／64.01 Hz，彼此仅差约1.2%，不能据此宣称已经覆盖宽转速驾驶或多款发动机。

本轮沿用已批准、用户认为清晰的F3原录音，复用已看过的20张原PTS显示注释；没有重新读图或补画精确RPM。计划在新音频读取前已固定，期间先完成用户的ADI V4算力问题，然后执行本轮提取。

## 提取和工程接口

复用80 ms Hann／240采样步长／16384 FFT；在固定锚点取100–450 Hz最显著实测峰除以5，检查2／3／7倍频。一次18周期孔径、5倍频共同相位修正，独立3／7倍频相干须各声道都高于0.8，至少32次观察；288分音、12统计分量。没有换窗口、锚点、参考阶次或降低声学门槛。

```text
获批素材与固定计划
  → local_voice_batch_v1/batch.py：已知控制、固定局部提取、导出编排
  → 既有 sound_dna 参数格式：分音均值／统计方向／每分音残差
  → 既有 sound_dna_export：显式种子、原C生成、无PCM时间线

local_voice_batch_v1/audit_kernels.py：独立时域卷积、路径、解调与稀疏C核查
inspect／verify：同音高频带和左右关系；不改变模型
```

已知递减及递增声源、边界拒绝、固定可见声线／静音控制均先于实录读取。原失败的通用相位提取研究仍未通过，本次局部成功不覆盖这些失败。

每个模型生成3条固定种子1／23117／61927、8秒持续OSC，另生成同一64 Hz音高下的3条；均单位原始增益，没有房间、EQ、逐条响度补偿或循环录音。总计12条C音频。它们目前是离线候选，未写进`voices/`或目录。

## 已核对的内容与未通过项

- 全部370个原生观察窗的功率、`L*conj(R)`交叉谱、峰值及标量路径独立核对。最大频带功率差约8.33e-17FS²、交叉谱差约4.39e-17FS²。
- 独立重建逆相位坐标与原坐标精确一致；直接时域FIR重建后转FLOAT，与两份保存提取波形逐样本一致。全部分音直接解调的均值误差至多1.47e-14FS、残差协方差误差至多9.59e-21。
- 12条C音频各检查14个覆盖0–8秒的采样位置，独立PRNG／直接三角求和最大差约2.99e-8FS；这是稀疏核对，不是全样本oracle。每个模型三随机种子输出不同。
- 另加的“每分音残差时间系数绝对差<1e-9”审计未通过。`audit1`原失败完整保留，`audit2`继续核对其他内容并明确返回未解决状态，没有把失败改成通过。最大比值差约2.82e-6／1.39e-6，出现在229阶，残差平方和约4.93e-18／8.75e-18。
- 固定诊断仅减少直接三角解调的大角度参数，原始模型不变；差异降到约2.67e-9／4.61e-9，但仍分别有8／6阶不满足原1e-9条件。它说明数值求和方式贡献明显，尚未完成严格条件误差界，不能把完整参数审计称为通过，也不据此判断车声有瑕疵。
- `compare1`在读实录前，把有限实余弦的频带相关当成无限解析信号而失败。`compare2`用双镜像、有限Hann窗的闭式几何级数参照修正；独立相关差约2.79e-14，而理想表达式确有约3.85e-8偏差。两次执行源与结果都保留。
- `verify1`用SciPy Welch／反序CSD复核全部两条参考、六条同音高C和四组跨片段配对。功率误差至多1.95e-16FS²，复相关差至多2.08e-14。它保留原参数比值未解决状态，不替代整个审计。

## 对主声线和分层的意义

同一64 Hz下，不作增益匹配，三种子平均的双声道频带误差为：

| 频带 | 第一段C相对参考 | 第二段C相对参考 |
|---|---:|---:|
| 28–120 Hz | −4.27 dB | −4.72 dB |
| 120–400 Hz | −0.31 dB | −0.15 dB |
| 400–1200 Hz | −0.23 dB | −0.30 dB |
| 1.2–3 kHz | −0.95 dB | −0.77 dB |
| 3–6 kHz | −2.16 dB | −2.46 dB |
| 6–8 kHz | −2.94 dB | −3.64 dB |
| 8–10 kHz | −3.64 dB | −3.85 dB |
| 10–14 kHz | −3.73 dB | −4.40 dB |

参考仅约0.215–0.219秒，生成声8秒；这里是短训练片段与长生成声的描述统计，不能当作听感评分、泛化通过条件或应全补回的发动机能量。缺口可能包括非谐波、车内、道路、风噪和处理影响。主声线已接近的120–1200 Hz与高低频缺口应分别处理，继续保留DNA／低频／左右联合细节的边界；不要整体增亮或把所有差额解释成机械摩擦。

四组模型／参考配对的平均绝对频带差约2.28／2.53／3.18／2.54 dB；样本时长不同、来源同视频，不作为独立跨录音泛化证明。两个根频率太近，不能把两份音色直接按RPM排列就宣称形成宽范围音色库。

原650份C/H、76份声音参数和F2三个文件均精确保持；未更改驾驶器、空间、UI、默认、录放身份、待听F2／F3强度，未重跑未改动的67项CTest。两张诊断图已目视，未作听音验收；没有新下载或推送。

下一步先在已知可控的小残差信号上确定参数比值的数值可分辨范围，再复核冻结模型；不继续修改这两段的窗口／阶次／门槛救援。之后仍需真正覆盖不同音高及工况的独立证据，才能建立连续驾驶音色库。多款真实发动机、完整状态音色与物理7.1.4仍未完成。

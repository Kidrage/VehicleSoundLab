# 左右相对相位声源 V1

本轮已生成两组中点、三个种子的持续 OSC 对照，优先核对**固定相位／左右相位变化**。两版共享完全相同的幅度，没有混响或扩宽器。[单播放器试听](http://127.0.0.1:8789/references/analysis/relative_phase_v1/review1/index.html)另附原 C 和未循环的原声短参考。听评待答，尚未替换实时 C。

上一目标轮只复核21569预算，未推进合成。本轮先完成上阶段归档及本地提交`1cf5039`，随后按固定计划验证其已知相位缺口。

## 方法和模块

上一版分别拟合左右绝对相位；两边边际接近，差值的关联仍会失真。本轮每个分音改成：

```
左右差相位 Δ = arg(zL · conj(zR))，在最大未观察圆周间隙展开
共同相位 C = arg(zL · exp(-iΔ/2))，再独立展开
重建：φL = C + Δ/2；φR = C − Δ/2
```

这里的共同相位是**每个分音的左右中点**，不是给整车声线统一加一个LFO，也不是此前“共同微扰·轻量”的同名实现。差相位描述录音L/R关联，不能直接当作物理左右气缸或车外声源坐标。

| 模块 | 功能 |
|---|---|
| `tools/relative_phase_v1/coordinates.py` | 编解码共同／相对相位及圆周分支 |
| `profile.py` | 同一幅度分位表、平秩正态分数、12因子PCA＋对角残差和AR编译 |
| `observe.py` | 圆周相位矩、左右幅度乘积与相位的有符号关联 |
| `render.py` | 一次幅度求值，同时写固定／变化相位两版OSC |
| 原 `radial_copula_v1/latent.py`、`quantiles.py` | 继续复用新随机创新、逐因子插值方差归一及连续逆CDF |

六个输入全部取自上一冻结包，不重新拟合声学时钟、源窗口或阶次。幅度分位表与上一版**逐元素精确相同**；换了相位坐标后联合PCA发生变化，所以新旧两种编译器的幅度时间过程不宣称精确相同。只有本轮固定／变化相位这对声音共享同一个幅度过程。

## 实际结果

九组已知控制包含同声道、固定相位差、共同PM、差分PM、反向AM、跨π、整体相位旋转、换左右和静音。源重建最大误差6.35e−16 FS；纯PM不产生调幅，固定左右相位差保持，静音精确零。

六个原素材观察各3组4096个Sobol样本，独立核查源节点、平秩、AR、完整有符号协方差及全部报告汇总后：

| 训练系数指标 | 结果 |
|---|---:|
| 原固定相位：平均复数左右相干度绝对误差 | 0.117974 |
| 上轮左右绝对相位模型 | 0.167441 |
| 本轮共同＋相对相位模型 | **0.067913** |
| 相对上轮绝对相位改善坐标 | 24／24 |
| 相对固定相位改善坐标 | 19／24；另5个退步 |
| 幅度功率CV误差L2：上轮／本轮 | 0.203304／0.203456 |

幅度起伏的近似质量基本保持，主要变化在左右关联。数字来自同批训练观察，既不是独立实车验证，也不是听感真实度分数；五个退步坐标完整保留，没有按频带切换模型掩盖。

两中点各3种子×2版本，共12条新8秒声音，以各自64.8044／64.0149 Hz固定声学根频率持续生成。37／1024分块的首组首种子**两版PCM均精确相同**。独立AR滤波、逐点逆CDF和标量正弦求和核查全部12条，最大FLOAT误差2.98e−8 FS，满足显式半ULP＋2e−10 FS界。

另以实际WAV的左右Welch/CSD作检查，并用独立重叠FFT、已知同相／偏相位信号复核：两组共8个高频带坐标均比本轮配对固定相位更接近原短参考，平均误差0.15603→0.09426；原C约0.15276。独立算法差异低于1.42e−14。**这仍是短变音高原声与8秒固定音高合成的统计比较，不是同轨迹重放。**

相邻统计更新的功率关联仍普遍低于原重叠四周期Hann观察；源观察本身含窗口平滑，不能直接把此差值都补成发动机慢调制。本轮未提高ρ、扫描强度或编造新的驾驶状态映射。

## 监听与工程边界

20条试听是6条原C、12条新配对声音和2条原始短参考。统一0.5增益及5ms淡化，无逐条响度补偿。变化相位会改变峰值，未增益原始FLOAT最高约1.0495 FS；发布试听约0.525 FS，没有截断或限幅来隐藏差别。

单播放器20项元数据、静音播放／seek、选择后暂停、快速选择竞态、手机无横向溢出检查通过；两张科学图及桌面／手机截图分别目视。页面可供听评，数值／浏览器通过不等于听感通过。上轮幅度听评、旧F2/F3听评互相独立，未覆盖成新结论。

该模型表示不写死V10，但目前只验证同一V10的六个局部观察；没有新增其他实车、完整RPM／负载覆盖或事件音色。继续保留V6的DNA／BODY／DETAIL／EVENT／AUX、唯一驾驶器和独立空间层。录音声场属于声纹观察，未来7.1.4的声源位置、反射与输出布局仍需分别实现。

当前670份C/H、82份声纹参数、3份保护F2文件和C索引保持精确；默认、认可moving35、驾驶器、owned、takes及room未改。本轮新模型／OSC在Python离线研究目录，尚无C实时移植，逐采样1152×12投影不能套用既有21569的800MCPS预算。多发动机、全驾驶状态和物理7.1.4目标仍未完成。

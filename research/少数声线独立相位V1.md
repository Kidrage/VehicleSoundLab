# 少数声线独立相位 V1

2026-11-13。离线有限窗研究；行驶35%保持，没有新实录拟合、怠速／加速DNA或C音轨。完整驾驶音色目标继续未完成。

## 本轮改进

上一模型要求所有声线只有幅度变化、相位变化全部共同。单条声线另有独立变化时，优化会把一部分失配吸收到共同相位。本轮保留大多数声线的共同相位，只允许**最多两条**具有有界实相位变化：

`angle_k = 2πk[u + ε(u)] + δ_k(u)`

`ε`仍以主周期计，`δ`以该声线的弧度计，二者不能混用。未选声线的`δ`严格为0；选中声线为0.5周期结点样条、控制量界限±1弧度。幅度仍为正的慢实包络、每条声线常量复系数。没有给全部声线自由复包络，也不声称识别出物理曲轴相位。

从原模型残差中选择独立变化：为各候选声线计算相位微变的前向导数，经过同一实波形有限窗投影，再以最小二乘计算它能解释的残差能量比例，取最高者。该比例是局部线性解释能力，不是发动机来源概率。超过预定0.2才添加该声线，联合求解后再检查残差；最多两条，不枚举组合找最好结果。

停止条件是归一化复投影残差≤0.003，且至少3条未选声线仍有幅度支持；坐标需单调、幅度需正。原相位p95≤0.0001周期、根音p95≤1%、留出功率≤0.5dB、复相关≤0.05及2条留出支持门槛全部保持。选择过程不读取案例标签、相位真值或10／15阶留出数据。

得到的共同坐标应用于**原始完整双声道**，独立细节仍保留在观察中；不把拟合的平均波形冒充新音色。L/R仍是录音观察，不是气缸组，也没有新增房间处理。

## 模块与证据

| 文件 | 职责 |
|---|---|
| `tools/minority_phase_v1/model.py` | 共同相位＋有界少数独立相位，解析前向导数与参数范围 |
| `selection.py` | 仅从当前观测残差计算候选方向及排序 |
| `fit.py` | 有上限的选择／联合求解、观测支持判定；不访问案例真值 |
| `fixtures.py` | 原7例逐样本保持；新增不同阶次、两条及全部独立变化 |
| `checks.py` | 零独立量精确等价和独立中心差分检查 |
| `validate_minority_phase_v1.py` | 12例执行、真实参数／坐标、逐次选择与求解状态 |
| `audit_minority_phase_v1.py` | 不重拟合的参数／输入边界／相位图核对 |

原7例基线只有在原计划、执行源、库版本、解析fixture、已保存参数／相位和实际残差都精确一致时复用。`validate1`因复数向量范数与实虚拼接范数的浮点求和差异导致精确比较失败，未进入案例；`validate2`统一为原计算表达式，保留精确比较，不添加容差，失败源保留。

零独立量输出与原模型逐样本相等；共同相位、两组独立相位、幅度和混合方向五类解析导数，中心差分相对误差最大约1.53e−8，通过原1e−6门槛。

## 实际结果

预定12例全部完成：**10正例通过原误差门槛，2反例由观测支持条件正确拒绝。** 原五个正常正例不新增分量，输出与保存基线精确一致；原“独立5阶”正例保持原要求，未改为反例。

所有正例最大相位p95约0.00005774周期、根音相对p95约0.03749%、留出功率差0.07827dB、左右复相关差0.00007537。5阶候选方向可解释约95.62%的原残差能量，高于相邻5.2阶的59.99%；选择没有读取实际标签。

单声线反例仅剩1条载波且没有留出支持，拒绝；全部声线独立变化时，即使选择3／1.4阶两个方向，归一化残差仍0.23916，超过0.003，拒绝。拒绝来自实际观测支持，未用相位真值替代支持判据。

8次新增联合求解均达到120次上限，**不宣称已收敛或全局最优**；上述结论仅为本组误差／支持门槛。原7例基线精确复用，新增5例基线重新计算。没有为通过而调整窗口、门槛、独立声线数或参考声线。

## 适用边界与下一步

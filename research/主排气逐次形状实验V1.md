# 主排气逐次形状 · 独立实验 V1

本轮把逐次变化放入主排气燃烧支路，检验它是否比只增加附加短响应更有帮助。七场景提供 V018原声／轻度／完整三档：[打开试听](主排气逐次形状试听V1.html)。原生V018及所有默认参数保留。候选还没有主观验收，完整档可能增加粗糙或毛刺。

## 为什么改这一处

此前实际分轨核查表明：附加压力／机械层确实改变波形，高转主排气仍很容易重复。V018已把响应形状做成可实时操作的功能，但完整混音差异相对原声约−41～−47dB。继续添加同类模态或加大机械音量，未必能改善用户指出的整体电子感。

已批准A录音的既有谱线补偿、跨周期与高频包络核查，支持继续研究未被固定周期解释的结构，但没有分离出真实随机燃烧或机械噪声。本轮不把这些统计量换算为需要添加的随机量。页面保留A低转与补油两个实录参照；它们与合成器没有匹配RPM、负载、话筒和响度，不是标定对照。

## C模块与路径

独立代码在 `experiments/event_color_v1/`：

| 文件 | 职责 |
|---|---|
| `split.c/.h` | 两个固定二阶Butterworth低通，独立滤波历史 |
| `profile.c/.h` | 分频、平滑和变化深度，明确的工程配方 |
| `color.c/.h` | 读取已有逐缸事件、两缸列控制、许可与旁路、主燃烧支路增量 |
| `probe.c` | 严格V018 take重建、完整混音、十声源与双精度诊断 |
| `checks.c` | 关闭旁路、原状态、燃烧许可、分块、布局、资格与滤波契约 |
| `CMakeLists.txt` | 从冻结V018生成仅含显式实例挂点的实验调度器；链接冻结核心库 |

主排气的低DNA与高阶OSC先按原算法生成；候选保存这一支路，经原燃烧供给增益后计算增量。增量在原有附加细节之后、DNA驱动的IR返回之前加入两个排气声源。泵气支路不经过候选；附加压力与结构、进气、机械和气流也不经过它。body会接收改变后的排气IR，这是已有明确路由。

令 `x` 为原主燃烧声，`l=LP1400(x)`、`u=LP4500(x)`，候选为：

`y = x + 0.45 m_mid (u−l) + 0.90 m_high (x−u)`

低通是固定二阶Butterworth。分量有重叠和相位，不是理想砖墙频带，不能据此声称低频波形完全不变。两项m来自同一次既有逐缸事件：

`target_mid = 0.65 energy + 0.35 shape`

`target_high = −0.20 energy + 0.80 shape`

energy／shape是已有C工程事件状态，不是测得缸压或焦耳。控制使用1.5ms一阶平滑，再乘候选力度和裁剪至0～1的 `irregularity/0.35`。右缸列控制沿用0.38ms工程延时及线性分数采样插值，与原声源的缸列延时约定保持一致。没有从录音L／R识别缸列，也没有为监听声道做随机失谐。

不新抽随机数、不改点火或曲轴时钟、不更改DNA系数。候选接受原有许可燃烧事件；断油或停机时不接受新事件，控制向零释放，已有滤波历史继续推进。其他模板、导入DNA、Pure OSC或关闭原逐次压力模型时旁路。0档完全跳过输出增量。

这是时变宽频增益，可能产生调制边带；没有宣称任意采样率下严格带限，也没有用新增噪声去追求参考平坦度。配方并非实测Lamborghini排气传递。它借鉴V6分开维护激励、声层和空间的方法，没有把上游非整数OSC直接当作目标车机械测量。

## 对照与实际结果

七场景：1200／4000／8000工程RPM，空挡补油、5000 RPM收油恢复、30s运动自动挡，以及8000 RPM与现有细节合用。最后一项启用65%燃烧／机械细节及75%响应形状，其余保持新增细节为0，以单独检查主支路候选。每个场景采用新录制的严格V018 take、相同输入和种子48271；不翻译历史take。

| 场景 | 完整档差异RMS相对原声 | 原声→完整档整段RMS变化 |
|---|---:|---:|
| 1200 RPM | −27.19dB | +0.0116dB |
| 4000 RPM | −21.21dB | +0.0296dB |
| 8000 RPM | −20.99dB | +0.0299dB |
| 空挡补油 | −25.06dB | +0.0115dB |
| 收油／恢复 | −21.42dB | +0.0281dB |
| 运动自动挡 | −20.71dB | +0.0347dB |
| 与现有细节合用 | −21.14dB | +0.0288dB |

差分仅描述候选改变了多少波形，不是机械声占比或真实度。三档共用一个场景固定增益，显示在页面；5ms余弦端点淡化、PCM24量化，不逐档归一化。float32原电平混音与十声源保留。实录只采用固定0.5增益、相同长度余弦端点淡化和PCM24量化，保留左右，不高通、降噪或压缩。

新候选确实降低已知模型周期的固定波形可预测性。用过去8个完整720°模型周期预测后4个周期，3–8kHz、左声道误差如下；该误差越大只表示较难重复，不表示更真实。

| 工程RPM | 原声 | 轻度 | 完整 |
|---|---:|---:|---:|
| 1200 | −3.969dB | −3.558dB | −2.774dB |
| 4000 | −8.615dB | −8.022dB | −6.637dB |
| 8000 | −9.910dB | −9.166dB | −7.471dB |

该指标在本轮只用于相同已知模型输入的机制检查，没有与未知RPM的参考误差相减。右声道及完整统计保存在 `analysis.json`。

## 验证与复现

- 独立CTest通过：原生0档精确旁路；完整驾驶、DNA、高阶、原逐缸随机与响应状态保持；停机没有新事件；1／257帧分块输出和完整同布局状态一致；stereo／12声道十源一致；其他模板、导入、Pure OSC及压力开关旁路。16／48／192kHz滤波冲激验证DC增益与衰减。
- 七场景0档float WAV与冻结V018重建逐字节一致。三档全部原驾驶日志及排除有意声学返回后的完整原核心状态哈希一致，事件计数一致，没有接受到无许可原事件。
- 除两排气源和有意接收其IR返回的body外，其余七源逐字节一致。8000 RPM的7.1.4与stereo十源及状态／驾驶日志一致；未进行真实扬声器阵列听评。
- 独立SciPy Butterworth设计和时域滤波，用C观察到的双精度原支路及控制，预测候选主支路，最大误差 `5.55e−16`；预测实际float32排气分轨的差分，最大误差 `5.91e−8`。这核对实现，不核对真实车声。
- Chrome实际静音解码／播放检查：21个候选、2个实录，版本切换保留位置与播放，场景切换停止归零，过期加载隔离，实录／合成互斥，HTTP／本地文件入口、桌面／手机布局通过，截图已检查。
- 原生V018源码、构建入口、二进制及V011排气系数另做哈希核对；原生界面与设备生命周期未修改，不重复无关的设备测试。此前33份冻结manifest身份保留。

```powershell
cmake --build build-experiment-event-color --config Release --parallel
ctest --test-dir build-experiment-event-color -C Release --output-on-failure
```

结果、独立核验、浏览器记录与冻结清单：`renders/event_color_v1/results.json`、`analysis.json`、`browser_qa.json`、`verification.json`、`baselines/event_color_v1/manifest.json`。脚本拒绝覆盖完成的数据；新实验需用新名称。

这轮提供更有辨识度的主排气逐次变化供听评，尚未确认它减少电子感。原V011连贯方向仍是最近获得认可的声线；主观自然度、目标车RPM×负载标定和实际7.1.4听评仍未完成，完整目标继续进行。

# V016 · 原生燃烧与机械细节实验

针对“整体都偏电子，先加强逐次燃烧与机械细节”的听评，V016 把已冻结的 character_v1 配方迁入原生 C 驾驶程序。此次交付是实时操控与录制集成。没有新增主观认可，也没有根据数值测试推断真实度提升。

## 试听操作

双击工作区根目录的 `Launch-character.cmd`。进入 **Sound detail**，最下方两个旋钮分别是：

| 控件 | 声音作用 |
|---|---|
| Combustion texture (test) | 每次燃烧的短压力响应；进入左右排气源及既有 IR 返回 |
| Mechanical transfer (test) | 同一燃烧事件激发较慢的结构余振，并增加原有机械源的可听度 |

两项均默认 0。可先各设 65%，与各为 0 时比较，再单独改变其中一层。65% 沿用之前离线合用版的设置，只是比较起点。保持其他旋钮和输出音量不动，听敲击、金属振铃、毛刺与高转声线的变化。它们是同一引擎中的连续控制，无需停止驾驶。

选择 Pedal driving，Start 点火／监听，W／S 油门／制动，Q／E 减挡／加挡；也可选择 Auto drive。现有运动策略继续松油保挡，制动安全降挡。New take、Save take、Replay take 可保存和回放实际操作；两项细节强度同其他参数一起记录。预设也保存两项数值。旧预设缺少它们时均取 0，其他有效参数保留。

`Launch.cmd` 仍启动冻结 V015。V016 使用 `VSLTAKE 2`、34 个明确语义字段和严格 DSP 版本；V015 旧 take 继续由 V015 回放，两个版本互相拒绝不兼容 take。此次不转换或覆盖旧文件。自动保存仍在 `performances/`。

## 状态与算法

继承上游 V6 的控制→工况→分层包络／事件→声学与空间组织方式。新机制由实际积分曲轴的 720° 点火时序驱动，每个缸保留独立随机种子、事件强度与形状记忆。CATCH／RUNNING、燃烧许可、燃油供给和原有 fired 激励共同决定是否新增事件。断油、停机不再生成燃烧冲击；已有余振按阻尼自然衰减。原有转动机械、泵气、气流仍按自己的条件工作。

短压力使用 1050／2900／6100 Hz 三条阻尼正弦，衰减常数 1.4／0.65／0.32 ms。结构使用 610／1180／2240／3870／5820 Hz 五条模态，衰减常数 12／8／5／3.5／2.5 ms。配方与冻结实验相同，`event_energy` 为无量纲工程强度。机械满强度额外增加原机械源的三倍幅度，即合计最高四倍（约 +12.04 dB），另有受激结构响应。

这些频率、衰减、强度、逐缸记忆和右缸列 0.38 ms 延时均含工程假设，不是从参考录音分离出的实车缸压、歧管或机体 FRF。录音左右声道也没有被当成发动机左右缸列。参考素材仅用于离线分析，实时核心不播放原车采样。

新增强度经 18 ms 参数平滑，分别受原有燃烧变化／机械模型开关约束。Pure OSC、导入 DNA、其他四模板旁路。切换模板或 DNA 资格时清理实验响应历史，避免回切出现旧余振或伪点火；逐缸随机流和计数仍属于各自引擎。没有使用离线宿主的全局绑定机制。

原 V011 的低 DNA、高阶与共享排气谱形文件保持逐字节一致。新压力进入排气对象，新结构进入机械对象，随后共用原有空间接收模块。十个 pre-master 声源仍独立；Stereo／7.1.4 共用源和事件，7.1.4 仍为 speaker bed。

## 验证与边界

18 项 CTests 已通过。包括三种采样率的逐缸调度、断油无新增事件、零转速余振、停机／Pure OSC／导入 DNA／模板旁路、模板回切无伪事件、热调参平滑、独立引擎与原 RNG／车辆状态不变。驾驶 take 测试增加工厂 V10，覆盖运行中强度变化、任意块长度重建、完整 character 状态以及布局独立性。

静音 waveOut 测试实际操作了两个新旋钮，检查只更新被触碰字段、非网格预设精确往返、V015 缺字段回退、回放时新控件锁定。实际设备录制在非零强度下运行；离线和设备回放都比较完整立体声浮点哈希、完整驾驶与 character 状态，另外检查缓冲断供和设备／墙钟比例。

最终数字与哈希记录在 `renders/v0.16.0/verification.json`；来源／交付文件和历史保护记录在 `workspace_audit.json`，冻结副本在 `baselines/v0.16.0`。比较包含五模板默认输出、30 秒驾驶、六组相同输入的基线与合用版，另检查中转单独两层。新 trace 追加实验遥测，所有原有驾驶列逐值比较。试听副本仅统一乘 0.5 后输出 PCM24，不做逐版本归一化、降噪或新增过滤。

本次核验的实际结果：

| 项目 | 结果 |
|---|---|
| 默认五模板、30 秒驾驶 | 与冻结 V015 的音频文件逐字节一致 |
| 六组基线与冻结实验 | float32 文件逐字节一致 |
| 非零强度相对冻结实验 | 全程最大差值 5.084×10⁻⁷；0.5 秒后最大 9.095×10⁻¹³ |
| 差值来源 | 原生从 0 按 18 ms 平滑强度，离线实验从固定强度起始；最大差值出现在启动过渡 |
| 实际驾驶 take | 511488 帧、8 次输入事件；立体声浮点 FNV-1a64 为 `0a97adb1a0eec574` |
| 设备／离线回放 | 完整音频哈希、驾驶状态及 character 状态一致；十个 stereo／7.1.4 源一致 |
| 设备运行 | 平均每 512 帧渲染 1.447 ms，块时长 10.667 ms；队列断供观测为 0 |
| 设备进度 | 实时 10.656／10.7874 秒；回放 10.656／10.6909 秒（设备／墙钟） |

FNV 是软件合成重建校验，不是声卡回录或声学测量。以上均为这次运行的数据，操作时序会随实际 UI 输入落在哪个设备块而变化，保存的 take 记录真实生效帧。

这些验证确认移植、路由、可操作性和可复现性。目标车的精确声纹／结构传递、状态参数标定、主观自然度与实际 7.1.4 阵列听评仍待完成。当前先获得同一配方在真实操作中的听评，再决定保留哪一层和怎样调整强度。

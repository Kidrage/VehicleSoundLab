# 怠速素材与独立声线 V1

当前 C 驾驶怠速仍主要依赖行驶 DNA 降调。本轮从已批准的 F2 尾排素材制作了新的**固定怠速离线候选**，供听音判断；没有将其接入实时驾驶，也没有把它当作已通过资格验证的共同相位 DNA。

[试听页](http://127.0.0.1:8789/references/analysis/idle_modal_v1/review2/index.html)：先切换原录音、旧 C 声源、新完整候选，再听新候选连续 12 秒。页面可独听低频、中频和高频，只有一个播放器。

## 素材与缺口

本轮核对全部 7 份已批准素材的文件身份，但不混合不同车型和机位。F2 的 6–12 秒作为主怠速素材；A 的两个车外低转片段和 E 片头分别观察。F1 多车／移动话筒、B 车内、D 台架不能直接当作同一尾排怠速；F3 驻车说话段继续排除。

实际 C 行程 0.93–1.43 秒处于 RUNNING／IDLE，工程 RPM 约 850，根音约 7.083–7.109 Hz。300 条主谐波最高载频约 2.125–2.133 kHz；该处独立相干低频及连续细节的支持量与分轨样本均为零。最高载频不是输出的硬截止频率，随机幅度边带和观察窗泄漏仍存在。

| 原生 30 Hz–14 kHz 总频带内功率占比，左声道 | F2 尾排原声 | 当前 C 怠速 |
|---|---:|---:|
| 400–2200 Hz | 4.115% | 0.768% |
| 2200–14000 Hz | 0.630% | 约 0.000000014% |

这些是录音混合频谱，不是物理声源比例，也不是可直接应用的 EQ 增益。原声的变化包含风噪和话筒移动，实际 RPM／冷热状态未确认。

## 新候选怎样生成

本次另走一个边界明确的固定怠速研究分支，不调用仍未合格的共同相位求解器。

1. 只用 F2 **6–9 秒训练**，保留 **9–12 秒**作同一录音内的未参与拟合对照。48 kHz 原生采样，无变调归一化、压缩或去噪。
2. 在固定 0.5 秒 Hann 窗中观察独立声线；要求在至少 80% 训练窗中有对应峰，保留 13 条。频率、均方根幅度和一个共同局部时刻的初始相对相位来自素材；**不强制整数阶次，不认定其为曲轴／点火时钟**。
3. 持续叠加这些正弦声线。剩余频带用同一 F2 训练段拟合的 6 组稳定 AR／SOS 共振器补足，连续产生新激励。所有周期细节包络关闭，不人为加 FM／AM 抖音；没有房间处理。
4. 只有参数进入研究 profile：频率、幅度、初相、滤波器及固定增益。没有 PCM、颗粒、原录音系数时间轴或片段循环。输出时长与音高独立。

独立声线能保留素材的局部结构，**不能保证长期发动机同步相位**；频率之间可能产生拍频。本轮也没有完整负载、RPM 或怠速到加速的过渡标定。此分支不豁免原共同相位提取器的资格门槛。

## 验证与交接

已知离栅双音的频率误差 0.03163 Hz，精确频率下复系数误差 2.67e−16；独立逐项余弦复核导出样本误差 4.79e−9 FS。三组预先指定随机种子全部保留，12 秒音频无削波；七频带／双声道的最大训练功率误差 0.499 dB，同录音保留段最大 1.136 dB。AR 单位方差通过独立多项式响应核查。

这些数值验证频带、实现和报告，**不证明机械自然度**。细节采用近单声道共同激励的近似，没有新立体声宽度或物理声源分离。旧 C 仅作固定工程根音的声源对照，不含完整驾驶状态包络；它单独用一次频带 RMS 对齐，其他新候选／参考共用源增益，再统一保护增益。车型、机位、实际 RPM 不同，不能把这次听音称为同工况还原测试。

首次素材分析的旧模型头解析错误、首次候选导出的功率字段错误及精确执行源均已保留。540 份 C/H、67 份运行声音配置以及认可行驶35%均未改，因此不重复旧 CTest。

参数整理中另将不参与生成的观察频率路径从 profile 移到独立证据文件。第一次用 WAV 容器 SHA 检查此次整理的一致性失败；保留失败后改为分别核查容器与解码样本：9 份 FLOAT 音频的样本全部逐位相等，容器时间戳可不同。最终 `trial4`／`audit2`／`review2` 为本轮交付，前序版本全部保留，声音算法和随机种子未调整。

下一步以听音定位：若新声线仍嗡鸣，先核查低频独立频率的长期相位；若细节像风声，先检查共振预算与机械声线覆盖。固定怠速音色成立后，再做受支持范围、平滑状态过渡及独立 C 模块接入，不能直接把这份固定频率 profile 当作全转速 DNA。

# 左右幅相关联与观察窗口 V1

本轮定位了上一版五处左右关联退步的共同缺口：**幅度与左右相位差的非线性关联仍未恢复**。完整保留训练正态分数协方差后，误差几乎不变，因此继续堆PCA分量不能解决当前缺口。

另确认现有密集重叠Hann窗会在没有物理慢调制的白噪声中产生约0.95的相邻功率关联。不能用这一关联直接指导实时调制器的ρ。

本轮是解释误差来源的诊断，没有新声音或默认替换。[上一版左右相位试听](http://127.0.0.1:8789/references/analysis/relative_phase_v1/review1/index.html)仍可比较，听评与父幅度、旧F2/F3问题分别待答。上一轮已完成候选及归档，是实际进展；本轮续接其明确留下的五处退步与时间窗口问题。

## 左右误差拆解

每个分音定义左右幅度乘积 `P=AL·AR`，以及相对相位单位矢量 `U=exp(i(φL−φR))`：

```
E[P·U] = E[P]·E[U] + Cov(P,U)
```

频带复数相干度还需除以左右平均能量的几何均值。以同一个源归一化分母拆出四项：幅度乘积变化、相位边际变化、幅相关联变化和分母变化。各项保留复数方向／正负和抵消，不裁成“噪声能量”或物理声源百分比。

六个冻结观察、3组4096个Sobol样本的24项平均绝对值：

| 误差项 | 平均模长 |
|---|---:|
| 幅度乘积 | 0.002864 |
| 相位边际 | 0.000675 |
| **幅度—相位关联** | **0.065425** |
| 能量归一化 | 0.0000476 |

总复数相干度误差的平均模长约0.067913。模长不能逐项相加；上表不是误差贡献率。相位边际进一步分成逆CDF连续插值偏差（平均约0.000230）和有限QMC差异（约0.000601），也没有以参数调整消掉它们。

五个退步坐标中，幅相关联项沿总复数误差方向的代数投影约94.8%～99.1%。这只说明这个统计误差主要朝哪一方向产生，**不是发动机声源能量比例，也不是主观电子感归因**。

七个已知控制分别检查相同、仅相位、仅幅度乘积、仅关联、仅分母、正负抵消及静音相干度不可定义。随后独立重算全部源／模型矩、相位积分、分解、五坐标和报告汇总；最大分解差约5.1e−16，相位积分差约7.8e−16。

## 完整协方差的诊断

使用同一幅度／相位分位表，以 `scores.T/sqrt(N)` 作为总体协方差因子，移除12因子加独立对角残差的近似。这个因子解析保留全部训练分数协方差，最大数值差约1.12e−15。

| 表示 | 平均复数相干度误差 |
|---|---:|
| 当前12因子＋对角残差 | 0.0679133 |
| 完整总体分数高斯诊断 | 0.0677251 |

24项中15项变好，9项变差，整体差异很小。**这不是新的高阶次预设、主成分扫描或音色候选。** 它区分了“少保留一些协方差方向”和“仅用高斯依赖表达原幅相关联”两个问题；本批训练证据支持下一步研究后者。

后续可行路线是建立**幅度条件下的相对相位分布**：在保持幅度边际和基本左右能量的前提下，直接核对条件圆周矩与`E[P·U]`。需要先检查给定幅度分布下目标是否可实现，再验证连续生成是否产生跳变、颤动或声线模糊。当前没有把这一构想称作已实现的系统，也没有从训练指标推导出听感保证。

## 观察窗口造成的时间关联

核对当前`tools/sound_dna/windowed.py`与先前原观察的冻结源码SHA精确相同：周期Hann4096、hop256、每周期1024点、分音FFT格点为`4×order`，带全局解调。因此相邻观察相隔四分之一声学周期，窗口支持四个周期，有16倍重叠。

在归一化周期坐标中，对**实白高斯噪声**解析计算所有阶次对的复协方差`R`和伪协方差`P`，频带功率协方差包含`|R|²+|P|²`。不能只用一个复数相关系数平方省略实信号伪协方差和阶次间项。

- 无限总体相邻功率关联约**0.949881**，即使输入没有物理慢调制。
- 按源的39～41行对理论协方差作去均值处理后，相邻比值约**0.93372～0.93482**。
- 后者是“期望去均值滞后积／期望去均值方差”，**不是样本相关系数的期望**。
- 六源实测相邻比值约0.843～0.997，更远滞后既有正持续，也有负值，不能压成统一ρ或把所有变化都判成窗口产物。

小尺寸实二次型的`2·tr(QiQj)`独立核对观察协方差和去均值；原4096点窗口再由有限几何级数的闭式和独立核对FFT计算，最大归一化差约8.9e−16。核查代码未调用生产端窗口内核。

白噪声参照位于归一化坐标，**不假设原生录音经时钟变换／抗混叠滤波后仍是独立白样本**。它没有辨识真实发动机时间常数，也不证明真实慢调制不存在。下一步应把候选生成的时间变化送过同一观察模型再比较，保留源窗口造成的平滑与不确定性，不能直接抬ρ“补齐”相邻关联。

## 工程结构与留痕

| 模块 | 职责 |
|---|---|
| `tools/stereo_phase_budget_v1/budget.py` | 复数有符号误差分解、连续相位分位表的解析圆周矩 |
| `window.py` | 原观察窗的实高斯参照、去均值矩与源滞后统计 |
| `run_stereo_phase_budget_v1.py` | 已知控制／冻结输入／完整总体诊断执行与记录 |
| `audit_stereo_phase_budget_v1.py` | 独立逆CDF、矩、求积、有限几何级数及实二次型核查 |
| `review_stereo_phase_budget_v1.py` | 科学图表发布 |
| `package_stereo_phase_budget_v1.py` | 保护清单、源码、证据与失败尝试归档 |

工作区`references/analysis/stereo_phase_budget_v1`保留`known1`、`known_audit1`、`real1`、`real_audit1`；`real_audit2`补强总体诊断的功率数组及全部图表JSON字段绑定，源与数值输出未改。首次图表`review1`图例遮住小分项，保留准确源码和图；`review2`只移动图例／修改标题，数值不改，窗口图逐字节一致，两张最终图分别目视。没有修改统计门槛、源窗口、阶次、ρ或相位强度。

当前670份C/H、82份参数、3份保护F2和C索引保持精确；默认、驾驶器、owned／takes、room、认可配方与父试听保持。本轮未重跑未改68CTest、下载、推送或产生新听评问题。新诊断位于DNA统计工具层，仍保留V6的DNA／BODY／DETAIL／EVENT／AUX、唯一驾驶器与独立未来空间接口。

多发动机、完整RPM／负载／驾驶状态、实时C候选和物理7.1.4仍未完成。下一步先资格验证幅度条件相位关联，再验证经过原观察窗的生成时间结构；通过后才能推进数值／性能／听感分别验收的C接入。

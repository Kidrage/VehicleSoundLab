# 新声源的高频与左右诊断 V1

本轮补齐新输入方法的诊断入口。新音频是声音比较参考，原`metric_target`只固定提取尺度；两者分别留痕。当前已验证解析案例和真实参考衔接，真实拟合仍在运行，不能据此宣称自然度改善或新的持续声源合格。

| 模块 | 职责 |
|---|---|
| `locked_source_diagnostics_v1/input.py` | 校验新方法的数学审计、捕获、源码与输入身份；不伪装成旧六段协议 |
| `virtual.py` | 用原合格测量器检查新目标与完整上下文，输出完整频带和左右统计 |
| `audit_stereo.py` | 独立Welch／CSD、直接mid/side、时间Gram和冻结序列统计复核 |
| `native_reference.py` | 把新准备数据对应回原48kHz区间与16／32倍查询，不需要伪造拟合结果 |
| `native_input.py` | 合并终止数学审计与物理参考衔接，之后才允许原生渲染 |
| `native_identity.py` | 独立检查新方法身份、旧标尺、新源和原始录音／查询的对应关系 |

三个非零解析案例都已通过新入口与独立核查，包含不等左右声道、0.35ms右声道相位延迟、右声道静音；六种损坏的审计／绑定拒绝。目标区和完整上下文均保存新参考与拟合波形，检查六宽带与全部原阶次线、功率、左右互谱、mid/side、CV、协方差和跨时差的变化，没有逐条增益匹配。

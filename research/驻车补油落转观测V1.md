# 驻车补油落转观测 · V1

已批准的 Performante 尾排录音中，第一段明显下降的主频率线约从 **314 Hz 降到 157 Hz，用时约 0.8 秒**。左右声道分别分析，以及 80／128／192 ms 三种窗口，都支持这个相对变化。它目前只能约束录音里的频率下降过程，不能直接给出实际转速、空挡摩擦或曲轴惯量。本轮维持 V0.13.0 驾驶／声音参数，新增离线分析工具和证据。

## 素材和处理

使用 `references/segments_v1.json` 中的 `A_exterior_blips`，经 `tools/reference_segments.py` 检查批准范围、原始文件和 float32 stereo 主文件 SHA256，再读取 238–248 秒。L／R 波形保持原值；共同选线仅平均左右功率，没有叠加声道波形，没有归一化、滤波、降噪、压缩或新导出参考音频。原有试听可用 `references/clean/A_corsa_tailpipe_blips.wav`，其固定 −6.0206 dB／28 Hz 高通／端点淡化不用于本次计算。

视频上下文支持驻车、车外尾部、驾驶门打开；空挡、踏板轨迹、实际 RPM 和负载没有得到确认。时间均为独立解码音频主文件中的秒数，未把视频 PTS 当作实测音画同步或松油时刻。

## 方法与可靠程度

此前半秒窗梳状谱的最优“基频”在补油过程中会跨倍频跳动。本轮手动选定清晰频率线的起始锚点，以谱峰的显著度、电平和连续性寻找路径。算法允许上升和下降，没有预设落转曲线或结束频率；找不到连续路径就保留失败，不插值补线。它用于已挑出的短片段，不是可直接部署的通用发动机转速识别器。

Hann 窗为 80／128／192 ms，步长 10 ms，32768 点 FFT。原始频率栅格分别为 12.5／7.8125／5.2083 Hz；补零后的 1.4648 Hz 和抛物线峰值插值不会提高两条相邻谱线的可分辨能力。时刻是窗口中心，路径经过重叠窗口平滑；不同窗口结果的接近程度不能当作统计置信区间，也不代表毫秒精度。

| 观测 | 结果 | 证据范围 |
|---|---|---|
| 第一段上方频率线，238.18–239.00 秒 | 128 ms 功率均值：314.46 → 157.03 Hz；端点间隔 0.81 s | 3 窗口 × L／R／功率均值，9 组均连通；频率终值／初值 0.4937–0.4995 |
| 第一段下方频率线，238.18–238.80 秒 | 与上方线共同下降；频率比约 0.60 | 128／192 ms 支持；80 ms 失败。缩短区间以避开后段近 100 Hz 的重叠 |
| 第二段上方线，240.90–241.70 秒 | 128 ms 下约 277.73 → 168.14 Hz，0.79 s | 80／192 ms 无连续路径；保留为较弱证据，不能视为同等可靠的第二次标定 |

全部 36 组路径尝试中 24 组连通、12 组失败；完整失败清单保存在结果 JSON 中。连通只说明存在符合约束的谱峰路径。首段上下两线约 3:5 的关系支持共同变化的频率族，但尚未证明对应哪两个物理发动机阶次。

![两段频率线与窗口检查](../references/analysis/rev_descent_v1/descent_tracks.png)

已知信号控制包含上升／下降谐波扫频、缺失基频／仅偶次分量、100 Hz 和 840 Hz 固定干扰、左右增益／相位差及固定种子 48271 的噪声。三类可跟踪扫频在各声道和功率均值中的 95 分位绝对误差均小于 3 音分；缺线和只有固定干扰的控制均报告无连续路径。这些结果验证选定条件下的工具行为，不是对实录误差的保证。另构造了两个隐藏基频相差一倍但波形相同的例子，明确展示只凭谱线不能唯一恢复物理基频。

## 对当前动力学的约束

在固定物理阶次 `q` 假设下，`f = q·RPM/60`，频率比也就是转速比；但绝对 RPM 取决于 `q`。若进一步假设空挡、有效油门为零且怠速支持尚未介入，冻结 V0.13 的工程代理满足：

```
J · d(2π·RPM/60)/dt = −[35 + 55·(RPM/8500)²]
J = 0.22 kg·m²
```

这些数值来源于冻结的本地 C 配置，不是兰博基尼测量。用冻结空挡日志中 6.505–7.505 秒验证此连续方程：实际模型从 6337.861 降到 3949.430 RPM，日志耗时 1 s，连续公式为 1.00084 s。小差异来自模型步进／日志舍入；这项检查只验证比较公式与本地模型相符。

对同一条约 314 → 157 Hz 的实录线，列出三个**尚未确认的阶次假设**：

| 假设的曲轴阶次 q | 对应的假设 RPM 区间 | 当前代理在零油门、开离合下预测耗时 |
|---|---|---|
| 2.5 | 7547 → 3769 | 1.48 s |
| 5 | 3774 → 1884 | 1.06 s |
| 7.5 | 2516 → 1256 | 0.77 s |

三者是展示歧义的条件计算，没有为它们赋予相同概率，也没有证明哪一个正确。2.5 阶可对应一排 V10 的主要点火频率，是值得核查的物理假设。若它成立且该段确为无负载零油门，当前代理会比所选录音区间落转更慢；换用其他未排除的阶次，对比结论则会改变。因此不能仅因频率下降用了 0.8 秒，就把摩擦调到某个数值或给惯量乘一个系数。

![阶次假设对模型对比的影响](../references/analysis/rev_descent_v1/conditional_order_comparison.png)

即便以后确定 RPM 和零油门／开离合，也主要约束净减速扭矩与惯量的比值，仍不能从一段声音独立分离惯量、摩擦、泵气、残余燃烧和附件负载。拟合一条 RPM 曲线也不会证明排气、进气和机械层的听感已真实。

## 与状态分层的关系

当前 C 实现沿用 V6 的“驾驶控制 → 状态 → 连续层／事件 → 空间”组织：`drive/lifecycle.c` 负责生命周期，`drive/shift.c` 管换挡阶段，`drive/fueling.c` 区分供给状态，`profiles/voicing.c` 与 `core/orchestrator.c` 负责每种工况的独立声层比例和包络，`core/events.c` 处理瞬态。收油不会把旋转机械声一并静音，内部降挡补油也不等同驾驶员重新踩油门。

本次录音中的频率下降不能直接标注 ECU 断油、离合断开或踏板松开的精确时刻。所测曲线只保存在离线研究中，不写入运行时 RPM 跟随器，也不作为状态机的强制事件时间。你已选择的“松油保挡、制动时安全降挡”继续生效。

后续动力学拟合需要先交叉确认主频率线的物理阶次，并找到转速／踏板／离合状态的独立依据。优先核查已批准素材中的连续镜头；新素材继续先交给你审阅。音色方向仍等待既有 V0.11／V0.13 试听反馈，不能用本次路径测试替代主观判断。

## 文件与复现

- `tools/ridge_tracks.py`：独立谱峰路径与相对变化计算。
- `tools/analyze_rev_descent.py`：规范素材读取、已知信号控制、实录观测和冻结模型条件对比。
- `references/analysis/rev_descent_v1/results.json`：完整参数、哈希、成功／失败路径、限制和模型假设。
- `references/analysis/rev_descent_v1/tracks.csv`：各路径逐帧频率、显著度、电平与相对电平支持标记。
- `references/analysis/rev_descent_v1/verification.json`：额外抗相位抵消／约束敏感性检查与历史文件审计。

本轮运行分析脚本即可复现主要计算；已生成的 `results.json` 会触发保护，避免覆盖完整的历史观测，重新计算应使用新的分析目录。C 运行时、二进制、预设和冻结试听均按 V0.13 保留。

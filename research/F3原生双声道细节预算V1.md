# F3 原生双声道细节预算 V1

**六个五挡锚点的高频缺失在原始采样时间上也存在，但不能用统一增亮、扩宽或一层平均噪声解决。** 本轮执行此前固定的 `F3_local_detail_budget_v1_plan.json`，补足选择细节生成结构所需的证据；尚未生成或替换新的音色候选。

前一目标轮完成了 ADI 估算 V5，属规划和留痕进展，没有改动合成。此次回到原素材与现有 C 输出，所有 667 份 C/H、82 份声音参数及三份保护 F2 参数保持。沿用原驾驶器、默认、行程及空间结构，不重复未修改的 68 项 CTest。

## 比较内容

取两次五挡升速各早／中／晚六个冻结观察，模型保持 288 分音／12 统计分量。根据冻结 `source_seconds` 坐标，直接从 `native.wav` 取首尾坐标内的原生整数采样，未重采样、降噪、归一化、增益匹配或重新选择窗口。六段长约 206–228 ms。

使用校验过哈希的冻结带限 C 导出器，按各自声学根频率生成三种子、每条 8 秒，共 18 条。每条在 0.5／3／6 秒截取与原生片段等长的窗口，每个锚点共九段。原 `reference.wav` 另作处理链诊断，不与原录音混称。

测量使用 48 kHz、4096 点周期 Hann、1024 点步进、8192 点 FFT，不去均值；八频带为 28–120、120–400、400–1200、1200–3000、3000–6000、6000–8000、8000–10000、10000–14000 Hz。功率和交叉谱在频带内积分，交叉方向明确为 `L × conj(R)`。所有原始复数功率矩阵、九段差额及其均值、正负特征值均保存。

## 发现与工程含义

| 观察 | 六锚点结果 | 含义 |
|---|---|---|
| 3–14 kHz 分频带总功率，C 相对原生录音 | 约 −2.15 至 −5.29 dB | 缺失超出原参考处理链的频带功率差，但仍未证明缺的是哪种物理声源 |
| 120–1200 Hz 总功率 | 通常约低 0.1–0.5 dB | 主声线的此段平均能量相近，不应整体大幅增益补偿 |
| 原处理参考相对原生录音 | 八频带最大绝对差约 0.101 dB | 对本批短片段的频带均值，不能把数 dB 缺失主要归因于参考处理；不代表处理链所有瞬态和相位无损 |
| 高频 Side/Mid | 部分频带的 C 已高于原声，最大约 1.83 dB | 不支持统一增加左右宽度；仍要保留实测复数相关性及左右电平 |
| 九段生成声的分频带功率跨度 | 部分高频约 2–7 dB | 包含有限窗口估计与模型统计变化；平均差额不能代表每段都能纯加法补齐，不能据此推断实车调制 |
| 平均左右差额矩阵 | 48 个锚点／频带中四个不正定，尽管全部左右对角差额为正 | 左右各缺能量不等于能加一套独立双声道声源精确补齐 |

例如，第一组早段 120–400／400–1200 Hz、第二组早段 400–1200 Hz、第二组晚段 120–400 Hz，平均差额矩阵均有负特征值。对应的负值按原样保存，没有截为零或强制拟合。

3–14 kHz 的六组平均差额矩阵均正定，但其中 3–6／6–8 kHz 的某些单段不正定；8–14 kHz 在这批九段比较中均正定。这只是有限输入下加法模型的矩阵可行性，不是自然度、泛化或机械来源证明。直接用九段均值拟合一层噪声，会忽略主 DNA 自身的短时变化。

## 下一步生成策略

保持现有相干主 DNA，先在原生时间轴区分谐波线、线间谱和频带包络，再决定哪部分可由独立细节层负责。新增细节至少要共同表达左右功率、复数交叉谱和随时间的能量预算；不能只拟合两条平均频谱，或将所有差额视为独立噪声。

尤其要检查主 DNA 的短时能量与残差如何共变。只有原素材支持时，才将这种关系沉淀为受同一源时钟控制的参数；不从短参考或随机种子推导油门、负载、换挡或燃烧周期规律。先用已知混合控制检验提取能否分清已有谐波与线间能量，再处理固定原素材窗口，避免把谐波细节重复叠加。

工程上仍沿用一套驾驶器和 `DNA / BODY / DETAIL / EVENT / AUX` 干声总线，细节声源的提取、参数、生成与空间渲染分别维护。录音中的左右关系属于观测到的双声道声床，不能直接标成两个实体声源；未来 7.1.4 的声源位置、传播及房间处理继续放在声源之后。本次没有新增房间模型或物理多声道验证。

本轮只完成细节预算测量，以上新增生成策略尚未实现或听评。F2 怠速与 F3 叠加细节仍独立待评，不重复提问、盲调强度或迁移默认；E“左右关系有改善，音色仍明显电子”的反馈保持。其他真实发动机、宽转速／负载及完整状态音色仍未完成。

## 核查与复现

先通过单声道、幅度不对称、正交和有符号延迟的解析控制，以及正／不定差额控制，再读取实录。独立审计使用 SciPy Welch、反序 CSD、直接 Mid/Side 功率及闭式二阶特征值；另对所有输入的每个窗、左右声道，在每带首／中／末频点进行显式三角 DFT。

共检查 70 组输入、460 个窗、22080 个复数 DFT 值。最大频带矩阵差约 `2.22e-16 FS²`、显式 DFT 幅度差约 `1.30e-11`，均通过原计划的绝对＋相对门槛。所有原生片段和 C 子段逐样本匹配，输入与冻结导出器哈希核对。`audit1` 完成原计划矩阵核查；`audit2` 额外覆盖发布到 JSON 的功率、相关性、Side/Mid 与 dB 比值，未改变测量或门槛。两次独立源快照均保留，测量／审计／绘图本轮无失败尝试。

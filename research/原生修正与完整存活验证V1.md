# 原生修正与完整存活验证 V1

本轮将免方阵T副本的原生三角访问接入离线提取器，并实现“基础求解→释放旧因子→原FFT修正”的完整流程。同一完整12289帧／49节点／288阶次／双声道已实际跑完，独立原方程、两次修正历史、保真和资源核验全部通过。它建立了可靠的完整提取路径，尚未生成新的可听音色。

## 模块与兼容边界

| 文件 | 职责 |
|---|---|
| `tools/waveform_correction_v1/inverse.py` | 共同右基／内层QR逆作用，保持全部方向；复制T仍为默认 |
| `native_inverse.py` | 显式选择原生三角后端，读取内层QR的上三角，避免`k×k`T副本 |
| `native_triangular.py` | 校验当前SciPy Cython LAPACK ABI，传实际leading dimension，原位解独立右端 |
| `pipeline.py` | 构建基础带状解，核实旧度量／图／T释放，再建修正因子；修正前释放旧X |
| `correct.py` | 固定两次完整原FFT修正，保存三步状态及两次更新 |
| `trace.py` | 从原完整有限窗与全部频点计算范数，不借用近似根范数 |
| `run_waveform_correction_native_full_v1.py` | 单次完整已知输入、资源预检、实际峰值及全部指标 |
| `audit_waveform_correction_native_full_v1.py` | 独立载波／FFT／完整伴随、全部历史、17项指标及存活核查 |

新后端通过`--inverse-backend native`显式选择，`--pipeline`重建基础解并执行阶段释放。现有默认复制后端和实时C接口保持。原生模块属于主机离线提取工具，没有移植到21569。

## 已知输入与独立核验

8组完整逆算子控制经过Decimal80／110位核查，包括秩缺失、大小尺度、混合旋转及全部基方向／独立右端；原7组任意Φ／W／R及初始扰动也通过。接着执行相同原12及共享8组，分别核验仅切换原生后端和完整重建释放流程，共40组结果；系数、稳定波形及全部历史与上一轮修正逐位一致。

资源审计验证旧数组的实际所有权及存活集合，没有以`overwrite`标记代替证据。新增范数实现还在13组Hann问题上与独立完整矩阵比较，通过2e-12门槛。首轮`storage_audit1`因旧报告缺少`pipeline`字段而中断；修改为显式兼容旧字段后`storage_audit2`通过，失败报告及两版执行源码保留，没有改变数值资格。

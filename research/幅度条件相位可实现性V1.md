# 幅度条件相位可实现性 V1

本轮把上一阶段的“幅度和相位需要关联起来”落实为一个可计算、可连续解码的条件表示。它能显著减小这批训练观察的左右关联误差，但也暴露了两个边界：**一部分目标在当前幅度／相位边际下不相容；稀疏最优解即使连续，也可能产生非常快的相位变化。** 因此没有生成试听或替换运行 C。

上一轮完成了用户要求的 ADI V6 复算留痕，属于算力证据进展，没有改善声音。本轮先独立复验并提交上阶段952文件归档，再继续幅相关联模型；全系统、多发动机、全状态和物理7.1.4目标保持。

## 从幅度到相位的条件关系

每个分音仍使用原幅度生成器的 `AL、AR`，令 `P=AL×AR`。目标是保留幅度和相对相位各自的分布，同时逼近录音中的 `E[P×exp(iδ)]`，而不是再加一个左右扩宽器。

对六份冻结F3观察，逐字节核对原3组4096点Sobol随机输入，复现全部12288组幅度。每个分音的P取32个概率分位节点，在节点之间使用连续的三角权重；统计每个权重的实际质量和加权P均值。实际幅度没有分箱硬切或修改。

原相对相位分位表有39～41行。将每段线性相位及两端恒值半格保留为概率单元，其圆周均值解析为：

```
m_j = exp(i*(δ_low+δ_high)/2) * sinc((δ_high−δ_low)/(2π))
```

非负联合质量 `w_ij` 保持幅度权重质量 `r_i` 和相位单元质量 `q_j`，目标复数矩为 `Σ p_i*m_j*w_ij`。逐分音线性规划求实部／虚部最大绝对误差的最小值，并保存完整原始解、对偶解和非负约束余量。

这是**特定连续权重／相位单元模型类**的可实现性检查；实部／虚部L∞度量依赖坐标轴，其欧氏误差位于L∞误差与其√2倍之间。逐分音最优不等于整频带欧氏最优。不能将模型类中的非零误差说成所有可能声源模型都无法实现。

## 六份观察的结果

| 项目 | 结果 |
|---|---:|
| 完整分音检查 | 6×288＝1728 |
| 当前模型类不能精确满足的目标 | 355 |
| 连相位任意选择也受有限幅度 `|E[PU]|≤E[P]` 限制的目标 | 153 |
| 父模型24频带坐标的平均复数相干度误差 | 0.0679133 |
| 逐分音LP解汇总的频带误差 | 0.00182267 |
| 加固定正概率后连续解码探针的频带误差 | 0.00182825 |

24个频带坐标均改善，但这是**训练系数矩的解析条件预测，不是新WAV、交叉验证或听感认可**。左右能量沿用同一批幅度；父模型按合并样本计算，避免把逐组归一化与合并归一化混用。源使用原观察能量，模型使用原生成能量，分母差异没有被隐藏。

153个相位自由界限也只针对这批有限幅度样本，不是总体统计证明。它说明后续不能仅调整相位：需要继续检查左右幅度的联合关系。355与153之差也不能全部归因为某个物理噪声，因为连续权重、相位单元和边际保持本身均有模型限制。

这些左右关系属于素材的双话筒观察，不识别缸列、排气口或物理声源方位。目前保留为stereo观察适配器的条件统计；未来7.1.4的对象定位、传播和房间渲染仍使用独立接口。求解器本身没有写入V10缸数或驾驶状态，其他发动机可复用表示，但仍需要各自的素材、状态和听感校准，当前六份F3观察不能证明多发动机覆盖。

## 连续还不够

为验证解码结构，只使用一个预先声明的`1e−4`正概率混合：将稀疏联合解与独立`r×q`混合，边际保持不变，矩偏差解析可算。运行时按P连续插值条件CDF，再由一个**独立于幅度的新均匀创新**解码相位；不能把旧的、与幅度相关的copula相位随机量直接当作独立输入。

这种映射在节点／相位单元边界连续，但稀疏解造成很小的概率单元：

- 逆CDF对均匀输入的斜率上界，中位数约`2.30×10^5`，最大约`1.12×10^6 rad／单位均匀变量`。
- 对归一化P的斜率上界最大约`1.58×10^9 rad／单位P`。

这些是保守局部上界，不是观测到的音频相位速度；但它们足以否定“只要数学连续，就可以直接接成自然的发动机声”的推论。固定正概率不是可调音色预设，没有扫描强度或把这个解作为新版本让用户反复听。

下一步应在**同一目标和边际约束内**研究最大熵／平滑内解，避免LP任意稀疏支撑，并单独检查连续变化的实际斜率、频谱与声线。仍须让生成时间结构经过原4096/Hann/hop256观察器再与素材比较，不能直接照抄重叠系数的高ρ，也不能用更多PCA分量掩盖依赖表达缺口。

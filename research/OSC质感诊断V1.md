# 旧 64 OSC 的“降采样／压缩感”诊断 V1

**后续听评：未通过。** 用户明确反馈“原来的低质／压缩感基本没变”。下文保留该轮测量与当时假设；不能据数值改善认定长窗是主要可听原因。后续见 [OSC 完整度对照 V2](OSC完整度对照V2.md)。冻结快照中的原报告保留当时状态。

2026-11-10。用户已确认：未变调的原版就有明显的低质量质感。旧 64 OSC 是音色方向基准，不能解释为音质已经通过验收；高频 50% 仅是暂定偏好，本轮暂停高频增强。

主要问题目前定位到**分析／重建丢失了快速声纹细节**。已经确认长窗幅相测量的时间分辨率不足，并发现谱线匹配缺陷；稀疏挑峰也会遗漏弱分量和宽带结构。这些能解释“主体像了，细节却被抹掉”的现象。哪部分最符合用户所说的劣质感，仍须通过听评判断。

[打开同增益对照](OSC质感诊断V1.html)：录音参考 → 仅匹配带宽 → 旧 64 OSC → 短窗联合拟合 · C。优先比较 2.6 秒后的车外部分。新候选没有加入高频层、事件源、残差录音或噪声。

## 1. 这轮比较的对象

输入沿用历史六秒片段 `references/clean/A_tailpipe_road_pull.wav` 的显式单声道坐标，以准确诊断旧算法。源 A 的 raw／float 主文件和历史清洗记录 hash 已核对；新车外观察另经素材目录读取。六秒前部含其他机位，不能把整段当成纯尾排标定，也没有可靠的同步 RPM／负载。

四个主对照都使用相同增益 0.5303559999483826（−5.50865 dB）、相同端点淡入淡出、48 kHz PCM24 输出。没有逐版 RMS 匹配、压缩器或限幅器。电平自然变化属于重建结果，不能据响度单独判断音质。

“仅匹配带宽”是录音经离线线性相位 80–14 kHz FIR 的控制项，保留频带内的录音纹理；它不是新的合成音色。录音参考也保留原 YouTube 来源的编码和录音问题。

## 2. 没有发现真正降采样或新增有损编码的证据

- 原版文件确实是 48 kHz、PCM24、288000 帧／6 秒。原生默认音高 1／高频 0 的 float 输出与找回的旧算法一致。
- 下载源 A 是 48 kHz Opus，容器平均码率约 104751 bit/s；素材本来就经过 YouTube 压缩。合成／试听链没有再编码为 MP3 或 Opus。
- 把**同一套旧 64 OSC 参数**以 192 kHz 合成，每四个取一个样本与 48 kHz 输出逐位一致。用正确的 FIR 低通再降到 48 kHz，与原生输出的相对差异约 −103.73 dB；新候选为 −102.12 dB。差异包含滤波误差与非严格带限的连接，不是对所有混叠的单独测量，但远低于模型误差，暂不支持把混叠当成主要原因。
- 上轮实际静音 waveOut 检查播放设备时间 6 秒／墙钟 6.116 秒，队列耗尽 0 次，float 指纹一致。它支持排除该次播放中的明显慢速／缺块问题，不代表已做声卡回录。

因此，“听起来像降采样”是有效的听感描述，但当前最有力的证据指向声纹信息损失，不能直接等同于文件采样率下降。

## 3. 85 ms 长窗能找到音高，却会抹平快变化

旧分析窗为 4096 样本／85.33 ms，步长 256 样本／5.33 ms。**每 5 ms 更新一次，并不等于获得了 5 ms 的细节**：每次测量仍然跨越约 85 ms。

用频率与调制完全已知的两音信号检查，25 Hz 的幅度调制分量经旧分析重建后，仅保留原来的 −35.17 dB；新候选为 −2.18 dB。这里测的是特定调制分量的保留量，不是整段音量，也不是音质分数。较慢的 3 Hz 调制，旧方法只有约 −0.37 dB 损失，所以早先的稳态／慢变化测试没有暴露这一问题。

![已知调制测试](../references/analysis/osc_quality_v1/am_control.png)

发动机录音中有快速强弱变化、相位变化、拍频和密集边带。长窗只抓住较稳定的尖峰时，主体频率可能正确，颗粒、粗糙度和连续细纹理却会丢失，呈现过分光滑又空洞的电子感。这是当前的听感解释，尚不能把所有起伏都认定为逐次燃烧。

## 4. 匹配和稀疏表示也有损失，但不是单独的解法

旧匹配先把所有谱线强行配对，再丢掉超过阈值的结果；这会阻塞一些本来合理的连接。新匹配先提供“结束／新生”的合法选项，再求解，保留原频差代价规则。六秒内新生次数从 24164 降到 7748；但只修此项，波形误差仅从 −11.106 改善到 −11.163 dB，不能据此声称它已解决听感。

旧挑峰还会排除低于突出度门限的成分，以及相距太近的邻峰。把最多 64 峰增加至 128 峰，选定时频格内的严重缺口比例从 11.31% 降到 3.83%，波形误差却仍只有 −11.169 dB。这个缺口比例受分析窗和阈值定义影响，不是“还原率”。

把所有分析窗直接缩到 1024 样本也不可取：频率分辨率和最低峰间距一同变化，实际录音平均只保留约 35 个峰，误差反而变成 −7.931 dB。应分别处理“分辨相近频率”和“跟随快速变化”两个需求。

相位连接曲率的大小也不能单独当成失真指标。新候选的相位修正量更大，波形却更接近录音；真实快变化也需要这样的相位运动。

## 5. 本轮优化：长窗找频率，短窗联合测幅相

新候选每帧完全沿用旧版挑出的频率，仍是 80–14 kHz、最多 64 个检测峰，没有通过额外高频或换声源掩盖问题。

1. 4096 样本长窗保留频率骨架。
2. 在 1024 样本／21.33 ms 短窗内，同时求所有候选频率的正弦／余弦系数，跟随更快的幅相变化。
3. 用原复系数作弱约束，正则量为 Gram 矩阵平均对角线的 0.005，抑制短窗中相邻频率难分辨带来的不稳定。
4. 修正谱线匹配后，输出幅度端点和三次相位系数，由已有 C 振荡器合成。模型不含 PCM 或残差波形。

解析 Hann Gram 矩阵与直接时域矩阵的控制检查最大差约 2.53×10⁻¹²。C 与 Python 的 rawfloat 最大差约 1.49×10⁻⁸；PCM24 试听差不超过一个最低有效位。

这里“64”是每个分析帧最多 64 个峰。新生／消失交叉淡化时有额外并行 OSC，导出的最大行数为 98；不是任意时刻严格只有 64 个固定振荡器。

## 6. 测得的改善与边界

相对波形误差定义为 `10 log10(mean((参考−合成)²)/mean(参考²))`，忽略首尾各 0.2 秒，越负表示误差越低。没有先做逐版响度或时移优化。

| 检查 | 旧方法 | 短窗联合拟合 |
|---|---:|---:|
| 六秒真实片段波形误差 | −11.106 dB | −17.398 dB |
| 选定局部时频格功率绝对误差中位数 | 2.890 dB | 0.913 dB |
| 已知 32 音稳态波形误差 | −46.619 dB | −69.502 dB |
| 已知 32 音上行扫频波形误差 | −24.704 dB | −47.040 dB |

真实片段波形误差降低约 6.29 dB，说明这套参数捕获了更多原信息；**不等于真实感提升了某个百分比**。仅匹配带宽的录音控制误差为 −24.665 dB，也表明剩余差异不能仅用带宽解释。

再检查实际车外重叠区 2.6–5.8 秒：分频后取 Hilbert 包络、归一化均值，比较 10–40 Hz 起伏与录音的相关性：

| 载频范围 | 旧 64 | 新候选 |
|---|---:|---:|
| 80–400 Hz | 0.413 | 0.886 |
| 400–1200 Hz | 0.433 | 0.956 |
| 1200–3000 Hz | 0.300 | 0.938 |
| 3000–8000 Hz | 0.281 | 0.932 |

40–80 Hz 包络也同向改善。这些起伏包含拍频、声源、录音噪声和空间作用，不能直接解释为独立的燃烧参数。

![相同增益的时频对照](../references/analysis/osc_quality_v1/spectrogram.png)

目前仍遗漏未检测的成分，所选时频格的严重缺口约 9.27%。这是单片段的拟合结果，还没有证明对其他发动机、其他录音或持续任意 RPM／负载有效。本轮未替换原生驾驶应用或旧监听窗口。

下一步先听“短窗联合拟合 · C”是否减轻用户指出的低质感，再决定是否需要建模未捕获的边带／密集分量；随后才能恢复高频细调，并将有效特征提炼为持续、随工况变化的 OSC 模型。

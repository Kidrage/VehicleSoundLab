# 共享离散基与提取资源 V1

**四个小型案例的数值一致性已通过；完整提取与音色改善尚未验证。** 用户对左右相位的反馈保持：声场更自然、音色未退化，但相对原录音仍有电子感。

## 改了什么

这是离线声纹提取工具，不是实时C声源的新版本。新方法标识为 `vsl.shared-rounded-source-observation/1`。

以前，正向路径先合成波形再FFT，转置走另一套逆运算；浮点舍入不同，极弱频带上的两条路径并不完全一致。现在先用明确的载波表、插值帽形基和规定乘法顺序构造离散声源列，再逐列编译观察块；正向与转置使用相同的块值。左右声道共用块存储，各自保留独立系数和相位。

没有删减阶次、节点、频点或声道。完整上下文、原七组目标与17项直接保真指标继续保留。这个新离散模型与原FFT组合路径分别记录；块内一致不能代替原波形／FFT保真，也不能说明电子感的原因已经找到。

| 模块 | 职责 |
| --- | --- |
| `tools/shared_basis_operator_v1/geometry.py` | 拥有输入副本，定义声源列、插值支持和系数布局 |
| `compiler.py` | 逐列FFT，生成左右共用观察块，限制缓存容量 |
| `operator.py` | 声源、完整／目标正向与转置、目标函数梯度 |
| `resources.py` | 完整几何的存储、乘积数和有限范围数组预算 |

## 核查结果

只使用原来保存的四个小型已知案例；没有重新拟合录音。独立参考逐项核对全部编译块，以及声源、正向、转置、七组目标和梯度，共3,377,044个元素，原比较门槛仍为 `2e-11`。

| 案例 | 最大尺度化误差 |
| --- | ---: |
| 双声道幅相变化 | 9.574693105866959e-16 |
| 右声道静音 | 5.01626732956025e-16 |
| 零输入 | 8.5327281335679065e-16 |
| 秩亏／零空间 | 8.462649351030242e-16 |

两次失败完整保留：`known1` 的目标波形转置漏了重排；`audit2` 错把代数零列当成没有空间支持的列。有效审核是 `support_audit2`，保留所有受支持的参数槽，包括零空间。原方法19项失败仍在；新旧路径最高相对差仍可到约 `3.26e-8`，没有改名算作原方法通过。

## 完整规模的代价

完整几何：18,430采样点／73节点／288阶／双声道，84,096个实未知数，56个完整观察窗、40个目标窗。本轮只计算其完整支持和成本，并实际执行其中一个最宽块。

| 项目 | 字节或操作数 |
| --- | ---: |
| 全局稠密矩阵 | 333,582,594,048 bytes（未分配） |
| 全部左右共用频谱块 | 18,128,240,640 bytes（未整体生成或保存） |
| 全部波形块 | 179,288,064 bytes |
| 最大单块：4098 × 10368 | 339,904,512 bytes |
| 作用一次的矩阵标量乘积数，正向／转置各 | 4,576,882,176 |
| 无缓存时，一次作用需逐列FFT | 552,960 |
| 当前有限范围数组预算 | 513,725,880 bytes |

数组预算不覆盖整个求解器、Python、BLAS或分配器。64 MiB默认缓存容不下完整规模的频谱块；反复作用会重复编译，需要解决存储／流式复用成本。

本机双线程BLAS下，最宽块编译 **1.4098秒**，正向 **15.785毫秒**，转置 **19.827毫秒**；内积一致性差 `4.003689149603979e-18`。进程累计工作集峰值483,549,184 bytes、私有提交峰值581,730,304 bytes。只执行56块中的1块，不能线性外推完整提取耗时、求解收敛或ADI MCPS。

# 怠速统一驾驶与录放 V1

固定F2怠速候选已成为**同一驾驶系统里的可选声源**，可以调量、录制和自包含重放。没有重新拟合音色，上一轮待定听评仍有效；实际F2 RPM／负载尚未标定。原默认可执行文件和认可行驶配方保留。

入口：`Launch-Idle-Drive-Study.cmd`；构建：`Build-Idle-Drive-Study.ps1`，使用独立`build-idle-drive-v1`目录。窗口默认停止、未点火、台架850工程RPM、房间0、候选量100%。开始监听后点火；复选框“怠速声线（候选）”切换0／100%，最后一个声层下拉框与“声层量”可连续调节。台架补油或模拟驾驶沿用原输入、自动挡运动策略及录放按钮。**新UI已编译，人工交互／目视和音色听评未完成。**

## 模块与控制

```mermaid
flowchart LR
    UI[原生输入与怠速量] --> Driver[唯一200Hz驾驶器]
    Driver --> Gate[RUNNING且IDLE]
    Source[独立OSC与连续共振] --> State[modal_layer/state]
    Gate --> State
    UI --> State
    State --> Mix[旧源保留1-w 加入候选]
    Mix --> Spatial[原空间处理一次]
    Spatial --> Output[stereo设备或12通道导出]
    Take[atlas_take拥有参数与采用帧] --> Source
    Take --> UI
```

- `modal_layer/state.*`只增加0–1量控制和18ms跟随；原80ms有限gate权重乘以该量，OSC／滤波／随机序列持续推进，零量不冻结或重置。没有新驾驶器、RPM时钟、PCM循环或房间模型。
- `atlas_drive`以明确类型的`idle_profile`借用参数，独占其声源状态；`idle_mix`控制替换量，`idle_weight`提供遥测，`idle_raw/idle`提供原始／包络后分轨。通用opaque处理器与此类型互斥。
- `experiments/idle_drive_v1/models.*`只加载原F2参数及已留痕的固定电平／过渡值；素材参数不写进通用DSP。源种子由已保存的主种子确定，主种子48271时沿用前轮149921。

80ms是工程过渡，18ms是控制平滑，850／2200是台架输入，都不是素材测得的发动机参数。F2候选频率比例固定1；F2 LP-610尾排和A Performante行驶段的交接仍是跨情境研究，不能视为同车全工况还原。

## 行程格式与拥有关系

`.vslrun`升级为**schema9／30个语义控制字段**。新增`idle_mix`及可选源的全部独立频率、双声道幅度／初相、Rdt系数／预热、源比例／层量／固定电平、进出样本数。运行时指针不写入磁盘，加载后绑定到拥有资产。

`at_assets_copy/valid`深拷贝并检查嵌套参数；`atlas_take_io/codec`使用显式小端字段与上界检查。设备回调仍只在成功提交后提交行程帧；播放器按实际采用帧重建控制。配置怠速时源哈希追加其raw／输出分轨，量0时也记录原始持续声源；未配置时保留原源哈希序列。generic opaque回调继续拒绝，不能静默遗漏。

schema8及更早行程使用各自冻结播放器；新格式和渲染身份严格区分。此版本没有通用中途状态快照，录制仍从新的第0帧开始。

原84条冻结WAV和3条驾驶CSV逐字节一致。实际静音设备录制384123帧后保存、清空外部模型、加载重放，输出哈希均为`70dddd2d38f2ab6b`；源哈希通过。取消在12800帧结束。队列空与块预算超限均0，录制／回放最大块约6.34／5.31ms；这次短运行不构成长时间实时保证。

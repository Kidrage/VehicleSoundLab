# V0.13 · 曲轴与离合耦合

V0.12 的轮上力已经采用有单位的扭矩和阻力，但发动机 RPM 仍跟随目标值。冻结日志中，同一力学采样的发动机只有 3628 RPM，轮速已对应约 3942 RPM，轮端换算的轴功率比当前发动机扭矩提供的功率高约 13.6 kW。这是本地模型一致性问题，不是对实车的判断，也不是一份完整的旧版能量预算。原始日志路径、哈希和计算点保存在 `drive_coupling_audit_v013.json`。

本轮把正常驾驶、空挡和换挡中的发动机转速交给曲轴与车辆联立积分。台架继续直接设置 RPM／有符号负载；声源算法保留 V0.11／V0.12 的版本，变化来自驾驶输入。启动／捕火／停机仍由独立生命周期控制器处理。

## 求解方法

曲轴惯量为 `J`，车辆和轮系等效质量为 `M`，有效传动系数为 `k` rad/m，离合扭矩为 `Tc`。每步使用隐式欧拉：

```
ω1 = max(0, ω0 + dt·(Te − Tc)/J)
v1 = max(0, v0 + dt·(Tc·k·ηdir − Froad)/M)
slip = ω1 − k·v1
```

正向传递 `ηdir=η`，倒拖时 `ηdir=1/η`，使两个方向的传动损失都为非负。对 `Tc` 求受正／反向容量限制的摩擦解：滑差随 `Tc` 单调下降，可用固定 44 次二分处理锁定、滑动、发动机停止和车辆停止的组合。摩擦作用满足 `Tc·slip ≥ 0`；容量不足时继续滑动，容量足够才锁定。空挡或完全打开离合时 `Tc=0`。

车辆质量中不再重复加入 `Jk²`；曲轴惯量已有独立角速度和动能。挡位改变不会凭空改变两个物理惯量的储能。起步转速只是离合／扭矩控制器的目标，不会直接覆盖物理 RPM。倒拖和制动共同受纵向轮胎力预算约束；仍未建立独立车轮滑移／ABS。

## 逐步能量预算

每个运行控制步记录：

- 曲轴和车辆动能变化。
- 发动机输入功 `Te·ω1·dt` 与路阻／制动功 `Froad·v1·dt`。
- 离合摩擦热 `Tc·(ω1−kv1)·dt`。
- 传动损失 `Tc·k·v1·(1−ηdir)·dt`。
- 隐式欧拉数值阻尼 `½J(Δω)² + ½M(Δv)²`。

上述项闭合到浮点误差。数值阻尼单独报告，**没有当作实测离合热量**。这说明所定义离散模型内部一致，不是连续时间求解零误差，也不是实车动力学准确度证明。

C 核心累计每一个 RUNNING 步的账目，CSV 记录这些累计值；没有从稀疏的 0.1 秒采样点伪造整段积分。CRANK／CATCH／STOPPING 的工程转速轨迹和台架外部驱动不在此预算内。生命周期与运行模型之间仍需要实车标定。

## 离合与换挡

起步用离合摩擦容量配合显式发动机扭矩削减，避免转速跟随器暗中增加动能。关闭油门且低于可耦合转速时打开离合，怠速支持独立计入轴端输入。内部同步油门、驾驶员踏板、发动机实际油门和离合传递继续分开。

升挡在切断动力后，让目标挡位路径以受限的 180 Nm 工程离合容量参与同步；发动机油门关闭，发动机动能通过摩擦传给车辆或转为热量。没有为追求快速掉转直接扫动 RPM。进入接合时从同步压力继续上升，避免压力退回零。

降挡补油仅在离合完全打开时执行，35 RPM 工程欠调偏置减少接合前冲。补油不会直接产生轮端力；重新接合后，已有转动惯量可以通过受约束的摩擦交换能量。驾驶员松油条件仍独立决定收油事件，内部补油不能把事件武装起来。超转请求继续拒绝，匹配失败继续退到空挡；松油保挡策略保留。

180 Nm、35 RPM、0.22 kg·m²、900 Nm 容量、30 ms 压力响应、2600 RPM 起步目标以及各增益都是工程假设。匹配超时保护为 1.2 秒，不是实际换挡持续时间。只有既有的 V10 峰值扭矩／功率两个点有厂家依据；各声音模板仍共用车辆代理。

## 验证与未完成项目

`tests/test_coupling.c` 检查解析锁定加速度、自由转动、摩擦滑动、停止边界、空挡、挡位切换储能，以及固定种子 48271 的 12,000 组离散能量／被动性控制。集成测试还确认换挡代码不能再次覆盖已求解的 RPM，完整自动驾驶累计账目闭合，降挡补油保持离合隔离，且运动自动挡无匹配中止。

实际导出与设备结果见 `renders/v0.13.0/verification.json`，新旧共同增益试听见 `V013试听.html`。四组台架输出与冻结 V0.12 逐字节相同；声音模型没有借这次动力链修改而重新调色。

本轮 15 项 CTest 全部通过。30 秒自动驾驶覆盖 5796 个运行控制步，8 次换挡、0 次匹配中止并最终停车；日志累计能量闭合误差约 3.6×10⁻⁷ J。四次升挡的日志观察时长约为 0.31～0.38 秒，仅为模型行为，非厂家性能数据。相同十个声源在 stereo／7.1.4 导出中逐字节相同。静音 UI／设备测试确认实际使用新求解器，512 帧平均渲染 1.2724 ms、最大 3.9414 ms，空队列观察 0 次；实际设备播放 10.6133 秒／墙钟 10.7424 秒。

当前摩擦／泵气损失和曲轴惯量比值尚未从批准的驻车补油素材拟合，空挡落转可能偏慢。模型也未包含独立双离合轴系、弹性传动轴、轮胎打滑、坡度、温度、离合热衰退与真实 ECU 控制。新系统算得自洽，不等于已完成这些参数的辨识。高频声线、状态谱形、进排气传递与实际 stereo／7.1.4 主观听音仍属完整目标的待办。

# 等价声源求解与零方向 V1

本轮保留同一声源目标，修正求解方式。四个有限矩阵及八个原始Hann控制通过独立复核；完整288分音仍未收敛，不能用于新的真实素材提取或持续声源。

## 算法与模块

把原问题写为`min_q ||Bq-b||² + qᵀRq`，其中`B=P Phi`包含全波形和左右共享加权完整窗，`R=.001 D2ᵀD2+.000001 I`。正则化目标不变，不减少分音、因子或节点更新密度。

最优解满足`q=R⁻¹Bᵀu`。原计划的声音采样空间解与它等价；直接构造逆矩阵和Gram矩阵可能放大舍入误差，所以先验证平方根形式。

| 文件 | 功能 |
|---|---|
| `tools/observer_representer_v1/dual.py` | 时间惩罚Cholesky根、观测空间增广对偶、独立可行对偶证据 |
| `tools/observer_representer_v1/primal.py` | `T=L_R⁻ᵀ`，求`min_z ||BTz-b||²+||z||²`，直接恢复`q=Tz` |
| `tools/observer_representer_v1/fixtures.py` | 有限33采样显式OSC／DCT正定度量；仅代数控制，不冒充4096点素材分析 |
| `tools/run_observer_representer_*` | 固定控制及一次完整问题；保存观测、源码、解与误差界 |

零初始Krylov空间在精确算术下保持于`range(TᵀBᵀ)`，故恢复的q保持在`range(R⁻¹Bᵀ)`。没有加入破坏此关系的逐列缩放，也没有额外从对偶残差再恢复参数。有限精度仍需实际验证。

保留原空间梯度2e-7、稠密解相对误差2e-7、LSMR允许stop1/2/4/5及4000上限。原残差缩放对偶和新增任意可行对偶两种gap都要求`gap <= 1e-6 J+1e-10`；没有用新增证据替代旧门槛。

## 实际结果

- 首次algebra1因`LinearOperator.H`只读属性命名冲突而失败，执行源码留存；更名后完整运行algebra2，没有拟合参数变化。
- 四个有限代数案例：稠密对偶解与原稠密最优解误差约3e-12，数学等价通过；迭代对偶恢复误差3.05e-6至8.09e-5，**0/4通过**。内部stop2和原梯度通过不代表参数精度通过。
- 同样四份冻结观测，平方根原形式误差4.62e-9至3.79e-8，**4/4通过**，全部原门槛及两种gap独立复核。
- 同样八份原4096-Hann前后文案例，**8/8通过**；最弱节点误差1.08e-7。最弱整个扩展记录高频6.4428%损失仍存在，没有被改写为成功。

## 下一步与工程边界

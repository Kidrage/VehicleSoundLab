# 原生误差分解与最高频带 V1

首段真实完整拟合的高频误差已定位到可分别检查的环节。**原保真仍未通过，当前没有新持续声源或实时 C 替换。** 本轮结果支持先检查源重采样器，暂不重复首段拟合或盲目续算剩余五段。

## 分解方式

使用同一段原生 48 kHz 双声道、原全 288 阶／73 节点、真实上下文、共同逆时钟和既有原生输出 FIR。定义：R 为原录音，F 为仅源 FIR 处理，P 为原相位网格的声明重建，Q 为拟合网格的同种重建，N 为连续 OSC 原生渲染。

`N−R = (F−R) + (P−F) + (Q−P) + (N−Q)`。

P／Q 的重建 S 使用归一化 Kaiser12 窗 sinc；半径 32／64／128 在 16× 下分别计算，半径 128 另算 32×。四组全部保留。S 是工程诊断参考，**不是原重采样器唯一的物理逆**，不能将 P−F 完全称为原素材损失。

每组保存全部采样、四项独立 LR 误差、每带完整 8×8 复 Gram、四项自功率和六项有符号交叉功率。误差功率存在相消，不能相加四项 NRMSE 或把各自能量写成占总误差的百分比。

|---|---:|---:|---:|---:|
| 0–3 kHz | 4.35e-8 | 6.80e-7 | 2.47e-4 | 1.15e-7 |
| 3–6 kHz | 4.71e-8 | 9.85e-5 | 4.19e-5 | 2.28e-6 |

在这段素材上，10–14 kHz 的源 FIR 与网格重建项明显大于保存解的网格拟合残差；总误差 0.01494 不能靠简单增加 OSC 高频振幅解释。14–24 kHz 原声能量极弱，源 14 kHz 低通贡献明显，仍保留原差异，不据此宣称已恢复全部高频。

四组的全部六个两两比较也已保存／复核。以原声频带归一化，0–14 kHz 任一分量的最大差约 1.24e-6，完整六带约 4.98e-6；整段分量最大差约 1.12e-7。这说明上述诊断对所测重建半径／倍率较稳定，不证明 S 是唯一逆或适用于任意时钟。

## 虚拟域最高频带为何失败

重新构造原目标的有限窗覆盖、规定 FP64 Hann、单边端点权重、原 amplitude 和原逐 bin 权重，复现全部六带原复数 NRMSE；最高带仍为 **0.0623242 > 原 0.02**。没有重估尺度、移除 bin、改权重或放宽门槛。

虚拟域采样率 65536 Hz，阶次载波中心为 `order × 64 Hz`。288 阶的最高中心是 18432 Hz：

| 原最高带内的诊断细分 | 复数 NRMSE |
|---|---:|
| 14–16 kHz | 0.0004900 |
| 16–18.432 kHz，不含上端点 | 0.004905 |
| 恰好 18.432 kHz 的单个中心 bin | 0.005700 |
| 严格高于 18.432 kHz | **0.99230** |

严格高于最高载波中心的部分占该带参考加权平方质量约 **0.39445%**，却包含约 **99.99115%** 的该带误差加权平方质量。这里的平方质量是原观察器度量，不是声学能量；同时发布了未加权 Welch FS²，不能混用单位。最高载波中心也不是严格带宽截止，因为分段系数包络带有边带。

这提示先查源 FIR→16× 重采样→线性查询和相位时间映射所引入的弱尾部，再决定是否需要改变声源表示。**尚未证明尾部一定由重采样产生，也没有把最高带失败改成通过。** 不能据一个短段就取消高频门槛或推广持续统计模型。

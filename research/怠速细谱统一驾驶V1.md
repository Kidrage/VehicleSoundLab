# 怠速细谱统一驾驶 V1

把前轮由批准F2录音提取的固定怠速候选接入同一个C驾驶器，供持续监听和调参；没有重新拟合或宣称音色获认可。行驶35%与旧固定怠速参数保持原样。

## 声音怎样组成

F2尾排6–9秒训练、9–12秒参考。真实RPM、温度、排气改装情况未知，L/R近单声道，不能据此制造实测立体声宽度。F1多车移动机位、F3带说话的驻车片段仍排除。

```text
13条原生Hz OSC ── 新生成的相关慢幅度 ── 主声线起伏量 ─┐
新高斯激励 ── 6×8192tap细谱形滤波 ── 细谱量 ─────────┤
                                                     ↓
唯一驾驶器的 RUNNING && IDLE ── 80ms过渡×怠速混合量 ── 合成
                                                     ↓
                      原有分轨／一次声床或对象路由／输出
```

不循环录音，不保留原幅度时间轴；频率／平均相位不作随机调制。幅度统计仍可能混入FM和噪声，不称物理燃烧AM。细谱滤波保留观察位置下的谱形，未分离机体、排气、环境和话筒响应；模块自身没有新增房间模型。

## 代码与控制

| 模块 | 职责 |
|---|---|
| `modal_source` | 13条独立频率／幅度／相位的OSC，有限参数斜坡 |
| `modal_texture` | 统计因子驱动的新相关增益，保持期望功率 |
| `partitioned_fir`／`spectral_texture` | 只读编译核、独立历史、新激励、预热及细谱持续生成 |
| `fine_idle_layer/profile,state` | 组合声源；外部gate、三个独立量、分轨及生命周期 |
| `atlas_drive` | 原200Hz驾驶器／包络，怠速替换权重；不另算RPM |
| `atlas_take`／`atlas_take_io` | 拥有原始参数和控制事件，严格身份下重合成 |
| `experiments/fine_idle_drive_v1` | F2参数宿主、专项验证和设备探针 |

`idle_mix`决定怠速候选替换比例；`idle_motion`控制主声线幅度起伏；`idle_detail`控制细谱量，三项均0–1。默认候选1／0.5／1只是研究初值。起伏与细谱量采用18ms有限斜坡，混合量沿用18ms跟随，进出怠速80ms立方淡化；所有声源静音时也持续推进。

细谱源比例固定1。界面850RPM是驾驶器测试输入，不是从F2测出的RPM，也不代表台架升到其他转速时已标定相应怠速音色。旧源按`1-w`撤去，新源按`w`进入；原事件／辅助层保持独立。

新状态在非实时线程分配／预热，在音频线程停止后销毁。调用者应零初始化对象，并在重新初始化或释放模型前调用`ad_render_dispose`／`am_render_dispose`／`at_player_dispose`。音频处理无文件IO或堆分配。

`.vslrun`更新为schema10／32字段，追加`idle_motion/idle_detail`。完整拥有Ms／Mt／Sf／Fi参数并重绑内部指针；新怠速与旧怠速或opaque回调互斥。新分轨加入源哈希，未配置时保持旧顺序。旧格式继续使用各自冻结播放器，不混读。

## 验证与证据

独立层核查原C声源一致、解析过渡／量跟随、静音时钟、动态控制和非法输入；驾驶核查零量输出及控制器一致、自包含保存／加载、清空外部模型重放、任意音频块、2／12布局源及前置一致、错误版本／超限模型／截断的事务拒绝。

整套61项中首次59通过；两个旧测试的恢复版本号仍写9，修正为10后两项定向通过，其他运行源码不变。84旧WAV／3轨迹CSV逐字节一致。没有为新声源适配放宽声音或数值阈值。

实际Stereo设备静音录制384123帧，清空外部模型后保存／加载／重放，输出哈希同为`24060d7d761d429c`；2／12前置和源一致，取消回放通过。512帧设备块约10.67ms，录制／重放最慢6.2897／5.3896ms，队列耗尽及块预算超出均0；仅短时证据，不是5ms完整驾驶或硬实时认证。

本地`references/analysis/fine_idle_drive_v1`保留kernel1头文件路径失败、kernel2、full1两项旧格式夹具失败、fixtures1修正、legacy1与device1，以及精确源码／模型／二进制；总冻结在`baselines/fine_idle_drive_v1`，摘要见同名JSON。

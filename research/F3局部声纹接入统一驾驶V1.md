# F3局部声纹接入统一驾驶 V1

**两组三锚点F3声纹已接入原生驾驶窗口、完整参数拥有权和行程录放。** 本轮推进的是从素材声纹到受驾驶控制的声源；没有把离线音频作为循环素材播放。

前一目标轮仅复核MCPS，没有推进合成。先将此前完成的局部库及全部证据冻结并提交为`36aa1bb`，再执行`catalog_local_F3_v1_plan.json`。两组三点模型逐字节复制自该冻结包，分别保留两次五挡升速的观察身份，不重新拟合、不混入六挡。

| 新选项 | 三个声学根频率 | 默认台架控制 |
|---|---|---|
| F3五挡升速一 · 三点局部声线 | 61.36080／64.80444／67.95806 Hz | 中点约7777工程RPM |
| F3五挡升速二 · 三点局部声线 | 60.81944／64.01487／67.36432 Hz | 中点约7682工程RPM |

RPM使用已有`root_per_rpm=1/120`映射，仍是控制假设，不是素材实测转速。三点来自同视频的一次局部升速，不能代表全转速、全负载、不同发动机或完整状态音色。

## 工程链路

```mermaid
flowchart LR
    A[六份冻结DNA参数] --> B[F3_local_models 非实时拥有与装配]
    B --> C[dc_preset / AtAssets 完整参数复制]
    C --> D[原 atlas_drive 唯一驾驶器]
    D --> E[原 SaVoice 三状态推进 / 相邻两点插值]
    E --> F[原六条干声总线]
    F --> G[原 Stereo / 12通道路由]
    C --> H[原 schema10 内嵌参数行程]
    H --> D
```

`F3_local_models.c/.h`只做非实时事务装载和指针绑定，`F3_local_checks.c`核对拥有权与源契约。原目录末尾追加索引10／11，前十项和默认选择保持；整个目录现在是十个V10观察／配方情境及两个解析示例，不是十二款发动机。新选项保留相同种子48271、32阶共同左右周期起点对齐和18ms参数跟随。

主声源、统计调制、驾驶、六干声总线、空间路由、参数拥有权和录放C实现均未修改。所有锚点的统计状态持续推进，音频时刻只插值相邻两点。沿用原模式：台架直接输入转速及正负负载，模拟驾驶由油门／制动和运动自动挡驱动；本轮没有新增按工况自动切换素材情境的策略。

本次没有另配高频细节或独立低频，因此细节控件禁用；低频控件仍是DNA内部的互补频带分层。主DNA仍保留其原有低／高频。房间默认0，空间投影继续位于声源之后。声学根频率超出两组局部范围时，原界面继续提示超出录音音高范围；启动、怠速和大范围驾驶仍可能发生变调外推。

## 验证与失败留痕

- 六份模型与父包manifest一致；原76份声音参数、三份保护F2参数保持。667份C/H＝659原样＋5份目录／装配／检查修改＋3份新增；接口和职责见`handoff/C文件索引.csv`。
- 两组分别在原参数拥有者被填污并释放后运行240123帧；捕获的每个原始DNA样本、统计状态及源时钟与原直接SaVoice契约一致。2／12通道的六干声总线和驾驶／DNA状态精确一致，三锚点均实际经过。这是工程一致性检查，非独立音色真实性证明。
- 完整目录构建的68项CTest通过。之后仅调整原生UI检查器的取样时间和日志；CTest执行代码及共享DSP保持，未重复这套未变测试。
- 原生窗口静音检查十二项的选择、控件、64123帧录音／回放、干声监听及跨音色内嵌回放后恢复实时配置；两组新增局部库各额外录制240123帧低／高／中控制。六个探测点最大根频率误差约0.0142Hz，小于原0.04Hz要求。
- 原十套WAV整文件和声源校验值保持一致。新旧播放器具有同一渲染身份`7d790f43…`，在不存在外部声音文件的工作目录中回放旧十套和新十二套内嵌行程；新两组与原生动态行程另核对2／12通道声源校验值。schema10／32控制字段保持。
- 九张程序自身窗口截图已逐张检查，未见新增布局裁切；这些静音测试和数值核查不代表人工听评或物理7.1.4验证。

首次`full1`因新增UI检查缺少`math.h`而报C4013；`full2`仅补头文件后通过构建和68项测试。首次`host1`把初次目标音高检查放在点火后1.25秒，尚未给0.28＋0.65秒启动态之后的0.10秒RPM／0.018秒DNA跟随留足收敛时间。`host2`将探测帧改为96000／144000／192000，保留240123总帧数和0.04Hz误差要求，并记录实际探测CSV。所有失败源、日志和后续成功记录均保留；这两处修正均未改变声音算法。

## 使用与后续

运行仓库根目录`Launch-Voice-Catalog.cmd`，在音色下拉框选择上述两个新选项。先开始监听、再点火；默认台架从中点开始。若自行构建，运行`Build-Voice-Catalog.ps1`，使用隔离的`build-catalog-local-v1`目录，旧播放器及行程仍保留。

下一步继续从批准素材建立更宽根频率和工况的独立证据，并为这些观察分别补充有依据的双声道／非谐波细节，沿用同一驾驶器和分层总线。F2怠速与F3叠加细节独立听评仍待答，不据数值结果迁移默认或盲调强度；E“左右关系有改善，音色仍明显电子”的反馈保持。其他真实发动机、全状态音色和物理7.1.4仍未完成，完整目标继续。

复现：`prepare_catalog_local_F3_v1.py`→`build_catalog_drive_v1.py --phase all`→`--phase host`→`regress_catalog_local_F3_v1.py`／`review_catalog_local_F3_v1.py`→`package_catalog_local_F3_v1.py`。每次证据输出必须使用新目录；失败尝试不可覆盖。冻结包`baselines/catalog_local_F3_v1`包含源、参数、可执行程序、失败／成功记录和全部校验。

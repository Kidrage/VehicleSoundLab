# 基础三角与提前释放 V1

本轮将基础求解的方阵T副本省掉，并把旧X的释放提前到内层因子分配之前。两项改动都显式选择，原复制后端和原修正流程保持默认；实时C音色、驾驶器和空间接口保持。

## 模块与数学边界

| 模块 | 职责 |
|---|---|
| `waveform_stream_v1/solver.py` | 新增可选`triangle_backend='native'`，从图QR原上三角和实际leading dimension求解；默认仍复制T |
| `waveform_early_release_v1/inverse.py` | `OwnedNativeInverse`接受唯一所有权容器；完整构造右基，再核实旧X死亡，才分配内层QR |
| `waveform_early_release_v1/pipeline.py` | 原基础解→释放旧度量／图→所有权转移→固定两次原FFT修正 |
| `audit_waveform_early_release_v1.py` | 独立核对数组生存期、别名、20组原结果及8条错误所有权拒绝路径 |
| `inspect_waveform_early_release_resources_v1.py`及独立审计 | 从已归档真实上下文取得形状，保持原节点／尺度，核算全部六段原范围和完整上下文 |

完整正交右基和恒等补空间均保留。仍是原平方根／Householder图求解与两次完整原算子修正，没有显式完整Q、法方程分解、相消Woodbury或分块对角近似。所有阶次、节点、时间范围和原数值门槛保持。

```text
基础：W + X + 图QR（直接读取其三角；无独立T）
释放：W／图QR
右基：X + 右QR
释放：X，并检查无外部所有权
内层：右QR + 内层QR
修正：完整原FFT／伴随，固定两步
```

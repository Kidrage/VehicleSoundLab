# 低频局部声线与持续性 V1

**已建立低频局部声线观察，但真实录音的连续提取仍不合格，没有新音色替换当前Demo。** 本轮从“固定锚点漏线”进一步检查随时间移动的声线；不把训练频谱拟合当作机械质感或物理分层证明。

## 方法与实际执行

只读原A车外208–210秒和F2尾排6–9秒训练文件，与上一轮冻结逐哈希相同；不读保留段、不新下载。30–300Hz、原生48kHz、0.5秒窗／0.25秒步进。

不按固定中央清单或峰值排名预设身份。每窗取原生峰，复用`line_motion_v1`已有的独立线性升降频波形和解析导数，联合拟合频率、变化率、幅度与初相；L拟合频率／变化率，R在同坐标下独立求幅相。该双声道坐标假设不是气缸组划分。

频率限于原生半格及邻峰间距内，变化率一次预声明±80Hz/s，最多60次评价。触边、预算耗尽和所有候选完整保存；没有扩大范围或挑最好窗口。算法仍假定局部恒幅、线性升降频，不能覆盖全部真实变化。

局部“受支持”要求数值成功、该线不触边，并解释扣除其他拟合线后至少80%的邻域功率。跨窗对应同时检查正反向频率预测和变化率，仅两端唯一的边继承身份；歧义／缺失断开，不补洞、不重连。至少连续五窗才描述其在当前局部模型下移动或固定，标签不代表机械部件。

| 文件 | 职责 |
|---|---|
| `tools/low_chirp_v1/fit.py` | 原生峰清单、局部模型与条件支持 |
| `tools/low_chirp_v1/link.py` | 频率／变化率对应、断点与有限持续性 |
| `tools/low_chirp_v1/controls.py` | 已知移动／固定混合、邻线／缺线和反例 |
| `tools/observe_low_chirp_v1.py` | 训练文件宿主与全部参数留痕 |
| `tools/diagnose_low_chirp_noise_v1.py` | 不改变算法的单声道噪声反例 |
| `tools/audit_low_chirp_v1.py` | 独立波形、支持、优化指标与全部对应重建 |

## 结果与限制

先行已知测试中，三条移动＋三条固定声线在七窗全部正确对应；纯音、升频、近邻、缺线、增益不变性、静音及预设双声道独立噪声／交叉例通过。真值仅评估结果，未用于初始化。这只验证有限已知例，不是声源检测器资格。

| 实录训练观察 | A车外低转 | F2尾排 |
|---|---:|---:|
| 原生窗口 | 7 | 11 |
| 数值成功窗口 | 5 | 8 |
| 全候选次数 | 129 | 241 |
| 条件支持次数 | 61 | 86 |
| 最长连续对应 | 2窗 | 3窗 |
| 达到五窗的固定／移动轨迹 | 0 | 0 |

这些是重叠窗口和候选的计数，不是独立试验数或声源数量。预算耗尽的窗口仍保存全部拟合参数，但不计受支持。不能通过跳过它们或增加允许断点，把连续性“修好”。

F2每窗30–120Hz的L声道训练残差功率占原功率约2.00%–8.82%，看似还原了很多能量，却仍没有五窗连续声线。这说明局部重建与可持续、可调参的声源结构是两项不同要求。残差与模型也不一定正交，不能将二者功率直接标成真实声层比例。

另外，原噪声控制左右独立，而F2有效近单声道。本轮按预声明补查，把同一已保存噪声的L复制为R=0.67L，算法／门槛／预算不变：**独立双声道噪声0条条件支持，近单声道噪声出现1条。** 已知控制原结果不变，但其覆盖不足被明确记录；局部支持不得解释为“检测到发动机音调”，更不能把该标准直接导出声源配置。

## 续接

下一步先用已知恒音、非线性频率变化、幅度变化与同源双声道噪声区分“恒幅线性模型失配”和“持续性规则失效”，再决定复包络／有限相关时间的统计表示。不先加多项式阶数、扩大范围、接回断线或给失败A补随机低频。已出现的单声道反例必须保留，不以新模型数值成功替代它。

声线复杂变化可作为独立统计问题研究，不等于新的共同发动机相位；原共享相位资格、实际RPM／负载、完整怠速／带载加速与7.1.4仍未完成。F2细谱V2候选仍待原听评，不重复提问。本轮不改运行模型、C、默认值或空间处理，不生成新的WAV／profile。

独立复核重建全部18个实录窗口的波形、残差、初始化线性条件、边界、损失、梯度缩放、局部支持及所有对应和分类；最大波形差2.01e−14FS。已知样本／混合配方和单声道反例也独立重建；没有重复非线性求解。`audit1`与补充已知／单声道检查的`audit2`均保留，图已目视。569份C/H及67声音配置以哈希保持，未重复59CTest。

全部参数、原生输入身份、计划、精确执行源、图表与反例冻结在`baselines/low_chirp_v1`。数值审计通过仅证明实现与报告一致；真实声源提取仍不合格。

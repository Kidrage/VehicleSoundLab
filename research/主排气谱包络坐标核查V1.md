# 主排气谱包络坐标核查 V1

批准的 A 车外补油第一段中，1.5–8 kHz 的平滑谱形，用固定 Hz 轮廓预测后段，比把轮廓随观察谱线整体移动更准确。这个观察跨三种谱线估计窗口、两种谱形平滑宽度及 L／R 保持。第二段的区分较弱，在较宽平滑下发生反转，不能扩大为整车规律。

这支持继续研究**逐次压力激励与固定频率声学谱形各自的作用**。它没有识别机械模态、真实发动机阶次或排气传递函数。当前 C 模型也已经有固定 Hz 包络；本轮结论是优先检查并标定已有主排气包络的参数与控制，不是宣称发现了一个原本缺失的模块。相位实验仍待听评，原生 V016 和所有已发布试听保持冻结。

## 新增方法

`tools/spectral_coordinates.py` 将条件谱形分析独立维护。`analyze_spectral_coordinates.py` 读取目录批准的 A 238–248 秒片段和已有下降谱线；`analyze_fired_shape_extension.py` 明确检查 C 的燃烧与断油区间；`verify_spectral_coordinates.py` 做独立数值和保存检查。

原始 stereo float32 样本通过 `reference_segments.py` 验证并读取，L／R 不合并。分析仅产生 PSD 矩阵、图表和 JSON，没有新参考 WAV、归一化、降噪或下载。不是音源分离。

1. 对原始通道做 4096-sample Hann STFT，hop 480 samples，48 kHz。窗口约 85.3 ms，无零填充。
2. 插值至 600–14000 Hz 的对数频率网格，每 octave 48 bins；平滑 **log PSD**，sigma 分别为 1/8 与 1/4 octave。这是几何谱形统计，不是频带积分能量。
3. 分别拟合固定 `log2(Hz)`、移动 `log2(Hz/观察谱线Hz)` 以及两者相加三种平滑轮廓。使用 1/12 octave 线性插值基函数和二阶差分正则；系数只从训练帧获得。正则 0.1 由已知解析谱形校准，未按参考数据调选。
4. 用之前的至少 12 帧训练，训练末帧与测试首帧中心相隔至少 192 ms；实测为 200 ms，超过本轮最大观察谱线窗口。每次检验之后 10 帧，测试块互不重叠；后续折允许使用已经过去的前一测试块。
5. 在各方法共同支持的 1500–8000 Hz bins 比较谱形。训练和比较均移除每帧的 dB 均值，因此明确排除整体电平；频谱轮廓可以用后段自身均值定义形状，这不是绝对幅度预测。指标为等对数频率 bin 的谱形 RMSE。

整个观察谱线在分析时已知，并未预测未来音高；其离线估计也可能受后续录音影响。测试检验的是**给定频率路径时的后段谱形**，不是在线转速预测或因果频率跟踪性能。频率线倍乘 2 不改变方法结果，无法由此确定物理阶次。

## 参考结果

下表为 128 ms 观察谱线路径，数值为 L／R 谱形 RMSE，单位 dB，越小仅表示该条件模型更能预测此处谱形。

| A 的观察区域／谱形 sigma | 固定 Hz | 随观察谱线移动 | 两种坐标合用 |
|---|---:|---:|---:|
| 第一段，1/8 octave | 1.501 / 1.590 | 2.208 / 2.139 | 3.560 / 3.586 |
| 第一段，1/4 octave | 1.067 / 1.170 | 1.629 / 1.625 | 2.631 / 2.761 |
| 第二段，1/8 octave | 1.237 / 1.209 | 1.452 / 1.458 | 3.466 / 3.580 |
| 第二段，1/4 octave | 0.930 / 0.879 | 0.833 / 0.882 | 2.291 / 2.404 |

第一段的测试帧覆盖约 238.503–238.993 秒，共 5 个测试块，每通道 5800 个谱形比较点；这不是 5800 次独立试验。第二段只有 4 块，覆盖约 241.223–241.613 秒。三种谱线窗口及两种平滑宽度使用重叠录音，不构成置信区间。

合用模型有更多参数却在真实片段后段更差，不能以训练拟合或模块数量论证模型更好。固定与移动轮廓在斜率／截距分配上有歧义，短片段的外推还会放大过拟合；图中绿色轮廓不能解释为已分离的“排气＋机械”传递。

## 合成器必须区分 FIRE 与 CUT

对冻结的相同空挡 take，另外检查了 3.0–4.2 秒燃烧区间和 6.45–7.85 秒断油区间。C trace 确认它们分别全程为 RUNNING／FIRE 和 RUNNING／CUT。下表为直接积分原始 Hz 坐标的 Welch PSD，尚未做谱形平滑或移除均值，列出 L 或左源：

| 对象／输出 | FIRE，1.5–8 kHz dBFS | CUT，1.5–8 kHz dBFS |
|---|---:|---:|
| 左排气源 | −39.13 | −167.57 |
| 左气流源 | −59.77 | −80.30 |
| 完整输出 L | −48.53 | −82.98 |

排气源是空间渲染与 master 之前的对象，不能与监听通道直接作物理功率相加。这些是数字电平，也不是实车 SPL。尤其不能用几乎无高频排气的 CUT 谱形去解释可听见的燃烧主音色。

FIRE 的 1/8 octave 谱形结果：排气两源的移动坐标误差为 1.686／1.819 dB，固定为 1.986／2.149 dB；完整混音则反过来，固定为 1.778／1.822 dB，移动为 2.310／2.274 dB。由此可见，独立声源与混音会给出不同的坐标偏好。C 使用的是 trace 的工程 drive RPM 坐标；音频相位还有 18 ms 平滑，未精确导出，因此这些只作带有明确局限的合成器诊断，不是真实转速同步阶次分析。

![分开检查实际燃烧区间](../references/analysis/spectral_coordinates_log_v1/fired_shape_prediction_checked.png)

C 与 A 的转速、负载、变化方向、麦克风及增益没有匹配。不能将两边 RMSE 相减作为音色误差，也不能由“参考固定、C 源移动”直接算出应增加多少机械声或滤波增益。

## 已排除的分析陷阱

初次 `spectral_coordinates_v1` 在线性功率上做宽 Gaussian 平滑。C 的 CUT 排气以低频泵气为主，高频极弱；移动的强低频成分会通过有限平滑核的尾部进入高频统计，造成谱形骤变。这个初次结果和当时源码均保留，未按其宽平滑的 C 排名拟合运行时。

独立已知 PSD 控制保持目标高频 bin 不变，只移动远处高 140 dB 的低频 bin：线性功率平滑的目标值变化约 **94.68 dB**，log-power 平滑只变化约 **0.0041 dB**。后者测的是另一种谱形统计，避开这个特定支配效应，并不保证消除全部窗泄漏、谱线重叠或跟踪误差。本轮原始频带电平另用不依赖该平滑器的 Welch／独立 FFT 积分核对。

解析谱形控制中，固定模型恢复固定轮廓的误差约 0.047 dB；移动模型恢复移动轮廓约 0.048 dB。完整无噪声加法 OSC 控制也给出正确偏好：固定 Hz 包络分别约 0.856 对 5.302 dB，移动包络约 0.768 对 5.530 dB。它证明方法可以辨别这两种已知情况，也再次表明固定 Hz 现象无需噪声就能出现。

当观察频率不变时，两种坐标给出相同结果，无法区分来源。所有控制和失败／不确定情况都保留，没有将误差解释为噪声比例、真实度或机械源占比。

## 对下一轮实现的约束

继续沿用 V6 的独立 DNA、机体、进气／排气细节与空间层，而不直接照搬其非整数 OSC 系数。核对的本地 V6 `gen/v10_powertrain.gendsp` 明确将 orders、intake、exhaust 和 residual 独立相加，再送入运行／怠速控制；这些是可维护的合成分工，不是目标车声学辨识结果。所读文本仍来自已固定提交 `ac2b37d8639027d79934a2023cf8d1d37d3b2f96`，未新下载或修改上游。

下一轮主排气候选应把以下部分分别保留：随曲轴运动的阶次／逐次激励、已有固定 Hz 幅度包络、独立因果相位响应，以及驾驶工况对它们的控制。优先做已有谱包络的有限校准与跨片段验证；保持燃烧／机械旋钮独立，不把平滑参考轮廓当作孤立排气 IR，也不直接增加白噪声或非整数 OSC 来追指标。上一轮相位试听结果可以决定是否继续保留其传递形状。

本轮没有修改原生 DSP、默认音色、驾驶常数或空间路由。原生 V016 源码／二进制、批准素材及此前 21 个冻结快照重新校验。无需重复没有改变的设备／UI 生命周期测试。整体真实感、按车型和工况标定、视频遥测与实际 7.1.4 听评仍未完成。

主要证据位于 `references/analysis/spectral_coordinates_log_v1/`：`results.json`、`fired_extension.json`、`summary.csv`、`verification.json`；冻结清单为 `baselines/spectral_coordinates_v1/manifest.json`。原始线性功率方法位于 `references/analysis/spectral_coordinates_v1/`，不作为本轮认可的物理结论。

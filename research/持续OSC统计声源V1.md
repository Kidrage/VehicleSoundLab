# 持续 OSC 统计声源 V1

2026-11-10。用户确认细节 OSC 原生窗口“**默认一致，有限变调也可接受**”。该认可覆盖既有六秒模型、0.90–1.10× 音高与速度联动，作为质量参照保留。本轮开始验证新的持续声源，不修改已认可窗口或系数。

[试听页](持续OSC统计声源V1.html)提供固定相对音高的录音短参考、含统计细节的 8 秒 OSC、仅平均声线，以及不同种子和中途改变音高的补充对照。**持续声源没有原录音的时间轴或片段循环。自然度尚待听评。**

## 来源与相对坐标

经统一目录读取 `A_exterior_moving`，核验原始文件与 float 主文件身份，L／R 保持为两个麦克风观察声道。参数只取源时间 **316.10–317.25 秒**。它是车外移动尾排混合录音，没有真实 RPM、踏板或负载标定。

80／128／192 ms 三种窗在该区间均检测到约 233.05–261.89 Hz 的同一候选上行声线，最大窗间差约 0.916 Hz。这是对本次频率估计的敏感性检查，不是独立真值或置信区间。

以观察声线除以 5 建立一个相对周期候选，将时间坐标统一到 **46.875 Hz**。除数 5 未被独立证明为物理点火阶次，不能直接换算成真实发动机 RPM。两声道共用时间映射；仅对这个明确标注的派生参考做 80–14 kHz FIR 与 16 倍 Kaiser 插值，保留原主文件。最大向上频率比例约 1.006，归一化参考长约 1.217 秒。

## 保存什么、生成什么

在归一化坐标上，每 256 样本取一个 1024 样本窗口，联合保留两个观察声道的 300 个复数谐波系数，并抵消窗口起点带来的已知载波相位。使用完整周期的矩形分析，避免把 Hann 的旁瓣直接当成持续调制特征。

从 225 个观察帧提取三个静态参数组：

1. 每条谐波的复均值：保留平均幅度、相位和两声道关系。
2. 12 个共同变化方向及其一阶时间相关性：表达多条谐波一起变化的结构。
3. 每条谐波剩余变化的四维协方差及相关性：联合描述 L／R 的实部、虚部，保留统计细节的声道联系。

前 12 个方向解释了约 93.59% 的**观测系数变化方差**。这不是声纹还原率、物理声源占比或真实感评分。剩余变化继续由协方差模型生成，没有被直接丢弃。

C 端以固定 seed 48271 初始化高斯调制状态，用拟合的 AR(1) 相关系数生成新的状态，再对连续复系数插值。线性插值的平均方差按 `(2+rho)/3` 的解析关系补偿。相关系数限制到 ±0.95，插值和限幅边界属于当前工程配方；它们不等同于测得的逐缸燃烧动力学。

最终声音只由公共相位下的正弦／余弦 OSC 求和。相对音高控制相位步进和调制更新尺度，输出由调用者指定时长，没有录音游标、逐帧系数表或音频样本回放。模型文件只保存上述静态统计数组；静态平均声线对照关闭调制。

## 模块

- `tools/sustain_osc_v1/observation.py`：候选声线与明确的共同时间归一化。
- `tools/sustain_osc_v1/profile.py`：复系数统计、共同变化方向、相关性和参数导出。
- `tools/sustain_osc_v1/oracle.py`：独立复指数求和与随机序列控制。
- `experiments/sustain_osc_v1/model.*`：有版本、范围、有限数值及截断校验的事务加载。
- `experiments/sustain_osc_v1/source.*`：可移植 C11 持续声源，独立相位、调制状态和 18 ms 参数跟随；处理内无分配或文件 I/O。
- `probe.c`：离线 float WAV，调用持续声源至指定时长。
- `checks.c`：解析音调、固定种子／分块一致性及控制平滑检查。

## 已完成的验证

- 三个固定声源及中途变音高版本都输出 **384000 帧／8 秒**，超过参数来源长度；变音高版在第 4 秒由 0.90× 转向 1.10×，时长仍不变。
- 改种子产生不同波形；第 6 秒后的片段不是第 0 秒片段的重复。源码和模型格式也没有可循环的录音时间表。
- 独立 Python 复指数求和与 C 谐波递推的最大 float 绝对差约 **2.96×10⁻⁸**。
- 解析已知谐波在 1.10× 下符合目标相位／频率；固定种子不同分块输出一致，非法参数被拒绝，调参平滑通过。
- 截断模型和非法谐波数量被加载器拒绝。
- 试听均用同一 **0.5／−6.0206 dB** 增益、5 ms 端点淡入淡出和 PCM24，无独立 RMS 匹配、压缩或额外增亮。float 原始导出保留可能超过 1 的样本，试听保留足够余量。
- 本轮仅新增独立 C 模块和离线研究，没有替换原生驾驶 DSP，也没有修改已认可监听窗口的音色或变速行为。

固定音高录音参考约 1.217 秒，不能与新生成波形做逐样本误差排名。主持续版与仅平均声线共用原系数均值，但加入变化会自然改变能量；本次两者整段 RMS 相差约 1.26 dB，没有另做响度补偿。

## 仍需听评与识别的边界

本模型概括的是一个短小、随时间变化的车外混合观察。它包括声源、车身、录音空间及录音处理的共同结果，**尚未分离 DNA／PAD／NVH／空间**，不能整块当作纯 DNA 再叠加同样的车身或 IR 贡献。

统计高斯调制可能会抹掉真实非高斯冲击、循环条件和高阶频率关系；参考的相对音高估计也有误差。未经过持续声听评，不能从方差或数值一致性宣称自然度已保留。本轮新生成音色与之前获认可的同片段重建是两项不同验收。

若持续版仍电子化或变成风噪，需要回查哪些跨谐波／跨周期结构在统计概括中丢失，保留原参照；不靠提高高频或单一事件触发器补救。若方向成立，再在车外低转、补油和移动情境中分别拟合与验证状态变化，逐步接入已有 DNA／PAD／NVH 分层和状态机。

## 结果与复现

`references/analysis/sustain_osc_v1/fit.json` 保存来源、路径敏感性和模型身份；`renders/results.json` 保存 C 输出、独立数值检查、控制及音频身份；审计在 `audit.json`。新快照为 `baselines/sustain_osc_v1`，旧窗口和所有历史音频保留。

构建：`cmake -S experiments/sustain_osc_v1 -B build-sustain-osc-v1 -G "Visual Studio 17 2022" -A x64`，再 `cmake --build build-sustain-osc-v1 --config Release`。检查：`ctest --test-dir build-sustain-osc-v1 -C Release --output-on-failure`。

先运行 `tools/fit_sustain_osc_v1.py`，再运行 `tools/render_sustain_osc_v1.py`。两者都拒绝覆盖已存在的结果目录。

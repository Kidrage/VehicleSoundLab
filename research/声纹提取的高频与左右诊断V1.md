# 声纹提取的高频与左右诊断 V1

2026-11-16。本阶段完成了独立的声域诊断工具及结果读取链，尚未产生新音色。上一目标轮仅复核 MCPS，没有合成进展。原六段 V10 提取仍由同一 PID245372／session83157 顺序执行，未重启、未修改其96份绑定源。

工具分别测量完整频谱和阶次中心，不再用少数阶次中心的读数代表全部高频。六个频带为0–3、3–6、6–8、8–10、10–14及14kHz以上；所有实际FFT频点包含DC／Nyquist。保留左右功率、复相干、直接计算的M/S能量、功率起伏CV、频带／声道协方差与1–8跳的有符号滞后协方差。没有增益匹配或补高频处理。

## 原失败及处理

原九组测量 `known1` 完成，但独立 `known_audit1` 在第一组失败：高频阶次中心的CV误差约4.085e-5，未通过原2e-10门槛。该控制信号保留第300阶的19200Hz真高频，而阶次诊断只取1–288阶；完整频谱正常，最后阶次频带只剩约6.04e-29的微小泄漏。不同FFT／窗口的微小舍入差经归一化放大。改用相同离散Hann定义仍有差异，不能只归因于窗口定义。

失败和原信号完整保留，没有把300阶移入诊断范围、删频带、换种子或放宽门槛。新验证明确分开：

1. 独立Welch／CSD核对全部线性功率、Gram、直接M/S及Parseval，保留原2e-11相对各控制自身能量门槛；直接DFT保留2e-10相对波形L1门槛。
2. 对同一份冻结功率／互谱序列，用独立标量公式检查全部统计，保留原2e-10门槛。
3. 继续执行并公布跨独立FFT的原统计检查。五项微小阶次能量的归一化检查仍失败，`legacy_cross_operator_all_statistics_qualified=false`，没有改写为全部通过。

额外输出一个随实际输入尺度缩放的FP64数值敏感度估计，以及功率下界余量／相对不确定性／独立resolved标记。它不截断功率，也不替代原数学defined标记。该模型是保守工程敏感度，**不是对NumPy／SciPy二进制FFT的已认证误差上界**；resolved也不是物理声源证据，不能豁免任何失败。

九组原控制及同一个128点全频点控制通过上述频谱与冻结序列统计验证。全频谱／Gram最大误差约5.09e-15，直接DFT约1.31e-14；真实低于1e-24的微弱高频／宽带仍保留。五项跨FFT失败来自缺少真实对应阶次的微小正能量，不应训练成发动机调制。

## 模块与运行

| 模块 | 职责 |
|---|---|
| `tools/extraction_sound_v1/measure.py` | 完整频谱、独立阶次中心、LR／M/S／时间统计 |
| `numerics.py` | 输入相对的数值敏感度及独立可信度标记 |
| `compare.py` | 所有有符号差异；零参考比值为null |
| `consume.py` | 只读已终止且独立审核的提取结果，绑定原输入身份 |
| `fixtures.py` | 固定控制信号，绝不作为发动机预设 |

`run_extraction_sound_known_v1.py`／`audit_extraction_sound_composed_v2.py`验证测量器；`run_extraction_sound_cases_v2.py`／`audit_extraction_sound_cases_v2.py`负责提取结果与诊断的绑定。三组既有左右不等／右声道延迟／右声道静音提取结果，分别验证原目标及完整真实上下文两种范围；六种伪造审核／哈希／状态／绑定被拒绝。首版结果审计与第二版按实际字段尺度加强的审计均保留。

仅当真实单段的`capture.npz`、终止报告和独立数学审核均已落盘，才可运行真实诊断，无需等待后五段或重启提取。示例参数见`run_extraction_sound_cases_v2.py --help`；真实模式的`--study`为单段目录，`--math-audit`为对应审核报告。已知控制使用`--known-check`，不能把已知控制通过称为真实素材通过。

## 与生成／驾驶／空间的关系

诊断把“缺高频”“左右关系丢失”“时间起伏不对”分开度量。虚拟每周期1024点／参考根频64Hz采用65536Hz分析轴；原录音48kHz单独记录，不能把两个频率轴直接作同一物理Hz比较。原生逆渲染、抗混叠与真实持续统计声源尚未完成；拟合时间轨迹只用于诊断，不能循环充当发动机。

左右录音关系留在源的stereo bed；它不自动识别排气、进气、车身等物理对象，更不等于已经完成7.1.4。后续仍按唯一驾驶器控制DNA／BODY／DETAIL／EVENT／AUX，空间渲染独立维护。六份素材仍是同一V10的两次升速，不能声称已完成多发动机／全状态。

完整证据位于本地`references/analysis/extraction_sound_v1`，包含首次失败、诊断、第二版测量／独立审核、三组消费控制与两次独立结果审计。670 C/H、82音色文件、3份F2、C索引、认可moving35、默认、唯一驾驶器、owned／takes、房间及听评保持。没有推送、下载、新听评或重复旧68项CTest。

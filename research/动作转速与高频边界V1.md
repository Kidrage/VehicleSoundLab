# 动作、转速与高频边界

2026-11-12。用户对“接火低频建立V1”反馈：**“差别不明显而且好像没那么好听”**，并追问动作、实际／目标RPM，以及高频缺失和音色是否真正可控。本候选没有通过改善听评，不能因宽带均值或功能测试通过而晋级；独立车外固定情境的相干低频认可仍保留。

## 试听实际模拟什么

三条C混音均为两次驻车启动、短暂运行、熄火，没有踩油门补油或车辆加速。第一轮实际CSV如下；第二轮从3.20秒重复相同控制过程。

| 第一轮试听时间 | 程序动作 | 控制器RPM |
|---|---|---|
| 0.15–0.43秒 | 起动机拖转 | 0→约216，工程渐近目标220 |
| 0.43–0.63秒 | 接火冲转 | 约216→1150 |
| 0.63–1.08秒 | 回落 | 1150→约850 |
| 1.08–2.25秒 | 短暂稳定运行 | 约850 |
| 2.25–2.80秒 | 熄火 | 衰减至停机 |

0.28秒拖转、0.20秒冲转、0.45秒回落、1150／850RPM均是`src/profiles/lifecycle.c`与原控制器的工程设定，**没有从A实录标定**。音色模型34.8375Hz的声学根音暂绑控制器850RPM，不能将其称为已识别曲轴频率或已确认的发动机阶次。实际OSC另有18ms跟随：接火段根音最大约46.84Hz；这同样不是实测RPM。

真正参考目标是A车内33–40秒的“拖转→接火→冲转→回落到启动后稳定运行”。目前没有可靠的真实峰值RPM／时间轨迹；先对齐动作与声音时序，再确定转速映射。不能拿1150／850的工程演示宣称已经还原该车。之前先比较低频增量、尚未建立目标曲线的顺序需要纠正。

## 高频模块与缺失

| 模块／数据 | 已有能力 | 当前局限 |
|---|---|---|
| `sound_dna`／`dna_atlas` | 由素材的复谐波均值、固定相位和幅度统计持续生成OSC；多锚点插值 | 谐波数有限；启动256阶×34.84Hz只到约8.92kHz，驻车低档288阶×10.01Hz只到约2.88kHz，低音高时上限更低。此上限不保证频带内能量充分。 |
| `sound_residual` | 密集正弦OSC拟合独立可加的频带功率与左右复相关 | 通用驾驶模型主要1.2–8kHz；固定载波不等于已还原燃烧／排气的动态细节。 |
| `residual_atlas` | 用根音选择细节谱形、持续插值；独立细节量 | 默认0，低档因观察带宽限制只启用至3kHz，较低中档至6kHz；仍共用DNA状态包络，没有已标定负载／状态细节轴。 |
| 启动细节候选 | 同A趋稳段300–8000Hz、12带预算，独立量 | 600–850Hz不能独立相加而保持0；只拟合趋稳平均统计，不能当作快速接火时变细节。 |
| `drive_aux` | 进气／机械／排气空气等独立工程声层 | 尚未完成录音对应的源分离／音色拟合，不能充当丢失高频的万能替代。 |

《启动后车内DNAV1》和本次《接火低频建立V1》的C混音没有后来新增的高频残差；《启动车内细节V1》及新原生研究入口才有可选补充。各历史试听页保持原版，不将新代码的能力反写成旧试听已有。

另外，四周期Hann分析只读整数谐波中心，已知宽带控制约只保留3/8功率，实录3–8kHz中心读取损失约4.2dB。这是已证实的一项遗漏机制，不代表全部损失都是噪声，也不能全DNA统一提亮修正。8kHz以上的剩余细节目前没有完整覆盖。

## 原录音怎样进入可控系统

实际链路是：批准录音分情境／片段→观察相对声学周期→提取左右谐波复系数→保存均值、统计方向及相关参数→C持续OSC→与录音比较频带／声道统计→对允许独立叠加的剩余功率另建OSC层。模型不保存原片PCM或按帧播放时间轴；持续DNA及驾驶链无需循环原片，旧的系数轨迹重建试听属于另一类历史工具。

已能控制相对音高／驾驶控制、幅度变化量、锚点、低频分层、细节层量、辅助层量和部分空间／事件。可是**统计声纹可控不等于已经建立完整发动机模型**：同RPM不同负载／收油／切扭的谱形、真实事件频带时序、细节调制速率与各层动态耦合尚未完整沉淀。UI也没有提供每频带／每调制方向的独立设计控制；当前细节滑条主要是量控制。完整动作／转速／状态的听感和多发动机泛化还需验证。

新声源主要消费原工况增益与音高，尚未消费旧DNA的完整状态谱形参数；前述1.20dB假差异已有后续候选改进，但原反例与真实起落联合资格依然未通过，不能只引用另外16个通过的控制。见[离线时钟校验](离线时钟校验V1.md)。后续优先补动作／转速证据、宽频表示与工况谱形和时变细节，避免继续把静态均值接近当作整体逼真。

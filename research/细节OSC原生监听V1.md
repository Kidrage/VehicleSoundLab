# 细节 OSC 原生监听 V1

2026-11-10。用户已明确反馈：**“细节保留版明显改善，录音参考正常”**。因此将完整度 V2 的 `rank64` 文件固定为新的重建质量参照：每帧最强 64 个复频率系数、四帧重叠、最多 256 项。这是片段音质改善的认可，不是最终真实度、变调或持续驾驶音色的验收。原文件与模型身份记录在 `research/timbre_quality_20261110.json`。

已将同一模型接入独立 C 实时监听窗口，默认 1× 的 PCM24 导出与被认可文件**逐样本一致**。本轮优先保住该声音，不压缩 OSC 数量，不增加高频层。

## 使用

双击工作区的 **Launch-detail-osc.cmd**。

- **播放／重新开始、停止**：监听六秒声纹片段；打开窗口时不自动发声。
- **音高／播放速度**：0.90–1.10×，默认 1×。这个控制将相位与声纹时间一起推进，音高升高时片段缩短；不是独立的 RPM 控制。
- **输出衰减**：0 至 −12 dB，默认 0 dB；0 dB 沿用已认可片段电平，不额外归一化或压缩。
- **循环六秒片段**：默认关闭。它重复当前轨迹，供连续审听；不能代替可持续的发动机声源模型。

界面仅有两个滑杆、循环选项和播放／停止。旧 `Launch-reference64.cmd`、原生驾驶应用 0.20.0 和全部历史版本保留。

## 音频模块

`experiments/detail_osc_v1/stream.*` 是可移植 C11 流式振荡器。它借用只读复系数模型，按当前连续的声纹位置，对最多四个活动短帧的正弦／余弦与 Hann 包络直接求和。输入步进变化前后相位位置保留，音高与增益目标使用 18 ms 跟随；音频处理内没有分配、文件 I/O 或源 PCM 读取。

`audio.*` 单独负责 waveOut 设备、事件队列、MMCSS、控制通信和设备停止淡出。`ui.c` 负责控件与状态显示，`probe.c` 负责离线 WAV，`checks.c` 负责处理不变量。系数加载复用未改动的 `osc_density_v1/model.*`，与 UI／设备分开。

**系数仍携带六秒录音的时间信息。** 这一步验证将已改善的重建质量带到可操作的本地监听，不是已经提炼出了发动机的持续发声规律。

## 验证结果

- 1× 导出的 PCM24 与认可版逐样本一致，最大差 0；float32 与原离线递推实现最大差约 7.28×10⁻¹²。
- 默认实时流与同一流式核心的离线 float 音频指纹一致：`eb2c52c3f35f4b81`。
- 实际静音 waveOut 设备提交并完成 288000 帧／6.000 秒；从首次成功提交计的播放墙钟约 6.020 秒，队列耗尽 0 次。
- 平均每 512 样本块渲染约 2.01 ms，最大约 4.95 ms，块时长 10.67 ms。这是本机本次测量，尚未证明目标嵌入式平台性能。
- UI 原生消息验证实际滑杆及循环按钮：调至 1.10×／−6 dB 后，持续播放并完成至少一次片段循环，队列耗尽 0 次；复位显示另有截图。
- CTest 检查实际模型的不同分块输出一致、参数非法输入拒绝、平滑、循环和结束行为。没有修改原生驾驶核心，不重跑其历史整套测试。
- 0.90× 和 1.10× 离线输出有限且无溢出，时长分别约 6.667 和 5.455 秒。变调的主观质量仍待听评，不声称任意调制无混叠。

### 保留的首轮设备检查

首次设备测试把 waveOut 冷启动耗时算进播放速率分母，6 秒设备音频对应 6.842 秒总墙钟，未通过速率阈值；队列为 0 次耗尽、音频指纹正确。首轮程序、输出和失败原因保留在 `references/analysis/detail_osc_v1/attempt1`。

随后分开记录完整墙钟、首次提交前启动耗时和实际播放区间。复核冷启动约 0.966 秒，总墙钟约 6.985 秒，其中播放约 6.020 秒；热启动／实时控件复核同样通过。没有放宽原播放速率阈值。

## 对算法方向的意义

当前证据支持：**先前的低质感与丢失／错误表达录音细节有关，这套保留更多短时复信息的 OSC 重建能明显改善。** 它没有单独区分 OSC 数量、分析窗、频率选择和相位连接各自的因果贡献，也不能把所有分散成分直接认定为噪声或逐缸燃烧。

后续持续模型需要保留两类相互联系的信息：随相对音高运动的相干声线，以及分频带的快速幅相变化／分散纹理；再用已有状态机控制各层强弱和过渡。FFT 频点不是物理发动机阶次，不能直接把 93.75 Hz 的频点间距映射到 RPM。

需要从规范目录中的车外低转、补油和移动片段分别提炼这些关系，并验证它们在新生成的持续音色中是否仍然有效。现有资料没有可靠的连续 RPM／负载遥测；低转、带载、收油、换挡的真实标定与工程状态映射仍须分别说明。PAD／NVH／空间继续作为独立层保留，当前不据此修改原生驾驶音色。

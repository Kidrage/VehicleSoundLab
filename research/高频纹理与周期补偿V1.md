# 高频纹理与观察谱线补偿 · V1

本轮保持 C 运行版本 **0.15.0** 和已有音色，新增离线分析。上一轮 goal turn 为 progress：完成了驾驶录制／回放。本轮检查高频纹理的分布和其控制来源，完整声浪与驾驶目标仍为 active。

## 找到的具体差距

当前完整 C 基线的高频仍明显偏向规则排气成分。更具体地说：在同一工程负载 `.85`、同一 FREE REV 台架工况下，1200～8000 RPM 的空气层 3–8 kHz 源功率几乎不变；排气源功率上升约 **4.9 dB**，空气／排气的相对比例因此下降约 **4.9 dB**。这是一项实际控制连接的观察，可以指导下一轮激励设计；不等于已经证明主观电子感的唯一原因。

| 工程 RPM | 空气两源功率之和 dBFS | 排气两源功率之和 dBFS | 空气／排气 dB |
|---:|---:|---:|---:|
| 1200 | −49.94 | −39.00 | −10.93 |
| 2400 | −49.95 | −36.84 | −13.11 |
| 4000 | −49.88 | −36.40 | −13.48 |
| 6000 | −49.92 | −35.82 | −14.10 |
| 8000 | −49.95 | −34.09 | −15.87 |

这里相加的是两条独立声源各自频带功率的中位数，不是相干波形相加后的混音功率；尚未包含空间路由和 master，也不是物理声功率。基线固定 seed 48271，取导出 2.5–5.8 秒。驾驶 CSV 确认上述各段均为 RUNNING／FREE REV，实际 RPM 已稳定，`air_gain=.0952`。

![独立声源的高频比例](../references/analysis/texture_v1/source_balance.png)

代码与结果一致：`core/nvh.c` 的高／中频滤波器基本固定；空气激励接受负载、工况包络和点火周期调幅。在这组恒负载 FREE REV 台架中，没有额外的 RPM 流量幅度法则。`core/orchestrator.c` 的 AIR 基础目标主要由正／负负载决定。低转到高转因此不会自动保持相同的纹理比例。正常驾驶仍可能因负载、工况、换挡和供给变化而不同，不能把台架结论泛化为“空气层完全不响应驾驶”。

## 录音中的分散细节不是简单的扫频假象

从统一目录读取已批准的 A 车外低转、补油、移动片段及 B 车内片段；校验原始文件和 float32 主文件 SHA256，保持 L／R 独立。不新增参考音频的归一化、降噪或声道合并。

先看原始频率坐标下的 3–8 kHz。85.3 ms Hann 窗、500 Hz sigma 平滑谱作频率白化后，逐帧谱平坦度的 L 声道中位数如下。该指标描述频谱是否集中，**不是噪声比例，也不是自然度分数**。

| 观测 | 平坦度中位数 |
|---|---:|
| A 车外低转 208–211 s | 0.537 |
| A 补油 238–248 s | 0.541 |
| A 移动尾排 316–319.5 s | 0.519 |
| B 车内 218–230 s | 0.500 |
| C 完整台架，4000 RPM／负载 .85 | 0.205 |
| C 完整台架，8000 RPM／负载 .85 | 0.195 |
| C Pure OSC，8000 RPM／负载 .85 | 约 0.0003 |

参考没有同步 RPM／负载和录音传递数据；此表不是同工况拟合误差或实时音色优劣排名。A 与 B 也不用于互相标定声场。每个通道、频带与窗口的完整分布均留在 JSON／CSV。

![原始频率坐标的参考与台架](../references/analysis/texture_v1/recordings_and_runtime.png)

单纯用谱平坦度判断“是否噪声”会出错。已知控制中的固定纯谐波，在 21.3 ms 窗下达到 **0.851**，高于白噪声的 **0.588**，原因是短窗不能分开密集谐波。同一算法用 85.3 ms 窗时，固定谐波降至 **0.0042**；快速扫频的纯谐波仍为 **0.583**，接近白噪声的 **0.569**。扫频本身就会把窄线铺开。

因此新增 `pitch_warp.py`：用一条受支持的观察谱线建立共同时间变换，在分析数组中抵消其相对频率变化。L／R 使用完全相同的映射。目标谱线频率选为最小输入频率的 98%，只向低处变调，避免把高频推向 Nyquist；16 倍 Kaiser 插值后再查询逆映射。用相同处理检查已知 14 kHz 信号，波形误差约 **−58.7 dB**。这里只为分析保留数组和映射，没有导出变调后的参考 WAV。

补偿后的窗口按观察谱线的 4／12 个周期设置，而非固定毫秒数，避免变调后频率变低又失去分辨率。已知扫频控制在 12 周期窗、观察频率的 20～40 倍范围，平坦度降至 **0.0018**，表明方法能恢复这种已知的谐波细结构。

![已知信号与补偿控制](../references/analysis/texture_v1/controls_resolution_log.png)

对 A 中此前已核实连续性的第一条下降谱线，分别用 80／128／192 ms 窗重新估计路径，取中心约 238.18–239.00 秒。12 周期补偿后，在观察谱线的 20～40 倍范围，平坦度仍约 **0.539～0.542**；低频随动线变清楚，高处依旧保留分散结构。该范围随原片段频率变化，大致覆盖原频率约 3.1–12.6 kHz 的不同部分，**不是固定原始 3–8 kHz**，不能用前后频带功率直接作残差百分比。

![真实片段的观察谱线补偿](../references/analysis/texture_v1/reference_pitch_compensation.png)

这支持把“高频尚有未被单一随动周期解释的纹理”列为研究对象。它没有分离物理湍流：逐缸差异、压力波形变化、固定频率的声学传递、其他声源、环境、编码和频率估计误差都仍可能贡献。给已知纯谐波的输入轨迹加入 1 Hz、5 Hz 速率的误差，补偿后部分帧的平坦度也可升到约 0.49；该压力测试不是对真实路径的误差估计。三个窗口结果相近也不是独立置信区间。

## 与 V6 的对应和下一步落点

检查 pinned V6 `v10_powertrain.gendsp` 的实际代码：其中名为 `bright`、`residual` 的路径本身用了 OSC 及脉冲调幅，不能因为叫 residual 就把它理解成已识别的噪声。精确代码行与哈希已存进本轮结果。

按用户的 DNA／机体／NVH 分层，下一轮应把高频气流／湍流激励的 **RPM × 负载 × 工况控制**作为独立候选处理。激励、滤波谱形和空间接收分别维护；已有 `air_left/right` 位于尾部，可继续独立路由至 stereo 或 7.1.4。保持点火压力周期与气流过程可分开控制，保留收油、断油泵气、换挡和熄火各自的资格条件与释放。

先用工程流量代理建立可解释且有界的变化律，再做固定驾驶 take 的试听对照。不能把表中的 0.54 当作调参目标、直接按差值填满随机嘶声，也不能从混合录音直接识别气流功率或阀门流量。首轮 16／64 仍是同片段频率轨迹预算；增加稳定 OSC 数量可以增加可表达的细节，但这些观测还不能证明有限 OSC 配方已与真 V10 等同。

## 文件与复现

| 文件 | 用途 |
|---|---|
| `tools/texture_metrics.py` | 每声道 STFT、宽谱形白化、集中度和功率观察 |
| `tools/pitch_warp.py` | 共同观察谱线的离线时间变换与逆映射 |
| `tools/texture_probe/` | 独立 C 测量宿主，链接不变的 V015 核心，不修改运行算法 |
| `tools/render_texture_probes.py` | 五种 RPM、两种负载、full／Pure OSC 共 20 组 float／take／十条分轨；四组 PCM 与冻结 V015 逐字节一致 |
| `tools/analyze_texture.py` | 已知控制、统一参考目录、补偿与运行时网格分析 |
| `tools/finalize_texture.py` | 独立解析控制、轨迹误差压力测试与源功率图 |
| `tools/verify_texture.py` | 文件、数值、源状态、参考及历史运行核心完整性核验 |
| `references/analysis/texture_v1/` | 原始诊断结果、补充验证、逐帧 CSV、图与 float 诊断；不上传 |

按顺序配置／编译 `tools/texture_probe` 到 `build-research-texture`，再运行 render、analyze、finalize、verify 脚本。已完成的数据有覆盖保护；新实验用新目录与版本。C 诊断输出不新增淡出或增益变化；实际文件是 float32，避免用 PCM16 的量化噪声解释高频分布。

本轮没有运行音色更新、没有新增视频工况事实或完成车厢／真实阵列标定。原 17 项 CTest 与原生设备证据保持；分析模块的校准、已知频率恢复、声道交换／增益不变性、插值误差、参考来源及历史版本校验独立完成。V10 的主观真实度、车辆专属声纹／动力学和真实 7.1.4 听评仍未完成。

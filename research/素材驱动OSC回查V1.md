## 已确认的问题

最早的 `tools/sinusoidal_experiment.py` 对录音逐帧检测谱峰，通过幅度插值、频率跟踪与三次相位插值重建。它保留的是片段中的时间变化，不是均匀谐波加一个固定包络。

原生工厂 DNA 的 `src/core/dna.c`、`exhaust_spectrum.c` 与 `profiles/high_orders.c` 仍主要采用工程谐波与手工谱包络。早期录音轨迹没有完整迁入原生音色模型。第一轮报告其实已标明这一区别；此前增加机械、压力和事件响应，没有补完这项迁移。这能解释实现路线为何偏离素材，但尚不能单凭代码证明每一种电子听感的成因。

现有驾驶、生命周期、供给、八种工况、六声层及其独立包络继续保留；它们是后续承载测量音色的控制结构。事件模块不再作为这轮音色推进的主线。

## 已完成的可核验结果

新增 `experiments/reference_osc_v1`，将录音检测的振荡器系数放入独立 C11 合成器。每段每个声道存储幅度起止、相位起点、角频率与相位多项式系数：

`y(t) = A(t) × cos(φ0 + ω0 t + c2 t² + c3 t³)`

相位连接同时约束两端频率和展开后的相位。谱峰出生／消失采用幅度渐变。它不需要事件触发、PCM 波形表、残差音频回放或随机噪声。保留独立的高频贡献，0 时只输出原有底层。

- 旧 64 OSC：C 重建使用原试听的增益与端点处理，和已保存的旧 PCM24 文件最大差异 `1.1920928955078125e-7`，即一个 24 位量化单位。原文件 hash 保持一致。
- 新车外片段：依据目录读取 208–211、238–248、316–319.5 秒立体声 float 原样本，分别拟合低转、补油、行驶。检测上限为 64 个共享频率支撑，每声道独立幅度／相位；不把 L/R 当作发动机缸列。
- 高频：从 `原音 − 底层OSC` 的残差检测 3–14 kHz、短窗 2048 点、最多 24 个支撑，独立生成 OSC，再按 35% 幅度加入。底层系数和增益不变。残差包含噪声、空间与跟踪误差，不是分离出的物理发动机声源。
- Python 独立区间公式与 C 原始 float 输出的最大差异小于 `6.0e-8`；检查了解析 AM/FM／立体声相位、1 与 257 帧分块一致性、18 ms 高频混合平滑，以及无效文件拒绝与失败加载保留旧模型。
- 13 个试听文件在浏览器全部解码；静音验证了 HTTP／本地文件、保留位置切换、播放中切换、片段重置和窄屏。没有据此声称主观音质通过。

原有两页早期试听、16／64 输出、最早 C 三层音频、所有冻结版本继续保留。B 仍在专用素材目录，未回到桌面。没有下载新素材。

## 从素材中得到的有限结论

以下为中央区间的平均频带功率差，单位 dB；负值表示合成版低于同片段原音。三版使用同一增益，没有按版本另做 RMS 匹配。

| 片段 | 64 OSC，3–8 kHz | 加高频，3–8 kHz | 64 OSC，8–14 kHz | 加高频，8–14 kHz |
|---|---:|---:|---:|---:|
| 车外低转 | −3.74 | −3.53 | −36.00 | −21.38 |
| 车外补油 | −3.57 | −3.30 | −15.54 | −14.08 |
| 车外行驶 | −2.00 | −1.84 | −22.44 | −17.49 |

强峰优先的 64 OSC 能保留不少主分音，却会遗漏弱的高频成分。单纯提高整体亮度会连主分音一起改变；独立上层分音可以保留底层，但本次保守补充仍未补齐高频。下一步需要按频带分配支撑预算、区分可跟踪分音与弥散成分，不能把增加 OSC 数量当作自然度保证。

同片段波形残差约为低转 −8.58 dB、补油 −8.44 dB、行驶 −11.40 dB；本次小比例高频补充几乎不改变全带残差，因为高频在总能量里占比很小。这些数字不是“模仿成功率”，也不能回答听感是否更像车。

跟踪分音的幅度和频率在变化，需要联合考虑谐波／非整数分音、包络、相位、谱线宽度、边带和工况变化。检测到的短期变化也可能来自估计误差、传播和录音处理，不能直接转成“实测逐缸抖动”。三次相位插值也不等于已经识别出某个真实机械 FM 调制器。

A Performante 与 B Tecnica 是两个 V10 车型参考，但 B 是车内双耳录音。B 本轮只作独立声道／频带观察，没有混入车外系数；车型、机位和驾驶条件同时不同，无法从 A/B 直接分离发动机设计差异。当前没有经审阅的新 V8／Porsche 素材，因此不把这轮结论外推为所有发动机的已验证模型。

## 如何接回可驾驶的系统

本次 C 模块播放的是**有时序的 OSC 参数轨迹**。它验证了录音到 C 的声线迁移，尚未解决任意转速、负载、工况、无限持续音与自由换挡。改变整条轨迹播放速度也不能替代发动机模型。

后续音色模型需要分别承载：

| 层／模块 | 由素材约束的内容 | 保留的控制职责 |
|---|---|---|
| DNA 主音色 | 分音幅度、阶次候选、非整数成分、相位／波形轮廓、局部 AM/FM | 从连续音高坐标映射到转速；曲轴与导入 DNA 时钟继续独立 |
| 高频细节 | 分频带支撑、弱分音、可观测调制与弥散残差的边界 | 独立强度和平滑；保留底层声音作为对照 |
| PAD／机体 | 可持续低频厚度及随工况的包络 | 比排气更慢的起落，不用单个事件替代持续层 |
| NVH／进气／空间 | 可观察的频带变化；物理模态或 IR 需独立证据 | 不把混合录音峰值直接称作机体模态，避免重复叠加录音空间 |
| 状态编排 | 低转、补油、带载、巡航、收油、换挡各自的连续谱形与比例 | 继续使用已有状态机与独立声层包络 |

先用相对音高和录音情境建立可插值声纹，再在有证据时接到绝对 RPM／负载；当前资料缺少可靠连续 ECU 读数。不同录音视角分别建模，不能把麦克风响应当作发动机本体。Serum 等设计音色可以走同样的分音与调制分析链，但须保留其音高映射和随力度变化的独立证据。

先核对找回的旧声线及高频方向，再将经过听评的模型作为新 DSP 版本接入。现有原生程序与冻结配方没有因技术重建通过而被替换。

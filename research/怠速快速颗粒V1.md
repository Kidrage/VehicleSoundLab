# 怠速快速颗粒 V1

本轮从已批准F2原生尾排录音继续提取怠速细节，新增[单播放器对照](http://127.0.0.1:8789/references/analysis/idle_microtexture_v1/review2/index.html)。保留13条OSC的频率、幅度、初相与原6组细谱共振器，只在1.2–14kHz细节上加入新的快速关联幅度。不是新增高频OSC云、音高抖动、原片循环或房间处理。

## 素材里发现的缺失

同样原生48kHz，F2的6–9秒训练、9–12秒检查；不降噪、压缩或逐条增益补偿。当前候选和录音同长3秒比较，六频带同一前向4阶Butterworth带通，首尾各丢100ms。检查段曾被观察过，来自同一录音，不能算独立验证。

2.2–4kHz的录音超额峰度为1.515／1.836，旧细谱候选约−0.063至0.028；10ms能量变异系数为0.608／0.657，候选约0.250–0.272。也就是说，旧候选保留平均频谱，却把短促聚集变成更均匀的高频沙声。原先只调13条低频主声线的慢幅度，几乎不改变这些高频读数。

用三个完整保留幅度谱、重新随机相位的控制，区分频谱本身引起的能量波动与额外的时间结构。它们只是观察控制，不是可交付的发动机合成或声源分离。固定13线全局投影残差也全部保存，不能称为分离出的机械摩擦。

## 本轮生成方法

从训练段非重叠10ms频带功率取半对数，计算四频带协方差，减去三个同谱相位控制的平均协方差。差矩阵本轮正定，最小特征值0.004956；**没有补对角线、投影、调门槛或复制原包络**。这仅是有限录音中的幅度代理，不证明燃烧、摩擦或任何物理源归属。

四频带对数幅度标准差约0.133／0.215／0.122／0.106，跨频带相关保留；10ms滞后差矩阵的迹给出一阶系数0.06806。复用已有新随机AR状态、方差归一余弦插值和`exp(s·z−s²·V)`期望平方功率补偿。每个频带左右使用同一增益，保持原近单声道关系。50%／100%是试听量，不是实车负载。

| 代码 | 职责 |
|---|---|
| `tools/observe_idle_microtexture_v1.py` | 原生颗粒、10／40ms能量、跨带相关与同谱控制；独立标量特征复核 |
| `tools/idle_microtexture_v1/profile.py` | 训练差协方差、资格与时间参数，不保存原轨迹 |
| `tools/idle_microtexture_v1/voice.py` | 原OSC和共振细节，只调指定频带；复用已有幅度状态 |
| `tools/run_idle_microtexture_v1.py` | 参数先冻结，再生成全部三种子／三档，最后报告旧检查段 |
| `tools/audit_idle_microtexture_v1.py` | 独立统计、PRNG／标量AR、复OSC及全长FFT卷积复核 |
| `tools/review_`／`check_`／`plot_`／`package_idle_microtexture_v1` | 简洁对照、页面检查、图与留痕 |

本轮是Python离线声源候选，未把未听评配方替换进C驾驶器。已有C的`modal_source`／`modal_texture`／`spectral_texture`仍各负其责；后续音色成立再移植细节幅度适配，唯一驾驶状态机和空间模块不变。原共同相位资格并不因此豁免。

## 结果与试听

全部三种子149921／277139／381611、0／50／100%共9组完整声／细节独奏均保留，没有挑种子、拟合后加量或逐版响度补偿。0量FLOAT与冻结细谱候选逐样本一致。独立重建全部9组最大误差1.4901e−8FS；峰值≤0.387FS。

100%把2.2–4kHz的平均超额峰度提高至约0.50、10ms能量变异系数提高至约0.46，向素材靠近但仍明显偏平滑。[三种子诊断图](idle_microtexture_v1_diagnostics.png)保留范围，未据此声称更像发动机。10ms观测和余弦插值无法唯一恢复更短的冲击；对数正态幅度也无有限硬上界，这些仍是候选边界。

试听页只有一个播放器、同增益1，可切完整声音／细节独奏。建议先听基准和50%，再听100%及原声：检查颗粒是否自然、是否新增沙噪／颤动。旧主声线幅度问题保持待答，不重复提问。

review1原文“共振频谱相同”已在review2改为“共振滤波器相同”：幅度调制会产生边带，不能声称输出频谱完全相同。两个页面、原文、浏览器检查与全部执行源码均保留；19组合、跳转／切换、手机布局静音检查通过、截图目视，不替代听评。

600份C/H、67运行声音文件、已认可行驶35%及所有旧声音不改；仅作本轮必要源统计／音频复核，未重跑61项旧C测试。当前目标是让怠速时间纹理更接近素材，仍待听评，未完成完整RPM／负载或多发动机验证。

# 共振细节：中频保护 V2

2026-11-12。用户反馈：**“替换35%效果还是可以的，70太难听了，高频完全损失没了，并且中频也很糊”**。已记录[原反馈](resonant_detail_v1_listening.json)。70%不作为改善版或默认；35%保留。

## 尝试及结果

上一轮35%／70%混音在**1.2–8kHz检查范围内**的频带能量误差均很小，仍出现明显主观差异。这不覆盖8kHz以上：谐波削减仍继续生效，而细节只按至8kHz的频带预算，没有保证更高频能量恢复。不能据此排除真正的高频总量损失，也不能将用户反馈仅归因为纹理。

即使某一频带能量相似，也不保证保住尖锐声线、清晰纹理与机械感；不能把能量／周期重复指标当作音色评分。较强替换削弱谐波结构、随机共振不足以补回细节，是另一工作假设，不是单一原因已被证实。本次按用户决定保留35%，不再扩展这段行驶音色的参数试验。

本轮只测试减少中频替换：保留3 kHz以下的原DNA谐波行，3–6 kHz按smoothstep逐渐增加功率削减量，6 kHz以上维持35%。幅度增益为`sqrt(1−0.35×mask)`；只打开原八带中的后四个细节滤波器。原LF、共振系数、包络、左右比例、随机序列和统一0.5输出增益保持，房间关闭。

| 项目 | 实际结果 |
|---|---|
| 原C削减与独立谐波求和最大差 | 5.60e−8 FS |
| 三种子活跃四带（3–8k）最大能量误差 | 0.0633 dB |
| 1.2–3k相对原版最大能量变化 | 0.00614 dB；谐波行精确保留，滤波裙边使总波形并非精确不变 |
| 共同增益后最高峰 | 0.5437 FS |
| 3–6k第一块周期重复 | 0.742–0.748；原版约0.859，上轮35%约0.54，录音约0.602 |
| 6–8k第一块周期重复 | 0.536–0.543，接近上轮35%，仍明显高于参考约0.057 |
| 用户结论 | 上轮35%更好，本轮不采用 |

三种子沿用8121907／23117／61927；逐采样生成的激励转float后，与冻结V1分轨逐样本一致。试听页的原版、35%及短录音参考共25文件与旧页字节一致。35个切换文件均通过HTTP字节核对、FFmpeg解码；播放器JS语法通过，只设一个播放器。未声称真实浏览器交互、原生设备或新的音色验收。

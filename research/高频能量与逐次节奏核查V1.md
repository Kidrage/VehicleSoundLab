# 高频能量与逐次节奏核查 V1

本轮把“高频波形重复”与“高频能量按节奏起伏”分开观察。当前 C 的高转主声源已具有很稳定的周期能量结构，V016 细节层只小幅改变了它。参考片段在给定谱线坐标下，固定的过去包络不能有效预测后续包络。**这不足以反推出真实逐缸随机度，也不支持直接增加固定节奏的噪声层。** 原生音色与驾驶参数没有变化。

## 观察方法与边界

参考只用已批准目录的 A `A_exterior_blips`（238–248 s），保留原始 L／R。采用已有下降谱线：第一段分别使用 80／128／192 ms 跟踪窗，第二段使用 128 ms。谱线不是已识别的点火阶次；用一个或五个观察谱线周期作为候选重复长度，均不据此标注真实 RPM 或缸列。

1. 用 513 点有限复数 FIR 观察 1.2–3、3–8 kHz 的解析功率。
2. 在原时间坐标去除慢变对数功率趋势：有限 Gaussian，σ=20 ms，截断 ±80 ms；再将每个完整候选周期按自身均值缩放。此为离线分析坐标，不改写或导出清洗后的参考音频。
3. 用之前八个周期的 8／16 个包络相位谐波预测之后四个周期；训练末端与测试起点至少相隔 200 ms。有限包络分析支持不跨越此隔离区。完整谱线、慢趋势和测试周期均值都是给定条件，不是在线预测结果。
4. 误差为预测残差平方和／实际包络变化平方和的 dB。**0 dB 表示只预测每周期均值；正值表示过去模板反而增加误差。** 测试周期各自拟合的谐波投影下限另列，避免将 8／16 谐波表达不了的尖脉冲误认成随机性。
5. 对测试周期各做一次随机的循环相位平移，共 64 组；两声道共享每次平移。报告其误差相对原模板的变化。这是人为破坏相位的对照，不是置信区间、真实度或噪声占比。

20 ms 是分析设定，会削弱一部分真实慢包络。扫频、频率路径误差、固定 Hz 传递、其他声源、环境和编码仍有影响。特别是参考与恒转台架没有匹配转速、负载和麦克风；不以两组误差之差来拟合随机声能。

## 原生声源与现有细节层

读取已冻结 float32 输出和燃烧支路 taps，不重新渲染或更改配方。稳态窗口为 2.5–4.8 s；该模型的缸列频率已知为 `RPM×10/240`。这里一个模型缸列周期对应参考表中“一个观察周期”的分析形式，但不代表两者物理阶次相同。

| 模型工况／3–8 kHz／L | 基线模板误差 | 压力与机械各 65% |
|---|---:|---:|
| 1200 RPM 完整混音 | −1.072 dB | −1.096 dB |
| 4000 RPM 完整混音 | −4.397 dB | −4.193 dB |
| 8000 RPM 完整混音 | −9.088 dB | −8.834 dB |

4000 RPM 单独压力／机械 100% 分别为 −4.316／−4.172 dB。8000 RPM 的原生燃烧支路约 −17.698 dB；它比完整混音更容易由固定包络预测。换为完整 720° 周期与 16 谐波的结果也保留在 JSON／CSV，不挑最低误差作为“最佳阶次”。

另检查已存在的空挡动态燃烧段 3–4.2 s，以及断油段 6.45–7.85 s，状态从实际 take 轨迹核实。断油时燃烧支路的原始解析带功率低于设定的 −160 dB 门限，因此不对近乎无声的支路做归一化节奏评分。泵气、机械等独立支路不因此被判断为无声。

## 已验证的反例与初始结果保留

初始版只除以每周期均值，会把指数衰减单音切成重复斜坡。即使随意提供 100 Hz 时钟，它也得到约 **14.31 dB** 的相位对照增量。这是慢包络造成的误判。加入有限慢趋势去除后，该信号的周期形态方差降至约 `4.84×10⁻¹⁵`，被判为无可测包络变化。初始数据和当时源代码完整保留在 `references/analysis/envelope_cycles_v1/`，新主结果使用独立的 `envelope_cycles_detrended_v1/`。

- 无调制噪声的相位增量约 −0.007／−0.011 dB；已知相位调制噪声约 +1.693／+1.760 dB，方法可以区分这两种生成机制。
- 纯加法 OSC 也能产生很强的周期高频能量。8 谐波模板误差约 −2.505 dB，恰好达到其谐波截断下限，不能将余下误差叫作随机燃烧。
- 已知 AM 扫频的周期归一化包络与独立解析式相比约 −76.40 dB；固定 Hz 谱形随扫频变化的无噪声 OSC 仍可改变包络可预测性。
- 独立三角基最小二乘／时域残差核对 FFT 计算，已知余弦的分数周期平移有闭式结果；另核对直接卷积、增益不变性、声道交换、周期内旋转及隔离区支持。

## 对下一次音色修改的约束

继续保留 V6 的主排气／机体／NVH 分工以及独立空间声源。当前证据更值得继续检验的是**主排气事件形态与传递如何随工况演变**；不应只通过增加固定机械模态、均匀噪声或更强同步调制来追求指标接近。也不能由本轮正误差证明实车缺乏点火同步结构：真实阶次和传递仍未识别。

本轮完成 120 组成功测量及独立数学核验，核对原生 144 个源码／契约文件、二进制、批准原音及 float32 主文件未变。完整数据与冻结清单分别在 `references/analysis/envelope_cycles_detrended_v1/verification.json` 和 `baselines/envelope_cycles_v1/manifest.json`。没有原生代码变化，因此不重复 CTest／设备测试。已有音色候选仍等待主观听评，本轮不宣称电子感已经改善。

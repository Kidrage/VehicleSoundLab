# 有限窗共同相位 V1

2026-11-13。**有限窗前向拟合能区分本轮已知信号中的共同相位曲率与慢幅度变化，但单声线独立相位变化仍造成偏差，整体未获资格。** 没有实录新拟合、怠速／加速DNA或C试听；行驶35%保持。

## 方法与模块

旧方法把长窗读到的平均相位近似为中心时刻相位，急变处有系统偏差。本轮直接拟合实波形通过同一有限窗之后的复数读数：

`x(u) = Σ A_k(u) [a_k cos(2πk(u+ε(u))) + b_k sin(2πk(u+ε(u)))]`

`ε`为共同相位修正；每阶`a/b`固定，`A`为正的慢变实幅度。不允许每阶任意时变复系数，否则任意共同相位都可被这些系数抵消。独立反例已构造两条相差约0.04主周期的相位，样本仍相同至1.44e−14，明确证明这种自由模型不可辨识。

| 离线模块 | 职责 |
|---|---|
| `tools/aperture_model_v1/basis.py` | 相位／幅度样条，固定起点自由度 |
| `forward.py` | 整条实波形的10周期Hann窗FFT，邻近格点及负频镜像自然保留 |
| `fit.py` | 常量声线系数、正幅度和共同相位联合求解；robust loss回调返回副本，避免SciPy原位缩放污染缓存 |
| `fixtures.py` | 独立解析高斯／正弦相位与幅度，不用逆模型样条造真值 |
| `checks.py` | 独立直接积分、中心差分、同一坐标处理原双声道及未拟合声线检查 |
| 两个命令 | `validate_aperture_model_v1.py`资格研究；`diagnose_aperture_model_v1.py`失败原因诊断 |

这仍是**已知稀疏拓扑、低频段原理研究**：40主周期、每周期128点，32.8Hz只是测试比例；1.4–7.4阶的14条声线参与拟合，10／15阶留出。10周期窗、0.25周期步进；相位0.5周期、幅度10周期结点，共194参数。不是14kHz完整提取器，也不证明实车周期／RPM。

## 实际结果

FFT与独立全局时间直接积分最大差2.87e−15；四类解析导数与中心差分相对误差最大4.63e−9，均通过。

预定条件：内部5–35周期共同相位误差p95≤0.0001周期、根音相对误差p95≤1%、留出声线功率差≤0.5dB、左右复相关差≤0.05，至少2条拟合及2条留出声线。相位误差只消除无关的常量原点；拟合过程不读取真值。原L/R应用同一个单调坐标，与同样插值下的真相位结果比较。

| 独立案例 | 相位误差p95／主周期 | 留出功率差dB | 门槛结果 |
|---|---:|---:|---|
| 恒定 | 0 | 0 | 通过 |
| 仅幅度慢变 | 0.00000431 | 0.07827 | 通过 |
| 共同相位弯曲 | 0.00003996 | 0.00115 | 通过 |
| 相位＋幅度 | 0.00003980 | 0.00232 | 通过 |
| 相位＋幅度＋噪声 | 0.00004357 | 0.00058 | 通过 |

| 只有一条声线，反例 | 不用于证明资格 | 8.24094 | 正确拒绝：1条拟合／0条留出支持 |

总7例，5／6正例过误差门槛，1反例正确拒绝。除恒定例外均达到80次求解上限，**不声称优化已收敛**；门槛接近不代替完整资格，更不是实车听感认可。

## 失败诊断

对原5阶独立变化案例，从实际保存参数继续同一目标、同一界限、同一窗300次；p95仅从0.000540310降至0.000540307周期，仍失败。代价从0.000784692225降至0.000784692089，仍达到迭代上限，因此不能证明全局最优。

另把**精确解析真相位**固定，仅求解相同声线系数／幅度，28次收敛，代价0.000790414309，反而高于带共同相位偏差的解。这说明当前“所有相位变化必须共同、每条声线仅可幅度变化”的目标允许用错误共同相位降低失配；增加迭代没有解决已观察到的偏差。真值仅用于诊断，不进入实际估计或资格。

`diagnose1`缺可选threadpoolctl导入，保留原失败源及记录；`diagnose2`改为可选依赖，完成续算及样条近似真相位比较。`diagnose3`改用精确解析真相位，消除样条近似混杂，并修图示的相位原点及内部误差纵轴。它只在模型／计划／实际参数／数组／代价／评估逐项精确一致后复用已结束的300次结果，没有重跑优化来挑更好的解。

# 怠速快速颗粒 C 监听 V1

前轮离线颗粒候选已有独立C实现和本地监听窗口。**这次保持冻结配方，不重新调音；音色听评仍待答，未替换主驾驶系统。**

运行[Launch-Fast-Idle-Study.cmd](../Launch-Fast-Idle-Study.cmd)，重新构建用[Build-Fast-Idle-Study.ps1](../Build-Fast-Idle-Study.ps1)。默认停止，点击“开始”持续生成；四个控制为主声线、细谱量、快速颗粒和监听电平。初值100%／100%／50%／−12dB，源保持固定音高，不能把它当成已标定的RPM模型。

## 模块边界

| 模块 | 职责 |
|---|---|
| `modal_source` | 原13条独立OSC；频率／相位／平均幅度不改 |
| `spectral_texture`／`partitioned_fir` | 原6组细谱滤波器与新随机激励，不改系数 |
| `modal_texture/envelope` | 复用原相关随机幅度核、方差归一插值、期望功率补偿 |
| **新增** `spectral_motion/profile,voice` | 参数绑定、频带到幅度组映射；在实际输出时钟调细节，左右共增益 |
| `experiments/idle_microtexture_v1/models,render` | F2宿主、固定音高、独立18ms量控制；不是驾驶状态机 |
| 同目录`ui.c`＋原`win_output` | 简洁Win32窗口与现有512帧Stereo传输 |

通用模块不含车型ID、原PCM／包络轨迹、房间或RPM时钟。映射0表示静态频带，1起表示共享幅度组，可多个频带用同一组；F2专用映射在实验宿主，选择1.2–14kHz四频带。`MtProfile`沿用原数值因子格式，这里的行表示幅度组，并非发动机阶次。

新谱形bank复制系数、声道比例与映射；幅度profile只读借用。分配、编译、预热、销毁与IO在非音频线程，设备停止并join之后才销毁。静音时声源／幅度RNG照常前进；粒度量0使用旧谱形累加算术，反复设置同一目标不重启斜坡。新文件`F2_fast_detail.mtexture`只有四维幅度因子和时间常数，旧主声线／细谱参数直接复用，没有复制成另一套调音资产。

## 已验证

6项独立工程测试通过，覆盖共享频带映射、静态频带、0量旧C精确一致、动态回0、同目标斜坡、非法输入不推进、谱形拥有和宿主量斜坡；其中4项是本次依赖的既有模块测试。无关双滤波器／双声道例先行，再核对F2全部三种子×0／50／100%，主声线／细节／混音共30条比较，最大误差`1.49011612e−8FS`，来自FLOAT量化；不能称跨Python／C所有文件字节相同。

1帧和479帧外部块的同一采样点颗粒控制输出逐字节一致，主声线不受这些颗粒控制影响；30秒持续生成的前12秒与短渲染一致。27609个实际240帧／5ms离线块最大3.3826ms，0次超预算；1帧契约测试有378次20.8微秒预算超出，保留FIR突发成本边界，不能据此称硬实时。

实际静音Stereo设备提交384123帧，主声线／细谱／颗粒量按明确采样点变化；设备输出与离线逐样本、源哈希一致：`4b4b55cfd6fe3050`。512帧块最慢2.0935ms，0队列耗尽／0超预算，监听峰0.09082FS。此为约8秒固定声源设备证据，不是完整驾驶、长期或7.1.4资格。

新Win32窗口已编译、启动并由进程确认响应。**人工点按／目视布局与听感尚未验证**，不把C核与设备验证当成UI验收。原[颗粒对照页](http://127.0.0.1:8789/references/analysis/idle_microtexture_v1/review2/index.html)仍可听，不重复提问。

旧600份C/H、67旧运行配置逐哈希保持；新增12份C/H，当前612份。未重复与此次新模块无依赖的旧61项驾驶回归；所有旧二进制、take和默认保持。冻结见`baselines/idle_microtexture_c_v1`，含精确源码、模型、5个exe、30条比较、设备录音与命令日志。

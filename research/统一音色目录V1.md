# 统一音色目录 V1

运行 `Launch-Voice-Catalog.cmd`，在同一个C驾驶窗口内选择已有配方。控制器、持续声源接口、分层监听、空间输出和自包含录放共用；目录装载与窗口会话独立维护。默认仍为原来的行驶35%＋细谱怠速候选，停止、未点火、房间0。

| 目录项 | 原有输入 | 范围 |
|---|---|---|
| 行驶35%＋细谱怠速候选 | A moving DNA／LF／moving_35＋F2 Ms／Mt／Sf | 工程组合；新联合起伏候选未接入 |
| 行驶35%完整配方 | 同一A moving DNA／LF／moving_35 | 固定行驶情境认可，不是全转速／负载已标定 |
| 驻车车外四锚点 | A stationary四档＋对应residual | 车外观察，与moving录音情境分别建模 |
| 高转车内双锚点 | E cabin两档＋对应residual | 高转局部，与车外分开 |
| 启动趋稳 | A start cabin settle＋startup detail／startup／catch | 既有启动工程配方，不是热怠速标定 |
| Warm Additive | 既有解析合成DNA | 工程示例，不是实车或用户Serum音色 |
| Hollow Spectrum | 既有解析合成DNA | 工程示例，不是实车或用户Serum音色 |

这是五个V10观察／配方情境与两个合成示例，不能据此声称五款或七款真实发动机音色完成。两项合成示例使用既有SCIFI驾驶策略，声学根频在工程4000RPM处对齐各自模型；V10各项沿用原映射，仍不是通过声学根频反推出真实RPM。

## 模块与生命周期

```mermaid
flowchart LR
  D[目录描述与既有参数文件] --> L[catalog_drive/models 非实时装载]
  L --> O[drive_catalog 拥有完整AtAssets与初始控制]
  O --> U[同一原生UI与session]
  U --> C[唯一驾驶器]
  C --> A[atlas_drive 既有生成核]
  A --> S[完整混音／分层监听／空间链]
  A --> T[原schema10自包含行程]
  T --> P[同一player 可单听回放]
```

`modules/drive_catalog`只负责目录身份、深拷贝只读资源和实际声层能力；`experiments/catalog_drive_v1/models.*`调用原有读取器组装配方；`session.*`管理原生主线程提交和回放返回。没有在音频回调里读取文件、分配资源或切换指针。原DSP／驾驶C文件均未改。

候选装载失败时当前音色保持。成功后UI先保留未保存行程、停止音频，再提交新配置、回到未点火，最后释放旧预设。录制和运行中的回放锁住音色菜单，分层监听仍可操作；正常监听时换音色也会先停止，不做跨预设热切换。

控件按当前实际配置启用。例如没有startup就不能调“启动机械声”，没有细谱怠速就不能调其起伏／细谱量。回放读取行程内嵌配置来显示能力，结束后驾驶编辑保持锁定；“开始／重新监听”恢复原实时预设及其控制。这样即使在V10窗口回放合成音色，也不会把合成音色的控制残留到V10实时配方中。

目录key和文字仅用于界面，不新增序列化字段。原schema10／32字段继续嵌入实际模型、驾驶profile、映射与初始控制；旧严格DSP身份保持。当前录音来源／配方文字不单独写入行程，不能从“行程内嵌音色”标签推断车型来源。

## 验证

七项均实际生成192123帧，经历点火、升速／带载、降速／收油、熄火与transport停止；不同块长的自包含回放逐样本一致。原装载输入与目录对象销毁后，行程仍独立运行。2／12声道的驾驶状态、声源哈希和六条干声总线一致；不要求空间渲染后的前L/R相同。

更关键的对照是用上一轮冻结的原播放器重放这七份新行程：完整WAV逐字节一致，音频和声源哈希均通过，DSP身份仍为`ac51d5ddbad3414b389ed58ce55188f35eee5aa0829860207e5dfed3dfc9bff3`。这证明目录没有修改实际生成算法，不证明这些情境或合成示例都已获得听感认可。

原生窗口207项自身控件／静音设备检查通过，覆盖全部七项、各辅助控件绑定、录制与分层回放，以及跨音色内嵌回放后恢复实时预设。每项设备录制64123帧，记录的断队列与超块预算均0；只是短测，不是长期硬实时验收。默认／回放／恢复三幅自身窗口图已目视检查，无独立鼠标操作验证。首次窗口检查发现录制期间音色菜单未锁定，修正后重跑通过；原失败源码和报告保留。

完整CTest结果、精确源码／既有参数、七组音轨与行程、旧播放器、全部命令和尝试见`drive_catalog_v1_summary.json`及本地`baselines/drive_catalog_v1`。旧627C/H仅UI文件调整，新增目录／宿主与验证代码；67份声音文件及原怠速参数保持。

最终65项CTest全部通过。七组新行程共1344861帧，冻结原播放器的完整WAV／声源与音频哈希均精确一致；637C/H＝626旧字节保持＋1份旧UI修改＋10新增。本轮未改声音模型或生成算法。

怠速“持续音符感”、完整带载加速／同RPM负载声纹、更多真实发动机拟合和实际7.1.4仍未完成。`idle_complex75_v1`保持待听，不在本轮晋级；接下来仍需按素材与人工听评推进声源／工况内容。

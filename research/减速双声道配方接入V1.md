# 减速双声道配方接入 V1

统一 C 窗口增加可选的“V10 · 减速车内声线＋双声道细节（试验）”。它使用上一轮已经提取并冻结的 E 参数，尚待听评。此次完成接入，未拟合新音色，也未把它自动绑定到收油／断油状态。怠速“持续合成器音符感”的独立候选仍在[原版／候选／F2原声页](http://127.0.0.1:8789/references/analysis/idle_complex75_v1/review1/index.html)待听，未移植或替换默认。

运行根目录 `Launch-Voice-Catalog.cmd`，从音色菜单选择新增项，再开始／点火。默认仍为原细谱怠速＋行驶35%。新项初始声学根频率为56.02318449591488Hz；界面约6722.78RPM来自工程约定 `root = RPM/120`，不是从视频测得的真实转速。细节支持在根频率比例0.90–1.10内淡入淡出，0.96–1.04为全量区；它不覆盖完整转速／负载。该配方没有独立低频层，低频滑条显示未配置，DNA本身仍含低频。

## 模块

| 文件／模块 | 职责 |
|---|---|
| `catalog_drive_v1/decel_models.*` | 非实时事务装载冻结的原始DNA、Rvs；构造35%功率撤出配方，无重拟合 |
| `drive_recipe/bank.c` | 在既有Rdt之外允许经过完整校验的Rvs；拒绝缺失、禁用、未知类型、根频率不匹配及无效稳定证书 |
| `drive_recipe/shape.c` | 原公式按下一采样的根频率／细节量撤出DNA功率；本轮未改 |
| `drive_resonance/voice.c` | 原持续双声道核，局部支持之外仍推进状态；本轮未改 |
| `drive_catalog`／`session` | 目录身份、参数深拷贝、停止后切换与回放后恢复实时 |
| `atlas_drive`／`atlas_take` | 原唯一驾驶器、分层、一次空间处理和自包含行程；本轮未改 |

撤出量为 `sqrt(1 − support² × detail_amount² × reduction)`；`reduction`在1.2–1.9kHz平滑过渡至0.35。细节为零或超出局部支持时恢复原DNA。Rvs沿用录音拟合的固定Hz双声道统计细节，不是逐次点火模型；也没有循环原PCM或新增房间。录音自身的车厢／麦克风特征可能保留在参数中，不能当作已分离的可剥离房间模型。

目录现在是七个V10观察／配方情境＋两个解析合成示例，**不是九款真实发动机**。旧八项索引、默认值、72份原音色参数和F2原配方保持；新增两份参数与源档案逐字节相同。

## 验证与兼容

专项检查涵盖独立解析功率撤出参考、平滑控制、局部支持进出、缺失／损坏拒绝、直接Rvs声核对照、静音持续推进及零细节恢复。九份192123帧实际导出检查同一驾驶器、2／12通道源／干声一致及拥有参数后的不同分块精确录放。完整测试、原生静音录放、旧八项PCM与播放器身份隔离的最终结果保存在[归档摘要](catalog_decel_v1_summary.json)。最终66项CTest、284项程序自身窗口检查通过；九次各64123帧静音录放无本轮记录的队列断流或块预算超限。八份旧WAV保持字节一致，九份新行程由新播放器完整重现，八份旧行程由冻结旧播放器重现；新旧交叉严格拒绝。五张窗口图已检查，未声称人工鼠标操作、长时实时保证或听评认可。这些检查不代表新音色获认可或物理7.1.4测试完成。

计划、修改前文件、每次构建／执行的确切源代码、参数、WAV、行程、日志及新播放器冻结在 `E:/VehicleSoundLab/baselines/catalog_decel_v1`。本次无新下载或远程推送。

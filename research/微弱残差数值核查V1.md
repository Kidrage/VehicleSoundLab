# 微弱残差数值核查 V1

**两份F3五挡模型保存的时间系数计算正确；上一轮替代计算路径的严格比值检查仍失败，但其差异可由已记录的数值扰动解释。** 本轮没有改变参数、音色或原1e-9门槛，没有把原审计改写成通过，也不把参数计算正确等同于音色或全驾驶状态验收。

前一轮完成了两个固定观察和12条C对照，属于实际进展。本轮按新固定计划先做已知小残差信号，再读取冻结样本；没有重新选窗或寻找更容易通过的音频。

## 结论和证据

1. 8组已知矩阵：64帧、8分音、0／3个统计分量、残差尺度1e-3／1e-6／1e-9／1e-12，加零分母、分母下限、正负截断4个原语控制。原存储公式与精确二进制有理数计算均在5e-15内；64次1e-6篡改均被拒绝。3分量且残差1e-9／1e-12时，即使已知输入也会使替代投影路径超过原1e-9门槛。
2. 用原提取／分解代码和完全相同的冻结原生样本重放，两份导出模型的SHA256与原模型完全相同；这项是确定性复现，**不是独立SVD实现**。
3. 对重放过程中实际使用的残差，以整数乘加精确计算全部576个时间系数，保存值最大误差2.22e-16；576次1e-6篡改均拒绝。使用独立Python `Fraction` 实现再次核对，未复用整数核。
4. 对原残差和三种替代残差，共1728对，精确分数验证了有限扰动界。原直接三角路径最大比值差约2.82e-6／1.39e-6；替代残差最大采样差仅约1.22e-14／1.10e-14FS，微弱分母放大了差异。同一FFT行只改PCA分数重建时，差异仅约1.74e-14／1.79e-13；因此本次实录的大差异主要来自直接解调／重建的数值差，不能都归因于PCA。

原1e-9检查仍保留为失败。新证据证明的是实际保存公式的计算及这几组记录数组的扰动范围，不是所有FFT／SVD实现的通用前向误差保证，也没有证明实录分解已完整恢复机械声。无需继续围绕这两段微弱比值换窗口、改门槛或制造新音色候选。

## 数值方法与模块

对残差序列`r`，原公式为：

```text
N = sum(r[t+1,c] * r[t,c])
D = sum(r[t,c]^2)
rho = clip(N / max(D, 1e-30), -0.95, 0.95)
```

`ratio_exact.py`把每个实际binary64数转换到共同的二进制整数网格；乘积与求和精确进行，最后一次转换回浮点。`ratio_trace.py`明确记录原分解算术，与独立检查分开。`audit_residual_ratio_numeric_v1.py`直接使用逐元素Fraction，核对原语、全部系数和扰动界。

对两个已记录序列A／B，令ε为每元素最大差、m为参与乘积数，可得`δN ≤ ε·(sum|A_next|+sum|A_prev|)+mε²`、`δD ≤ 2ε·sum|A_prev|+mε²`。因此除法后差异可用分母下界及截断的1-Lipschitz性质约束。所有这些运算均用精确分数完成。**这是依赖实际A／B的事后扰动界，不是放宽一个新的合格阈值。**

## 扩展音高前发现的接入限制

检查现有C装载器发现：`harmonics × base_hz × 1.1 ≤ 21600`。288分音时，模型文件的训练根频率上限约为**68.181818 Hz**。这不是驾驶器的运行转速上限；现有atlas能把已装入的低根频率模型继续变调，并在19.2–21.6 kHz渐隐分音。问题是更高根频率的新训练锚点无法装入。

只用已知合成参数调用现有原C导出程序：上限减1e-6接受并生成480帧；上限加1e-6及90 Hz均返回2，创建音频前拒绝。未读取新的高段实录，不能断言F3哪一段已越界。

现有独立Sound DNA振荡器没有随实际根频率进行的运行时带限，故不能直接放开旧装载保护。下一步应增加**明确选用的带限装载／合成接口**，复用原参数、统计层和唯一驾驶器；先用已知高阶纯音检查混叠、渐隐、块长与旧输出，再接更高音高的真实锚点。原安全装载接口、默认音色、旧录放身份和冻结播放器都需保留。不要为绕过该限制静默减少已认可分音或重复高段拟合搜索。

`limits1`最初把WAVE_FORMAT_EXTENSIBLE浮点WAV误当成普通format-tag3，接受路径已运行但文件头核对失败；`limits2`正确解析原有32-bit FLOAT子格式后，三项预定边界结果通过。两次执行与文件均保留，C程序、根频率和预期结果未改。

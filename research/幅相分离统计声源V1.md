# 幅相分离统计声源 V1

本轮已生成可听的 **OSC 统计声源候选**。它把幅度分布与相位变化分开表示，避免上一轮“纯相位输入也产生调幅”的串扰；保留同一幅度过程的固定相位／变化相位对照。当前仅离线研究，未替换运行 C、认可配方或默认声音。

试听：[单播放器对照](http://127.0.0.1:8789/references/analysis/radial_copula_v1/review1/index.html)。先比较同组、同一“生成1”的“原C DNA”和“新幅度 · 固定相位”；第三种相位变化版供诊断，左右关联还未做好。页面没有自动播放。

## 算法与模块

输入只用上一轮已冻结、独立核查的六个 F3 声纹系数，保留288分音、左右声道及原声学根频率。每个模型包含正幅度边际表、相位边际表、最多12个联合因子及逐特征残差。

| 模块 | 功能 |
|---|---|
| `tools/radial_copula_v1/quantiles.py` | 连续逆CDF查表；幅度始终非负，一次解析缩放精确保留每个分音／声道的平均平方幅度 |
| `profile.py` | 幅度和圆周相位分别编码；平秩正态分数、左右联合PCA＋对角残差、因子／残差AR系数 |
| `latent.py` | 新生成的高斯创新与AR状态；插值时逐因子归一化方差，不产生固定周期的边际能量起伏 |
| `render.py` | 固定声学音高的离线OSC，沿用分音数量与19.2–21.6kHz带限，固定相位／变化相位两种解码 |
| `observe.py` | 系数频带功率、完整有符号协方差、复数左右相干度及相邻观察的功率关联 |

幅度表为排序后的分音幅度，而非原时间序列。令 `u=Φ(g)`，对 `(i+0.5)/N` 处的幅度分位点连续插值，边缘恒定；再按解析 `E[A²]` 作一次缩放。它没有保留可回放的PCM、完整系数帧序列或原始时间顺序。

相位先在每个分音／声道的最大空角间隙处展开，避免跨±π时直接插值走长路，再单独查表。固定相位版仍使用原复数均值相位。相位表不是曲轴抖动或真实左右机械声源的辨识结果。

联合正态分数以12个主因子和独立对角残差近似，AR更新频率为 `4×root`。左右／幅相关联由这些联合因子表达，不是两组互不相关的随机数。插值时对每个AR因子除以 `sqrt((1−u)²+u²+2ρu(1−u))`，因此每个插值位置都保持标准正态边际；ρ沿用0.95上限。没有扫描分量数、强度、窗长或ρ寻找通过结果。

两种新版本的**幅度与随机序列完全相同**，仅相位解码不同。没有新增高频云、混响、扩宽器或独立驾驶时钟。

## 已验证的进展

七组已知控制：恒定、纯AM、纯PM、AM+PM、跨±π、左右反向AM和静音，全部通过。纯PM／跨界相位不会产生额外幅度变化，纯AM不会带来额外相位变化；静音为精确零。独立核查包括每个分位节点、分段高斯求积、平秩、AR滤波及直接OSC求和。恒定对照还与上一轮冻结原C比较。

六个 F3 模型各用3组、每组4096个扰动Sobol分布样本核查（不是独立录音验证）：

| 指标 | 结果 |
|---|---:|
| 48个高频带／左右坐标的功率CV误差L2：旧模型／新模型 | 2.19237／0.20330 |
| 相对旧表示的上述综合误差下降 | 90.73% |
| 各频带／左右平均功率最大偏差 | 0.00920 dB |
| 每分音／声道 `E[A²]` 独立积分相对误差 | 小于1.2e−15 |
| 连续幅度分位表 `E[A⁴]` 相对原离散观察误差范围 | −7.09%～+0.049% |
| QMC完整协方差独立核查误差／平均功率乘积 | 小于6.2e−17 |

90.73%只指**训练系数功率CV的统计误差**，不是音色真实度提高了91%。连续分位插值和低秩关联仍有偏差；例如第一组 early 的8–10kHz右声道CV约0.243，原观察约0.102，尚未完全恢复联合变化。所有有符号协方差均保存，没有把负方向裁成独立噪声预算。

## 仍未解决的相位／左右与时间问题

相位变化版的平均复数左右相干度误差约0.1674；相同新幅度、固定相位版约0.1180。24个观察坐标中18个变差。因此，**本版相位分支不作为空间改进或默认迁移**，只作诊断对照；纯AM／PM不串扰的数学通过不能替代这个真实素材检查。

两组中点8秒生成的相邻更新功率关联也低于原重叠Hann观察。保存完整时间关联，没有把静态分布接近说成时序完全正确。

后续优先改相位坐标：检验“共同相位＋左右相对相位”的表示，直接约束左右差值分布及其与幅度的联合关系；不靠随机扩宽或简单提高相位强度。随后再检验时间结构，不能只增加主成分或调ρ来挽救指标。固定相位幅度候选的听评独立待答，不以统计通过替代人耳。

## 试听内容与工程边界

两次五挡升速的中点分别以64.8044／64.0149 Hz生成，每组3种子、每种子原C／新幅度固定相位／新幅度变化相位，共18条8秒声音；另有2条原始短参考。统一0.5增益、首尾5 ms淡化，没有逐条响度补偿。原参考不循环，保留原音高变化；固定音高合成不是原视频的转速轨迹重放。

12条新合成均通过独立AR、逆CDF和直接正弦求和，FLOAT量化误差采用显式半ULP＋2e−10 FS界。第一中点变化相位版的37／1024分块PCM精确相同。单播放器20项元数据、静音播放、选择后暂停、快速选择竞态、窄屏与JS错误检查通过；桌面／手机截图和两张科学图已分别目视。

六个模型只是当前V10的六个局部观察，不能称为六种发动机。方法没有写死V10周期结构，其他发动机仍需各自素材和完整状态验证。继续保留 V6 的 DNA／BODY／DETAIL／EVENT／AUX、唯一驾驶器及独立空间层；未来7.1.4不能把本录音L/R当作物理左右气缸源直接布置。

本轮未加入实时C、UI参数录放或7.1.4渲染。现有670份C/H、82份参数、保护F2、C索引、认可moving35、默认、driver／owned／take／room均保持。此次Python离线查表算法没有21569性能实测，不能直接套用旧C的800MCPS估算。

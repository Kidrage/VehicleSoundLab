# 完整窗与前后文提取 V1

本轮验证了“全波形保留片段首尾、完整分析窗约束相对频谱”的提取方法。真实前后文能改善已知弱高频的中央目标，但完整288分音求解尚未通过数值门槛。没有生成或推广新音色，也没有修改实时 C。

## 方法与模块

原完整窗度量的高频统计受片段截断影响；本轮将这两类约束分开：

`J = ||Phi(q)-x||² / sigma² + ||W a F_supported(Phi(q)-x)||² + .001||D2 q||² + .000001||q||²`

第一项保留所有有限记录采样；第二项只使用完整4096点Hann窗，步长256。M个完整窗、N个采样时，`a=sqrt(N/(256M))`。原左右共享六频带、全局功率1e-8数学floor、节点、阶次和正则化强度保留；floor不代表测出的录音噪声。

| 文件 | 责任 |
|---|---|
| `tools/observer_supported_v1/metric.py` | 完整窗、频带权重、实际时间覆盖、伴随 |
| `tools/observer_supported_v1/fit.py` | 组合目标、原参数空间梯度、阶次时间块预条件与一次LSMR |
| `tools/observer_supported_v1/audit_oracle.py` | 独立SciPy帧、显式实矩阵、稠密解 |
| `tools/observer_supported_v1/full_oracle.py` | 完整规模标量OSC、节点伴随、直接载波积分与最优性界复核 |
| `tools/run_observer_*known_v1.py` | 固定实验、保存观测／解／执行源码；不进入音频回调 |

当前仍是归一化声学坐标：1024采样／周期，示意root64Hz。不是原生48kHz录音、实测RPM或驾驶状态覆盖。

## 新的耦合证据与下一步

完整已知问题有56448个实参数；所有声学数据行都是24578个波形采样的线性变换，数据零空间维度至少31870。新增频谱权重不会增加波形观测秩。正的ridge仍保证正则化目标有唯一最优解，这与物理声源可识别性不同。

中央单节点的576个实参数只作用于511个非零采样，至少有65个数据零方向。直接SVD及独立载波／FFT检查确认一个方向的加权数据范数约4.60e-15，而保存解沿此方向的惩罚导数为−0.000134393。没有应用这个方向修改解。这是跨分音耦合的具体证据，不声称它是全部求解失败或电子音色的唯一原因。

下一步按`research/observer_representer_v1_plan.json`验证同一目标的样本空间等价解：先小规模显式矩阵／原始与对偶证据，再同一完整已知问题；不盲加迭代、减少分音或降节点密度。完整数值门槛通过前，不开始六份实源新拟合。真实素材还必须有真实相邻录音和独立支持的相位坐标，不能零填充、反射或循环拟合轨迹。

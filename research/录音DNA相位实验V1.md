# 录音 DNA 与相位 · 实验 1

本轮针对“整体偏电子，先加强逐次燃烧与机械细节”中的主排气脉冲形状，检查真实参考能否提供可迁移的谐波相位，并把局部系数交给原有 C 振荡器试听。现有证据支持局部谐波快照，尚不支持跨转速的固定相位标定。V011 主声线、V016 原生程序和驾驶状态机均保留。

[打开简洁试听页](录音DNA相位试听V1.html)：三个窗口，每个两种相位。共六段 3 秒恒定音高音频，可保留时间切换。已批准的原录音补油片段另有手动参考入口，不与快照做同步或响度匹配。

## 来源与拟合坐标

只分析已批准 A：Performante 车外补油，源视频 238–248 秒。经 `references/segments_v1.json` 与 `tools/reference_segments.py` 校验来源和允许用途，双声道 float 主文件不变。B 为车内参考，本轮不用于车外相位拟合；无新增下载。

使用已冻结的 `rev_descent_v1` 下降谱线路径，明确保留路径名称、两种窗口长度和两种除数。路径频率除以 1 或 5 只是观察坐标候选，没有确定它的物理点火阶次，更没有换算为实测 RPM。用给定分段线性频率路径的精确积分建立扫频相位，Hann 加权联合最小二乘拟合余弦、正弦及 DC；最多 128 条谐波、8 kHz。128 ms 窗口中的相位零点统一放在窗口中心。

| 快照 | 源秒数 | 坐标基频 / Hz | 加权局部拟合误差 L / R，dB |
| --- | --- | --- | --- |
| 第一次补油，前窗口 | 238.204–238.332 | 58.6824 | −12.23 / −12.05 |
| 第一次补油，后窗口 | 238.846–238.974 | 33.9436 | −20.72 / −20.41 |
| 第二次补油，前窗口 | 240.924–241.052 | 52.9653 | −12.44 / −12.37 |

误差是局部确定性拟合误差，不能换成真实度、机械占比或缺失噪声比例。冻结快照丢弃了落转、周期变化和拟合残差。低转 208–211 秒的两条锚定路径没有贯通，未从中导出相位标定。

## 相位能否跨窗口复用

先用相邻三条谐波的二阶相位差，消除任意常量相位和按阶次线性变化的时间原点。前后拟合支持区间隔开至少 0.2 秒，不共享音频样本。原始 12 组检验均缺少至少三个共同强三元组，状态为“未测得”，不能据此称为不稳定。

为适应稀疏谐波，另建补充分析，原始方法、代码与结果均保留。补充规则在评分前固定：等间距三元组 `(k−d,k,k+d)`，全部 `d=1…16`，每条谐波幅度至少为该窗口同声道峰值的 3%，前后窗口均需满足。未来幅度只用于预先声明的筛选和权重，未来相位不参与选择；频率路径已知，这不是波形或驾驶状态预测。所有间距都留档，没有挑选最优间距。

12 组中仍有 10 组强三元组不足。第二次补油、除数 5 的 128／256 ms 两组可计算汇总比较，各声道仅 5–8 个重叠三元组；沿用过去相位形状的弦误差比零曲率基准高约 2.67–3.92 dB。重叠组合不是独立样本，两个窗口长度也不是独立实验。这没有显示当前坐标下的固定相位能稳定迁移，亦不能排除其他坐标、更好路径或局部动态模型的作用。常量与线性相位被刻意消除，也限制了此检验能够观察的变化。

## C 合成和模块边界

- `tools/phase_fingerprint.py`：扫频积分、局部复系数拟合、相邻相位检验和既有 `.dna` 导出。
- `tools/analyze_phase_fingerprint.py`：经目录校验的参考研究与三个快照；初始结果保留。
- `tools/analyze_spaced_phase.py`：独立的稀疏等间距补充检验。
- `experiments/observed_dna_v1/observation.c/.h`：每个麦克风观察声道各用一个原有 custom-DNA 实例。
- `experiments/observed_dna_v1/probe.c`：离线 float WAV 输出，与实时声卡和 UI 分离。
- `tools/render_observed_dna.py`、`observed_dna_page.html` 和复用的 `seekable_review_player_v1.js`：渲染、页面与播放控制分离。

链接冻结 V016 库，直接调用未改动的 `vsl_load_dna`、`vsl_dna_update`、`vsl_dna_tick`。48 kHz、种子 48271、固定原生 3000 RPM（对应导入基频），8 ms 系数平滑先预热 250 ms，再从两路共同相位零点输出 3 秒。没有运行时参考录音回放。

原生导入对每路做 `.36/sqrt(sum(amplitude²))` 归一化，另有最小能量下限。本诊断显式抵消该增益，恢复拟合幅度与录音左右电平比例；两路不是物理发动机缸列，不注入原生 V10 左右 bank。原生 Import DNA 界面仍是单个 DNA 导入；这次双观察声道的并行渲染只存在于离线诊断。

两种方式：保留拟合相位；或对左右同时减去每条左路谐波的相位。后者保持每条谐波的幅度和左右相对相位，改变周期脉冲形状。两版均保留完整局部复系数和 `.dna` 文件。没有加入随机噪声、失谐或新的机械增益。

六段试听共用固定 −6.0206 dB 和 5 ms 线性端点淡入淡出，无逐段归一化、压缩、去噪或高通。峰值最高约 0.828。原始 float 合成峰值允许超过 1，不做削波，只提供已留余量的 PCM24 给页面播放。另一个原录音手动参考沿用已有固定 −6.02 dB／5 ms 余弦端点版本，同样无高通；最初页面曾误写“28 Hz 高通”，已在冻结前改正，初始标签和证据留在 `initial_reference_label/`，音频没有变更。

## 验证与结论边界

无噪声解析扫频、相位原点不变性、左右交换与增益控制通过。C 的六段完整 float 输出与独立复指数求和最大差约 `5.98e−8`；1 帧与 257 帧调用的 WAV 逐字节相同。另从 C 输出重新拟合复系数，检查实际谐波幅相和左右关系。既有 DNA 管线检查通过：已知 220／440／660 Hz WAV → 拟合 DNA → 原生 C → WAV，支持中文路径。

实际无声浏览器播放检查覆盖六段载入、时间定位、播放状态保持、切窗口从零停止、参考与合成互斥播放、HTTP／本地文件入口、图像和手机宽度。它验证操作和解码，不代替听感。144 个原生源代码／测试／构建契约文件、原生二进制、V011 主声线和此前 27 个快照的清单身份均核对；此前所有历史快照内容没有重新全量审计。

目前不能把“真实录音导出的某个静态波形”当作完整发动机。OSC 能准确实现这些局部谐波系数；真实排气的跨工况相位、动态压力响应和独立机械来源仍需更可靠证据与听评。此实验不宣称已降低电子味，不替换尚待听评的燃烧／机械、谱形或相位候选。

当前听评重点是：在相同谐波能量下，保留局部拟合相位是否更接近所需的颗粒与排气冲击。如果只改变尖锐度而没有接近目标，就不能仅凭局部拟合较好而并入主声线。现有机械层保持独立，继续由已有分层与调参入口评估。

# V018：实时燃烧／结构响应形状

本轮将已经冻结的 `response_shape_v1` C 候选接入原生程序，支持驾驶中调参、保存预设、录制和回放。它是默认关闭的实验控件，尚未获得主观听感认可。用户认可的 V011 连贯排气声线继续保留。

## 操作

双击工作区 `Launch-current.cmd` 或 `Launch-response-shape.cmd`。按 Start 开始监听，在 Sound detail 底部：

1. 保持 Pure OSC 关闭，使用工厂 V10。
2. 将 Combustion texture 和／或 Mechanical transfer 调到需要的强度；可先各65%。它们分别启用逐次压力与结构细节。
3. 比较 Response shape 的0／50／100%。它改变上面两项的响应形状；上面两项都为0时没有效果。
4. 用相同转速／负载比较，或使用 New take 录制实际驾驶与调参，Save take／Play take 回放。

新参数默认0，旧预设没有该字段时也为0。它使用18ms逐样本平滑；调回0会保留已有尾音，不能要求即时回到旧波形。新会话从0开始则与V017保持完整输出一致。

旧版本入口：`Launch-v017.cmd`、`Launch-character.cmd`（V016）、`Launch.cmd`（V015）。旧 take 用匹配版本回放。V018 文件是 DSP0.18.0／VSLTAKE3／35个显式语义字段，双向拒绝与V017混用，不修改历史文件。

## 算法与维护

| 文件 | 职责 |
|---|---|
| `src/core/response_kernel.c/.h` | 三组固定阻尼正弦、逐样本推进、事件冲击和孤立脉冲能量补偿 |
| `src/core/response_shape.c/.h` | 接收已有许可燃烧事件，适配压力缸列／结构响应及右缸列延时 |
| `src/core/response_types.h` | 每个引擎独立的响应状态、历史与计数器 |
| `src/profiles/response_shape.c/.h` | 衰减比例、负载／转速／逐次事件映射，独立工程配方 |
| `src/core/character.c` | 原有事件调度与随机数；同时驱动旧响应与新候选 |
| `src/session/parameters.h`、`src/io/take_file.c` | 显式字段、严格版本协议；共用原有录制／重建路径 |
| `src/app/tuning.c`、`preset.c` | 单一新增旋钮及预设保存；只更新被操作的参数 |

保持原共振频率，衰减族为旧配方的0.55／1／1.7倍。每次事件按下式选择旧响应与较短／较长响应的混合比例：

`q = amount × [0.55 × (2 pull − 1) + 0.20 × (2 speed − 1) + 0.25 × event_shape]`

其中speed是1200～8000 RPM映射至0～1的裁剪值，pull来自现有工况包络。正值偏短，负值偏长；旋钮100%表示完整映射量，不是始终选择最短响应，也不表示最真实。孤立脉冲的连续平方积分补偿用于控制形状变化带来的能量偏移；它不保证重叠冲击／完整混音响度恒定，也不是热力学能量。

固定响应族并行保留已有拖尾，不在旧振铃上直接重写阻尼。沿用同一曲轴事件、燃烧许可、事件强度与独立随机流；不增加事件或重新扰动驾驶。停机／断油阻止新燃烧冲击，旋转机械与已有振铃仍按原模型继续。已有显式机械增益增强保持不变，本次只替换新增模态响应。Pure OSC、其他模板和导入DNA的旁路规则保留。

V6上游方法仍是驾驶→状态→独立声层／事件→空间；本次没有把Max图塞进一个C文件。上游文本快照固定在 `ac2b37d8639027d79934a2023cf8d1d37d3b2f96`，补充文件 `research/upstream_v6_response/v10_powertrain.gendsp` 的SHA256为 `28be732d5d4c9497140562c89cd53cb3af5a82685ecd2945808d263767dd0584`。上游含若干非整数频比的独立振荡器，并不能作为实测机械FRF使用。

- 实际带调参录制的stereo／7.1.4：十个独立声源逐字节一致，完整驾驶日志一致；stereo与原生离线回放WAV一致。实际扬声器阵列听评仍未完成。

## 听感与证据边界

本次是将候选变成可实际操控的原生功能，没有新增素材下载或物理标定。已有A／B是排气、机械、话筒与空间混合后的录音，不能由此标注这些阻尼为实测Lamborghini参数，也不能把L／R录音直接当物理缸列。

完整混音的候选变化较小。它适合检验“逐次响应形状是否有帮助”，不能由频谱差、可重建或测试通过推出更真实。前一轮燃烧／机械两层的主观比较仍待反馈；此前候选没有被默认启用。主声线的电子感、按RPM×负载标定和实际7.1.4听评均未完成，整体目标继续进行。

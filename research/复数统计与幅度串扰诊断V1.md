# 复数统计与幅度串扰诊断 V1

本轮发现了一项可复现的声纹表示失配：**对复数系数拟合高斯分布，再取模长，不能保证保留录音的幅度变化。只有相位变化的恒幅输入也会产生额外调幅。** 六个 F3 局部声纹的系数观察也出现明显功率起伏失配。下一步优先验证幅度／相位分开表示，暂不继续添加独立高频层。

这是生成方法的诊断，不是新音色的听感验收，也没有证明“电子感全部由此造成”。当前运行 C、认可行驶35%配方、默认声音及独立待听 F2／F3 均保持。

## 机制与边界

原 `sound_dna/statistics.py` 保存复数系数 Re／Im 的均值、低秩协方差和逐分音残差；`sound_dna/texture.c` 生成相关高斯状态；`dna_atlas/voice.c::magnitude()` 取 `hypot(re,im)`，配固定的平均相位，驱动原 OSC。

例如 `z=A·exp(±iδ)`，输入幅度恒为 A。具有同样总体均值／协方差的高斯变量，在旋转坐标中是 `A·cosδ + i·A·sinδ·G`。其模长不恒定。δ=0.5 rad 时，系数功率的变异系数 CV=`std(power)/mean(power)` 为 `sqrt(2)·sin²δ≈0.325`，而真实输入为零。该例并不依赖低秩截断。

保留三个不同层次：

- 原始系数行的总体经验矩，分母 N。
- 完整总体协方差下的高斯矩，不经过12分量截断；以及原模型检查点矩，模型协方差分母 N−1。
- 原模型线性插值时的分布矩。按 `νρ(u)=3/(2+ρ)·[(1−u)²+u²+2ρu(1−u)]` 积分，同时保留条件均值起伏项。均匀 u 是分布诊断，不是实际 C 分数序列或时间协方差证明。

这里的频带功率是 `Σ|z_h,c|²/2`：不包含短时波形窗的泄漏、谐波间拍频和相位演化，不能直接称为原生录音频带功率，更不能解释成物理噪声份额。

## 已知输入和原 C

固定64行、288分音、最多12统计分量；四条有效分音为64／110／140／190阶，根频率64 Hz。分别构造恒定、纯AM、纯PM和AM+PM，幅度深度0.25、相位±0.5 rad；没有扫参数挑结果。

全部使用原 `factorize()`、原模型导出器和冻结原 `local_atlas_export.exe`／`SaVoice`。先重放原576000帧解析样例，WAV字节精确；再运行四组×三种子、各4秒。PM组另作37／512分块，WAV字节精确。

| 纯PM恒幅控制 | 结果 |
|---|---:|
| 输入系数功率 CV | 约0 |
| 完整总体协方差高斯 CV | 0.325055 |
| 原模型＋均匀插值相位 CV | 0.340574 |
| 原C后三秒四个高频带／左右／三种子的去趋势标准差 | 0.4387–0.4535 dB |

原C恒定对照的相应标准差低于4e−9 dB。系数分布矩与有限波形带观察是两类量，不能把0.3406直接换算成0.45 dB。

## 六个 F3 冻结声纹

读取两次五挡观察的 early／mid／late，共六个原有锚点。**不重估时钟、不改窗、不改旧参数。** 用原 native FLOAT、保存的 source_seconds 坐标、原截止频率及原采样器重建训练时的 double 波形；转FLOAT后与原 normalized.wav 全部精确相同。

240行系数的全部138240个复数值经显式DFT核查，最大误差1.995e−14；独立直接卷积重建与原FFT卷积重建最大差1.333e−15 FS。原模型所有逐分音4×4协方差也回查，最大差9.715e−17。

| 四个高频带×左右，共48坐标 | 系数功率 CV 范围 |
|---|---:|
| 原始系数经验观察 | 0.1020–0.3997 |
| 完整总体协方差高斯重建 | 0.4175–0.7352 |
| 原模型＋均匀插值相位 | 0.4228–0.7386 |
| 恒定原RMS幅度、只保留观察相位的反事实，经原统计模型 | 0.3766–0.7251 |

完整总体协方差高斯的 CV 在48／48坐标均高于原始观察，为对应观察的1.40–4.46倍。因此，这项失配不需要依赖 N−1 或低秩截断才出现。检查点与均匀插值的CV差仅约0.000040–0.000142，**对这些分布矩而言**，单改插值不足以消除失配；这不是实际有限时序的因果分解。

另做保留幅度、固定相位的反事实，其原模型CV范围0.1534–0.3704，较接近原观察，但仍有偏差。这不是音色候选，也不能作为复活此前被否决的 A `harmonic_magnitude50/100` 的理由。

保留所有有符号协方差差值和负特征方向，不把“原观察−模型”裁成正定噪声预算。上述反事实不可相加，也不是原声中幅度／相位的物理贡献率。这些是短训练孔径的观察，没有独立录音的泛化保证。

## 工程优化路线

1. 保留原OSC／锚点库和唯一驾驶器；把统计声纹的**正幅度、相位运动、左右联合关系**分开参数化，避免相位方差自动变成幅度方差。
2. 新幅度模型必须同时检验平均能量、功率分布、频带／左右联合矩和时间变化。不能仅把 Re／Im 改成幅度高斯，或只消除抖动导致声音僵硬。
3. 相位模型先用已知AM／PM控制证明不会互相串扰，再核对原素材。录音相位包含有限窗、干涉和其他声源，不自动解释成曲轴抖动。
4. 通过后才做独立离线听音候选，使用同一原始声线／增益／随机种子对照，不盲扫强度；听感认可后再移植模块化 C、接原驾驶链。当前不替换默认。
5. 沿用 V6 的 DNA／BODY／DETAIL／EVENT／AUX。声源统计保留 L/R，事件由同一驾驶状态机触发；空间／IR继续在独立层，未来7.1.4路由不混进声纹拟合。本轮没有增加房间或扩宽器。

其他发动机、完整驾驶状态标定及物理7.1.4验证仍未完成，完整目标保持进行中。

## 复核与留痕

模块：`tools/coefficient_geometry_v1/fixtures.py` 管已知输入／反事实，`moments.py` 管经验与高斯二次型矩；运行、独立审计、绘图及打包分离。计划：`research/coefficient_geometry_v1_plan.json`。

独立审计用观察空间Gram核查完整高斯矩，用插值协方差的多项式积分核查三点求积，并单独核查 C 随机状态／直接振荡器求和。12条C稀疏最大误差7.194e−9 FS，保持原 `0.5001 float32 ULP+2e−9 FS` 门槛。所有弱频带另加平均功率归一化核查，最大误差：已知2.656e−15、真实1.830e−15（上限2e−9），不是只靠FS单位的绝对容差通过。

`known_audit1` 在对近空频带重新FFT后取对数，协方差比较失败（最大差5.377e−9）。`known_audit2` 先独立核对Welch功率，再对已核查的原矩阵作标量log和协方差；保留原数据／全部门槛。`known_audit3`／`real_audit2` 额外加强弱频带的无量纲检查。所有失败、通过及准确执行脚本均保留。没有重跑未改的68项CTest。

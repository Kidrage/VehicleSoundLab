# 短压力响应的采样核查 V1

当前逐次压力层在 48 kHz 下存在可测的超带宽折叠。受控测试中，完整交流频带的误差约比理想带限压力响应低 37–38 dB；16 kHz 下约低 21–22 dB。C 递推与定义的连续响应一致，这个差异来自短衰减响应本身并非带限，不能直接称为计算错误或整体电子感的主因。V017 原生程序和音色保持冻结。

本次没有新增音色候选或试听入口。主观方向继续通过已有燃烧／机械调参器确定，避免以单位模块的误差数字直接调整整套声线。

## 条件与比较对象

链接冻结 V017 的实际 `pressure_texture.c` 和 modal 库。从 C 导出 1050／2900／6100 Hz 的频率、1.4／0.65／0.32 ms 衰减、权重，以及十缸点火角和 bank 分配；没有另写一份手工参数表。事件强度保留当前固定缸间系数，随机形状为零，逐次强度恒定。三个工程转速 1200／4000／8000 RPM，五个采样率 16／44.1／48／96／192 kHz，共 15 组。

这不是整台发动机重放：没有动态驾驶、音量包络、随机调制、主 DNA、机械层、短 IR、master 或空间处理。右 bank 的 0.38 ms 延迟特意归零，隔离采样误差；左右两路仍保持各自的点火几何和事件权重。先预热 0.6 秒，再观察 0.6 秒；每个观察区间包含整数个模型周期。没有新下载或处理真实参考素材。

定义的单模态响应为 `h(t)=weight × exp(−t/decay) × sin(2πf0t)`，t≥0。用所有过去周期响应的几何级数直接求连续稳态值，与 C 的实际 float WAV 逐样本核对。再计算同一个连续系统的谐波系数，只保留奈奎斯特频率以内的分量，构造理想带限版本。两者差值包含超出奈奎斯特的谐波折回；不会把原本存在的直流分量误算为交流误差。

理想硬截频参考是非因果的诊断对象，不是建议直接装入实时程序的滤波器。C 在精确奈奎斯特处的实数成分按正负频率合并。所选采样起点与点火位置固定，不代表所有采样相位下的最坏值。

## 结果

下表是 8000 工程 RPM、左 bank 的误差功率／理想带限响应功率，单位 dB；越负仅表示这个特定采样比较的差异较小。

| 采样率 | 全交流频带 | 3–8 kHz |
| --- | ---: | ---: |
| 16 kHz | −21.77 | −7.97 |
| 44.1 kHz | −41.30 | −36.20 |
| 48 kHz | −37.79 | −31.44 |
| 96 kHz | −46.85 | −43.71 |
| 192 kHz | −55.88 | −55.81 |

3–8 kHz 使用两版在同一频带内的功率作分母；它不能与全频数字直接当作误差能量大小比较。16 kHz 的频带上界正好是奈奎斯特，此处结果尤其不能用于宣称原生 48 kHz 有同等严重问题。

44.1 kHz 不是每个场景都比 48 kHz 差。别名分量会随采样网格、点火位置及相干叠加改变：1200 RPM、44.1 kHz 的左右结果分别约 −36.10／−43.76 dB，而 48 kHz 左右均约 −37.22 dB。不能用这 15 组推导所有转速和相位下的单调排序、最坏界限或听感排名。

![受控压力层的采样误差](../renders/pressure_sampling_v1/pressure_sampling.png)

实际原生监听固定使用 48 kHz。这个实验没有测完整混音的误差，不能把压力层的差异直接套到整车声音，也没有判断用户是否能听出差别。更高采样率的单位模块结果不能单独证明实时过采样值得增加 CPU 和滤波延迟。

## 独立验证与后续约束

15 组 C 输出与闭式连续响应的最大误差小于 2e−9。另一种实现把所有已发生事件逐个相加，在每组 257 个分散采样点复核，不使用几何级数。理想版本的若干谐波再通过对连续冲激响应做数值傅里叶积分核对，不复用解析传递函数公式。交流误差同时由 FFT／Parseval 和时域方差核对；保存理想 WAV 的 float32 舍入另用明确界限检查。已知超带宽正弦的折叠、相同输入的零误差，以及增益、DC 偏置和声道交换控制通过。

此外，单个衰减正弦的积分为正，当前受控压力序列本来就含 DC。8000 RPM 时理想左右均值约 0.001895／0.001899，采用单位 voice／DNA 控制；这不是实际完整输出的 DC，也不是实车静态压力。分析把它单列，不能靠 DC 增大分母而宣称交流误差很小。是否在未来压力声源或监听链增加低频阻断，需要连同相位和低频声线评估。

初次无限区间加权积分漏掉了窄响应，返回接近零和很小的误差估计，却未通过谐波复系数核对。失败方法与可复现用例保留于 `initial_infinite_quadrature/`；最终积分截断在最大衰减时间的 40 倍，遗漏尾部另有解析上界。积分器自己的误差估计没有当作严格界限。

后续若改压力采样方法，应分别检查：带内谱形与相位、额外延迟、事件时间和 RNG、计算开销，以及实际混音中的可闻贡献。不能只以减少单位模块误差为由覆盖已认可的主排气方向。当前不改主程序采样率，也不叠加另一套任意模态配方。

模块在 `experiments/pressure_sampling_v1/`、`tools/analyze_pressure_sampling.py` 和 `tools/verify_pressure_sampling.py`；数据及输入哈希在 `renders/pressure_sampling_v1/`，冻结于 `baselines/pressure_sampling_v1/`。核对 V017 原生源／测试／构建契约和二进制未变，保存此前 29 个快照清单的身份。本轮没有原生 DSP／UI 修改，因此不重复设备和全部 CTest；使用并核对 V017 已冻结的 19 项测试及设备证据。

# 完整声源算子与数值限制 V1

这轮把上次的小型约束思路推进到完整声源算子：**288阶、73节点、立体声、84,096个实未知量均已运行，并独立检查全部正向输出和伴随系数。** 尚未实现可用于真实素材的约束求解器，也没有新音频或C音色替换。

## 已实现的模块

| 模块 | 作用 |
| --- | --- |
| `source.py` | 完整复包络OSC声源、实向量展开、声源伴随；复用原FFT合成，不构建大矩阵 |
| `observation.py` | 明确的4096点Hann／256步长／全部2049频格观察器及实线性伴随 |
| `prior.py` | 原节点曲率先验及逆运算，只保存73节点轴上的小矩阵 |
| `system.py` | 完整上下文目标／梯度、目标七分组、原全部17项指标 |
| `oracle.py` | 不引用上述新实现的独立标量／稠密核查路径 |

模块位于`tools/constrained_source_operator_v1`。权重、幅度和波形尺度由调用者明确传入、复制持有，处理时不会重新估计。原准入仍是**目标波形＋六频带**，完整波形、上下文频带及三个区域的诊断也保留，未偷偷改成新门槛。

## 已执行的结果与未通过部分

四个小型案例保留完整8193样本、4096分析窗、全部频格和左右声道，另外独立构建每一行稠密矩阵。第五个案例使用完整18430样本／73节点／288阶的共同幅相变化、左右差异和弱高频，没有缩阶替代。

完整规模案例的1,393,798个输出／系数／指标元素检查通过，最大缩放差约`2.615e-13`。但**整个方法仍未通过数值准入**：穷尽检查保留19项超出原`2e-11`检查门槛的结果，集中在小案例的极弱频带稠密重建及近抵消梯度，最大约`3.260e-8`。随机伴随点积通过，不能代替这些失败。

在一个失败案例中，时间域伴随梯度峰值约`1.205e7`，投影后的系数梯度峰值仅约`67.7`，对累加和舍入非常敏感。`known2`尝试更宽类型，但本机`float64`和`longdouble`的显式尾数位都为52，**没有获得额外精度**。不能把类型名当成精度保证，也不能据这些差异判断电子感来源。

首轮`known1/known_audit1`失败、第二轮`known2/known_audit2`失败均保留。首次穷尽检查`known_all_audit2`还发现报告中的窗数假设错误：57是原目标节点数，完整上下文实际有56个受支持频谱窗，目标40个窗；`known_all_audit3`按样本数／窗长／步长重新计算后完成全部检查，19项数值失败保持。当前首次失败即停止的审核入口也已修正窗数计算；本轮完整结果来自独立穷尽入口，不改写旧执行记录。

## 资源含义

完整规模若显式保存完整实数据矩阵，估算约333.6 GB（310.7 GiB）。本次矩阵自由路径实际运行，没有分配该矩阵或真实素材因子。该已知算子案例记录的累计工作集峰值约162 MB；它只是本次进程观测，**不是完整约束求解器的峰值保证或实时算力结论**。ADI仍按800 MCPS规划／900分配，未经硬件测量。

## 下一步

先针对上述失败做数值误差预算：分开声源插值／有限精度FFT／稠密列构造／抵消累加，保留每项绝对误差和条件数信息；需要更高精度时使用真正可核查的补偿或多精度参考，不再依赖本机`longdouble`。原检查失败继续保留，不通过放宽频带或删掉弱分音获得准入。随后才能核验矩阵自由约束求解器的收敛和资源，再单独登记真实素材实验。

这一步提供了完整算子的实现和具体数值反例，尚不证明新的音色、持续统计或自然度。原C1最高带`0.110128276 > 0.02`、统计准入false及认可声音保持；五层、多发动机、全工况、唯一驾驶控制和独立未来7.1.4目标继续。

# 多谱线声学坐标 V1

2026-11-13。**新增离线多谱线提取方法，15个正例／3个反例的已知信号验证通过；原E固定片段的粗轨迹恢复，但相位一致性仍失败。没有新怠速模型、C音色或听感验收。**

## 方法与模块

| 文件 | 职责 |
|---|---|
| `tools/multicarrier_clock_v1/coarse.py` | 在原80ms观察中，用至少3条不同实测谱线联合选择声学根音；连续性路径、保留原格点测量、8Hz零相位平滑，并把超出测量支持的点约束回实测范围 |
| `tools/multicarrier_clock_v1/phase.py` | 同一原始L声道估计公共相位；全段校准各谱线固定相位，按一致性选择依据；原始L/R使用同一时间坐标，不独立对齐左右 |
| `tools/multicarrier_clock_v1/fixtures.py` | 独立构造已知相位／频率和左右差异的测试信号，不调用估计器生成真值 |
| `tools/validate_multicarrier_clock_v1.py` | 同时核对音高、相位映射后的高频功率及复数左右相关，不用一个音高误差替代音色保真 |
| `tools/fit_multicarrier_source_v1.py` | 只在已知测试全部通过后评估原E固定区间；控制输入、相位／留出门槛及已有参数导出／C探针调用。此次因相位失败，没有执行参数导出或C生成分支 |

粗音高不能跨缺失观测补出一条“实测轨迹”；平滑前后都需要当帧实测谱线支持。它不是ECU转速。当前15–80Hz范围也是研究参数，不覆盖所有真实发动机周期。

相位分析用四周期窗，候选依据为2／3／5／7／15阶；其他阶次保留作独立检查，包括10／20。固定做三轮校正，每轮从原始双声道重新取样，不对上轮重采样音频层层加工，不添加合成噪声、房间或补高频。未通过的泛化时钟研究及旧播放器保持。

## 为什么同时检查高频

本轮已知干扰测试再次显示：音高误差小于1%，高频功率仍可能损失数dB。一个声学周期中极小的时间误差，在高阶谐波上会变成较大的相位误差；用这个坐标平均声纹，会把本来存在的高频抹掉。这里证明的是测试信号中的风险机制，**未证明它是既有实录／试听问题的唯一或主导原因**。

改进包括：多线共识、抑制粗轨迹引入的快抖动、全段固定相位校准、优先采用彼此一致且离局部干扰较远的谱线，以及从原始音频反复校正残留偏差。保留原高频门槛，不通过增益补偿掩盖损失。

## 验证与原E结果

正例包含低／高根音稳态与慢波动、单线短暂缺失、AM旁带、2／3／5阶附近强干扰、2／3／5阶相位扰动、左右0.7ms延迟、缓升转和0.38秒内25→70Hz折线升转。反例为单载波、全部载波中断及纯噪声，均不得得到可用模型。

固定门槛：音高相对误差p95≤1%，各频带／左右功率误差≤0.5dB，复数左右相关误差≤0.05，至少2条未参与相位拟合的谱线有足够支持和一致性。所有18项在`validate9`通过；具体最大值及各项结果见汇总JSON和图。它仍只验证这组已知信号，不代表任意实车、快速启动或驾驶音色都已解决。

随后仅评估原E5.2–7.8秒、初始32.8Hz，未换区间／窗长／参考寻找通过。粗轨迹现在是`measured_consensus`，相位阶段为`source_phase_rejected`，没有前后半段声纹通过、参数导出或新声音版本。约33Hz的主谱线间距未必就是完整发动机周期；也需排查背景混合和录音传递，不能直接用它标定怠速RPM。

下一步先做失败原因诊断：保留当前坐标，检查低阶主梳状谱与更细旁带是否属于同一周期、哪些谱线有持续相位依据。不对这段重新裁窗／换参考／扫窗口找到绿色结果；新的周期识别方法先用独立已知信号验证。真实怠速／中低转带载／同RPM负载声纹仍待完成。

## 留痕

`validate1`因测试初值为整数导致数组类型错误中断，源码和报告保留；`validate2`完整运行后暴露均值受污染的问题；`validate3`中位数改善部分情况，低阶邻线泄漏仍失败；`validate4/5`四周期／全段校准未独立解决高频损失；`validate6`固定迭代仍有干扰反例；`validate7/8`平滑改善抖动但约束不当拒绝快速升转，更多迭代也会放大测量误差；`validate9`扩展共同相位依据、约束平滑到实测支持后通过。未删除失败或调低误差标准。

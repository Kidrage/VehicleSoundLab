# 主排气相位成形实验 V1

本轮将排气波形的相位关系独立做成可试听的 C 实验。它能在保持孤立声源稳态幅度响应的条件下改变压力波形的尖峰与拖尾，但没有证据证明这就能消除电子感。V016 的原生程序、燃烧／机械配方、驾驶状态机和 V011 连续排气系数均保持冻结。新增方案尚未获得用户听感认可。

试听：[主排气相位成形试听 V1](主排气相位成形试听V1.html)。本地服务地址为 `http://127.0.0.1:8789/research/主排气相位成形试听V1.html`。建议先比较 4000／8000 RPM 完整混音，再听对应的两排气源独奏；最后听补油、收油及驾驶过程。四个按钮保留播放位置。

## 为什么做这一轮

用户已认可 V011 的连续性和总体方向，最新要求为“整体都偏电子：先加强逐次燃烧与机械细节”。V016 已将逐次压力与机械结构两层作为默认关闭的独立旋钮接入原生程序。上一轮[效用核查](燃烧机械细节效用核查V1.md)发现：它们确实改变了波形，高转速部分却仍然有很强的循环可预测性。因此，继续加大相同阻尼正弦层的电平，不能自动解决主排气的合成感。

现有主排气**已经**具有固定 Hz 包络、随转速移动的阶次、工况谱形、两缸列点火几何、缸列延时和共享燃烧变化。不能把问题归因于“原模型没有转速相关频谱”。本轮只考察另一项可分离因素：声音经过具有频率相关相位的因果路径后，压力波形是否更适合目标声线。

全通不会自行产生新的随机逐次差异，也不会把固定重复的源变成真实燃烧。现有工程声源和声学参数仍未完成目标车识别。这个实验只能决定相位成形是否值得继续研究；若听感无明显收益，应回到随负载、转速和逐次燃烧变化的主压力波形，而不是靠叠加更多相同模态推动版本。

## 信号链与参数

独立源码位于 `experiments/exhaust_phase_v1/`，使用可移植 C11：

| 文件 | 职责 |
|---|---|
| `allpass.c/.h` | 二阶因果全通，转置直接 II 型，逐实例状态 |
| `profile.c/.h` | 固定频率、Q 和延时配方 |
| `transfer.c/.h` | 两排气源路径、旁路资格、历史清空 |
| `probe.c` | 冻结驾驶 take 重建、float32 混音／分轨、冲激与 7.1.4 元数据导出 |
| `checks.c` | 能量／衰减、状态独立性、布局与旁路契约 |
| `CMakeLists.txt` | 从冻结 V016 生成带显式实例参数的调度副本，链接其原有核心库 |

处理位置为原有排气／高阶／泵气／细节合成之后、DNA 驱动的短 IR 返回之前。左右两个排气源应用**同一个传递函数**，各有独立历史，原来的缸列相对时序保留。这不是左右去相关或声场加宽方案。分轨的左右是两个物理源对象，不是监听耳朵位置；完整 stereo 混音再经过已有空间模块。

| 选项 | 配方 |
|---|---|
| 原声基线 | 完全旁路 |
| 只延时 1 ms | 两源共同延时 1 ms；48 kHz 下为 48 samples |
| 相位色散 Q 0.7 | 串联 260、1250、3100 Hz 三个二阶全通，各 Q=0.7 |
| 相位色散 Q 1.4 | 相同中心频率，各 Q=1.4 |

中心频率借用已有 V10 工程包络位置；Q、延时和模型均是探索设定，未由兰博基尼歧管、排气压力或传递函数测量得到。固定 1 ms 只是延时对照，并不在各频段匹配两种色散的群延时。工厂 V10 之外、导入 DNA 和 Pure OSC 均旁路；切换资格时清空响应历史。该页面固定配置，不提供运行中切换过滤器的原生控件，也未宣称可无缝动态调 Q。

## 对照输入与导出

使用 V016 已保存的 schema2 驾驶 take，种子 48271。七组输入为 1200／4000／8000 RPM、空挡补油、收油恢复、30 秒运动自动挡，以及燃烧／机械各 65% 的 8000 RPM。每组四版从相同 frame-zero 状态重建；逐帧控制事件不变。另有低中高转速的两源独奏，共 40 个 PCM24 比较文件。

每组四版使用同一固定增益，保留实际电平差异，不逐版归一化；浮点主文件和十源分轨保留原电平。完整混音包含原有非线性输出保护，本批峰值均低于 0.95，未触发削波。没有增加噪声、额外失真、额外 OSC 或参考录音播放。

批准的 A 车外片段 208–211 秒、238–248 秒供手动参考，经 `reference_segments.py` 核对来源和 raw／float 哈希。处理仅为固定 0.5 增益（−6.0206 dB）、5 ms 余弦端点淡化和 PCM24 量化；未高通、降噪、归一化或合并声道。参考与合成的转速、踏板、负载、录音链和增益不匹配，不能据此计算真实度百分比。

## 验证结果

- CTest `causal_exhaust_phase_contracts` 通过：16／48／192 kHz 单节冲激能量和衰减，完整驾驶／原燃烧／细节状态独立，旁路恢复，以及 stereo／12ch 源一致性。
- 7 组基线混音逐字节等于冻结 V016；各候选驾驶 trace 逐字节一致。除两排气源及有意接收其 IR 返回的 body 外，其余七个源保持逐字节一致。
- 12 个 C 导出冲激响应在 16／48／192 kHz 的幅度响应误差小于 `1e-6`，冲激能量与 1 的差小于 `1e-6`，左右响应相同。
- 独立 Python FFT 卷积对比：将基线 float32 排气分轨与 C 实测冲激卷积，和实际候选分轨比较。42 个比较全部通过，最大绝对差 `6.845e-8`；容差包含输入、冲激和输出的 float32 量化。1 ms 对照的两源分轨严格等于基线后移 48 samples。
- 强色散 8000 RPM 的 7.1.4 导出与 stereo 保持十源分轨和驾驶 trace 逐字节一致，坐标来自 C 场景定义。未进行物理 7.1.4 阵列试听。
- 浏览器实际静音播放检查通过：40 个对照及 2 个参考加载，版本切换保留位置和播放状态，参考与合成互斥播放，无 JS 错误或手机横向溢出；桌面和手机截图均已检查。自动静音播放不代表主观试听验收。

48 kHz 下测得的群延时：

| 选项 | 260 Hz | 1250 Hz | 3100 Hz |
|---|---:|---:|---:|
| 延时对照 | 1.000 ms | 1.000 ms | 1.000 ms |
| Q 0.7 | 2.237 ms | 0.601 ms | 0.228 ms |
| Q 1.4 | 3.704 ms | 0.865 ms | 0.346 ms |

![C 实测幅度与群延时](../renders/exhaust_phase_v1/transfer_response.png)

孤立声源的单位幅度响应**不保证完整混音的幅度或 RMS 不变**。有限窗口会截断尾声，排气与机体等声层的干涉会变化，且既有 IR 返回明确接收处理后的排气。本批 4000 RPM 的三种候选完整混音 RMS 比基线低约 0.21–0.23 dB；对应左排气源仅差约 0.0002–0.0010 dB。页面保留这些差异，因此需要结合源独奏判断收益来自波形还是声层干涉。静态全通亦没有引入新的逐次随机细节，不能以这轮输出宣称燃烧变化已解决。

证据文件：`renders/exhaust_phase_v1/results.json`、`independent_convolution.json`、`browser_qa.json`、`ctest.txt` 和 `verification.json`。冻结清单为 `baselines/exhaust_phase_v1/manifest.json`；原生源码、二进制、批准素材和此前 20 个快照另经哈希检查。

## 构建与下一步

```powershell
cmake -S experiments/exhaust_phase_v1 -B build-experiment-exhaust-phase -A x64
cmake --build build-experiment-exhaust-phase --config Release --parallel
ctest --test-dir build-experiment-exhaust-phase -C Release --output-on-failure
```

实验链接 `build-v016/Release/vsl_core.lib`，依赖冻结 V016 源码和对应库；不修改稳定入口，也不覆盖原生工程。`render_exhaust_phase.py`、`analyze_exhaust_phase.py` 和 `verify_exhaust_phase.py` 会拒绝覆盖已有完整证据；重做实验应使用新名称。

下一项决策由这批具体对照的听感决定：相位成形是否减弱电子感、是否损失尖锐声线、是否只增加腔体感。若相位不足以改善，应优先研究主压力激励随 RPM／负载／逐次事件的波形和谱包络，再决定是否替换配方。整体真实感、目标车声学标定与完整驾驶模拟仍在进行中。

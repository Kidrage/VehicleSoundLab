# F2 谱峰身份 V1

**37Hz附近成分没有在6.5–7.5秒消失；之前变化的是幅度排名。** 本轮修正了分析解释，并核对漏掉该峰的影响，尚未得到可用于实时生成的新怠速DNA。

沿用已批准的F2尾排6–12秒、九个原1秒Hann窗和原生48kHz双声道。用户已确认这些短参考较清楚、轻微风噪可接受；F3驻车54–56秒因说话遮盖继续排除定量／DNA用途。短片段可用不等于整份素材或合成音色通过。

## 方法与模块

| 模块 | 职责 |
|---|---|
| `line_motion_v1/correspondence.py` | 使用原始20–250Hz全部局部峰，按相邻观察的频率邻域建立对应图，不按强度选身份 |
| `line_motion_v1/identity_controls.py` | 排名交换、合并／分裂、缺峰、等距歧义、输入顺序／增益不变性及已知六声线控制 |
| `observe_F2_peak_identity_v1.py` | 保存九窗对应图；仅在预先指定的6.5–7.5秒，比较原五线与加入实测37Hz的六线拟合 |
| `audit_F2_peak_identity_v1.py` | 独立距离矩阵／并查集复核所有边、歧义和身份；独立复指数重建原／新波形、初始化、损失、梯度与边界 |
| `publish_F2_peak_identity_v1.py` | 绘制排名交换、离散对应及残差；不生成音频或导出DNA |

相邻峰距离不超过2Hz时保留连边。这来自原1秒Hann窗的首零半宽，是分辨率邻域，不是实测发动机加速度上限。只有一旧峰／一新峰的独立连通分组继承编号；多对一、一对多或多对多全部保留歧义，并结束旧编号。不按幅度强行配对、不补缺峰、不重连间断，编号不是物理声源身份或连续相位。

六线对照只补入已经保存的次强37Hz峰。其余局部模型保持不变：各声线独立幅相、频率初值取原生FFT峰、升频率初始0、观察样本线性幅度初始化；频率范围±0.5Hz、升频率±2Hz/s、最多60次评价及原容差不变。该窗是发现问题后选定的探索性分析，不能称留出验证。

## 结果及实际意义

- 排名交换等七项图控制通过；原五项与扩展九窗控制通过。已知六线从观察峰初始化，中心最大误差0Hz、波形相对误差约1.63e−14；仅验证匹配该模型的合成例子。
- 实录6.5–7.5秒：45Hz功率18162.49、37Hz功率17747.51；两者同时存在，37Hz排名第二。先前“37→45身份切换”应理解为**选峰槽位的最强峰更换**，不能说物理发动机成分跳频。
- 每声道全频区有184个一对一分组、115个歧义分组，形成344个离散编号。37／38Hz序列在9–10秒出现歧义，必须断开；不能因邻近频率而拼出整段共同相位。左右报告一致，不是两份独立录音验证。
- 加入37Hz后，两声道的加权拟合损失均由0.000549894747降至0.000528308396，下降**3.9255%**；37Hz残差投影由0.005552014降至0.000225661，下降**95.9355%**。后者是单频投影幅度，不是全频带误差或听感改善比例。
- 原75／112／187Hz三主线的边界标志仍为`未触边／触边／触边`；新增37Hz未触边。补漏峰没有解决主要声线的局部模型失配，不能扩大范围后直接交付。

独立复核通过：波形最大差8.33e−17、损失差1.08e−19、梯度最优性差1.60e−19、投影差2.60e−18、初始化差1.39e−16。没有重新求解实录拟合。观察、审计和首版／修正版图表均留存；第二版只加大图顶端留白，数据不变。

## 工程边界与后续

这一结果支持保留多个并存成分，不能把每个区域的最强峰当成唯一发动机成分，也不能把所有局部峰都纳入DNA。风噪、旁瓣及其他声源仍可能产生峰，训练损失下降不证明自然度提高。

下一步先用已知、幅度随时间变化的多声线例子，区分恒幅局部模型将幅度变化误拟合成升频率的影响，再决定是否需要实录局部包络模型；保持原窗口／界限，不扫阈值、模型阶数或迭代预算。真实共同相位提取仍需通过原失败36声线正例、全部17项、全33线、逐线14kHz及原E验证；本轮对应图不替代这些条件。

已认可行驶35%、540份C/H、voices、唯一驾驶器与stereo／未来7.1.4结构保持；没有新实时参数、音轨或DNA，未重跑未改动的55项CTest。真实怠速、完整带载加速、同RPM不同负载及总目标继续未完成。原A低转听评问题继续等待原答复，不重复提问。

# 怠速：减轻持续音符感

当前人工反馈是“节奏太规整，像持续的合成器音符”。待听版本是 **idle_complex75_v1**；它已生成并完成数值及页面检查，尚未获得听感认可，也未替换实时 C。不把后续加速统计研究当作怠速音色升级。

[打开原版／候选／F2原声对照](http://127.0.0.1:8789/references/analysis/idle_complex75_v1/review1/index.html)。先选“完整声音”，在原版与新版之间切换；再选“只听主声线”辨别起伏。三组生成各24秒，两段原声各3秒，同增益，无新增房间效果。

## 原因和这次的改法

保留平均频谱仍可能得到稳定长音。既有观察显示，旧版约75Hz声学主线周围的短时幅度／相位变化明显弱于F2录音；这是可检查的合成缺口，尚不是物理燃烧源分离结论。

候选从已批准F2尾排6–9秒提取这条声线的复包络，学习“变化有多快、幅度和相位怎样一起变化”，编译为两输入两输出统计FIR。运行时由新随机序列驱动这个滤波器，再调制原OSC。9–12秒只作已经看过的检查参考。滤波器不包含录音PCM或原包络时间轴，不循环原片段，也没有加入固定频率LFO。

只替换这一条主线的变化；其余12条主声线和细节配方保留。额外的“原力度改用独立随机流”控制，用于区分新变化模型与随机实现／关联改变的影响。

## 工程入口

`Launch-Layer-Monitor-Study.cmd`现已提供同一驾驶窗口中的DNA／细节等干声单听，便于定位持续音符感；切换不改变声源运行，录制仍保留完整行程。它沿用现有细谱怠速C，下面的新复包络候选仍独立待听，未移植。[分层接口与验证](驾驶分层监听V1.md)。

| 层次 | 文件或模块 | 当前状态 |
|---|---|---|
| 素材提取 | `tools/idle_complex75_v1/extract.py` | 离线，相对复包络 |
| 统计模型与持续驱动 | `tools/idle_complex75_v1/model.py` | 通用二维FIR／插值／复增益；该配方只拟合F2 |
| 试听渲染 | `tools/render_idle_complex75_v1.py` | 固定种子的有限24秒导出 |
| 已有C怠速接口 | `modules/fine_idle_layer`、`modal_source`、`modal_texture`、`spectral_texture` | 主声线／起伏／细节分开维护，新复包络配方尚未接入 |
| 驾驶接入 | `modules/atlas_drive` | 已有单一驾驶状态机和怠速许可，候选不另建控制器 |

现有C接入只在 `RUNNING && IDLE` 时淡入怠速层；声源在许可关闭时仍持续推进，并非每次进入怠速就重触发同一片声音。后续移植应保持这一接口，滤波器编译／内存分配放在音频线程之外，并为新增状态单独验证录放重现。

完整证据和局限见[怠速联合起伏V1](怠速联合起伏V1.md)；冻结在 `E:/VehicleSoundLab/baselines/idle_complex75_v1`。

## 判断与后续

新候选是否少了长音符感、是否新增颤音，需要人工试听。部分8–15Hz偏移功率已超过检查段，低偏移仍不足，不能称完全还原。它没有证明75Hz是曲轴／点火基频，也不能仅凭该频率换算RPM；F2没有可靠同步转速证据。

先依据此候选听感决定是否独立移植C，再检查与既有怠速进出状态的连续性。不继续盲目排列强度，也不以统计拟合替代声音判断。行驶35%认可配方、旧模型和录放保持原样；完整驾驶、多发动机和空间化目标仍未完成。

# V0.11 排气谱形衔接

运行核心 0.11.0，构建 `build-v011`，入口 `Launch.cmd`。上一 goal turn 为 progress：完成 V010 连续启动。本轮处理主排气谱形边界，完整实车音色、空间和驾驶模拟目标仍为 active。

## 找到了什么

工厂 V10 的 DNA 使用 128 个 720° 周期分音，每缸列的强谐波对应周期分音的 5 倍。因此最后一个由 DNA 覆盖的整缸列阶是 25，高阶 OSC 从 26 附近接入。这里的 25／26 是缸列谐波编号，和早期比较的 16／64 条频率轨迹预算不是同一个计数。

旧版两条路径采用不同的谱形、归一系数和状态增益。高阶又在 DNA 已结束的位置开始淡入，边界缺少互补内容。实际 Pure OSC／零循环变化源分轨中，这个固定代码边界出现明显凹陷；它会随着 RPM 移动，不是由实车测量得到的共振。

| 工程台架 RPM | V010 第 26 相对第 25 阶，负载 .18 | V011，同条件 |
|---|---:|---:|
| 1200 | −48.96 dB | −0.48 dB |
| 2400 | −24.89 dB | −0.62 dB |
| 4000 | −13.45 dB | −1.07 dB |
| 6000 | −4.52 dB | −1.07 dB |
| 8000 | −1.74 dB | −0.89 dB |

旧版高转在边界后还会重新抬升，例如 8000 RPM 的第 28 阶比第 25 阶高约 12.5 dB。新版补齐低中转边界，也会降低部分高转突起。因此不能预设它一定更亮或更真实，需要同增益审听。

## 怎么改

`core/exhaust_spectrum.c/.h` 提取原来 DNA 的工厂谱包络，低 DNA 的系数和归一计算不变。`VslDna.factory_scale` 保存本次更新的归一系数，高阶在低 DNA 之后更新，供延续路径使用。

对 V10 的强缸列整阶 n，延续系数为 `E(5n, f) × factory_scale × bank_weight`。`bank_weight` 是原 DNA 对该缸列五个工程气缸权重之和；不是由录音 L／R 拟合出的两缸列增益。相位继续采用原 54°／90° 家族几何与 .38 ms 工程传播延迟，并消费同一套压力相位／幅度变化。

在第 26～48 阶，将延续系数乘 `1-b`，原高频细节系数乘 `b`，其中 `b=smoothstep((n-25.6)/(48-25.6))`。没有重复添加 DNA 已覆盖的主缸列谐波。延续分量使用原 DNA 声源增益 `.65 × dna_gain × DNA`，再乘 `detail/.55`；旧高频曲线仍使用其独立工况增益。默认 detail=.55 时，入口延续原低阶幅度法则；调到零时，整个高阶延伸立即无输出。

`profiles/high_orders.c` 保存过渡终点 48 阶和参考 detail=.55；`high_order_types.h` 单独保存两侧延续系数及 8 ms 平滑状态。Nyquist 余量、14 kHz 上界、压力调制频率余量和导入 DNA 旁路继续有效。UI 没有新增控件。

这仍是工程谱形：没有增加参考采样重放，没有把每帧参考频率轨迹塞进运行时，也没有识别物理歧管传递函数。只延续强缸列整阶，较弱的完整 720° 分量在第 128 个周期分音之后仍省略。它不能替代完整的压力源、管路辐射和逐缸标定。

## 参考重新分析的结论

通过 `reference_segments.py` 读取已核对的 A 车外低转 208–211 s、补油 238–248 s、行驶 316–319.5 s；不回用已知包含切镜的旧范围。读取 float32 主文件，没有新清洗、增益或声道折叠；共用候选只取两声道功率平均。

新增 `harmonic_family.py` 与 `analyze_reference_orders.py`。半秒 Hann 窗、50 ms hop，局部平滑谱扣除后比较多种谐波间距。真实频率分辨率约 2 Hz，65536 FFT 的 .732 Hz 零填充网格不等于分辨率。

A 低转段的强谱线仍在约 102～106 Hz；候选会在约 51～53 Hz 和其倍频等位置切换。合成的 52.3 Hz 完整谐波控制估到约 52.35 Hz；仅保留偶数谐波后，估到约 104.65 Hz。单谱线也不能证明更低的原始基频。快速补油／行驶段还有窗内扫频模糊，自动候选跳转明显，不能作为 ECU／换挡标签。

若把约 51.7 Hz **假设**为每缸列点火基频，才对应约 1240 RPM；这个身份没有视频转速遥测证实。因此本轮没有改 850 RPM 工程怠速，也没有将候选转换成实车 RPM×负载图。完整记录在 `references/analysis/order_families_v1/results.json`。

再次查询 GitHub HEAD，仍为 V6 基线 `ac2b37d8639027d79934a2023cf8d1d37d3b2f96`，见 `research/upstream_head_v011.json`。继续采用其共用控制系统和分层发声思路。V6 的低频 pulse、orders、bright、intake/exhaust、residual 各有独立增益；本地改动修正的是自身两个谐波求和模块之间的边界，不把 V6 的 Ferrari 参数当作 Lamborghini 测量值。上游文件保持原样。

## 验证与试听

13 项 CTest 通过，原始记录为 `renders/v0.11.0/ctest.log`。新增测试对实际合成信号作复数投影，覆盖五种 RPM、两种负载、左右两源的第 25～29 阶连续性及相对相位；原有供给、降挡、启动、压力、机械、随机种子、block 切分和空间检查继续通过。没有通过重复运行全部测试寻找偶然通过。

另外实际导出了十组固定转速／负载的 Pure OSC 源。低侧第 15～25 阶变化小于 .002 dB，新版第 25～29 阶的相邻幅度变化均小于 6 dB。频谱图只证明代码边界不再制造凹陷，不证明目标车真实度。

九组完整场景的新旧 CSV 逐字节一致。每组七个其他源——进气、机械、左右气流、事件、路噪、风噪——逐字节一致；排气和有意依赖排气的湿机体 IR 返回会改变。其他四模板、detail=0 和导入 DNA 的对应导出逐字节一致。stereo／7.1.4 十个源分轨继续相同，仍为 speaker bed 而非 Atmos 对象封装。

实际 UI 静音检查通过参数隔离、新旧预设、启动、换挡、停机和导出；设备平均 1.3239 ms／512 帧，最大 3.8223 ms，设备 10.6987 s／墙钟 10.8224 s，队列耗空零次。浏览器完成 24 次场景／版本切换、两段参考、位置保持、播放互斥与手机宽度检查。它们不构成实际声卡环回或主观听音。

试听为九组完整场景与三组两排气源独奏，每组使用一个共同固定增益，没有新旧分别归一化或压缩。独奏的 L／R 表示两个声源，不是双耳监听空间。批准参考仍使用既有 −6.0206 dB、28 Hz 高通、5 ms 端点淡化副本，与合成版本未做响度匹配。

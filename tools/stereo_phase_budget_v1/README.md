# Stereo dependence and observation-window budget

Diagnostic modules for the six frozen common/relative-phase Sound DNA models.
They do not generate new audio or change a runtime profile.

| Module | Responsibility |
|---|---|
| `budget.py` | Signed amplitude-product, circular phase-moment, amplitude/phase-association and denominator decomposition; analytic circular quantile integral |
| `window.py` | Exact real-white-Gaussian power covariance of the existing harmonic observer, including complex pseudocovariance, and finite-row demeaning |

The run host reuses frozen current-model moments and produces exactly one full
population score-Gaussian diagnostic. This is not a rank sweep or proposed runtime
model. The independent auditor reconstructs the nonlinear quantiles, quadrature
phase integral and complex moments; a finite geometric-series window formula and
small dense real quadratic forms independently check the FFT window kernel.

The five regressions are dominated by amplitude/relative-phase association error.
Restoring the full Gaussian score covariance barely changes that error. Dense
Hann overlap also produces high power lag correlation without physical slow
modulation. A stationary white null is neither an engine model nor proof that
real modulation is absent. The finite-row curve is a ratio of expected demeaned
moments, not the expectation of a sample correlation.

Run/audit/figure/package hosts preserve exact sources, signed data and the original
670C/H,82voices,3F2 contracts. Parent listening questions stay independently open.
The next source model must represent amplitude-conditioned relative phase and
qualify time variation through the actual observation kernel; it must retain the
single driver, V6 buses and independent future spatial interface. Full engines,
states, physical7.1.4 and a target C port remain incomplete.

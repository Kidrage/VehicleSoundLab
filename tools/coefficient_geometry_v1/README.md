# Coefficient geometry diagnostic

Tests the original Gaussian complex-coefficient compiler followed by the existing magnitude/fixed-phase OSC voice. This is a generic representation diagnostic, not a new preset, source separator, controller or runtime port.

- `fixtures.py`: exact balanced AM/PM populations and explicitly nonphysical counterfactuals.
- `moments.py`: empirical coefficient-band powers, full-population Gaussian closure, original factor-model checkpoint and uniform interpolation-phase moments. Quadratic-form conditional covariance includes conditional-mean ripple.
- `../run_coefficient_geometry_v1.py`: known-first original compiler/C controls, then the six frozen F3 anchors; reconstruct original double training data from saved coordinates, never refit clocks.
- `../audit_coefficient_geometry_v1.py`: closed-form AM/PM truth, observation-space Grams, polynomial interpolation integration, original PRNG/direct OSC sums, independent convolution and all complex DFT coefficients. Also checks weak-band moments normalized by mean-power products.
- `../review_coefficient_geometry_v1.py`: two scientific figures and bounded descriptive results; no new listening candidate.
- `../package_coefficient_geometry_v1.py`: all attempts, original runtime/voice manifests, sources and independent freeze verification.

Population denominator N and original compiler denominator N−1 remain distinct. Uniform interpolation phase is a distributional diagnostic, not an exact sampled-fraction or temporal-law statement. Coefficient-band power omits waveform beats and leakage. Counterfactuals do not identify physical contributions and are not proposed sound layers.

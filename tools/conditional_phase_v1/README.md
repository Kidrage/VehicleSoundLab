# Conditional relative-phase feasibility

`transport.py` keeps the existing generated amplitude products and continuous
relative-phase quantile marginal. Continuous amplitude-product hat weights define
conditional rows; a certified nonnegative transport LP measures the closest
source weighted circular moment in this explicitly limited class.

`decoder.py` qualifies a continuous conditional inverse CDF after one declared
positivity floor. It does not define a new engine time law or an audible preset.
An independent phase-uniform innovation is required: the old copula phase normal
is amplitude-correlated and cannot be reused as if it were independent.

All outcomes, dual certificates, marginal errors, floor bias and inverse slopes
must be retained. A sparse feasible LP or mathematical continuity is not proof of
naturalness, bounded modulation or universal feasibility. No C/audio/default or
spatial processing is changed; the original single driver and V6 buses remain.

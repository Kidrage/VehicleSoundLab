厚度：先少量增加250 Hz以下的DNA分音；这是调整现有声线，独立低频轰鸣层在驾驶窗口里另调。

电子感：先保留参考的平均相位，适量降低逐分音起伏，再少量恢复联动起伏。把“细节”推满不保证更真实。

亮度：先调高频±1–3 dB，再微调倾斜。纯净或空心音色可以用独立分音幅度构造，左右相位决定部分声场差异。

流程边界：本页编辑现有Sound DNA声源。BODY / DETAIL / EVENT / AUX及驾驶状态，在原生驾驶窗口分别调节。任意新片段的拟合效果需要试听确认。

JSON可编辑完整mean、basis、root协方差因子和相关系数；恢复预设不需要原始音频。

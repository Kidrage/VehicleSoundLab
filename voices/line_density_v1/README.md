# 固定 A 高频密度实验

未通过听评，不接入默认模型库或驾驶锚点。仅适用于A移动尾排316.10–317.25秒衍生的46.875Hz坐标，不能套用到A驻车或E车内。

`index.json`给出三组DNA／残差配对。0量使用原认可DNA，仅补非负频带功率差额；25／50是工程高频功率重分配量，不是测得的噪声份额。原Sound DNA模型的均值／basis／root乘共同正增益`sqrt(1-amount*smoothstep(1200..1900Hz))`，相关系数、维度和低谐波原样保留。残差由实际C输出重新拟合。

载入仍使用既有`sd_profile_load`和`sr_profile_read`，声源核分别为`modules/sound_dna`与`modules/sound_residual`。独立相干低频继续使用原模型、seed48271、scale1.6658265329883064。试听seed8121907，输出共同0.5增益，无逐版归一化；25／50另用两种子复核。

当前是C独立分轨后离线汇总，尚无新的联合实时宿主。512条已分配载波中，高频每带每个观察声道实际主要只有32条共享线；近mono情境的另一组载波增益近零，仍可能过于稀疏。不能把同参考平均功率匹配当自然度、时间包络或声场验收。

完整方法、失败留痕和验证见[研究记录](../../research/局部谱线与高频密度V1.md)。已认可DNA／相干LF模型与旧行程播放器保持原样。

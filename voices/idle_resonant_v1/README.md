# 驻车低转 · 连续共振细节候选

来自已批准A243.9–247.1s，同机位独立建模；不是确认热怠速，不给出虚构RPM。原低转C DNA保留；两个方案分别补入细节、或额外在1.2–1.9k以上轻量削减谐波功率后补入细节。

`detail.json`保存九带AR24／带通、固定增益、左右比例、显式声学根音和随机种子规则，不含PCM／轨迹／房间。周期包络均未满足本轮资格条件，全部平坦；不是点火事件触发器，也不是严格纯OSC。

沿用同一`resonant_detail_v1.voice`离线核，额外以`idle_texture_v1`处理任意根音预算和低转参数。无C加载器／设备／驾驶接入，音色待评；当前行驶35%选择保持。见[研究说明](../../research/驻车低转声源V1.md)。

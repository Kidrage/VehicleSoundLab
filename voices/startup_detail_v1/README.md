# A启动车内平均细节候选

同批准A 38.48–39.51秒趋稳语境，与`startup_settle_v1`模型成对。按实际C DNA输出的左右协方差差额生成`SrProfile`，12带、每带32共享／32独立正弦；11带有新增量，600–850Hz不可独立叠加，保持0。

这是一份平均统计候选，没有PCM、时间轴或新幅度调制。运行复用`residual_atlas`，根音只选谱形、不整体变调细节载波。不能转给其他录音视角或据此宣称完整启动／不同发动机还原。

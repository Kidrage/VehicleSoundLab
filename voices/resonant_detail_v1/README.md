# 连续激励／共振细节 · 离线模型

`detail.json`保存本轮固定A车外情境的八带24阶AR、后置带通、弱周期功率包络、左右比例及两个替换量的固定增益。它没有PCM、录音时间轴或房间响应；AR极点是统计谱形描述，不是已识别的发动机物理模态。

主声线仍由现有`Sound DNA` C OSC生成；高频共同正增益按预设派生模型。新细节使用持续随机激励与IIR滤波，**整版不是严格纯正弦OSC**。细节属于发动机音色的纹理部分，不能当作已完成的道路／风／NVH环境噪声层。

当前只供Python离线核与试听；没有C加载器、设备接入、驾驶／行程字段或默认替换。三随机种子数值通过不代表音色验收。声学根音46.875Hz是归一化坐标，不是物理RPM。

实现见`tools/resonant_detail_v1/{envelope,filters,voice,controls}.py`；来源、验证和试听见[研究说明](../../research/连续共振细节替换V1.md)。
